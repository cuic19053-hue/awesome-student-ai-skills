# 撰写规范、格式标准、信息采集清单

本文件分三部分：① 通用格式标准；② 各类申报书撰写要点；③ 信息采集清单（按类型）。

---

## 一、通用格式标准

### 1.1 字体字号

| 元素 | 中文字体 | 英文/数字 | 字号 | 其他 |
|------|----------|-----------|------|------|
| 标题（封面） | 黑体 | Times New Roman | 二号 | 加粗、居中 |
| 一级标题 | 黑体 | Times New Roman | 三号 | 加粗、居中，段前段后 12pt |
| 二级标题 | 黑体 | Times New Roman | 小三 | 加粗、左对齐，段前段后 6pt |
| 三级标题 | 宋体 | Times New Roman | 四号 | 加粗 |
| 正文 | 宋体 | Times New Roman | 小四 | 1.5 倍行距，首行缩进 2 字符 |
| 表格 | 宋体 | Times New Roman | 五号 | 居中 |
| 脚注 | 宋体 | Times New Roman | 小五 | 单倍行距 |

> 不同学校可能有微调（如部分要求"仿宋 GB2312"），以学校下发模板为准。**生成的 docx 一定要按模板替换，不要套默认字体**。

### 1.2 段落

- 正文段落首行缩进 2 个汉字
- 段前段后默认 0 行
- 1.5 倍行距（少部分学校要求 22 磅固定行距）
- 不要用空行代替段间距

### 1.3 页面

- 纸张：A4（210mm × 297mm）
- 页边距：上下 2.54cm，左右 2.5cm（部分学校要求 3cm）
- 页码：底部居中，宋体五号
- 页眉：可填学校名称 + 申报书类型（看学校要求）

### 1.4 表格

- 表格整体居中
- 表头加粗、居中
- 单元格内文字居中（数字右对齐）
- 表号在表上方："表 1 XXXX"（黑体五号，居中）
- 跨页表格要重复表头

### 1.5 序号体系

```
一、（一级，中文数字 + 顿号）
（一）（二级，中文数字 + 括号）
1.（三级，阿拉伯数字 + 点）
（1）（四级，阿拉伯数字 + 括号）
①（五级，带圈数字）
```

不要混用 1. / 1.1 / 1.1.1（这是论文写法，不是申报书写法）。

### 1.6 标点

- 中文标点用全角："，。：；！？"
- 括号统一用中文全角：（）【】《》
- 英文内容用半角
- 不混用中英文标点（如 ❌"包括：A,B,C" → ✅"包括：A，B，C"）

## 二、各类申报书撰写要点

### 2.1 项目类（大创 / 科研 / 竞赛）

**立项背景的"3+2"写法**：
- 3 句话讲时代背景（政策、行业、学术）——简短
- 2 句话讲现实痛点——具体到场景、人群、数据

✅ 好的开头：
> "随着我国'双碳'目标的推进，分布式光伏装机量 2024 年突破 6 亿千瓦（国家能源局数据）。但分布式光伏的故障检测主要依赖人工巡检，平均响应时间超过 48 小时，导致发电损失高达 5%~8%。本项目针对这一痛点..."

❌ 坏的开头：
> "在新时代背景下，新能源发展具有重要的战略意义。本项目具有重要理论价值与现实意义..."

**创新点的"对比式"写法**：
> "本项目采用 [你的方法]，与已有 [传统方法] 相比，[具体优势]，[量化提升 N%]。"

不能只写"具有创新性"——评审一眼识破。

**预期成果的"可量化"原则**：
- ❌ "发表论文若干"、"取得一定成果"
- ✅ "在中文核心期刊发表论文 1 篇，申请发明专利 1 项，形成调研报告 1 份（约 2 万字）"

**技术路线流程图**：
- 用 draw.io / Visio / mermaid 画
- 横向流程图优于纵向
- 关键节点标注交付物
- 流程图下方加图注："图 1 项目技术路线图"

**进度安排的"甘特表"**：
- 按月划分（不要写"前期""中期""后期"）
- 每个阶段必须有可交付物
- 留 1~2 个月的弹性时间应对突发情况

### 2.2 评优类（奖学金 / 优秀毕业生）

**"事实 + 数据"原则**：
- ❌ "我学习成绩优异" → ✅ "本学年 GPA 3.85/4.0，专业排名第 2/87"
- ❌ "积极参加科研活动" → ✅ "主持校级大创项目 1 项，发表中文核心论文 1 篇（第一作者）"
- ❌ "热心公益" → ✅ "累计志愿服务时长 120 小时，参与三下乡 2 次"

**分段逻辑**：思想 → 学习 → 科研 / 实践 → 生活，每段都要有具体事例。

**避免过度自我表扬**：
- 不用"特别""非常""极其"
- 不用"深感""深切""深刻"等抒情词
- 不堆砌形容词，让事实说话

**结尾朴素**：
- ❌ "恳请领导批准！"
- ✅ "以上是我的基本情况，恳请评审。无论结果如何，我都将继续努力。"

### 2.3 活动类（三下乡 / 社会实践）

**实施方案要"按天列出"**：
```
7 月 15 日：抵达 XX 县，与当地团委对接，开展预调研
7 月 16-17 日：走访 3 个行政村，每村访谈 10 户
7 月 18 日：在 XX 小学开展支教，4 课时
...
```

**安全保障预案**：
- 必须有"应急联系人"（指导老师 1 名 + 队长 1 名）
- 必须有"应急流程"（事故 → 队长 → 指导老师 → 学院 → 110/120）
- 必须有"保险购买情况"——全员短期意外险

**预期成果**：
- 调研报告：明确字数（如 1.5 万字）
- 新闻稿：明确发布平台（中青网、校团委公众号）
- 视频：明确时长（如 5 分钟纪录短片）

### 2.4 政治身份类（申请材料 / 阶段汇报）

**对党的认识**：
- 必须提到党的指导思想（特别是习近平新时代中国特色社会主义思想）
- 必须提到党的最终目标（共产主义）
- 必须提到党的宗旨（全心全意为人民服务）
- 不能照抄党章原文，要用自己话写

**个人经历部分**：
- 必须真实——党支部会向辅导员核实
- 必须有"思想变化过程"——不能只列事实
- 必须提到家庭主要成员政治面貌（特别是父母）

**个人不足**：
- 不能写"我最大的缺点就是工作太投入"
- 应该写具体的、可改进的不足（如"理论学习系统性不够""实践能力仍需加强"）
- 必须有改进措施

**政治用语的规范性**：
- "中国共产党"（不能简写为"党"）
- "党组织"（不能写成"党的组织"——OK，但前者更正式）
- "习近平新时代中国特色社会主义思想"（必须全称，不能简写）
- "党的二十大"（不能写"20 大"）

### 2.5 升学类（保研推免）

**个人陈述的"三段论"**：
1. 为什么选这个方向：本科阶段的学习 / 实践经历如何引导你
2. 为什么选这个学校：导师的研究方向、学校的平台资源
3. 研究生阶段计划：课程学习、科研计划、长期目标

**避免**：
- "贵校是我梦寐以求的学府"——空话
- "我从小就对 XX 充满兴趣"——评审查的是本科 4 年的真实投入
- 长篇大论家庭背景——除非与研究方向直接相关

## 三、信息采集清单

### 3.1 通用必采（所有类型）

| 字段 | 说明 | 示例 |
|------|------|------|
| 姓名 | 真实姓名 | 张三 |
| 性别 | | 男 / 女 |
| 学号 | 完整学号 | 2022123456 |
| 学院 | 学院全称 | 计算机科学与技术学院 |
| 专业 | 专业全称 | 计算机科学与技术 |
| 年级 | 入学年份 + 年级 | 2022 级 大三 |
| 班级 | | 计科 2201 班 |
| 政治面貌 | 群众 / 共青团员 / 中共党员 / 优秀团员/积极分子 | 共青团员 |
| 联系电话 | 手机号 | 138XXXXXXXX |
| 邮箱 | 学校邮箱优先 | xxx@xxx.edu.cn |

### 3.2 大创 / 科研立项专属

```
项目信息：
  - 项目名称（草稿即可，可后续优化）
  - 项目类型（创新训练 / 创业训练 / 创业实践）
  - 项目来源（自主选题 / 教师转化 / 企业委托）
  - 所属一级学科
  - 起止时间
  - 申请经费

团队信息（每人）：
  - 姓名、学号、专业、年级、分工、联系方式

指导教师：
  - 姓名、职称、研究方向、联系方式、邮箱

内容信息：
  - 项目背景（你看到的具体痛点，1~2 个真实场景）
  - 国内外已有方案（你了解的 3~5 个相关研究 / 产品）
  - 你的创新点（与已有方案的区别）
  - 拟采用的方法 / 工具
  - 预期成果（论文 / 专利 / 报告 / 系统）
  - 进度（按月计划）
  - 经费预算分项（差旅 / 材料 / 调研 / 会议 / 其他）
  - 前期基础（团队相关课程、项目经验）
```

### 3.3 奖学金专属

```
学业信息：
  - 申报学年（如 2024-2025 学年）
  - 申报奖学金全称（如"2025 年度国家奖学金"）
  - GPA / 加权平均分
  - 专业排名（X / N）
  - 主干课程成绩（5~8 门）
  - 英语等级成绩（CET-4 / CET-6 / TOEFL / IELTS）
  - 计算机等级

荣誉经历（按时间倒序）：
  - 时间、奖项全称、级别（国家 / 省 / 校 / 院）

科研经历：
  - 大创 / 科研立项参与情况
  - 论文（含期刊级别、作者排序）
  - 专利
  - 学科竞赛获奖

社会实践：
  - 学生干部职务（含任期）
  - 志愿服务时长
  - 三下乡 / 社会实践参与情况
  - 实习经历

家庭情况（仅励志类）：
  - 家庭年收入
  - 是否建档立卡 / 低保
  - 是否有家庭重大变故
```

### 3.4 三下乡专属

```
团队信息：
  - 团队名称
  - 实践主题（对应团中央年度主题）
  - 实践地点（精确到村 / 社区）
  - 实践时间（含出发 / 返程日期）
  - 团队人数（6~15 人）

成员信息（每人）：
  - 姓名、学号、专业年级、分工、紧急联系人

指导教师：
  - 姓名、职称、联系方式、能否随队

实践内容：
  - 选址理由（为什么去这里，与主题的契合度）
  - 实践对象基本情况
  - 实践形式（调研 / 支教 / 宣讲 / 服务）
  - 每日活动安排

保障：
  - 是否全员购买意外险
  - 应急联系人
  - 应急流程
  - 当地对接单位 / 联系人

预期成果：
  - 调研报告（字数）
  - 新闻稿（篇数、发布平台）
  - 视频 / 图片
  - 物资捐赠 / 服务记录

经费：
  - 交通、食宿、物资、印刷、其他
```

### 3.5 申请材料专属

```
个人基本信息：
  - 姓名、学号、专业、年级
  - 出生年月
  - 家庭出身
  - 本人成分（学生）

家庭主要成员（父母、兄弟姐妹）：
  - 姓名、与本人关系、政治面貌、工作单位、职务

个人经历：
  - 小学、初中、高中、大学起止时间
  - 入队、入团时间
  - 大学期间担任的职务
  - 参加党课情况

思想发展过程：
  - 何时开始考虑入团
  - 影响自己最深的人 / 事
  - 学习党章 / 党史的体会
  - 当前对党的认识

个人不足：
  - 至少 2 个真实不足
  - 改进措施

递交信息：
  - 递交日期
  - 递交对象（党支部全称）
```

### 3.6 保研推免专属

```
学业硬指标：
  - 前 6 学期 GPA / 加权
  - 专业排名（X / N）
  - CET-4 / CET-6 成绩
  - TOEFL / IELTS 成绩（如有）

科研软实力：
  - 论文（每篇：题目、期刊、级别、作者排序、录用时间）
  - 专利（每项：名称、类型、申请号、状态）
  - 大创 / 科研立项（每个：项目名称、级别、负责人 / 参与、起止时间）
  - 学科竞赛（每个：竞赛名称、奖项、级别、时间）

申请信息：
  - 申请学校
  - 申请学院 / 研究方向
  - 申请导师（如已联系）
  - 是否参加夏令营 / 预推免

推荐信：
  - 推荐人 1（姓名、职称、关系）
  - 推荐人 2

个人陈述要点：
  - 选择该方向的原因
  - 本科阶段科研经历
  - 研究生阶段计划
  - 长期职业规划
```

## 四、采集纪律

1. **分批提问**：不要一次抛 20 个问题。先采通用必采，再采类型专属。
2. **追问具体**：用户说"我参加过科研"——追问"什么项目？负责人还是参与？多长时间？产出什么？"
3. **不替用户编**：拿不准的事实，让用户去查证后再填。
4. **保留原话**：用户口述的经历，可以保留其原意但用书面语整理，不要过度升华。
5. **复述确认**：信息采完后，按申报书栏目顺序复述给用户确认，再进入撰写阶段。
