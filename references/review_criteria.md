# 评审维度 + 加分技巧 + 自检清单

本文件汇总各高校公开的评审办法（西南大学、合肥工业大学、南京大学、人民大学等），整理出可操作的"评审视角"指南。**写完申报书后必须按本文档做自检**——评审专家不会比你更仔细地看你的申报书。

---

## 一、项目类（大创 / 科研立项）评审

### 1.1 评审流程（多数高校通用）

```
1. 形式审查（学院教务）
   ↓ 不合格的直接淘汰
2. 同行评议（3 位专家函评）
   ↓ 平均分排序
3. 学院评审会（教学委员会）
   ↓ 投票决定立项级别
4. 学校复核（教务处 / 团委）
   ↓ 公示 5 个工作日
5. 立项发文
```

**关键数据**：
- 国家级大创通过率约 30%
- 省级约 50%
- 校级约 70%
- 优秀（结题）比例控制在 15% 左右，良好 40% 以内

### 1.2 评分维度（参考西南大学、合肥工业大学）

| 维度 | 权重 | 评分要点 | 加分项 | 扣分项 |
|------|------|----------|--------|--------|
| 创新性 | 25-30% | 选题前沿性、方法新颖性、与已有工作区别 | 跨学科融合、新技术应用、解决卡脖子问题 | "本项目具有创新性"无具体支撑 |
| 可行性 | 20-25% | 技术路线合理、时间够、能力匹配、经费够 | 前期已有数据 / 原型、导师有相关项目支撑 | 团队成员全是大一、方法明显不可行 |
| 必要性 | 15-20% | 痛点真实、意义明确 | 引用最新政策 / 数据、有调研基础 | "具有重要理论意义"等空话 |
| 团队 | 10-15% | 分工合理、专业互补、指导教师参与 | 跨年级跨专业、指导教师有相关成果 | 团队拼凑无分工、专业与项目不匹配 |
| 规范性 | 10% | 格式正确、栏目齐全、表述清晰 | 表格清晰、流程图规范、参考文献规范 | 错别字、字号不统一、栏目缺失 |

### 1.3 函评专家的"3 分钟决策"心理

函评专家一般 1 天要看 10~15 份申报书，**每份平均 5~10 分钟**。决策路径：

```
第 1 分钟：看项目名称 + 简介 + 创新点
  → 决定是否继续看
第 2-3 分钟：看背景 + 研究内容
  → 判断有没有真问题
第 4-5 分钟：看技术路线 + 进度 + 预算
  → 判断能不能做成
第 6-10 分钟：扫团队 + 前期基础 + 参考文献
  → 判断可信度
```

**结论**：
- 项目名称必须一句话讲清——不能"基于...的...研究"堆 4 层
- 简介必须开门见山——不写时代背景，先讲做什么
- 创新点必须可对比——必须有"相比已有 X，本方法 Y"
- 技术路线必须可视化——配流程图，不要纯文字
- 预算必须合理——总额不要顶满上限，分项有计算依据

### 1.4 加分技巧

1. **数据本地化**：背景部分引用本校 / 本省 / 本行业的真实数据，比全国数据更有说服力
2. **前期基础具象**：附"已完成的预实验结果""已发表的 1 篇相关论文""已搭建的实验平台照片"
3. **导师权重**：如果导师是相关领域的知名学者，在"指导教师"栏明确写其相关项目和成果
4. **跨学科合作**：团队成员跨 2 个以上一级学科，在"创新点"里强调交叉视角
5. **产学结合**：如有企业合作 / 委托函，附在附件里——评审会重点看
6. **预期成果分级**：写"中文核心论文 1 篇 + 校级竞赛获奖 1 项 + 调研报告 1 份"，比"发表论文若干"加分多
7. **进度甘特图**：用 Excel / Project 画甘特图，比纯文字表格专业感强

### 1.5 自检清单（提交前必查）

```
□ 项目名称是否 ≤ 25 字，是否包含核心关键词
□ 简介是否在 300 字内讲清"做什么、为谁、怎么做、产出什么"
□ 背景部分是否引用了具体数据 / 政策
□ 创新点是否有 2~3 个，每个有"对比式"陈述
□ 技术路线是否有流程图
□ 进度安排是否按月列出，每阶段有交付物
□ 预期成果是否可量化（论文 X 篇 / 专利 X 项 / 系统 X 个）
□ 经费预算是否分项，是否有计算依据
□ 团队成员是否分工明确
□ 指导教师职称、研究方向是否填写完整
□ 是否有错别字 / 格式错乱
□ 是否在截止时间前 3 天完成（留出修改时间）
```

## 二、评优类（奖学金 / 优秀毕业生）评审

### 2.1 评审流程

```
1. 学生申请（提交申请书 + 证明材料）
2. 班级评议（班委会 + 学生代表，5~7 人）
   ↓ 投票产生推荐名单
3. 辅导员审核（核实成绩、获奖、违纪记录）
4. 学院评审委员会（分管副书记 + 教务 + 辅导员代表）
   ↓ 投票产生学院名单
5. 学校评审委员会（学工部 + 教务处 + 财务处）
   ↓ 公示 5 个工作日
6. 发文表彰
```

### 2.2 国家奖学金评审要点（教育部统一标准）

**硬性条件**（不达标直接淘汰）：
- 学年 GPA / 综合测评排名位于专业前 10%
- 无任何课程不及格
- 无违纪记录
- 未欠学费

**软性评审**（同等条件下加分）：
- 思想品德：是否入团、是否担任学生干部、是否有突出表现
- 学术研究：发表论文、参与大创、学科竞赛获奖
- 社会实践：三下乡、志愿服务、实习
- 文体活动：校级以上文体竞赛获奖
- 创新创业：创业项目、专利

### 2.3 国家励志奖学金特殊点

- 必须是家庭经济困难学生（学校建档立卡）
- 学习成绩要求略低于国奖（前 30% 即可）
- 申请书要详细写家庭情况（父母职业、收入、健康、是否单亲 / 留守）
- 必须附家庭经济困难证明

### 2.4 加分技巧

1. **数据优先**：每段都以"数据 / 事实"开头，让评审一眼看到亮点
2. **获奖倒序**：按时间倒序列获奖，最近的、最高级别的放最前
3. **责任担当**：担任学生干部要写"具体做了什么"（组织 X 次活动、服务 Y 名同学），不只是"担任 XX 部长"
4. **志愿服务**：必须写时长（"累计 120 小时"），最好有代表性活动 1~2 个详写
5. **科研经历**：写清"角色"（负责人 / 第一作者 / 参与者），不要含糊
6. **结尾朴素**：不写"恳请批准"，写"无论结果如何，我都将继续努力"——评审更欣赏

### 2.5 自检清单

```
□ 是否开门见山说明申报什么奖项
□ 学习成绩是否准确（GPA、排名、X/N）
□ 是否分思想 / 学习 / 科研 / 实践 / 生活五段
□ 每段是否有具体事例和数据
□ 是否按时间倒序列获奖
□ 是否有"我"的具体行动（不只是"积极""主动"等形容词）
□ 结尾是否朴素
□ 落款日期是否正确
□ 是否与证明材料一致（申请书里的奖项要在附件里有证书）
```

## 三、活动类（三下乡）评审

### 3.1 评审重点

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 主题契合 | 20% | 是否紧扣当年团中央主题 |
| 方案可行性 | 25% | 实施方案是否具体到天，地点是否对接 |
| 安全保障 | 20% | 预案是否完备，是否全员保险 |
| 团队结构 | 15% | 是否跨学科、是否有指导教师随队 |
| 预期成果 | 10% | 是否可量化、是否有传播计划 |
| 经费合理 | 10% | 预算是否节约、是否自筹部分经费 |

### 3.2 加分技巧

1. **主题命名**：团队名称含"赴 + 地点 + 主题"格式（如"赴井冈山红色文化调研实践团"）
2. **地点选择**：选择有示范意义的地方（革命老区、乡村振兴示范村、自贸区等）
3. **校地共建**：如有当地团委 / 单位的合作函，附在附件里
4. **持续机制**：写明"建立长效合作机制，连续 3 年跟踪"——评审喜欢持续性
5. **传播规划**：明确"国家级媒体 X 篇 + 省级 X 篇 + 校级 X 篇 + 新媒体平台 X 个"
6. **专业服务**：跨学科团队，能提供支教 / 调研 / 科技服务 / 政策宣讲等多元化服务
7. **指导教师随队**：指导教师能随队加分很多（不能随队要说明理由）

### 3.3 自检清单

```
□ 实践主题是否对应团中央年度主题
□ 实践地点是否精确到村 / 社区
□ 是否按天列出活动安排
□ 安全预案是否包含应急联系人和流程
□ 是否全员购买意外险
□ 预期成果是否可量化（报告字数、新闻篇数、视频时长）
□ 经费预算是否分项
□ 是否有指导教师意见签字
```

## 四、政治身份类（申请材料）评审

### 4.1 党支部审查要点

1. **是否本人手写**（部分学校要求手写）——笔迹对比
2. **是否抄网络模板**——查重
3. **对党的认识是否完整**——必须包含指导思想、最终目标、宗旨
4. **入团动机是否端正**——不能写"为了好找工作""为了面子"
5. **个人经历是否真实**——向辅导员、同学核实
6. **个人不足是否真诚**——不能写"工作太投入""追求完美"等假缺点
7. **政治用语是否规范**——不能有错别字、不能简写

### 4.2 申请材料的高频问题

| 问题 | 后果 |
|------|------|
| 字数不足 3000 字 | 退回重写 |
| 大段抄网络模板 | 退回重写，记入考察期表现 |
| 对党的认识有错误表述 | 退回重写 |
| 个人不足写"假缺点" | 党支部书记谈话质疑 |
| 未提及习近平新时代中国特色社会主义思想 | 退回重写 |
| 字迹潦草 / 涂改严重 | 退回重写 |

### 4.3 加分技巧

1. **结合本人真实经历**：写"大学军训时看到教官身上的党员先锋作用""疫情封控期间看到党员志愿者"等具体场景
2. **结合时事**：提到党的二十大、二十届三中全会等最新会议精神
3. **家庭影响**：父母是党员的，写"从小受父母影响"——但要具体到某件事
4. **课程学习**：提到参加党课、马列学习小组、读《共产党宣言》《毛泽东选集》等
5. **个人不足真实**：写"理论学习系统性不够，对党史中的某些细节理解不深"——比"工作太投入"真诚

## 五、升学类（保研推免）评审

### 5.1 评审"三档"

```
第一档：硬指标达标 + 科研突出 → 直接收
  - GPA 前 5% + SCI 论文 / 国家级竞赛一等奖
第二档：硬指标达标 + 科研一般 → 进入面试
  - GPA 前 10% + 校级科研经历
第三档：硬指标擦线 → 直接拒
  - GPA 排名靠后 / 英语未过线
```

### 5.2 个人陈述评审

| 评审关注 | 加分写法 | 扣分写法 |
|----------|----------|----------|
| 选方向理由 | 本科某门课 / 某次实验激发兴趣 | "从小就对 XX 充满兴趣" |
| 科研经历 | 具体说明自己的角色和贡献 | "参与了 XX 项目"（含糊） |
| 学校选择 | 提到具体导师的研究方向、学校的平台 | "贵校是我梦寐以求的" |
| 研究生计划 | 具体到研究方向、目标产出 | "努力学习、刻苦钻研" |
| 长期规划 | 学术志向明确（读博 / 进研究所） | 含糊带过 |

### 5.3 加分技巧

1. **明确目标导师**：提前联系并提及"已与 XX 老师邮件沟通，对方研究方向与本人在 XX 上的兴趣高度契合"
2. **附论文 / 项目截图**：将代表性论文 / 项目成果截图作为附件，比纯文字更有说服力
3. **推荐信到位**：推荐人最好是该领域的知名学者，或与目标导师有合作
4. **夏令营造势**：参加过目标学校夏令营的，明确写出"获优秀营员"
5. **避免海投感**：个人陈述针对每个学校单独写，不要用同一份

## 六、通用评审红线（所有类型）

1. **造假**：编造获奖、论文、成绩、家庭情况——记入档案
2. **抄袭**：大段抄网络模板——查重发现直接淘汰
3. **错别字**：超过 5 个错别字会被认为态度不端正
4. **栏目缺失**：必填栏目空着——形式审查不通过
5. **超字数**：超过规定字数 20% 以上——部分学校直接淘汰
6. **逾期提交**：超过截止时间——直接不受理
7. **格式混乱**：字体字号不统一、表格错位——影响函评专家阅读体验
8. **政治错误**：政治用语错误、领导职务写错——政治身份类直接退回

## 七、自检流程（推荐执行顺序）

```
第 1 步：内容自检
  □ 是否有造假 / 抄袭
  □ 栏目是否齐全
  □ 字数是否达标
  □ 数据是否准确

第 2 步：结构自检
  □ 段落逻辑是否清晰
  □ 序号是否规范
  □ 表格是否完整
  □ 图表是否规范

第 3 步：语言自检
  □ 是否有错别字
  □ 是否有口语化表达
  □ 是否有空话套话
  □ 标点是否规范

第 4 步：格式自检
  □ 字体字号是否统一
  □ 行距是否 1.5 倍
  □ 页边距是否正确
  □ 页码是否完整

第 5 步：评审视角模拟
  □ 扮演函评专家，1 分钟看完简介和创新点
  □ 扮演辅导员，核实成绩 / 获奖真实性
  □ 扮演党支部，查重并核查政治用语
  □ 扮演面试官，找个人陈述的漏洞
```
