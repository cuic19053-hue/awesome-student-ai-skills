### 规范 4：技术方案深度（含数学公式）

**案例 2 含 4 个核心算法**，每个含：
1. 问题描述
2. 算法名称（缩写，如 ASCN/Fire-Transformer/Fire-LIO-SAM）
3. 数学公式（含变量定义）
4. 算法流程图（图示）
5. 核心创新点

**示例（案例 2 的 ASCN 算法）**：
```
密度计算公式：ρ(p) = |N(p, r)| / V(r)
其中 N(p, r) 表示以点 p 为中心、半径为 r 的邻域内的点集，V(r) 为该邻域球体积

动态扩张率：δ = δ_min + (δ_max - δ_min) · (1 - ρ̂)
其中 ρ̂ 为归一化密度值，δ_max 和 δ_min 分别为扩张率的上下界
```

**规范**：
1. 每个核心算法必须含**数学公式**（至少 1 个）
2. 公式必须**编号**（如式(1)、式(2)）
3. 公式后必须**解释每个变量的含义**
4. 必须**配算法流程图**（用文字描述流程）
5. 算法名称必须**有缩写**（如 PI-STGNN = Physics-Informed Spatio-Temporal Graph Neural Network）

### 规范 7：商业部分完整度（创业类必备）

**案例 2 完整商业部分**：
1. **市场分析**（5 小节）：市场需求/目标市场/市场前景/产品或服务前景/SWOT 分析
2. **营销模式**（4 小节）：产品策略/定价策略/地点渠道策略/促销策略（4P 框架）
3. **财务分析**（6 小节）：资金筹备/固定资产明细/流动资产明细/利润预计/风险分析/退出策略
4. **5 年财务三表**：
   - 销售数量和销售收入表（按产品/服务分项）
   - 产品成本预测表（原材料/直接人工/制造费用）
   - 管理费用预测表（研发/租金/办公/工资/设备/其他）
   - 销售费用预测表（推广/培训/售后/物流/工资/其他）
   - 现金流量预测表（经营/投资/筹资三类活动）
   - 净现值表（含折现率 10%）
   - 盈利能力指标表（销售毛利率/利润率/资产利润率/净利润率）
   - 资产负债表（流动/非流动资产 + 流动负债 + 所有者权益）
   - 短期偿债能力指标表（流动比率/现金比率/现金流量比率）
   - 长期偿债能力指标表（资产负债率）
5. **3C 定价模型**（成本/竞争/客户）
6. **产品生命周期 4P 营销组合图**
7. **盈利模式**（整机销售/租赁/专业服务/保养维护）

**规范**：
1. 创业类申报书必须含**完整 4P + 3C + SWOT + 5 年三表**
2. 财务表格必须**精确到小数点后 2 位**
3. NPV 必须给出**折现率假设**和**结论**（NPV > 0 → 项目可行）
4. 资产负债表必须**负债 + 所有者权益 = 资产**（会计恒等式）
5. 必须含**短期 + 长期偿债能力指标**
