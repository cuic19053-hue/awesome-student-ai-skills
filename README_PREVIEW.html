🛡️ 为什么生成的材料不是废话套话？（立项逻辑与系统架构）

通用大模型（如直接问 ChatGPT / 豆包）写出的申报书通常有三大致命硬伤：不知评委偏好、喜欢编造虚假奖项、生成长文档时上下文漂移超时。

为了解决这些痛点，我们设计了完整的 Agent 协同与质量闭环：

核心设计与防幻觉机制

  1. 绝不替你捏造事实（强制追问机制） 这是本项目的底线设计：AI 必须先问清你的真实数据再动笔，缺信息强制追问。写「班级第二」就是「班级第二」，绝不写「获得多项荣誉」这种空话。
  2. 三层规范加载（Agent Skills 规范）
  3. 元数据层（~100 tokens）：仅载入赛道名称与简介；
  4. 指令层：命中赛道后才载入对应的 SKILL.md 指令；
  5. 资源层：撰写过程中按需载入 references/ 评审偏好、文献综述模板与避坑清单。上下文不爆炸，长文本杜绝漂移。
  6. 真实公文排版引擎（非粗糙文本复制） 底层通过 Python-docx 渲染，支持国家公文标准（二号黑体、小四宋体、1.5 倍行距、首行缩进 2 字符、自动三线表与签字盖章栏），生成即可直接提交。

❓ 常见问题

「AI 会不会替我编造奖项和经历？」 不会。AI 先问清你的真实信息再动笔，缺信息必须追问。写「班级第二」就是「班级第二」，绝不润色成「名列前茅」。但提交前请务必自己对照学校通知逐项核对。

「要收费吗？要自己配 API Key 吗？」 不要。在线工作台和本地版均免费，普通使用无需申请任何模型 Key。

「我的个人信息会被上传吗？」 在线版：材料保存在你的账号下，自定义模型 Key 按账号加密。本地版：一切保存在本机 .agent-data/，用本机 Ollama 推理。注意：你主动触发搜索官方通知时，搜索关键词会发到公开搜索服务。

「为什么可信？」 - 真实赛事实战：团队打挑战杯从校赛一路冲进国赛，申报书磨了十几轮，这套东西是先解决自己的问题长出来的。 - 真实流量验证：抖音一条视频，0 推广，一周内 8,000+ 赞、6,000+ 收藏、1,400+ 转发（看原视频）。 - 真实金奖逻辑：拆解了上百篇国家级金奖 / 一等奖真实申报书，提炼评审逻辑与格式规范，不包含任何受版权保护的原文段落。

💻 本地运行与极客接入

如果你习惯在本地环境工作，或者希望将技能库接入自己的 Agent IDE，可以通过以下方式使用：

① 在本地 Agent IDE 里用（WorkBuddy / Claude Code / Codex / Cursor / Trae） 1. 克隆仓库，安装依赖：`pip install -r utils/requirements.txt`（提供 `python-docx` 等底层依赖） 2. 把根目录 `SKILL.md`（或具体赛道 `subskills/<赛道>/SKILL.md`）作为**系统提示词**喂给 AI 3. 直接说：「我想写一份大创申请书」 AI 会做三件事：交互式追问你的真实信息 → 调用 `utils/dispatcher.py` 决策树匹配赛道 → 执行 `subskills/<赛道>/build.py`，把 JSON 数据渲染成带标准字号、表格、签字栏的 `.docx`。
② MCP 服务接入（Claude Desktop / Cursor / Codex） 仓库自带标准 MCP Server（`mcp_server.py`），支持赛道路由、公共知识检索、信息采集、模拟评审和 Word 渲染。公共指南不是官方政策；官方资料按学校、年度及适用对象筛选，真实授权范文与尚缺资料的状态见 [RAG 状态说明](./docs/rag-status.md)。 
{
  "mcpServers": {
    "student-skills": {
      "command": "python3",
      "args": ["<你的项目绝对路径>/mcp_server.py"]
    }
  }
}
或用 `uv` 免配虚拟环境： 
{
  "mcpServers": {
    "student-skills": {
      "command": "uv",
      "args": ["--directory", "<你的项目绝对路径>", "run", "mcp_server.py"]
    }
  }
}
③ 指定学校版式（--school） 各校模板在栏目顺序、字号、页边距上有微调。项目按「先出内容、再套版式」两层工作： 
python subskills/national-scholarship/build.py \
  --data my_info.json \
  --school pku \
  --out 国家奖学金申请书.docx
`--school` 支持英文缩写 / 中文全称 / 简称（`pku` / `北京大学` / `北大` / `THU` 均可）。已收录 `pku`、`tsinghua`、`whu`、`zju`；传入未收录的学校会提示清单并按默认版式输出，**不会静默降级**。 想加自己学校：复制 `utils/schools/template_default.json` 为 `template_<学校id>.json` 改好即可。
④ 私有化本地部署（局域网自建 + Ollama 本地模型） 数据完全不出内网。部署方法、数据库配置、已知限制见 [`server/README.md`](./server/README.md)。 ⚠️ 实验版尚不适合未经身份验证和数据隔离审查就作为多人公网服务使用。
⑤ 没有任何工具时的土办法：直接粘网页 AI 1. 打开豆包 / DeepSeek / Claude 等网页版 2. 在 [`subskills/`](./subskills/README.md) 找到需要的赛道，复制 `SKILL.md` 全文 3. 粘进对话框：「我要申请 xxx，请按这个 skill 帮我写」 ⚠️ 网页 AI 只输出纯文本，没有图片和 Word 排版。

  • 所有子技能的 build.py 已内置 GBK 流容错，即使在未开 UTF-8 的原生 GBK 终端下也会安全降级，不会因 Unicode 状态符号抛 UnicodeEncodeError。
