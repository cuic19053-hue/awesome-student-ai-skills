✦ GETTING STARTED

新手引导 · 3分钟玩转申报 Agent

1. 需求与赛道
2. 两种模型模式
3. 材料事实防幻觉
4. 导出 Word 草稿
STEP 01 一句话需求，自动锁定 35 个高校赛道

在首页输入框直接说出你的申报诉求，Agent 会自动识别并匹配专业评审标准：

  • 科研与立项：大创创新训练/创业训练、校级/院级立项、挑战杯课外科技等。
  • 荣誉与奖学金：国家奖学金、国家励志奖学金、校级/企业单项奖学金等。
  • 实践与升学：三下乡社会实践、保研推免材料、入团申请书、选调生申请等。
💡 小贴士：无需背诵赛道名称，直接说“我想申请大创”或“大二想评三好学生”，系统会自动分流！
STEP 02 推理算力：平台免配置 vs 自带 Key 免积分

点击右上角 「⚙ 模型配置」，可随时自由切换 2 种算力方式：

  • 💎 平台融合模型包（默认）：免配 API Key 开箱即用。新用户注册即赠 3 次免费对话体验！文本撰写自动走 DeepSeek Flash，路线图/配图走 GPT Image，按实际用量扣积分（点击「充值积分」可到店铺买卡密兑换）。
  • 🔑 自定义 API (自带 Key / BYOK)：填入你的 DeepSeek、通义千问、硅基流动或 OpenAI Key，工作台 0 扣积分，无限畅写！Key 仅保存在当前标签页，绝不存入服务器数据库。
🚀 小贴士：自己有官方 API Key 的同学强烈推荐使用「自定义 API」，完全免费不扣积分！
STEP 03 严格事实核查，绝不虚构与学术造假

申报材料是面向高校与教育主管部门的严谨公文，工作台内置学术诚信底线：

  • 上传材料做证据：支持上传学校红头文件、申报模板、已有科研成果或证明照片。
  • 未核实不引用：上传材料必须经你在界面上确认文字后，Agent 才会将其作为事实证据。
  • 拒绝无据幻觉：缺失的数据或经历，Agent 会明确标记「待补充」并逐步追问，绝不自作主张编造。
🛡️ 安全提醒：提交最终材料前，务必逐项人工核验真实性与政策条款。
STEP 04 逐章协同润色，一键导出规范 Word 草稿

材料创作全流程透明可控，随时微调修改：

  • 拟定大纲：先确认目录结构与赛道要求，可随时增删章节。
  • 逐章共创：各章节单独撰写与润色，不满意可一键重新生成。
  • 路线图与流程图：自动提炼节点并生成高保真图表，直接嵌入文档。
  • 一键下载 Word：点击「📥 导出草稿」，直接下载符合高校字体、字号、表格规范的 .docx 文件！
