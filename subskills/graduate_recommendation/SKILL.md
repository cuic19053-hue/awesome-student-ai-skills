# 保研推免申请书 SKILL

## 一、适用场景与触发条件

本 skill 用于生成保研推免申请书，适用范围：

- 大三学生申请外校或本校研究生推免资格
- 夏令营（5~7 月）、预推免（8~9 月）、九推（9 月底~10 月）三种渠道任一
- 申请方向为学术型硕士、专业型硕士、直博

**保研推免 vs 考研**：

| 维度 | 保研推免 | 考研 |
|------|----------|------|
| 入口 | 本校推免资格 + 目标院校接收 | 全国统考 |
| 时间线 | 大三下至大四上 | 大四上 12 月统考 |
| 材料重点 | 学业 + 科研 + 匹配度 | 初试分数 + 复试表现 |
| 申请书性质 | 自荐材料 + 个人陈述 | 复试简历 |
| 评审节奏 | 短时间多投递，匹配度优先 | 一校一志愿 |

**三种渠道差异**：

| 渠道 | 时间 | 录取概率 | 材料侧重点 |
|------|------|----------|------------|
| 夏令营 | 5~7 月 | 高（优营基本直录） | 学业 + 科研潜力 |
| 预推免 | 8~9 月 | 中 | 学业 + 科研成果 + 匹配度 |
| 九推 | 9.28~10.20 | 低（捡漏为主） | 已有 offer + 应急材料 |

**触发条件**：用户提到"保研""推免""夏令营申请""预推免""九推""研究生推免""保研申请书""保研个人陈述"任一关键词时激活。

**不触发**：用户明确说"考研报名表""研究生复试简历"——属其他 skill 范围。

## 二、工作流程总览

四阶段流程，禁止跳步：

**阶段 1：信息采集（30~50 分钟）**
按第四节"信息采集清单"分批采集，先采学业硬指标，再采科研软实力，最后采申请信息与推荐信。每采完一类即复述确认。

**阶段 2：栏目内容撰写（60~90 分钟）**
按栏目顺序撰写：基本信息 → 学业情况 → 科研经历 → 个人陈述 → 推荐信情况 → 附件清单。个人陈述与科研经历为重点，需单独校对。

**阶段 3：docx 生成（5 分钟）**
调用 build.py 生成 docx，自动应用统一格式标准。生成后由用户人工补充签字、盖章。

**阶段 4：质检与提交（15 分钟）**
按第十二节"质检清单"逐项核对，确认无缺失字段、无禁用句、附件齐全后提交。

**禁止行为**：
- 不替用户编造数据（GPA、排名、论文级别必须真实）
- 不套用网络模板（个人陈述一旦套用直接淘汰）
- 不省略推荐信情况栏（即使推荐信未寄出也要写明推荐人信息）
- 不在科研经历栏只写"参与"（必须含角色与产出）
- 不长篇大论家庭背景（除非与研究方向直接相关）

## 三、信息采集清单

### 3.1 学业硬指标（必采）

| 字段 | 说明 | 示例 |
|------|------|------|
| gpa_6sem | 前 6 学期 GPA（含分母） | 3.92/4.0 |
| weighted_avg | 加权平均分 | 91.5/100 |
| rank | 专业排名（X/N） | 1/87 |
| rank_percent | 排名百分比 | 前 1.1% |
| main_courses | 主修课程（含学期/学分/成绩） | 数组 |
| scholarships | 奖学金（时间/名称/级别） | 数组 |
| cet4 | CET-4 成绩 | 580 |
| cet6 | CET-6 成绩 | 580 |
| toefl | TOEFL 成绩（如有） | 105 |
| ielts | IELTS 成绩（如有） | 7.5 |
| recommend_qualified | 是否已取得本校推免资格 | 是/否 |

**追问话术**：
- "你前 6 学期 GPA 是多少？分母是 4.0 还是 5.0？"
- "专业排名 X/N，N 是专业总人数还是同年级人数？"
- "CET-6 考了几次？最高分多少？"
- "奖学金请按时间倒序列出，注明级别（国家/省/校/院）"

### 3.2 科研软实力（必采）

**论文**（每篇）：
- title 题目
- journal 期刊或会议全称
- level 级别（SCI 一区/二区/EI/CCF-A/B/C/中文核心/普通）
- author_order 作者排序（1/2/3...）
- status 状态（已发表/已录用/在审/已投）
- publish_date 发表或录用时间

**专利**（每项）：
- name 专利名称
- type 类型（发明/实用新型/外观）
- apply_no 申请号
- status 状态（已授权/实质审查/已公开/已受理）
- inventor_order 发明人排序

**大创/科研立项**（每个）：
- project_name 项目名称
- level 级别（国家级/省级/校级）
- role 角色（负责人/参与）
- duration 起止时间
- output 项目产出

**学科竞赛**（每个）：
- contest_name 竞赛全称
- award 奖项（特/一/二/三）
- level 级别（国家/省/校）
- time 获奖时间

**追问话术**：
- "论文作者排序是第几作者？通信作者吗？"
- "大创项目你是负责人还是参与？参与几个？"
- "竞赛获奖级别是国家级还是省级？证书上有写吗？"

### 3.4 推荐信（必采）

**推荐人 1**（一般为本校导师）：
- name 姓名
- title 职称
- relation 与申请人关系（任课教师/科研导师/班主任）
- research_area 研究方向
- contact 联系方式

**推荐人 2**（一般为另一位任课教师或科研导师）：
同上字段。

### 3.5 个人陈述要点（必采）

- direction_motivation 选择该方向的真实契机（具体事件/项目/论文）
- school_match 选择该校的具体理由（导师/平台/资源）
- graduate_plan 研究生阶段计划（课程/科研/产出）
- career_goal 长期职业规划（一句话即可）

**字段缺失处理**：
- P0 字段（姓名/GPA/排名/CET-6/申请学校/申请方向）缺失：必须追问
- 论文/专利/大创可缺失（少数申请人无）
- 推荐人联系方式缺失：留空让用户后续手填

## 五、各栏目撰写规范

### 5.1 基本信息撰写规范

- 外语水平写法："CET-6 580 / TOEFL 105（2024.10）/ IELTS 7.5（2024.11）"。多证书按时间倒序。
- 政治面貌写全称：中共党员 / 中共预备党员 / 共青团员 / 群众。
- 邮箱用学校邮箱（xxx@xxx.edu.cn），不用 QQ 邮箱。
- 联系电话为手机号，不用座机。
- 出生年月写"2003 年 5 月"，不写"2003.05"。
- 班级写全称"计科 2201 班"，不写"计科 1 班"。

### 5.2 学业情况撰写规范

- GPA 必须含分母："3.92/4.0"，不写"3.92"。
- 排名必须含基数："专业排名第 1/87"，不写"专业第一"。
- 排名百分比精确到小数点后一位："前 1.1%"。
- 主修课程仅列专业核心课与高分课程（≥85 分），不列公选课。
- 奖学金注明级别与覆盖率："国家奖学金（专业前 1%）"。
- 加权平均分与 GPA 同时给出："GPA 3.92/4.0，加权 91.5/100"。
- 推免资格写明："已取得本校 2026 届推免资格（2025.09 公布）"。

### 5.3 科研经历撰写规范

- 每个项目必须含 5 要素：时间 / 项目名 / 级别 / 角色 / 产出。
- 论文必须注明作者排序与状态："第一作者，已录用"。
- 专利必须注明类型与状态："发明专利，已授权"。
- 竞赛必须注明级别与时间："全国大学生数学建模竞赛，国家二等奖，2024.11"。
- 实验室参与必须说明具体工作："负责数据标注与模型训练，独立完成 XX 模块"。
- 论文级别缩写规范：SCI 一区/二区/三区、CCF-A/B/C、EI、中文核心、普通。
- 作者排序写明："第一作者""第二作者""通信作者""共同一作"，不写"主要作者"。
- 项目角色写明："负责人""参与""核心成员"，不写"核心参与"。
- 产出量化："准确率提升 7pp""数据集 5000 条""专利 1 项"，不写"取得成果"。

### 5.4 个人陈述撰写规范

详见第六节。核心要点：
- 字数 800~1500 字（建议 1000~1200 字）
- 三段论结构，每段有明确主题句
- 必须含具体事件、具体导师、具体论文
- 禁用句详见第九节
- 第一段必含本科科研经历的具体描述
- 第二段必含目标院校的具体优势数据
- 第三段必含研究生阶段的具体产出预期
- 三段之间用承接句过渡，不用"综上所述"

### 5.5 推荐信情况撰写规范

- 推荐人 1 一般为本校科研导师或任课教师，职称副教授及以上。
- 推荐人 2 一般为另一位任课教师或班主任。
- "关系"字段写具体：科研导师 / 任课教师（XX 课程）/ 毕业设计指导教师 / 班主任。
- 如推荐人未确定，写"拟邀请 XX 教授（XX 学院）撰写推荐信"。
- 推荐人研究方向应与申请方向有一定关联，增强匹配度。
- 推荐人职称须真实，评审会核实。
- 联系方式优先邮箱，附电话作为补充。

### 5.6 附件清单撰写规范

- 每项注明份数："成绩单 1 份（教务处盖章）"。
- 论文证明附录用通知或见刊页面，不附手稿。
- 专利证明附受理通知书或授权证书，不附申请书。
- 推荐信由推荐人签字后密封寄送，附件清单注明"由推荐人直接寄送"。
- 获奖证书附复印件，不附原件。
- 附件按重要性排序，最重要的成绩单放第一。
- 附件总页数控制在 30 页以内，过厚评审不愿翻。
- 电子版提交时合并为单个 PDF，按附件清单顺序排列。

## 六、个人陈述三段论撰写方法

个人陈述是保研推免申请书的核心，评审重点考察真实性、匹配度、计划性。三段论结构如下：

### 6.1 第一段：为什么选这个方向（300~500 字）

**核心要素**：具体事件 → 兴趣触发 → 深入探索 → 方向确认。

**句式模板**：
> 我对 [研究方向] 的兴趣，源于 [具体时间] 参加 [具体项目/课程] 时的经历。当时我们 [做了什么]，遇到 [具体问题]，后来 [如何解决]。这次经历让我意识到 [对该方向的核心认识]。此后我 [主动深入的下一步行动]，进一步确认了在该方向深入研究的决心。

**正例**：
> 我对自然语言处理的兴趣，源于大二参加校级大创项目"XX 法律问答系统"时的经历。当时我们用 BERT 微调做意图识别，准确率卡在 82% 上不去，后来尝试对比学习才突破到 89%。这次经历让我意识到：表征学习是 NLP 的核心问题之一。此后我阅读了 XX 老师 2024 年 ACL 论文，复现了其中的对比学习框架，进一步确认了在该方向深入研究的决心。

**反例**（禁用）：
> 我从小就对计算机科学充满浓厚的兴趣。本科期间我认真学习专业课，对自然语言处理产生了浓厚兴趣，希望能在研究生阶段深入学习。

**禁忌**：
- "从小就对 XX 充满兴趣"——评审查的是本科 4 年的真实投入
- "贵校是我梦寐以求的学府"——空话
- 长篇大论家庭背景——除非与研究方向直接相关
- 只列课程成绩——课程是基础，不是方向选择的契机

### 6.2 第二段：为什么选这个学校（300~500 字）

**核心要素**：导师匹配 + 平台资源 + 已建立的联系。

**句式模板**：
> 选择 [申请学校] 基于三点考虑：一是 [该校在该方向的具体优势，含数据]；二是 [与拟申请导师的具体联系，含沟通情况]；三是 [平台/资源/课程体系的具体优势]。

**正例**：
> 选择 XX 大学基于三点考虑：一是贵校计算机学院在自然语言处理方向拥有 X 位 IEEE Fellow，近 3 年在 ACL/EMNLP 发表论文 20+ 篇，研究实力全国领先；二是已与 XX 老师邮件沟通 3 次，老师的研究方向（对比学习与知识蒸馏融合）与本人在对比学习上的兴趣高度契合，老师建议我提前阅读其课题组 2024 年 ACL 论文；三是贵校拥有 XX 国家重点实验室，配备 A100 GPU 集群，能提供本方向所需的大规模计算资源。

**反例**（禁用）：
> 贵校历史悠久、师资雄厚、学风严谨，是我梦寐以求的学府。如能进入贵校深造，我将倍感荣幸，必将倍加珍惜。

**禁忌**：
- "梦寐以求""倍感荣幸"——空话
- 不提具体导师——评审认为未做功课
- 不提具体数据——评审怀疑功课不深

### 6.3 第三段：研究生阶段计划（200~500 字）

**核心要素**：课程学习 + 科研计划 + 长期目标。

**句式模板**：
> 研究生阶段我的计划分三步：研一 [课程学习 + 文献调研]，重点修读 [具体课程]；研二 [科研推进]，计划在 [具体方向] 深入研究，预期产出 [论文/系统/专利]；研三 [总结提升 + 申请博士/就业]，长期目标是 [一句话职业规划]。

**正例**：
> 研究生阶段我的计划分三步：研一系统修读《深度学习》《自然语言处理》《统计学习方法》等核心课程，同时跟随导师完成文献调研 50 篇；研二在对比学习与知识蒸馏融合方向深入研究，预期在 CCF-B 类会议发表论文 1 篇；研三总结成果申请博士，长期目标是成为高校 NLP 方向研究者，推动低资源场景下的语言理解技术落地。

**反例**（禁用）：
> 我将努力学习，刻苦钻研，争取在科研上取得突破，为导师和学校争光。

**禁忌**：
- "努力学习""刻苦钻研"——空话
- 不提具体方向——评审认为计划不实
- 不提具体产出——评审无法评估计划可行性

### 6.4 三段衔接技巧

- 第一段尾句引出第二段："这次经历让我关注到 XX 老师的工作..."
- 第二段尾句引出第三段："基于上述匹配，我制定了如下研究生阶段计划..."
- 不用"综上所述""总而言之"等机械过渡词。

### 6.5 个人陈述完整示例（约 1100 字）

**第一段：为什么选 NLP 方向（约 400 字）**

> 我对自然语言处理的兴趣，源于大二参加校级大创项目"基于对比学习的法律问答系统"时的经历。当时我们用 BERT 微调做意图识别，准确率卡在 82% 上不去，后来尝试对比学习才突破到 89%。这次经历让我意识到：表征学习是 NLP 的核心问题之一。此后我阅读了 XX 老师 2024 年 ACL 论文《XX》，复现了其中的对比学习框架，并在自己项目上做了改进实验，进一步确认了在该方向深入研究的决心。这段经历也让我系统掌握了 PyTorch、HuggingFace Transformers 等工具，具备了独立开展 NLP 研究的初步能力。

**第二段：为什么选 XX 大学（约 400 字）**

> 选择 XX 大学基于三点考虑：一是贵校计算机学院在自然语言处理方向拥有 3 位 IEEE Fellow，近 3 年在 ACL、EMNLP、NAACL 发表论文 20+ 篇，研究实力全国领先；二是已与拟申请导师 XX 教授邮件沟通 3 次，老师的研究方向（对比学习与知识蒸馏融合）与本人在对比学习上的兴趣高度契合，老师建议我提前阅读其课题组 2024 年 ACL 论文并复现核心代码；三是贵校拥有 XX 国家重点实验室，配备 A100 GPU 集群 8 卡节点，能提供本方向所需的大规模预训练计算资源，这是多数院校难以提供的硬件条件。

**第三段：研究生阶段计划（约 300 字）**

> 研究生阶段我的计划分三步：研一系统修读《深度学习》《自然语言处理》《统计学习方法》等核心课程，重点补强数学基础，同时跟随导师完成文献调研 50 篇；研二在对比学习与知识蒸馏融合方向深入研究，重点突破低资源场景下的鲁棒表征问题，预期在 CCF-B 类会议发表论文 1 篇；研三总结成果申请博士，长期目标是成为高校 NLP 方向研究者，推动低资源场景下的语言理解技术落地。

### 6.6 个人陈述字数控制

- 第一段 300~500 字，过短无法讲清契机，过长挤压后两段
- 第二段 300~500 字，三点理由各占 100 字左右
- 第三段 200~500 字，三步计划各 60~150 字
- 总字数 800~1500 字，最佳 1000~1200 字
- 字数 <800：评审认为投入不够
- 字数 >1500：评审没时间看，重点被稀释
- 字数自检脚本见第十二节质检清单

### 6.7 个人陈述提交前自查清单

提交前逐项核对：

- □ 第一段含本科科研具体经历（项目名 + 时间 + 问题 + 解决）
- □ 第一段含对研究方向的核心认识（不是"感兴趣"）
- □ 第一段含下一步主动行动（不是被动接受）
- □ 第二段含目标院校的具体优势数据（论文数/师资数/平台名）
- □ 第二段含与拟申请导师的具体联系（邮件次数/方向契合点）
- □ 第二段含目标院校的具体资源（实验室名/设备型号）
- □ 第三段含研究生阶段的具体课程计划
- □ 第三段含研究生阶段的具体科研方向与预期产出
- □ 第三段含长期职业规划（一句话）
- □ 全文无禁用句（梦寐以求/从小就对/倍感荣幸/师资雄厚等）
- □ 三段之间有承接句过渡
- □ 总字数 800~1500 字

## 七、科研经历撰写方法

科研经历是评审"软实力"的核心依据，必须按"时间 / 项目 / 角色 / 产出"四要素量化表达。

### 7.1 大创/科研立项撰写方法

**表格列**：项目名称 / 级别 / 角色 / 起止时间 / 项目产出

**正例**：
| 项目名称 | 级别 | 角色 | 起止时间 | 项目产出 |
|----------|------|------|----------|----------|
| 基于对比学习的法律问答系统 | 国家级 | 负责人 | 2024.03-2025.03 | 准确率提升 7 个百分点，论文投 EMNLP 2024 |

**反例**：
- "参与多个大创项目"——含糊
- "项目取得一定成果"——不可量化
- 不写起止时间——评审怀疑真实性

### 7.2 论文撰写方法

**表格列**：题目 / 期刊或会议 / 级别 / 作者排序 / 状态 / 时间

**正例**：
| 题目 | 期刊或会议 | 级别 | 排序 | 状态 | 时间 |
|------|------------|------|------|------|------|
| XX 法律问答中的对比学习 | EMNLP 2024 | CCF-B | 1 | 在审 | 2024.06 |

**反例**：
- "发表多篇论文"——含糊
- 不写期刊级别——评审无法评估
- 不写作者排序——评审怀疑贡献度

### 7.3 专利撰写方法

**表格列**：名称 / 类型 / 申请号 / 状态 / 发明人排序

**正例**：
| 名称 | 类型 | 申请号 | 状态 | 排序 |
|------|------|--------|------|------|
| 一种基于对比学习的文本分类方法 | 发明专利 | CN2024XXXXXXX | 实质审查 | 1（学生一作） |

**反例**：
- "申请多项专利"——含糊
- 不写类型——评审无法评估含金量
- 不写发明人排序——评审怀疑贡献度

### 7.4 学科竞赛撰写方法

**表格列**：竞赛全称 / 奖项 / 级别 / 获奖时间

**正例**：
| 竞赛全称 | 奖项 | 级别 | 获奖时间 |
|----------|------|------|----------|
| 全国大学生数学建模竞赛 | 国家二等奖 | 国家级 | 2024.11 |

**反例**：
- "数学建模竞赛获奖"——含糊
- 不写级别——评审无法评估
- 不写时间——评审怀疑真实性

### 7.5 实验室/导师科研参与撰写方法

100~300 字自由叙述，必须含：
- 进入实验室时间与方式
- 具体承担的工作
- 产出与收获
- 与申请方向的关联

**正例**：
> 2023.09 起进入 XX 教授课题组，参与"低资源场景下的对话理解"项目。主要负责：构建含 5000 条多轮对话的中文数据集；复现 3 个基线模型并优化对比学习模块；独立完成数据标注规范文档 1 份。期间掌握了 PyTorch、HuggingFace Transformers 等工具，对低资源 NLP 有了系统认识，为研究生阶段在该方向深入研究奠定基础。

**反例**：
> 2023 年进入 XX 教授课题组，参与了多个项目的研究工作，学到了很多知识。

### 7.6 科研经历量化表达参考

量化表达能为评审提供客观依据，以下是常用量化表达：

| 类别 | 量化表达示例 |
|------|-------------|
| 准确率提升 | 准确率从 82% 提升至 89%（+7pp） |
| 数据集规模 | 构建含 5000 条多轮对话的中文数据集 |
| 文献调研量 | 系统调研近 3 年顶会论文 50 篇 |
| 代码量 | 独立实现 3000+ 行 PyTorch 代码 |
| 实验次数 | 完成 50+ 组对比实验 |
| 工作时长 | 连续投入 12 个月 |
| 资源占用 | 使用 A100 GPU 800 卡时 |
| 样本规模 | 处理 100 万条原始文本 |

### 7.7 科研经历撰写顺序

1. 按重要性排序：论文 > 专利 > 大创 > 竞赛 > 实验室参与
2. 同一类别内按时间倒序：最新的放前面
3. 一作项目优先，参与项目次之
4. 高级别项目优先，低级别项目次之
5. 实验室参与叙述放在表格之后作为补充说明

### 7.8 科研经历与个人陈述呼应

个人陈述第一段提到的科研经历，必须在科研经历栏目有详细记录；
科研经历栏目的高亮项目，必须在个人陈述中提到。两者相互印证，避免评审质疑真实性。

呼应示例：
- 个人陈述："主持国家级大创《基于对比学习的法律问答系统》，准确率提升 7pp"
- 科研经历表：项目名称 + 级别 + 角色 + 起止 + 产出（7pp 与论文投稿）
- 附件清单：大创立项书 + 结题证明 + EMNLP 投稿确认邮件

## 八、评审标准与打分维度

保研推免申请书评审四维度（参考多所 985 院校评审办法）：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 学业硬指标 | 40% | GPA + 排名 + 英语成绩，达不到线直接淘汰 |
| 科研软实力 | 35% | 论文（SCI/EI/中文核心）+ 专利 + 大创 |
| 匹配度 | 15% | 本科专业/经历与申请方向的契合度 |
| 个人陈述 | 10% | 体现对该方向的真实了解，不能套模板 |

### 8.1 学业硬指标评分细则（40%）

- GPA：3.9+ 满分；3.7~3.9 折半；3.5~3.7 减分；3.5 以下直接淘汰（不同学校阈值不同）
- 排名：前 1% 满分；前 5% 优秀；前 10% 良好；前 20% 一般
- 英语：CET-6 ≥425 必过；TOEFL ≥100 / IELTS ≥7.0 加分；TOEFL ≥110 / IELTS ≥7.5 大幅加分

**门槛线**（多数 985 院校）：
- GPA 前 10% 或排名前 5%（不同校差异大）
- CET-6 ≥425（部分要求 ≥460）
- 部分院校要求 TOEFL/IELTS 成绩

### 8.2 科研软实力评分细则（35%）

- SCI 一区/CCF-A 论文：每篇 8~10 分（一作）
- SCI 二区/CCF-B 论文：每篇 5~7 分（一作）
- EI/CCF-C/中文核心论文：每篇 2~4 分（一作）
- 发明专利（已授权）：每项 5~7 分（一作）
- 国家级大创（负责人）：5~8 分
- 国家级竞赛（一等及以上）：3~5 分

非一作论文按作者排序递减：二作 60%，三作 30%，三作以后不计分。

### 8.3 匹配度评分细则（15%）

- 本科专业与申请方向一致：满分
- 本科专业相近（如计算机 → 人工智能）：80%
- 本科专业跨度大但有相关科研经历：60%
- 跨度大且无相关经历：扣分

### 8.4 个人陈述评分细则（10%）

- 体现真实经历与方向理解：满分
- 提到具体导师与论文：加分
- 套模板或空话：直接淘汰
- 字数不达标（<800 或 >1500）：扣分

### 8.5 一票否决项

- 个人陈述套模板（含"贵校是我梦寐以求的学府"等禁用句）
- 学业硬指标不达门槛（GPA/排名/英语任一不达标）
- 推荐信造假（推荐人不知情或冒用他人名义）
- 论文/专利造假（虚构作者排序或状态）

### 8.6 评分计算示例

**示例 1：优秀申请人（90 分）**
- 学业硬指标：GPA 3.92/4.0 排名 1/87 + CET-6 580 + TOEFL 105 → 38/40
- 科研软实力：SCI 二区一作 1 篇 + 国家级大创负责人 + 发明专利一作 → 32/35
- 匹配度：本科 NLP 方向 + 申请 NLP 方向 → 14/15
- 个人陈述：具体导师 + 具体论文 + 三段论清晰 → 9/10
- 合计：93 分，A 档录取

**示例 2：良好申请人（75 分）**
- 学业硬指标：GPA 3.78/4.0 排名 5/87 + CET-6 510 → 33/40
- 科研软实力：中文核心一作 1 篇 + 校级大创负责人 + 数学建模国二 → 22/35
- 匹配度：本科计算机 + 申请人工智能 → 12/15
- 个人陈述：有具体导师但无具体论文 → 7/10
- 合计：74 分，B 档备选

**示例 3：边缘申请人（55 分）**
- 学业硬指标：GPA 3.65/4.0 排名 12/87 + CET-6 450 → 26/40
- 科研软实力：校级大创参与 + 省级竞赛二等 → 12/35
- 匹配度：本科软件工程 + 申请 AI（有相关课程） → 9/15
- 个人陈述：套模板（"梦寐以求"） → 0/10（一票否决）
- 合计：47 分，淘汰

### 8.7 提分策略

- 学业硬指标已定型，无法短期提升
- 科研软实力可在夏令营前冲刺：投稿 1 篇会议论文（即使 under review 也加分）
- 匹配度可在个人陈述中强化：突出本科相关课程、自学经历、复现工作
- 个人陈述是唯一可短期提分的栏目：投入 3~5 天反复打磨
- 推荐信质量由推荐人决定，但申请人可提供详细素材帮助推荐人撰写

## 九、避坑指南与正反例

### 9.1 个人陈述套模板

❌ "我从小就对计算机科学充满浓厚的兴趣。贵校是我梦寐以求的学府。"
✅ "我对自然语言处理的兴趣，源于大二参加校级大创项目'XX 法律问答系统'时的经历。"

### 9.2 科研经历含糊

❌ "大学期间积极参与科研，参加多个项目，发表多篇论文。"
✅ "2024.03-至今：主持国家级大创《XX》，负责对比学习模块，准确率提升 7pp；2023.05：第一作者在《计算机应用》发表中文核心论文 1 篇。"

### 9.3 推荐"梦寐以求"

❌ "贵校历史悠久、师资雄厚、学风严谨，是我梦寐以求的学府。"
✅ "选择贵校基于三点考虑：一是贵校 NLP 方向拥有 X 位 IEEE Fellow；二是已与 XX 老师邮件沟通；三是拥有 XX 国家重点实验室。"

### 9.4 GPA 不写分母

❌ "GPA 3.92，专业排名第一。"
✅ "GPA 3.92/4.0，专业排名第 1/87（前 1.1%）。"

### 9.5 论文不写作者排序

❌ "发表论文多篇。"
✅ "第一作者 1 篇（中文核心），第二作者 1 篇（CCF-B 在审）。"

### 9.6 推荐信栏空白

❌ 推荐信栏只写"已请 XX 老师写"。
✅ 写明推荐人姓名、职称、关系、研究方向、联系方式，注明推荐信寄送时间。

### 9.7 附件清单不全

❌ 附件清单只写"成绩单、证书"。
✅ 列出 6~8 项，每项注明份数与盖章情况。

### 9.8 个人陈述超字数

❌ 个人陈述 3000 字（评审没时间看）。
✅ 800~1500 字，三段论，每段有明确主题句。

### 9.9 长篇大论家庭背景

❌ 用 300 字写家庭经济情况与父母职业。
✅ 家庭背景与研究方向无关则不写；有关则 50 字以内带过。

### 9.10 不提具体导师

❌ "贵校师资雄厚，导师众多。"
✅ "拟申请 XX 老师为导师，老师研究方向为对比学习与知识蒸馏融合，已邮件沟通 3 次。"

### 9.11 加权平均分写法不规范

❌ "平均分 91.5。"
✅ "加权平均分 91.5/100，GPA 3.92/4.0。"

### 9.12 推荐人职称造假

❌ 写"XX 院士""XX 教授"但实际未联系
✅ 写真实推荐人，注明"已与推荐人确认同意撰写推荐信"

### 9.13 个人陈述三段比例失衡

❌ 第一段 700 字，第二、三段各 200 字（比例为 7:2:2）
✅ 三段比例约 4:4:3（第一段 400 字、第二段 400 字、第三段 300 字）

### 9.14 论文状态隐瞒

❌ 只写"已发表"，不注明录用时间或见刊状态
✅ 注明"已录用，2024.10 见刊"或"已投，under review"

### 9.15 附件清单与正文不呼应

❌ 个人陈述提到"EMNLP 投稿论文"，附件清单无投稿证明
✅ 附件清单第 3 项："EMNLP 2024 投稿确认邮件 + 在审证明 1 份"

提交前逐项核对，缺一不可：

**格式检查**：

7. □ 封面标题黑体二号居中
8. □ 表格表头加粗，单元格内容居中
9. □ 序号体系一致（一、/1./（1）不混用）

**内容检查**：
10. □ 基本信息表 10 行齐全
11. □ GPA 含分母，排名含基数，CET-6 ≥425
12. □ 主修课程表 10~15 门，奖学金按时间倒序
13. □ 科研经历四张子表（大创/论文/专利/竞赛）齐全

15. □ 个人陈述无禁用句（"梦寐以求""从小就对"等）

**真实性检查**：

24. □ 推荐人确已同意撰写推荐信

**字数自检脚本**：
```python
import re
text = open('personal_statement.txt', encoding='utf-8').read()

print(f'中文字数：{cn}')
assert 800 <= cn <= 1500, f'字数 {cn} 不在 800~1500 区间'
```

**禁用句检查脚本**：

forbidden = ['梦寐以求', '从小就对', '倍感荣幸', '倍加珍惜',

## 十二、学校差异处理

不同学校保研推免申请书模板有差异，按学校适配：

| 学校类型 | 模板差异 | 适配方式 |
|----------|----------|----------|
| 顶尖 985（清北复交） | 含英文个人陈述 | 增设英文 PS 段落 |
| 普通 985 | 标准模板 | 直接套用 |
| 211 院校 | 字数偏少（PS 500~800） | 调整字数区间 |
| 中科院系统 | 重视科研计划（PS 1500~2000） | 第三段扩展至 800 字 |
| 海外高校 | 纯英文 PS + CV | 不适用本 skill |

**5 校保研政策差异**：

| 学校 | GPA 门槛 | 英语门槛 | PS 字数 | 特色 |
|------|----------|----------|---------|------|
| 清华大学 | 前 5% | CET-6 ≥460 | 1000~1500 | 重视科研计划 |
| 北京大学 | 前 3% | TOEFL ≥100 | 1500~2000 | 重视方向匹配 |
| 复旦大学 | 前 10% | CET-6 ≥425 | 800~1200 | 重视综合素质 |
| 上海交大 | 前 5% | CET-6 ≥425 | 1000~1500 | 重视工程能力 |
| 浙江大学 | 前 10% | CET-6 ≥425 | 800~1500 | 重视交叉学科 |

**5 校特色适配要点**：

- **清华大学**：PS 第三段（研究生计划）扩展至 500~700 字，需含具体研究问题与技术路线；附件需附导师推荐信（强推）。
- **北京大学**：PS 字数偏长，三段比例 5:5:5，每段约 500 字；强调与拟申请导师的研究方向匹配度。
- **复旦大学**：PS 简洁，三段比例 4:4:2，第三段可只写 200 字；综合素质栏可加学生工作内容。
- **上海交大**：PS 中需突出工程能力与代码贡献，建议附件加 GitHub 项目链接。
- **浙江大学**：PS 重视跨学科潜力，可提交叉研究兴趣，附件加跨院选课证明。

**适配步骤**：
1. 优先用目标院校下发的官方模板
2. 按官方模板字段顺序重新组织本 skill 生成内容
3. 字数与栏目微调以官方要求为准
4. 检查官方是否有特殊栏目（如"获奖证明清单表""英语水平证明表"）
5. 本 skill 作为内容质量参考，不替代官方模板

**通用提醒**：
- 不同渠道（夏令营/预推免/九推）材料要求可能不同，按渠道官方指南为准
- 同一学校不同学院要求可能不同（如计算机学院 vs 软件学院），按学院指南为准
- 提交前 3 天完成，留出导师修改与盖章流转时间
- 电子版提交时按官方系统要求命名，不要使用默认文件名
