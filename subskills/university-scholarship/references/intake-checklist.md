# 三、信息采集清单

> 从 `subskills/university-scholarship/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要逐条向用户提问采集信息时。

| 字段 | 说明 | 示例 | 缺失追问策略 |
|------|------|------|--------------|
| name | 申请人姓名 | 王晨 | "申请人全名？" |
| student_id | 学号 | 2022123456 | "学号？" |
| gender | 性别 | 男/女 | "性别？" |
| college | 学院全称 | 计算机科学与技术学院 | "学院全称？" |

### 3.2 学业信息（硬指标，8 字段，**核心**）

| 字段 | 说明 | 示例 |
|------|------|------|
| level | 申报等级（手动指定或自动匹配） | 一等/二等/三等 |
| gpa | GPA | 3.65/4.0 |
| weighted_avg | 加权平均分 | 85.2 |
| rank | 专业排名 | 4/87（一等）/10/87（二等）/20/87（三等） |
| rank_total | 专业总人数 | 87 |
| core_courses | 主干课程成绩 4~6 门 | [{name,credit,score},...] |
| semester_gpa | 学期 GPA 表（4 学期） | [{semester,gpa,weighted},...] |
| course_count | 本学年修读课程数 | 12 |

### 3.3 英语计算机等级（5 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| cet4 | CET-4 成绩 | 510 |
| cet6 | CET-6 成绩 | 480（二等可不填） |
| toefl | TOEFL 成绩（可选） | 95 |
| ielts | IELTS 成绩（可选） | 6.5 |
| computer_level | 计算机等级 | 二级 C 语言 |

### 3.4 荣誉经历（按时间倒序，可选）

每项荣誉 4 字段：时间（YYYY.MM）、奖项全称、级别（国家/省/校/院）、颁发单位。

示例：
- 2024.11 校级三好学生 XX 大学
- 2024.05 校级优秀共青团员 XX 大学

### 3.5 科研实践（可选，校级不强制）

**学科竞赛**：竞赛全称、奖项（校级即可）、时间、角色。
**大创/科研立项**：项目名称、级别（校级即可）、角色、时间、产出。
**学生工作**：职务 + 任期 + 履职数据（活动数、服务人次）。
**志愿服务**：时长 + 服务对象 + 频次。

校级奖学金不强制要求本段，若用户无科研实践经历，可直接跳过本段，将字数分配给学习方面。

### 3.6 生活方面（4 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| dorm_role | 宿舍职务 | 宿舍长 |
| dorm_activity | 宿舍活动 | 组织 6 次集体活动 |
| dorm_honor | 宿舍荣誉 | 文明宿舍 |
| lifestyle | 生活作风 | 勤俭节约，作息规律 |

### 3.7 字段优先级与追问话术

**P0 必采**（缺则无法撰写）：name、major、grade、level、gpa、rank、core_courses、semester_gpa
**P1 重要**（缺则影响质量）：political_status、weighted_avg、cet4、computer_level
**P2 可选**（缺则用占位或跳过）：student_id、phone、research、volunteer、honors

追问话术示例：
- 用户说"我成绩还可以"→ "GPA 是多少？加权平均分？专业排名（X/N）？"
- 用户说"我修了一些课"→ "主干课程 4~6 门，每门课程名/学分/成绩？"
- 用户说"我每学期 GPA 都不错"→ "请按学期列出 4 学期 GPA 与加权平均分"
- 用户说"我想申请二等"→ "你的加权平均分和排名？需匹配二等门槛（≥80 + 前 15%）"

**等级自动匹配规则**：
- 加权 ≥85 且 排名前 5% → 推荐一等
- 加权 ≥80 且 排名前 5%~15% → 推荐二等
- 加权 ≥75 且 排名前 15%~30% → 推荐三等
- 加权 <75 或 排名 >30% → 不建议申请，告知用户改申其他奖学金

**复述确认**：所有信息采完后，按"等级/学业/英语计算机/荣誉/科研实践/生活"顺序复述给用户确认，再进入撰写阶段。
