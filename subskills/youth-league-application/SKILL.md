# 入团申请书 Skill

本 skill 处理"入团申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 政治规范质检 → 团支部大会预演。入团申请书是 14-28 周岁青年（含未入团的中学/大学在校生）首次向团组织正式表达入团意愿的文书，书信体而非表格体。一经递交团支部将组织考察与谈话，最终经团支部大会讨论表决，并报上级团组织批准。撰写须严肃认真、实事求是，禁抄网络模板、禁抄团章原文、禁用简写、禁用"志愿书"三字。

输出文件：可提交的 .docx（A4 纸张，上下 2.54cm 左右 2.5cm，黑体二号标题居中、宋体小四正文 1.5 倍行距首行缩进 2 字符、"此致"另起一行空两格"敬礼！"另起一行顶格、落款右对齐）。**本 docx 仅作内容质量参考与电子预审用，最终递交须由用户本人手写誊抄**。

## §0 红线提示（生成前必读，违反任一项即退回重写）

### 0.1 本人手写前置（最重要）

本科及中学阶段入团申请书**须本人手写**，电子版仅作内容质量参考与电子预审用：

- 笔：黑色水笔 0.5mm（不用蓝色、不用圆珠笔、不用可擦笔）
- 纸：学校指定稿纸（多数为红色横线纸或信纸，A4 大小）
- 字迹：工整清晰，**不能涂改、不能使用修正带、不能使用涂改液**——写错字直接换纸
- 落款日期：与递交日期一致，用汉字"年""月""日"格式
- 签名：本人手写签名（不能打印、不能代签）

本 skill 生成的 docx 仅供用户审阅内容、核对政治表述、自查字数与结构使用。**用户最终递交时必须按学校规范将 docx 内容誊抄为手写版**，电子 docx 不能直接作为最终递交件。

### 0.2 申请人须年满 14 周岁且不满 28 周岁

《中国共产主义青年团章程》第一条规定："年龄在十四周岁以上，二十八周岁以下的中国青年，承认团的章程，愿意参加团的一个组织并在其中积极工作、执行团的决议和按期交纳团费的，可以申请加入中国共产主义青年团。"

**生成前必须前置确认申请人年龄**（按递交日期计算）：

- 若用户未满 14 周岁：不能生成申请书。需提示用户："根据团章规定，申请人须年满 14 周岁。您目前的年龄不符合条件，请于年满 14 周岁后再递交。"
- 若用户已满 28 周岁：不能生成申请书。需提示用户："根据团章规定，团员年满 28 周岁且没有担任团内职务后应办理离团手续。您已超过入团年龄上限，无法再申请入团。"
- 若用户已 28 周岁但仍在中学/大学就读且确有入团意愿的特殊情况，须交由本校团委个案审批，本 skill 不直接生成。

### 0.3 全文禁出现"志愿书"三字

"入团申请书"与"入团志愿书"是两份**不同**的文书：

| 文书 | 递交时机 | 由谁填写 | 性质 |
|------|----------|----------|------|
| 入团申请书 | 申请人主动递交，14 周岁后随时可申请 | 申请人本人撰写 | 表达入团意愿 |
| 入团志愿书 | 团组织下发，被确定为发展对象后填写 | 申请人本人填写（团组织审核） | 履行入团手续的正式表格 |

为避免与《入团志愿书》混淆，**入团申请书全文不得出现"志愿书"三字**。注意：与推优申请书不同，入团申请书允许使用"志愿"二字本身（如"我志愿加入中国共产主义青年团"是合规表述，但"我的入团志愿书"则禁用）。常见的错误写法有：

- ❌ "我的入团志愿书"（应改为"我的入团申请"或"我的入团意愿"）
- ❌ "填写入团志愿书后"（应改为"被确定为发展对象并填写《入团志愿书》后"，且仅可在第四段提及，不在开篇出现）
- ❌ "随附入团志愿书一份"（不应附，志愿书是发展对象阶段才填）

正确的"志愿"用法：
- ✓ "我志愿加入中国共产主义青年团。"（开篇首句替代版，与"我申请加入"二选一）
- ✓ "我志愿为共产主义事业奋斗。"（表达决心，可在第四段使用）

### 0.4 不涉及宗教、伪科学、唯心论、消极反动言论

入团申请书是政治文书，全文不得出现：

- 任何宗教内容（不得引用佛教、基督教、伊斯兰教等任何宗教教义；不得说"感谢上帝""佛祖保佑"等）
- 伪科学内容（不得说"特异功能""灵异事件""超自然力量"等）
- 唯心论内容（不得说"命运""缘分""天意"等作为入团动机）
- 消极反动言论（不得发表任何否定党的领导、否定社会主义制度、否定改革开放的言论）

入团动机须以马克思主义为指导，以对团的正确认识为基础，以向党组织靠拢、做党的助手和后备军的实践为依据。

### 0.5 内容不得超前或滞后

**超前典型**（不真实，必退回）：

- 初一学生刚入学就递交，却写"为班级做了大量贡献""组织了多次活动""深受同学信任"——初一上学期无此类经历
- 大一新生写"在专业学习中取得优异成绩""获得多项荣誉"——大一上学期无评优评先
- 未参加任何志愿服务却写"长期坚持志愿服务""累计服务时长 100 小时"
- 未担任任何学生干部却写"在班级工作中发挥了骨干作用"

**滞后典型**（政治表述过时，必退回）：

- 仍引用团的十七大内容而未提团的十九大精神（团十九大于 2023 年 6 月召开，阿东当选团十九届中央书记处第一书记）
- 仍写"全国共有共青团员 7300 万"等旧数据（截至 2023 年底为 7415.1 万名）
- 仍写"全面建成小康社会"作为目标（2021 年已全面建成，应为"全面建成社会主义现代化强国"）
- 仍引用 2018 年团十八大精神而未提团十九大精神

### 0.6 抄袭后果（严重）

共青团中央 2023 年《关于加强新时代团员队伍建设的意见》明确：**严重抄袭入团申请书的，建议不予吸收为团员**，并对团支部书记等团务人员予以谈话、批评教育。具体后果：

- 申请人本人：不予吸收为团员（已发展的予以除名）/ 不予列为发展对象（未发展的）/ 记入团员发展档案
- 团支部书记：谈话、批评教育
- 入团介绍人：谈话、批评教育
- 严重者：团内警告、严重警告处分

**团支部会查重**，常见查重方式：

- 与同一支部历年申请书比对
- 与中国青年网、人民网等官方范文比对
- 与团章原文比对（连续 50 字以上雷同即认定抄袭）
- 与推优申请书模板比对（团/党申请书结构相似度高，常见混抄）

### 0.7 错别字与语句通顺

入团申请书全文错别字不得超过 3 处（按 2000 字计算），语句须通顺。常见易错字：

- ❌ "共青团员" → ✓ "共青团员"（注意"青"字写法）
- ❌ "党的助手" → ✓ "党的助手和后备军"（团章完整表述）
- ❌ "先锋队" → ✓ 党是先锋队，团是"先进青年的群团组织"（注意团不是先锋队）
- ❌ "五四运动" → ✓ "五四运动"（注意"四"字写法）
- ❌ "团委" → ✓ "共青团委员会"或"共青团XX委员会"（正式称呼）
- ❌ "团代会" → ✓ "团的代表大会"或"团XX大"（正式称呼）

## §1 适用场景与触发条件

### 1.1 适用

本 skill 适用于以下场景：

- 中学生（初中二年级以上、年满 14 周岁）首次申请入团
- 高中生（已满 14 周岁）首次申请入团
- 大学生（大一至大四、已满 14 周岁但未满 28 周岁）首次申请入团
- 研究生（未满 28 周岁）首次申请入团（少见但合规）
- 28 周岁以下在职青年首次申请入团（如学校职工、企业青年职工）

### 1.2 不适用（需走其他 skill）

以下场景不适用本 skill：

- **已是团员但需写《团员转接申请》**：转团组织关系，非入团申请，本 skill 不处理
- **已是团员但需写《阶段汇报》**：走 summary_report skill（阶段汇报）
- **已是团员但需写《推优申请书》**：走 youth_league_application skill（推优申请）
- **28 周岁以上首次申请推优**：直接走 youth_league_application skill，无需先入团（28 周岁以上不再发展团员，但推优不受影响）
- **保留团籍的党员**：已是党员，无需再入团

### 1.3 前置确认（触发后第一句话必须问，6 项硬门槛）

| 序号 | 硬门槛 | 不通过处置 |
|------|--------|------------|
| H1 | 申请人是否年满 14 周岁且不满 28 周岁？ | 未满 14 周岁提示年满后再申请；已满 28 周岁提示无法申请 |
| H2 | 申请人当前是否已是共青团员？ | 已是团员提示无需再申请，应走《团员转接申请》或《阶段汇报》 |
| H3 | 申请人当前是否已是中共党员？ | 已是党员提示无需再申请入团 |
| H4 | 申请人是否有重大违纪记录或处分期内？ | 处分期内通常不予吸收为团员，提示用户先解除处分 |
| H5 | 申请人所在学校是否有"入团指标"限制？ | 多数学校每学期入团名额有限，须先确认指标情况 |
| H6 | 申请人是否愿意按时交纳团费、参加团组织活动？ | 不愿则不应申请入团 |

```

助手：在开始撰写前，我需要确认 6 项硬门槛，请逐一回答：

  H2: 您目前是否已是共青团员？
  H3: 您目前是否已是中共党员？
  H4: 您是否有任何违纪处分（处分期内）？
  H5: 您所在学校本学期的入团指标您是否已获得或确认有指标？
  H6: 您是否愿意按时交纳团费、参加团组织活动？
用户：[依次回答]
助手：6 项硬门槛已确认，进入信息采集阶段……
```

## §2 入团申请 vs 推优申请 5 维度区分表

### 2.1 5 维度对比表

入团申请书与推优申请书同属政治文书，但 5 个维度有本质区别，撰写时不可混淆：

| 维度 | 入团申请书 | 推优申请书 |
|------|-----------|-----------|
| **年龄** | 14 周岁 ≤ 申请人 < 28 周岁 | 申请人 ≥ 18 周岁 |
| **字数** | 1500-2000 字（3 档：1500/1800/2000） | 1500-4000 字（4 档：1500/2500/3000/3500，按学校档位） |
| **前置** | 无前置条件（年满 14 周岁即可），但须由团组织考察 3 个月以上 | 通常须先入团并被列为推优积极分子（党员发展"团推优"路径） |
| **重点** | 共青团性质、团章、团史、五四精神、青年责任担当 | 党的性质、党的指导思想（6 项）、两个确立、两个维护、共产主义信仰 |
| **上报** | 团支部大会讨论表决 → 上级团组织批准 → 上报共青团上级委员会备案 | 党支部委员会审查 → 党支部大会讨论表决 → 上级党委批准 → 报县级党委组织部门备案 |

### 2.2 边界判定口诀

> **"团小党大、团轻党重、团青年党成人"**
> - 团小党大：团是党的助手和后备军，团从属于党
> - 团轻党重：团申请书字数少于党申请书，理论表述少于党申请书
> - 团青年党成人：团面向 14-28 周岁青年，党面向 18 周岁以上成人

### 2.3 3 个混淆场景处置

**场景 1：用户说"我要写一份政治类申请书"，未明确是团还是党**

询问话术："您是要申请加入共青团（入团，14-28 周岁青年），还是申请加入中国共产党（推优，18 周岁以上）？两者目标组织、年龄要求、字数、必引理论均不同，请明确选择。"

**场景 2：18-28 周岁大学生，既可入团也可推优**

处置：通常按"先团后党"路径——若用户尚未入团，建议先入团再推优（部分学校党员发展优先吸收已入团者）；若用户已是团员，可直接申请推优。若用户坚持不入团直接推优，本 skill 不适用，应转 youth_league_application skill。

**场景 3：用户已是党员，又想"补办入团"**

处置：已是党员者无需再入团，且党员通常自动保留团籍至 28 周岁。提示用户："您已是中共党员，无需再申请入团。如需办理团组织关系相关手续，请直接联系您所在团支部。"

### 2.4 何时先入团后推优（"团推优"路径）

党员发展"推优"路径（28 周岁以下）：

```
入团申请书 → 团支部大会通过 → 上级团委批准 → 团员
   ↓ 至少 1 年
团员 → 团支部推优 → 党支部 → 推优积极分子 → 发展对象 → 预备党员 → 正式党员
```

若用户最终目标是推优但尚未入团，且年龄在 14-28 周岁之间，建议先入团（本 skill 适用），入团满 1 年后再申请推优。28 周岁以上者可直接申请推优，无需先入团。

## §3 字数下限分级表（3 档：1500/1800/2000）

### 3.1 3 档字数版本

入团申请书按学校类型与申请人学段分 3 档字数版本：

| word_count_version | 字数目标 | 字数下限 | 适用学校 | 段落配比 |
|--------------------|----------|----------|----------|----------|
| `compact` | 1500 字 | 1200 字 | 中学（初二-高三）、大学新生（大一未满一学期）、要求宽松的学校 | 8%/40%/32%/20% |
| `standard` | 1800 字 | 1500 字 | 大学本科（默认档位）、要求中等的学校 | 8%/38%/38%/16% |
| `enhanced` | 2000 字 | 1700 字 | 985/211 高校、要求严格的学校、申请人为研究生 | 7%/40%/38%/15% |

**默认档位**：standard（1800 字），适用于大多数大学本科生。

### 3.2 字数自检脚本（生成后必跑）

```python

with open("output.txt", "r", encoding="utf-8") as f:
    text = f.read()

# 统计中文字符数
chinese_chars = len(re.findall(r"[\u4e00-\u9fff]", text))
print(f"中文字符数：{chinese_chars}")

# 字数下限校验
school_tier_min = {
    "compact": 1200,
    "standard": 1500,
    "enhanced": 1700,
}
```

### 6.1 共青团性质（团章总纲）

## §8 落款日期格式硬规范

### 8.1 落款日期必须用汉字"年""月""日"

入团申请书落款日期**必须用汉字"年""月""日"格式**，不能用"2025.6.15"或"2025-06-15"等数字格式。

| 格式 | 是否合规 | 示例 |
|------|----------|------|
| 汉字格式 | ✓ 合规 | 2025 年 6 月 15 日 |
| 数字加点 | ❌ 不合规 | 2025.6.15 |
| 数字加横线 | ❌ 不合规 | 2025-06-15 |
| 数字加斜线 | ❌ 不合规 | 2025/6/15 |
| 仅年月 | △ 仅在出生年月时允许 | 2009 年 5 月 |

### 8.2 落款格式

落款右对齐两行：

```
                                            申请人：张明（XX 学院 XX 专业 2024 级 XX 班 学号 XXXXXXXX）
                                                                                          2025 年 5 月 4 日
```

### 8.3 落款日期与递交日期一致

落款日期必须与递交日期一致，不能出现"递交日期 2025 年 5 月 4 日，落款日期 2025 年 5 月 1 日"的情况。建议选择有意义的日子递交：

- **5 月 4 日**：五四青年节（推荐）
- **5 月 5 日**：团庆日（团的一大召开日，推荐）
- **9 月 1 日**：开学日（推荐，新学期新起点）
- **10 月 1 日**：国庆节
- **12 月 9 日**：一二·九运动纪念日

### 8.4 build.py 处理

build.py 的 `normalize_date` 函数自动将以下格式规范化为汉字格式：

- "2025 年 6 月 15 日" → "2025 年 6 月 15 日"（已规范，仅去除多余空白）
- "2025.6.15" → "2025 年 6 月 15 日"（自动转换并警告）
- "2025-06-15" → "2025 年 6 月 15 日"（自动转换并警告）
- "2025/6/15" → "2025 年 6 月 15 日"（自动转换并警告）
- "2025 年 6 月" → "2025 年 6 月"（仅年月，保留）

团支部收到入团申请书后，须按以下流程处理：

```
接收申请书 → 3 个月以上考察 → 确定发展对象 → 团支部大会讨论表决 → 上级团委批准 → 入团仪式 → 上报备案
```

### 9.2 9 步流程详解

| 步骤 | 时间节点 | 工作内容 | 责任人 |
|------|----------|----------|--------|
| 1 | 递交日 | 申请人递交入团申请书至团支部 | 申请人 |
| 2 | 递交后 1 周内 | 团支部书记或组织委员同申请人谈话，了解基本情况 | 团支书或组织委员 |
| 3 | 递交后 1 个月内 | 团支部指定 2 名团员作为申请人联系人（培养联系人） | 团支部委员会 |
| 4 | 考察期内（至少 3 个月） | 培养联系人定期（每月至少 1 次）与申请人谈话，培养教育 | 培养联系人 |
| 5 | 考察期满 | 团支部委员会讨论，确定发展对象 | 团支部委员会 |
| 6 | 确定发展对象后 | 申请人填写《入团志愿书》 | 申请人 |
| 7 | 填表后 1 个月内 | 召开团支部大会讨论表决（须有本支部半数以上有选举权的团员到会方可召开，赞成人数须超过应到会有表决权团员的半数方可通过） | 团支部 |
| 8 | 通过后 1 个月内 | 上级团委审批（须由团支部将《入团志愿书》等材料报送上级团委） | 上级团委 |
| 9 | 审批通过后 1 个月内 | 举行入团仪式，新团员面向团旗进行入团宣誓 | 团支部 |

### 9.3 上报流程（团支部大会后的 5 步）

团支部大会通过后，须按以下 5 步上报：

1. **团支部委员会审查**：在团支部大会前，团支部委员会须对发展对象进行审查，并报上级团委预审
2. **团支部大会讨论表决**：须有本支部半数以上有选举权的团员到会方可召开；赞成人数须超过应到会有表决权团员的半数方可通过
3. **上报上级团委**：团支部将《入团志愿书》、申请人考察材料、团支部大会决议等报送上级团委
4. **上级团委审批**：上级团委在 1 个月内审批，审批须由团委委员会集体讨论决定
5. **报共青团上级委员会备案**：审批通过后，报共青团上级委员会备案，并将新团员信息录入"智慧团建"系统

### 9.4 入团仪式（9 项程序）

入团仪式须按以下 9 项程序进行：

1. **奏唱国歌**
2. **主持人说明举行入团仪式的意义，宣布新团员名单**
3. **向新团员颁发团员证，为新团员佩戴团徽**（团徽应佩戴在左胸前）
4. **向上级团组织的代表或团支部书记带领新团员宣誓**（入团誓词 80 字）
5. **入团介绍人代表宣读《入团志愿书》中"介绍人意见"**
6. **新团员代表发言**
7. **老团员代表发言**
8. **党组织代表或上级团组织代表讲话**
9. **奏唱团歌**（《光荣啊，中国共青团》）

### 9.5 入团誓词（80 字，团章原文）

入团誓词（仅入团仪式上由新团员宣读，不在入团申请书中引用）：

> 我志愿加入中国共产主义青年团，坚决拥护中国共产党的领导，遵守团的章程，执行团的决议，履行团员义务，严守团的纪律，勤奋学习，积极工作，吃苦在前，享受在后，为共产主义事业而奋斗。

## §11 抄袭问责后果

### 11.1 申请人本人后果

- **未发展者**：不予列为发展对象，记入团员发展档案
- **已发展者**：予以除名，记入团员档案
- **严重者**：记入团籍档案，影响后续评优、推优

### 11.2 团务人员连带问责

- **团支部书记**：谈话、批评教育
- **入团介绍人**：谈话、批评教育
- **严重者**：团内警告、严重警告处分

### 11.3 抄袭判定标准

| 抄袭类型 | 判定标准 |
|----------|----------|
| 与网络模板雷同 | 连续 30 字雷同 |
| 与团章原文雷同 | 连续 50 字雷同 |
| 与同支部历年申请书雷同 | 连续 50 字雷同 |
| 与推优申请书模板雷同（混抄） | 连续 30 字雷同 |

### 11.4 避免抄袭的方法

1. **入团动机必须个性化**：举一件最近半年内让您触动最深的具体事情，时间、地点、人物、事件、感悟都要具体
2. **个人经历必须真实**：教育经历、家庭背景、担任过的职务、获得过的荣誉都要如实填写
3. **个人不足必须真实**：避免假缺点，举 2-3 个真实不足（含具体表现 + 改进措施）
4. **理论表述用自己的话解读**：必引 4 项理论表述可以引用，但要在引用后用自己的话解读含义

### 11.5 抄袭与引用的区分

| 类型 | 是否合规 | 说明 |
|------|----------|------|
| 引用团章总纲"共青团性质"完整表述 | ✓ 合规 | 必引项，按 §6.1 引用 |
| 引用团章团员义务条款 | ✓ 合规 | 必引项，用自己的话解读 |
| 引用 1922 年团的一大召开日 | ✓ 合规 | 必引项，史实引用 |
| 引用五四精神四词 | ✓ 合规 | 必引项，按 §6.4 引用 |
| 抄网络入团申请书模板的"作为一名当代大学生……"开头 | ❌ 抄袭 | 须用自己的话开头 |
| 抄网络模板的"我决心以实际行动争取早日入团"结尾 | ❌ 抄袭 | 须用自己的话结尾 |
| 抄团章第三条"团员必须履行下列义务"后整段抄录 | ❌ 抄袭 | 须用自己的话概括 |
| 抄推优申请书中的"全心全意为人民服务"段 | ❌ 抄袭混抄 | 须改为团员视角 |

## §12 句式参考（填空式，不是可照抄的金句）

> ⚠️ **本节的方括号是必填占位，不是可选的润色位置。**
> 原「金句模板」已被移除——那些句子是 AI 生成的排比抒情句，
> 通篇无具体事实，属典型套话，评委会判为态度不端正。
> 正确用法：把每个 `[...]` 换成你自己的真实信息，填不出就说明素材不足，应先补素材。

### 12.1 开篇志愿表达段

- `[年月]`，我在 `[具体场合，如：学院团委组织的团课/班会/宣讲会]` 上第一次系统了解共青团。
- 让我产生入团想法的是一件具体的事：`[时间]`、`[地点]`、`[谁做了什么]`、`[你当时的反应]`。
- 此后我做了两件事：读了 `[书名]`，参加了 `[活动名]`，前后持续 `[N]` 个月。

### 12.2 对团的认识段

**必须引用团章原句**（可照录），然后紧跟个人事实：

> 团章规定，共青团是"广大青年在实践中学习中国特色社会主义和共产主义的学校"。
> `[时间]` 我参加 `[具体活动]`，在 `[具体场景]` 中 `[具体做法]`，产出 `[可核查结果]`。

- 团史引用：1922 年 5 月 5 日中国社会主义青年团第一次全国代表大会在广州召开。
- 引完必须接：这段历史让你做了什么 `[具体行动]`，而不是"深受鼓舞"这类空话。

### 12.3 个人情况段

- `[时间]`，我参加 `[具体活动]`，看到 `[具体场景]`，让我开始思考 `[具体问题]`。
- 此后我阅读 `[具体书目]`、参加 `[具体培训 N 学时]`，逐渐认识到 `[具体认识]`。
- 在 `[具体实践]` 中，我看到 `[可量化变化，如：参与人数从 X 增到 Y]`。

### 12.4 入团态度段

- 若团组织暂未批准，我将 `[具体改进动作 1]`、`[具体改进动作 2]`，并在 `[时间]` 后再次递交。
- 承诺必须可核查：写"每月参加 `[N]` 次志愿服务"，不要写"严格要求自己"。

### 12.5 禁用空话清单

以下空话套话在申请书中**严禁使用**（视为态度不端正）：

- "我从小就对团有深厚感情"
- "团是伟大的团，光荣的团，正确的团"
- "我希望能在团的领导下为人民服务"（无具体行动支撑）
- "我将全心全意为人民服务"（无具体措施）
- "我一定会成为一名合格的共青团员"（未递交就承诺，不实）
- "我对团的认识很深刻"（自评，应由团组织评价）

## §14 3 档字数版本（1500/1800/2000）

### 14.1 3 档对照表

| word_count_version | 字数目标 | 字数下限 | 段落配比 | 适用 | school_tier |
|--------------------|----------|----------|----------|------|-------------|
| `compact` | 1500 字 | 1200 字 | 8%/40%/32%/20% | 中学、大学新生、要求宽松的学校 | middle/loose |
| `standard` | 1800 字 | 1500 字 | 8%/38%/38%/16% | 大学本科（默认）、要求中等的学校 | normal |
| `enhanced` | 2000 字 | 1700 字 | 7%/40%/38%/15% | 985/211 高校、要求严格的学校、研究生 | strict |

### 14.2 各档撰写要点（4 段字数分配）

| word_count_version | 第一段 | 第二段 | 第三段 | 第四段 |
|--------------------|--------|--------|--------|--------|
| `compact`（1500 字） | 80-120 字 | 600 字（4 小节 × 150 字） | 480 字（4 小节 × 120 字） | 300 字 |
| `standard`（1800 字） | 120-150 字 | 684 字（4 小节 × 170 字） | 684 字（4 小节 × 170 字） | 288 字 |
| `enhanced`（2000 字） | 140 字 | 800 字（4 小节 × 200 字） | 760 字（4 小节 × 190 字） | 300 字 |

### 14.3 字数版本选择决策树

```
申请人当前身份？
├─ 中学生（初中/高中）
│   └─ 选 compact（1500 字）
├─ 大学新生（大一未满一学期）
│   └─ 选 compact（1500 字）
├─ 大一第二学期及大二
│   └─ 选 standard（1800 字，默认）
├─ 大三大四
│   └─ 选 standard（1800 字，默认）或 enhanced（2000 字，若学校要求严格）
├─ 研究生
│   └─ 选 enhanced（2000 字）
└─ 在职青年
    └─ 选 standard（1800 字，默认）
```

### 14.4 字数版本切换

用户可在 data.json 中通过 `word_count_version` 字段切换：

```json
{
  "word_count_version": "standard",
  "school_tier": "normal",
  ...
}
```

build.py 根据此字段路由不同的段落配比与详略程度。
