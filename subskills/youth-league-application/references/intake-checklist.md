# §4 信息采集清单

> 从 `subskills/youth-league-application/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要逐条向用户提问采集信息时。

### 4.1 字段优先级

| 优先级 | 含义 | 缺失处理 |
|--------|------|----------|
| P0 | 必采字段，缺失则不能生成 | 生成前必须追问 |
| P1 | 重要字段，缺失会用默认值但有警告 | 生成前尽量追问 |
| P2 | 可选字段，缺失会用默认值无警告 | 用户主动提供时才填 |

### 4.2 P0 字段清单（10 项，必采）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `name` | str | 申请人姓名（真实姓名，不能用昵称） |
| `student_id` | str | 学号（中学生用学籍号） |
| `gender` | str | 性别（男/女） |
| `birth_date` | str | 出生年月（用于年龄核验，汉字格式"YYYY 年 M 月"） |
| `college` | str | 学院/年级全称（中学写"XX 中学初三 X 班"） |
| `major` | str | 专业全称（中学写"无"或留空） |
| `grade` | str | 年级（如"2024 级 大一"/"初三 2024 级"） |
| `league_branch` | str | 团支部全称（如"计算机科学与技术学院 2024 级 1 班团支部"） |
| `submit_date` | str | 递交日期（汉字格式"YYYY 年 M 月 D 日"） |
| `political_status` | str | 政治面貌（群众/少先队员；已是团员或党员的见 H2/H3） |

### 4.3 P1 字段清单（6 项，重要）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `motivation` | str | 入团动机（具体事例，不少于 200 字） |
| `team_join_date` | str | 加入少先队日期（如已加入少先队） |
| `family_members` | list | 家庭主要成员数组（与推优申请书同结构，但政治面貌须含） |
| `education_history` | list | 个人经历数组（小学/初中/高中/大学） |
| `shortcomings` | list | 个人不足数组（2-3 个真实不足） |
| `ideology_story` | list | 思想发展事例数组（2-3 个具体事例） |

### 4.4 P2 字段清单（5 项，可选）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `class_name` | str | 班级（如"计科 2401 班"） |
| `family_origin` | str | 家庭出身 |
| `identity` | str | 本人成分（学生/工人/农民等） |
| `social_relations` | list | 主要社会关系数组（祖父、外祖父母等） |
| `honor_awards` | list | 获得过的荣誉与奖励 |

### 4.5 信息采集追问话术

完成 6 项硬门槛确认后，按以下顺序追问信息：

```
助手：感谢确认。现在进入信息采集阶段，我需要您提供以下信息（请按编号回答）：

【基本信息】
1. 您的姓名、学号、性别、出生年月
2. 您所在的学院/年级、专业、班级
3. 您所在团支部的全称（如不确定，可写"XX 学院 XX 级 XX 班团支部"）
4. 您计划递交日期（汉字格式，如"2025 年 5 月 4 日"——建议选五四青年节或团庆日递交）
5. 您当前的政治面貌（少先队员/群众）

【入团动机】
6. 您为什么想入团？请举一件最近半年内让您触动最深的具体事情（时间、地点、人物、事件、您的感悟）

【个人经历】
7. 您的小学/初中/高中/大学经历（每段起止时间、学校、是否担任班干部）
8. 您加入少先队的日期（如已加入）
9. 您获得过哪些荣誉或奖励（含校级及以上）

【家庭背景】
10. 您的父母姓名、政治面貌、工作单位及职务
11. 您的兄弟姐妹情况（如有）

【个人不足】
12. 您觉得自己在哪些方面还存在不足？（请举 2-3 个真实不足，避免假缺点如"工作太投入""学习太刻苦"）

【今后努力方向】
13. 入团后您打算如何改进？请具体说三方面（学习/思想/实践）

回答完成后，我会复述您的信息，确认无误后生成入团申请书。
```

### 4.6 复述确认（生成前最后一步）

信息采集完成后，助手须复述所采集的全部信息，请用户确认。复述模板：

```
助手：请确认以下信息是否准确无误（确认无误后我将生成入团申请书）：

【基本信息】
  姓名：[name]
  学号：[student_id]
  性别：[gender]
  出生年月：[birth_date]（按递交日期计算，您将年满 [age] 周岁，符合 14-28 周岁要求）
  学院/专业：[college] [major]
  年级/班级：[grade] [class_name]
  团支部：[league_branch]
  递交日期：[submit_date]
  政治面貌：[political_status]

【入团动机】
  [motivation 摘要]

【个人经历】
  [education_history 摘要]
  加入少先队日期：[team_join_date]

【家庭背景】
  [family_members 摘要]

【个人不足】
  [shortcomings 摘要]

【今后努力方向】
  [对应第四段]

字数版本：[word_count_version]（目标 [target] 字）

请回复"确认"开始生成；如需修改，请说明修改内容。
```
