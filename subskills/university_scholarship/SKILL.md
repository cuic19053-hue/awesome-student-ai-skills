# 校级奖学金申请书 Skill

本 skill 处理"校级奖学金申请书"全流程：信息采集 → 等级匹配 → 书信体撰写 → docx 生成 → 质检。校级奖学金是本科生最易申请的奖学金（门槛最低、覆盖面最广），评审侧重纯学习：GPA、专业排名、单科成绩；不强制要求科研、竞赛、志愿服务。仅处理校级一/二/三等，国家奖学金（8000 元）与国家励志奖学金（5000 元）请走其他 skill。

子类型与硬门槛：
- 校级一等：GPA 加权平均分 ≥85，专业排名前 5%（如 4/87）
- 校级二等：GPA 加权平均分 ≥80，专业排名前 15%（如 10/87）
- 校级三等：GPA 加权平均分 ≥75，专业排名前 30%（如 20/87）

与国奖的关键区别：弱化科研实践（不强制要求）、强化纯学业表现（学业权重 70%）、申请书更短（800~1500 字而非 1200~2000 字）、不强制国家级竞赛或论文。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐）。

## 一、适用场景与触发条件

**适用**：用户提到"校级奖学金""校奖学金""校一等/二等/三等奖学金""大学奖学金""学校奖学金"等关键词，且本人 GPA 排名专业前 30%。等级由用户学业数据自动判定（亦可由用户指定）。

**不适用**（需走其他 skill）：
- 国家奖学金（8000 元，需国家级竞赛/论文，GPA 前 5%）→ 走国奖 skill
- 国家励志奖学金（5000 元，需家庭经济困难认定）→ 走励志 skill
- 企业专项奖学金（侧重行业兴趣与职业规划）→ 走企业奖学金 skill
- 单项奖学金（科研/社工/文体，仅看单项突出）→ 走单项奖学金 skill

**等级判定规则**（按数据自动匹配，用户也可手动指定）：

| 等级 | 加权平均分门槛 | 专业排名门槛 | 金额参考 | 覆盖面 |
|------|----------------|--------------|----------|--------|
| 校级一等 | ≥85 | 前 5% | 1500~3000 元 | 3%~5% |
| 校级二等 | ≥80 | 前 15% | 1000~1500 元 | 8%~10% |
| 校级三等 | ≥75 | 前 30% | 500~800 元 | 15%~20% |

**子类型区分**：
- 校级 vs 国奖：校级仅需 GPA，国奖需国家级竞赛/论文，GPA 前 5%
- 校级 vs 励志：校级不写家庭困难，励志必须含家庭经济情况段
- 校级一等 vs 二等 vs 三等：硬门槛与字数侧重不同（详见第七章）

**触发后第一步**：核对硬门槛。若用户排名 >30% 或加权 <75，告知"校级奖学金最低门槛为加权 75 + 排名前 30%，建议改申企业专项或单项奖学金"，避免无效申请。等级优先按用户指定，否则按学业数据自动匹配。

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（5~8 轮对话）**：
按"通用必采 → 学业信息（重点） → 学期 GPA 表 → 荣誉经历 → 科研实践（可选） → 生活方面"顺序采集。每轮不超过 5 个字段。校级奖学金学业信息是核心，必须采集完整。科研实践与志愿服务为可选项，缺则跳过对应段落。

**阶段 2 等级匹配与书信体撰写（一次性产出）**：
先按学业数据匹配等级（或采用用户指定等级），再按"标题 → 称呼 → 开头 → 思想方面 → 学习方面（重点，占 50% 篇幅） → 科研实践方面（可选） → 生活方面 → 结尾 → 落款"顺序撰写。正文 800~1500 字，每段严格控制在规范区间。事实+数据原则，禁止形容词堆砌。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十一章，需包含 level 字段（一等/二等/三等）、core_courses 主干课程列表、semester_gpa 学期 GPA 表（4 学期）。

**阶段 4 质检**：
按第十二章 25 项清单逐项检查。任何一项不达标返回阶段 2 修改。重点检查等级与数据是否匹配、主干课程表与学期 GPA 表是否齐全。

**禁止行为**：
- 开头抒情堆砌（"时光荏苒""岁月如梭"）
- 形容词代替事实（"成绩优异""积极参加"）
- 获奖不写级别与时间
- 学生干部只写头衔不写履职
- 结尾"恳请领导批准"
- 编造 GPA/排名/单科成绩
- 把国奖内容（国家级竞赛/论文）作为主体段
- 把励志内容（家庭困难）写入校级申请书
- 等级与学业数据不匹配（如三等数据却申请一等）

## 三、信息采集清单

### 3.1 通用必采（10 字段）

| 字段 | 说明 | 示例 | 缺失追问策略 |
|------|------|------|--------------|
| name | 申请人姓名 | 王晨 | "申请人全名？" |
| student_id | 学号 | 2022123456 | "学号？" |
| gender | 性别 | 男/女 | "性别？" |
| college | 学院全称 | 计算机科学与技术学院 | "学院全称？" |
| major | 专业全称 | 计算机科学与技术 | "专业全称？" |
| grade | 年级 | 2022 级 大三 | "入学年份与年级？" |
| class_name | 班级 | 计科 2201 班 | "班级？" |
| political_status | 政治面貌 | 共青团员 | "政治面貌？" |
| phone | 联系电话 | 138XXXXXXXX | "手机号？" |
| apply_year | 申报学年 | 2024-2025 学年 | "申报学年？" |

### 3.2 学业信息（硬指标，8 字段，**核心**）

| 字段 | 说明 | 示例 |
|------|------|------|
| level | 申报等级（手动指定或自动匹配） | 一等/二等/三等 |
| gpa | GPA | 3.65/4.0 |
| weighted_avg | 加权平均分 | 85.2 |
| rank | 专业排名 | 4/87（一等）/10/87（二等）/20/87（三等） |
| rank_total | 专业总人数 | 87 |
| core_courses | 主干课程成绩 4~6 门 | [{name,credit,score},...] |
| semester_gpa | 学期 GPA 表（4 学期） | [{semester,gpa,weighted},...] |
| course_count | 本学年修读课程数 | 12 |

### 3.3 英语计算机等级（5 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| cet4 | CET-4 成绩 | 510 |
| cet6 | CET-6 成绩 | 480（二等可不填） |
| toefl | TOEFL 成绩（可选） | 95 |
| ielts | IELTS 成绩（可选） | 6.5 |
| computer_level | 计算机等级 | 二级 C 语言 |

### 3.4 荣誉经历（按时间倒序，可选）

每项荣誉 4 字段：时间（YYYY.MM）、奖项全称、级别（国家/省/校/院）、颁发单位。

示例：
- 2024.11 校级三好学生 XX 大学
- 2024.05 校级优秀共青团员 XX 大学

### 3.5 科研实践（可选，校级不强制）

**学科竞赛**：竞赛全称、奖项（校级即可）、时间、角色。
**大创/科研立项**：项目名称、级别（校级即可）、角色、时间、产出。
**学生工作**：职务 + 任期 + 履职数据（活动数、服务人次）。
**志愿服务**：时长 + 服务对象 + 频次。

校级奖学金不强制要求本段，若用户无科研实践经历，可直接跳过本段，将字数分配给学习方面。

### 3.6 生活方面（4 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| dorm_role | 宿舍职务 | 宿舍长 |
| dorm_activity | 宿舍活动 | 组织 6 次集体活动 |
| dorm_honor | 宿舍荣誉 | 文明宿舍 |
| lifestyle | 生活作风 | 勤俭节约，作息规律 |

### 3.7 字段优先级与追问话术

**P0 必采**（缺则无法撰写）：name、major、grade、level、gpa、rank、core_courses、semester_gpa
**P1 重要**（缺则影响质量）：political_status、weighted_avg、cet4、computer_level
**P2 可选**（缺则用占位或跳过）：student_id、phone、research、volunteer、honors

追问话术示例：
- 用户说"我成绩还可以"→ "GPA 是多少？加权平均分？专业排名（X/N）？"
- 用户说"我修了一些课"→ "主干课程 4~6 门，每门课程名/学分/成绩？"
- 用户说"我每学期 GPA 都不错"→ "请按学期列出 4 学期 GPA 与加权平均分"
- 用户说"我想申请二等"→ "你的加权平均分和排名？需匹配二等门槛（≥80 + 前 15%）"

**等级自动匹配规则**：
- 加权 ≥85 且 排名前 5% → 推荐一等
- 加权 ≥80 且 排名前 5%~15% → 推荐二等
- 加权 ≥75 且 排名前 15%~30% → 推荐三等
- 加权 <75 或 排名 >30% → 不建议申请，告知用户改申其他奖学金

**复述确认**：所有信息采完后，按"等级/学业/英语计算机/荣誉/科研实践/生活"顺序复述给用户确认，再进入撰写阶段。

## 四、书信体结构详解

校级奖学金申请书是书信体（非表格），整体结构：

```
标题：校级奖学金申请书（黑体二号居中）

称呼：尊敬的学院领导、评审委员会：（顶格，全角冒号）

开头（80~120 字）：
  身份 + 申报等级 + 核心数据 2 项 + 进入正文

一、思想方面（120~180 字）
  政治立场 + 入团/团情况 + 思想觉悟 + 1 件具体事

二、学习方面（350~500 字，**重点，占 50% 篇幅**）
  GPA + 排名 + 主干课程表 + 学期 GPA 表 + 英语计算机等级 + 学习方法

三、科研与实践方面（150~250 字，**可选**）
  竞赛 + 大创 + 学生工作 + 志愿服务（任一即可）

四、生活方面（100~150 字）
  生活作风 + 人际关系（不写家庭困难）

结尾（60~100 字）：
  事实总结 + 朴素表态 + "此致/敬礼！"

落款（右对齐）：
  申请人：XXX
  XXXX 年 XX 月 XX 日
```

### 4.1 标题

格式：黑体二号，居中，段前段后 12pt。

文本：固定为"校级奖学金申请书"（8 字），不要写"2025 年度校级二等学金申请书"——标题简洁有力，等级在正文开头出现即可。部分学校要求"XX 大学奖学金申请书"，按学校模板调整 build.py 标题常量。

### 4.2 称呼

格式：顶格（首行不缩进），宋体小四，加冒号。

文本：固定为"尊敬的学院领导、评审委员会："。冒号用全角"："（非半角":"）。

部分学校要求"尊敬的评审委员会："或"尊敬的学院领导："——按学校下发模板调整。

### 4.3 开头段落

字数：80~120 字，1 段。比国奖/励志开头更短。

句式 3 句结构：
1. 身份 + 申报等级："我是 XX 学院 XX 专业 2022 级学生 XXX，特申请 2024-2025 学年校级二等奖学金。"
2. 核心数据 2 项："本学年 GPA X.XX/4.0，专业排名第 X/N。"
3. 进入正文："现将本人情况汇报如下："

禁止：抒情开头（时光荏苒/岁月如梭/感慨万千）、感谢老师培养、回顾大学时光、堆砌多项荣誉（荣誉放正文段落，不放开头）。

### 4.4 思想方面

字数：120~180 字，1 段。比国奖/励志短。

要素 4 项（必须真实，党支部会向辅导员核实）：
- 政治立场：拥护党的领导、学习习近平新时代中国特色社会主义思想
- 入团/团情况：入团时间、优秀团员/积极分子培养阶段
- 思想觉悟：党课学习次数、理论学习
- 1 件具体事：主题党日/志愿服务/阶段汇报

句式："作为一名共青团员，我拥护中国共产党的领导，认真学习习近平新时代中国特色社会主义思想。2024.10 参与学院分党校第 8 期培训班结业；提交阶段汇报 2 篇。"

### 4.5 学习方面（**重点**）

字数：350~500 字，3~4 段。**全篇重点**，评审权重 70%。占正文 50% 篇幅。

要素 6 项：
1. GPA 表达："本学年 GPA 3.65/4.0，加权平均分 85.2，专业排名第 4/87（前 4.6%）"
2. 主干课程表（4~6 门，表格呈现，含课程名/学分/成绩）
3. 主干课程亮点描述："高等数学 95、数据结构 92，专业核心课平均 90 分"
4. 学期 GPA 表（4 学期，表格呈现，含学期/GPA/加权平均分，展示稳定或进步趋势）
5. 英语等级："CET-4 568 分（2023.06）、CET-6 480 分（2024.06）"
6. 计算机等级 + 学习方法（1 句）："计算机二级 C 语言。学习上注重课前预习与课后总结。"

禁止：形容词堆砌、不写具体数据、写"成绩优异"、主干课程少于 4 门、学期 GPA 表缺失。

### 4.6 科研与实践方面（**可选**）

字数：150~250 字，1~2 段。评审权重 20%。

校级奖学金不强制要求本段。若用户有相关经历则写，无则跳过，将字数分配给学习方面。

要素 4 类（任 1 项即可成段）：

**学科竞赛**（校级即可）：竞赛全称、奖项、时间、角色。例："2025.05 校级程序设计竞赛 二等奖（队长），负责算法实现"。

**大创/科研立项**（校级即可）：项目名称、级别、角色、时间、产出。例："主持校级大创项目《XX》（2024.03-2025.03），负责方案设计，结题评估良好"。

**学生工作**：职务 + 任期 + 履职数据。例："担任班级学习委员（2024.09-2025.06），组织学习经验交流会 5 次，服务同学 30 余人次"。

**志愿服务**：时长 + 服务对象 + 频次。例："累计志愿服务 60 小时，参与图书馆管理员工作（每月 5 小时）"。

### 4.7 生活方面

字数：100~150 字，1 段。比国奖/励志短。

要素 3 项：
- 生活作风（勤俭、规律、自律）
- 人际关系（团结同学、乐于助人，举 1 个具体例子）
- 经济情况（校级**不写家庭困难**，励志类才写）

句式："生活中我注重勤俭节约，作息规律。担任宿舍长期间，组织宿舍 6 次集体活动，宿舍连续两学期获评'文明宿舍'。与同学相处融洽，曾帮助室友完成 1 次实验调试。"

### 4.8 结尾

字数：60~100 字，1 段。比国奖/励志短。

结构 3 部分：
1. 事实总结："以上是我本学年的基本情况。"
2. 朴素表态："无论结果如何，我都将以此为新的起点，继续努力学习。"
3. 礼貌收尾："恳请评审委员会予以考虑。"
4. "此致"另起一行，空两格
5. "敬礼！"另起一行，顶格

禁止："完全符合""恳请领导批准""倍感荣幸"等绝对化/乞求/抒情词。

### 4.9 落款

格式：右对齐，宋体小四。

文本：
```
                                              申请人：王晨
                                              2025 年 6 月 15 日
```

日期格式与全文统一（全用阿拉伯数字或全用中文大写，二选一）。落款与正文之间空 1 行。

## 五、各段落撰写规范

### 5.1 字数配比

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 开头 | 80~120 | 9% |
| 思想方面 | 120~180 | 14% |
| 学习方面 | 350~500 | 50% |
| 科研与实践 | 150~250 | 17%（可选） |
| 生活方面 | 100~150 | 10% |
| 结尾 | 60~100 | 7% |
| 合计（含科研实践） | 800~1300 | 100% |
| 合计（无科研实践） | 700~1050 | 100% |

学习方面必须占总字数 50% 以上（评审重点）。无科研实践时，学习方面可扩展至 500~600 字。

### 5.2 句式规范

**事实句**（核心）："主语 + 动词 + 数据 + 时间/范围"
- ✅ "本学年 GPA 3.65/4.0，专业排名第 4/87"
- ✅ "2025.05 校级程序设计竞赛 二等奖"

**禁止抒情句**：
- ❌ "时光荏苒，岁月如梭"
- ❌ "怀着激动的心情"
- ❌ "感慨万千"

**禁止评价句**：
- ❌ "我学习成绩优异"
- ❌ "我科研能力突出"
- ❌ "我热心公益"

**慎用副词**：
- 禁用：特别/非常/极其/深感/深切/深刻
- 可用：曾/已/将/在/于（事实描述）

### 5.3 事实+数据原则

每段必须含 3 个以上可验证事实或数据：
- 思想方面：党课 X 次、阶段汇报 X 篇、志愿活动 X 次
- 学习方面：GPA X.XX、排名 X/N、主干课程 X 门 85+、CET-4 X 分、学期 GPA 4 学期数据
- 科研方面：竞赛 X 项（含级别与角色）、大创 X 项、学生工作 X 月
- 生活方面：宿舍评比 X 次、集体活动 X 次

无数据则不写——评审查不到证据等于没写。

### 5.4 段落衔接

### 5.5 时态与时间表达

- 过去事实用"已完成""已发表""已获得"
- 持续状态用"担任""参与"
- 时间格式统一为"YYYY.MM"或"YYYY 年 MM 月"
- 时间倒序排列（最近的在前）

### 5.6 段落字数自检

撰写完成后用以下脚本核对各段字数：

import re
text = open('output.txt').read()
sections = {

## 六、学习方面撰写方法

学习方面是校级奖学金评审的"硬指标段"（权重 70%），撰写 6 要素：

### 6.1 GPA 表达

**必须 3 项齐全**：GPA 绝对值 + 加权平均分 + 专业排名。

✅ 标准表达：
> 本学年 GPA 3.65/4.0，加权平均分 85.2，专业排名第 4/87（前 4.6%）

❌ 错误表达：
> 学习成绩优异，名列前茅
> GPA 3.6（缺排名）
> 排名专业第四（缺基数 4/N）

**GPA 制度差异处理**：
- 4.0 制：写"3.65/4.0"
- 5.0 制：写"4.45/5.0"
- 百分制：写"加权平均分 85.2"

学校使用何种制度，按成绩单原始数据填写，不要换算。

### 6.2 主干课程展示

**选课原则**：4~6 门，专业核心课优先，分数 80+（一等 90+，二等 85+，三等 80+），含 1~2 门基础课（如高等数学）。

**表格格式**（必须用表格）：

| 课程名称 | 学分 | 成绩 |
|----------|------|------|
| 高等数学（上） | 5 | 95 |
| 数据结构 | 4 | 92 |
| 操作系统 | 4 | 89 |
| 计算机网络 | 3 | 88 |

**描述句式**：表格后用 1 句话概括
✅ "高等数学 95、数据结构 92，专业核心课平均 90 分。"

❌ "主干课程成绩如下表所示："（指代）
❌ "成绩优异，多门课程 90+。"（无数据）

### 6.3 学期 GPA 表（校级专属）

校级奖学金评审特别关注"持续稳定"或"持续进步"，必须含 4 学期 GPA 表：

| 学期 | GPA | 加权平均分 |
|------|-----|-----------|
| 第 1 学期 | 3.55/4.0 | 84.2 |
| 第 2 学期 | 3.62/4.0 | 84.8 |
| 第 3 学期 | 3.68/4.0 | 85.5 |
| 第 4 学期 | 3.65/4.0 | 85.2 |

**撰写策略**：
- 一等（拔尖）：4 学期 GPA 均 ≥3.8 或加权均 ≥88，强调"持续拔尖"
- 二等（稳定）：4 学期 GPA 波动 ≤0.1，强调"持续稳定"
- 三等（进步）：4 学期 GPA 单调上升，强调"持续进步"

❌ 错误表达：
> 各学期成绩稳定，无挂科。（无具体数据）

✅ "大学前 4 学期 GPA 由 3.55 提升至 3.68，加权平均分由 84.2 提升至 85.5，呈现稳步上升趋势。"

### 6.4 英语计算机等级

**英语**（按等级递进写）：
- CET-4：✅ "CET-4 510 分（2023.06）"
- CET-6：✅ "CET-6 480 分（2024.06）"（一等建议 CET-6，二等 CET-4 即可）
- 无证书：不写，或写"具备良好英文文献阅读能力"

**计算机**：
- 二级：✅ "计算机二级 C 语言"
- 三级：✅ "计算机三级数据库技术"

**禁用**：
- ❌ "英语水平良好"（无数据）
- ❌ "计算机能力较强"（无证书）

### 6.5 学习态度与方法（1~2 句）

学习方面末尾用 1~2 句话讲学习态度与方法，**不要长篇大论**：

✅ "学习上注重课前预习与课后总结，建立知识体系；遇到问题主动与老师、同学讨论。"

❌ "我学习刻苦努力，每天早起晚睡，泡在图书馆，是我大学生活的真实写照。"

### 6.6 完整示例（学习方面 450 字，二等）

> 二、学习方面
>
> 本学年 GPA 3.65/4.0，加权平均分 85.2，专业排名第 10/87（前 11.5%）。修读 12 门课程，9 门 80 分以上。主干课程成绩如下：
>
> | 课程名称 | 学分 | 成绩 |
> |----------|------|------|
> | 高等数学（上） | 5 | 95 |
> | 数据结构 | 4 | 92 |
> | 操作系统 | 4 | 89 |
> | 计算机网络 | 3 | 88 |
> | 数据库原理 | 3 | 90 |
>
> 高等数学 95、数据结构 92，专业核心课平均 90 分，全部 85+。大学前 4 学期 GPA 与加权平均分如下：
>
> | 学期 | GPA | 加权平均分 |
> |------|-----|-----------|
> | 第 1 学期 | 3.55/4.0 | 84.2 |
> | 第 2 学期 | 3.62/4.0 | 84.8 |
> | 第 3 学期 | 3.68/4.0 | 85.5 |
> | 第 4 学期 | 3.65/4.0 | 85.2 |
>
> 4 学期 GPA 在 3.55~3.68 之间稳定波动，加权平均分稳定在 84~86 区间，学业表现持续稳定。CET-4 510 分（2023.06）、CET-6 480 分（2024.06）；计算机二级 C 语言。学习上注重课前预习与课后总结，建立知识体系。

### 6.7 GPA 制度差异处理

不同学校成绩单格式不同，处理规则：
- 4.0 制（多数 985/211）：直接写"3.65/4.0"
- 5.0 制（部分高校）：直接写"4.45/5.0"，不要换算成 4.0 制
- 百分制（部分老牌院校）：写"加权平均分 85.2"，并备注"百分制"
- 排名一定要写基数："10/87"而非"专业第十"

转专业学生：按现专业排名填写，注明"原 XX 专业转入，排名按现专业计算"。

辅修学位：单独写"辅修 XX 专业 GPA X.XX"，不计入主修 GPA。

## 七、不同等级的撰写策略

三个等级评审侧重不同，撰写策略差异显著：

### 7.1 校级一等：强调"拔尖"

**门槛**：加权 ≥85 + 排名前 5%。

**撰写策略**：
- 开头核心数据突出排名（如"专业排名第 4/87，前 4.6%"）
- 学习方面：主干课程 5~6 门 90+，加权平均分 ≥88，学期 GPA 表 4 学期均 ≥3.8
- 强调"持续拔尖"：4 学期 GPA 均稳定在高位
- 学习方法可适当展开（不超过 2 句）
- 科研实践段建议包含（如有）：校级一等奖/国家级三等奖以上、校级大创优秀结题
- 推荐字数：1000~1500 字（接近上限）

**一等专属表达**：
- ✅ "本学年 GPA 3.92/4.0，加权平均分 92.5，专业排名第 1/87（前 1.1%），居本专业首位。"
- ✅ "4 学期 GPA 均稳定在 3.85 以上，加权平均分均超 90，学业表现持续拔尖。"

**一等完整开头示例**：
> 我是计算机科学与技术学院计算机科学与技术专业 2022 级学生张明，特申请 2024-2025 学年校级一等奖学金。本学年 GPA 3.92/4.0，专业排名第 1/87。现将本人情况汇报如下：

**一等学期 GPA 表示例**：

| 学期 | GPA | 加权平均分 |
|------|-----|-----------|
| 第 1 学期 | 3.88/4.0 | 90.5 |
| 第 2 学期 | 3.90/4.0 | 91.2 |
| 第 3 学期 | 3.92/4.0 | 92.8 |
| 第 4 学期 | 3.92/4.0 | 92.5 |

### 7.2 校级二等：强调"稳定"

**门槛**：加权 ≥80 + 排名前 15%。

**撰写策略**：
- 开头核心数据突出排名区间（如"专业排名第 10/87，前 11.5%"）
- 学习方面：主干课程 4~5 门 85+，加权平均分 83~88，学期 GPA 表 4 学期波动 ≤0.15
- 强调"持续稳定"：4 学期 GPA 波动小
- 学习方法 1 句即可
- 科研实践段可选：有则写校级二等奖、参与大创即可
- 推荐字数：900~1300 字

**二等专属表达**：
- ✅ "本学年 GPA 3.65/4.0，加权平均分 85.2，专业排名第 10/87（前 11.5%），位于专业前列。"
- ✅ "4 学期 GPA 在 3.55~3.68 区间稳定波动，学业表现持续稳定。"

**二等学期 GPA 表示例**：

| 学期 | GPA | 加权平均分 |
|------|-----|-----------|
| 第 1 学期 | 3.58/4.0 | 84.5 |
| 第 2 学期 | 3.62/4.0 | 84.8 |
| 第 3 学期 | 3.65/4.0 | 85.5 |
| 第 4 学期 | 3.65/4.0 | 85.2 |

波动幅度仅 0.07，加权波动 1.0 分，体现持续稳定。

### 7.3 校级三等：强调"进步"

**门槛**：加权 ≥75 + 排名前 30%。

**撰写策略**：
- 开头核心数据突出达标（如"专业排名第 20/87，前 23%"）
- 学习方面：主干课程 4 门 80+，加权平均分 78~82，学期 GPA 表呈现上升趋势
- 强调"持续进步"：4 学期 GPA 单调上升或后期上升
- 学习方法可写"克服困难、稳步提升"等具体事（1~2 句）
- 科研实践段一般不写（如有则简单提）
- 推荐字数：800~1200 字（接近下限）

**三等专属表达**：
- ✅ "本学年 GPA 3.25/4.0，加权平均分 80.5，专业排名第 20/87（前 23%），达到校级奖学金评定标准。"
- ✅ "4 学期 GPA 由 3.05 提升至 3.45，加权平均分由 78.2 提升至 82.1，呈现稳步上升趋势。"

**三等学期 GPA 表示例**：

| 学期 | GPA | 加权平均分 |
|------|-----|-----------|
| 第 1 学期 | 3.05/4.0 | 78.2 |
| 第 2 学期 | 3.18/4.0 | 79.5 |
| 第 3 学期 | 3.32/4.0 | 80.8 |
| 第 4 学期 | 3.45/4.0 | 82.1 |

GPA 单调上升 0.40，加权上升 3.9 分，体现持续进步。三等撰写时可在学习方法段补充一句具体事："大二上学期通过主动请教老师与参加学习小组，高等数学由 78 分提升至本学期 92 分，掌握了主动学习方法。"

### 7.4 等级误配避坑

- ❌ 三等数据却申请一等：评审一眼识破，直接淘汰
- ❌ 一等数据却申请三等：浪费申请机会，建议改申一等
- ❌ 学期 GPA 表显示下降却申请高等级：评审会质疑
- ✅ 等级与数据匹配：加权 ≥85 + 前 5% → 一等；80~85 + 前 5~15% → 二等；75~80 + 前 15~30% → 三等

## 八、评审标准与打分维度

校级奖学金评审 3 维度（参考多所高校实施细则，区别于国奖 4 维度）：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 学业 | 70% | GPA 排名、主干课程、学期 GPA 趋势、英语计算机等级 |
| 综合素质 | 20% | 学生工作、志愿服务、社会实践、文体特长、科研竞赛 |
| 思想 | 10% | 政治面貌、入团情况、阶段汇报、党团活动 |

### 8.1 学业 70% 评分细则

- 排名 1-3/N：满分
- 排名 4-5/N：扣 3 分
- 排名 6-10/N：扣 8 分
- 排名 11-15/N：扣 12 分
- 排名 16-30/N：扣 18 分
- 排名 >30/N：直接淘汰
- 主干课程 85+ 占比 ≥80%：满分
- 学期 GPA 4 学期均稳定或上升：加分
- CET-6 ≥425：基础分；≥500：加分
- 计算机二级：基础分；三级及以上：加分

### 8.2 综合素质 20% 评分细则

- 班长/团支书 + 评优：满分
- 校级学生组织部长/副部长：80 分
- 班委 + 评优：75 分
- 志愿服务 ≥50 小时：加分
- 校级竞赛二等奖及以上：加分
- 校级大创（结题）：加分
- 文体特长（校级以上奖项）：加分

### 8.3 思想 10% 评分细则

- 中共党员：满分
- 优秀团员/积极分子（培养 1 年+）：85 分
- 共青团员 + 优秀团员：75 分
- 共青团员：60 分
- 阶段汇报 ≥2 篇/年：加分
- 党团活动有具体事例：加分

### 8.4 评分计算示例

> 王晨（二等）：学业 85 分×70% + 综合素质 75 分×20% + 思想 75 分×10%
> = 59.5 + 15 + 7.5 = 82 分

**提分策略**：
- 学业已达上限 → 重点提综合素质（学生工作+志愿服务）
- 综合素质已达上限 → 重点提思想（入团+阶段汇报）
- 三等提分：学期 GPA 上升趋势可加学业分

### 8.5 一票否决项

- 本学年有挂科
- 本学年有违纪处分
- GPA 排名 >30%
- 材料造假（GPA/排名/课程成绩）
- 抄袭他人申请书
- 等级与数据不匹配（如三等数据申请一等）

任一项触发 → 直接淘汰，不再评审。

### 9.7 学期 GPA 表缺失

❌ "各学期成绩稳定，无挂科。"（无具体数据，校级评审特别看重学期 GPA 趋势）

✅ 用表格呈现 4 学期 GPA 与加权平均分，并用 1 句话概括趋势（稳定/上升/拔尖）。

### 9.8 排名不写基数

❌ "专业排名前十""排名专业前 15%"

✅ "专业排名第 10/87""排名 20/87（前 23%）"

评审需要基数判断前 X% 门槛，无基数视为材料不合格。

### 9.9 课程成绩不写学分

❌ "高等数学 95、数据结构 92、操作系统 89"

（无学分，评审无法判断课程权重）

✅ 用表格呈现：课程名称/学分/成绩三列齐全。

### 9.10 等级与数据不匹配

❌ 加权 78 + 排名 20/87 却申请"校级一等"

✅ 加权 78 + 排名 20/87 应申请"校级三等"（加权 ≥75 + 前 30%）

❌ 加权 92 + 排名 1/87 却申请"校级三等"（浪费机会）

✅ 加权 92 + 排名 1/87 应申请"校级一等"（≥85 + 前 5%），并考虑同时申国奖。

### 12.1 字数自动检查

撰写完成后用以下脚本核对各段字数：

```python
import re
text = open('output.txt').read()
def extract(text, start, end):
    s = text.find(start); e = text.find(end)
    return text[s:e] if s >= 0 and e > s else ''
sections = {
    '开头': extract(text, '申请书', '一、思想'),
    '思想': extract(text, '一、思想', '二、学习'),
    '学习': extract(text, '二、学习', '三、'),
    '科研': extract(text, '三、', '四、生活'),
    '生活': extract(text, '四、生活', '此致'),
    '结尾': extract(text, '此致', '申请人'),
}
limits = {
    '开头': (80, 120), '思想': (120, 180), '学习': (350, 500),
    '科研': (150, 250), '生活': (100, 150), '结尾': (60, 100),
}
for name, content in sections.items():
    n = len(re.sub(r'[\s\W]', '', content))
    lo, hi = limits[name]
    status = '✅' if lo <= n <= hi else '❌'
    print(f'{status} {name}: {n} 字（{lo}~{hi}）')
```

### 12.2 错别字检查清单

## 十三、学校差异处理

不同学校校级奖学金申请书模板与评定标准有微调：

**字数差异**：多数学校要求 800~1500 字，少数要求 1000~1800 字。按学校要求调整字数区间。

**称呼差异**：默认"尊敬的学院领导、评审委员会："，部分学校改为"尊敬的评审委员会："或"尊敬的学院领导："。

**栏目顺序**：极少数学校把"生活方面"前移到"思想方面"后。按学校模板调整 build.py 调用顺序。

**主干课程呈现**：表格（推荐，本 skill 默认）或文字（"高等数学 95、数据结构 92……"）。

**字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。

**5 校一等评定标准差异**：

| 学校 | 一等门槛 | 一等金额 | 特色 |
|------|----------|----------|------|
| 清华大学 | GPA 前 5% + 综测 A | 3000 元 | 学业与综测双门槛 |
| 北京大学 | GPA 前 5% + 学业 A | 3000 元 | 需院系学术委员会评审 |
| 浙江大学 | 加权 ≥85 + 前 5% | 2000 元 | 主干课程必须 90+ |
| 复旦大学 | GPA 前 10% + 学业 A | 2500 元 | 一等覆盖面较宽 |
| 上海交大 | 加权 ≥85 + 前 5% | 2000 元 | CET-6 ≥425 为必填 |

适配流程：先问"学校下发的校级奖学金申请书模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按本 skill 默认处理。

**附加栏目**：部分学校要求附"成绩单（教务处盖章）""获奖证书复印件""英语等级证书"。提醒用户在 docx 后附纸质材料。

**等级切换**：若用户学业数据介于二等与一等之间，告知"加权 85.2 排名 6/87，已达到一等门槛，建议改申一等；如二等评审更看重综合素质，亦可保留二等"。

本 skill 执行流程：触发 → 核对硬门槛 → 等级匹配 → 信息采集 → 书信体撰写 → 调 build.py 生成 docx → 25 项质检 → 提交。校级奖学金门槛低、通过率高，但仍需严谨撰写以避免被退回。
