# 单项奖学金申请书 Skill

本 skill 处理"单项奖学金申请书"全流程：信息采集 → 子方向判定 → 书信体撰写 → docx 生成 → 质检。单项奖学金评审侧重**单项突出**（不要求全面发展），4 个子方向：科研单项、社工单项、文体单项、学习进步单项。各方向必写该方向的具体成绩，其他方面可简略。仅处理单项类，国奖（10000 元）、励志（6000 元）、校级一/二/三等、企业专项请走其他 skill。

子方向与硬门槛：
- 科研单项：第一作者论文 1 篇（中文核心及以上）或发明专利 1 项或大创国家级立项
- 社工单项：学生干部职务 + 组织活动 ≥5 场或志愿服务 ≥80 小时
- 文体单项：校级及以上文艺/体育竞赛获奖 ≥1 项（前 3 名或等级奖）
- 学习进步单项：GPA 较上一学年提升 ≥0.5 或排名提升 ≥30%

与校级奖学金的关键区别：单项突出而非全面发展、其他方面可简略、评审权重单项 70%/综合 20%/思想 10%、字数 800~1500 字（与校级一致但段落配比不同）。

输出文件：可提交的 .docx（A4，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐）。

## 一、适用场景与触发条件

**适用**：用户提到"单项奖学金""科研单项""社工单项""文体单项""学习进步单项"等关键词，且在某一方向有突出表现（其他方面不要求全面发展）。子方向由用户主述+数据自动判定。

**不适用**（走其他 skill）：
- 国家奖学金（10000 元，全面发展，GPA 前 5%）→ 走国奖 skill
- 国家励志奖学金（6000 元，需家庭经济困难认定）→ 走励志 skill
- 校级奖学金（纯学习，GPA 前 30%）→ 走校级奖学金 skill
- 企业专项奖学金（侧重行业兴趣与职业规划）→ 走企业奖学金 skill

**子方向判定规则**：

| 子方向 | 触发数据 | 典型场景 |
|--------|----------|----------|
| 科研单项 | 论文/专利/大创任意 1 项 | 第一作者 [收录级别] 论文 [N] 篇 |
| 社工单项 | 学生干部职务 + 活动/志愿服务数据 | [职务] + 组织 [N] 场活动 + 服务 [N] 人次 |
| 文体单项 | 文艺/体育竞赛获奖数据 | [赛事全称] [等级] |
| 学习进步单项 | GPA 提升幅度或排名提升幅度 | GPA [X.XX]→[X.XX] 或排名 [N]→[N] |

**触发后第一步**：核对子方向硬门槛。若用户在 4 个方向均有突出表现，建议改申校级一等或国奖；若 4 个方向均不达标，告知"单项奖学金需在某方向有突出成绩，建议改申校级奖学金"，避免无效申请。

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（5~8 轮对话）**：
按"通用必采 → 子方向判定 → 该方向专属字段 → 其他方面（简略）"顺序采集。每轮不超过 5 个字段。子方向判定优先：先确认用户在某方向有突出成绩，再深度采集该方向数据。其他方面（思想/学业/生活）简略采集即可。

**阶段 2 子方向判定与书信体撰写（一次性产出）**：
先按数据判定子方向（或采用用户指定），再按"标题 → 称呼 → 开头 → 单项突出表现（重点，占 60% 篇幅） → 其他方面（简略） → 结尾 → 落款"顺序撰写。正文 800~1500 字，每段严格控制在规范区间。事实+数据原则，单项段落必须有量化数据与表格。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十章，需包含 category 字段（research/social_work/art_sport/progress）+ 该方向专属字段。生成 docx 时按 category 动态选择表格类型。

**阶段 4 质检**：
按第十一章 22 项清单逐项检查。任何一项不达标返回阶段 2 修改。重点检查：单项数据是否齐全（论文含期刊级别/作者排序、活动含场次/服务人数、获奖含级别/角色、GPA 提升含基数）；其他方面是否简略（不超过 250 字）；附件证明是否齐全。

**禁止行为**：
- 开头抒情堆砌（"时光荏苒""岁月如梭"）
- 形容词代替事实（"科研能力突出""工作认真负责"）
- 把其他方向数据写满（单项突出是重点，其他简略）
- 论文不写期刊级别与作者排序
- 学生干部只写头衔不写履职
- 文体获奖不写级别与角色
- GPA 提升不写基数与幅度
- 结尾"恳请领导批准"
- 编造单项成绩
- 把国奖内容（全面发展）写入单项申请书

## 四、书信体结构详解

### 4.1 整体结构

```
标题：X 单项奖学金申请书（居中，二号字）
称呼：尊敬的学院领导、评审委员会：（顶格，全角冒号）
开头（80~120 字）
一、单项突出表现（重点，450~800 字，含表格）
二、其他方面（简略，150~250 字）
结尾（60~100 字）
此致（另起一行，空两格）
敬礼！（另起一行，顶格）
落款（右对齐，含申请人+日期）
```

### 4.2 标题

固定格式"X 单项奖学金申请书"，X 按子方向填充：
- research → 科研单项奖学金申请书（10 字）
- social_work → 社工单项奖学金申请书（10 字）
- art_sport → 文体单项奖学金申请书（10 字）
- progress → 学习进步单项奖学金申请书（11 字）

黑体二号，居中，段前段后 12pt。

### 4.3 称呼

固定"尊敬的学院领导、评审委员会："，顶格（不缩进），全角冒号，宋体小四。少数学校要求"尊敬的领导："亦可，以学校模板为准。

### 4.4 开头（80~120 字）

3 句结构：
1. 身份（学院+专业+年级+姓名）
2. 申报（学年+某单项奖学金）
3. 单项核心数据 1 项 + 进入正文

模板：
"我是 XX 学院 XX 专业 2022 级学生 XXX，特申请 2024-2025 学年科研单项奖学金。本学年以第一作者在《XX》发表 SCI 论文 1 篇，主持国家级大创 1 项。现将本人情况汇报如下："

各方向核心数据示例（数字为写法，须换成真实值）：
- research：第一作者论文 [N] 篇/发明专利 [N] 项/[项目级别] 大创 [N] 项
- social_work：组织大型活动 [N] 场/服务 [N] 人次/志愿服务 [N] 小时
- art_sport：[赛事全称] [等级]/[赛事名称] [名次]
- progress：GPA 由 [X.XX] 提升至 [X.XX]/排名由 [N] 提升至 [N]

### 4.5 一、单项突出表现（450~800 字，重点）

按子方向不同分别撰写，必须含表格：

**4.5.1 科研单项**：
- 一句话总述研究方向与时间（30~50 字）
- 论文表（含题目/期刊/级别/作者排序/时间）
- 专利表（含名称/类型/申请号/状态/发明人排序）
- 大创表（含项目名/级别/角色/起止时间/产出）
- 科研小结（80~150 字）：研究内容、方法、贡献、收获

**4.5.2 社工单项**：
- 一句话总述职务与任期（30~50 字）
- 学生干部履职表（含活动名/时间/规模/本人角色）
- 志愿服务表（含项目名/时长/服务对象）
- 履职亮点段（80~150 字）：最具代表性的 1~2 件事，含数据

**4.5.3 文体单项**：
- 一句话总述训练年限与方向（30~50 字）
- 获奖/作品表（含竞赛名/级别/时间/角色/作品名）
- 训练与团队经历段（80~150 字）：日常训练、参赛历程、团队贡献

**4.5.4 学习进步单项**：
- 一句话总述进步幅度（30~50 字）
- GPA 提升表（含学期/GPA/加权平均分/排名）
- 进步课程对比表（含课程名/上学年成绩/本学年成绩）
- 进步方法段（80~150 字）：学习方法调整、时间管理、求助策略

### 4.6 二、其他方面（150~250 字，简略）

非该方向内容简略撰写，3 句结构：
1. 学业/思想（80~120 字）：本学年 GPA+排名+政治面貌+党团活动
2. 生活（50~80 字）：生活作风+人际关系
3. 综合荣誉（30~50 字）：其他奖项

不要展开写，目的是体现"全面发展但不喧宾夺主"。学习进步单项的"其他方面"无需重复 GPA 数据，仅写思想+生活+综合荣誉。

### 4.7 结尾（60~100 字）

3 句结构：
1. 事实总结（"以上是本人在 XX 方面的基本情况"）
2. 朴素表态（"无论结果如何，我都将以此为新的起点，继续努力"）
3. 谦辞（"恳请评审委员会予以考虑"）

禁止"完全符合""恳请领导批准"等绝对化或乞求性表述。

### 4.8 此致/敬礼！

- "此致"另起一行，空两格（首行缩进 2 字符）
- "敬礼！"另起一行，顶格（不缩进）
- 末尾感叹号全角

### 4.9 落款（右对齐）

- 申请人：XXX（右对齐）
- XXXX 年 XX 月 XX 日（右对齐）
- 落款前空一行

### 4.10 整体字数配比

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 开头 | 80~120 | 10% |
| 单项突出表现 | 450~800 | 60% |
| 其他方面 | 150~250 | 20% |
| 结尾 | 60~100 | 10% |
| 合计 | 800~1500 | 100% |

单项突出表现不足 450 字 → 重写；其他方面超过 250 字 → 删减。

### 4.11 各子方向开头模板对照

| 子方向 | 开头模板（80~120 字，数字均为占位） |
|--------|----------------------|
| 科研 | "我是 [学院全称] [专业全称] [年级]学生 [姓名]，特申请 [学年] 科研单项奖学金。本学年以第一作者在《[期刊全称]》发表 [论文级别] 论文 [N] 篇，主持 [项目级别] 大创 [N] 项。现将本人情况汇报如下：" |
| 社工 | "我是 [学院全称] [专业全称] [年级]学生 [姓名]，特申请 [学年] 社工单项奖学金。本学年担任 [职务全称]，组织活动 [N] 场，累计参与 [N] 人次。现将本人情况汇报如下：" |
| 文体 | "我是 [学院全称] [专业全称] [年级]学生 [姓名]，特申请 [学年] 文体单项奖学金。本学年获 [竞赛/展演全称] [等级]，[学习/训练年限] [N] 年。现将本人情况汇报如下：" |
| 进步 | "我是 [学院全称] [专业全称] [年级]学生 [姓名]，特申请 [学年] 学习进步单项奖学金。本学年 GPA 由 [X.XX] 提升至 [X.XX]，专业排名由 [N]/[N] 提升至 [N]/[N]。现将本人情况汇报如下：" |

### 4.12 各子方向单项段落要素速查

| 子方向 | 必含表格 | 必含段落 | 字数下限 |
|--------|----------|----------|----------|
| 科研 | 论文表+专利表+大创表 | 总述+科研小结 | 450 |
| 社工 | 履职表+志愿服务表 | 总述+履职亮点 | 450 |
| 文体 | 获奖作品表 | 总述+训练与团队经历 | 450 |
| 进步 | GPA 提升表+进步课程表 | 总述+进步方法 | 450 |

任一表格缺失 → 单项段落不完整；任一段落字数不足 → 重写。

### 4.13 各子方向其他方面模板对照

其他方面段落统一 150~250 字，3 句结构（学业/思想+生活+综合荣誉）。各子方向模板：

**科研单项其他方面**：
"学业方面，本学年 GPA [X.XX]/4.0，专业排名第 [N]/[N]；CET-6 [N] 分，计算机[二级/三级] [科目名]通过。作为共青团员，参加学院分党校第 [N] 期培训班结业。生活中勤俭节约，作息规律，担任宿舍长期间宿舍连续 [N] 学期获评'文明宿舍'。"

**社工单项其他方面**：
"学业方面，本学年 GPA [X.XX]/4.0，专业排名第 [N]/[N]；CET-4 [N] 分。作为 [政治面貌]，参加学院分党校培训结业，提交阶段汇报 [N] 篇。生活中勤俭节约，与同学相处融洽，宿舍连续 [N] 学期获评'文明宿舍'。"

**进步单项其他方面**：
"作为共青团员，拥护中国共产党的领导，参加学院组织的党团活动 [N] 次。生活中勤俭节约，作息规律，担任宿舍长期间推动宿舍卫生评分由 [N] 提升至 [N]。"

注意：进步单项不重复 GPA 数据；其他子方向其他方面不展开该方向数据。

## 五、各段落撰写规范

### 5.1 事实句式

每段必须以"事实+数据"句式撰写，禁止形容词开头：
- ✅ "本学年以第一作者在《[期刊全称]》（[收录级别]）发表论文 [N] 篇，影响因子 [N]。"
- ❌ "本学年科研能力突出，取得丰硕成果。"

### 5.2 段落首句规范

每段首句须概括本段核心事实：
- ✅ "本学年科研工作主要围绕自然语言处理方向展开，已发表 SCI 论文 1 篇、申请发明专利 1 项、主持国家级大创 1 项。"
- ❌ "在科研方面，我取得了一些成绩。"

### 5.3 段落衔接

段与段之间用过渡句衔接，但不要用"如下所示""如下文所述"等指代：
- ✅ "在科研工作的同时，我也注重学业基础。"
- ❌ "如下所示，本人在其他方面也有表现。"

### 5.4 时态

正文用过去时（描述本学年已发生的事）；展望句用将来时。

### 5.5 高频词禁用清单

- 形容词：优异、突出、丰硕、显著、积极、深入、扎实、刻苦
- 抒情词：深感、深切、深刻、倍加、倍感、由衷
- 套话：全面发展、综合素质、思想觉悟、积极向上、不断进取、再接再厉
- 恭维词：领导、老师（用"评审委员会"代替）

### 5.6 数据呈现规范

- GPA：3.65/4.0（含基数）
- 排名：10/87（含基数）
- 论文：第一作者+期刊级别+影响因子（如有）
- 专利：发明/实用新型+发明人排序+申请号或授权号
- 大创：级别+角色+起止时间+产出
- 活动：活动名+时间+规模+本人角色
- 获奖：竞赛全称+级别+角色+作品名

### 5.7 字数自检

撰写完成后用以下脚本核对各段字数：

```python
import re
text = open('output.txt').read()
def extract(text, start, end):
    s = text.find(start); e = text.find(end)
    return text[s:e] if s >= 0 and e > s else ''
sections = {
    '开头': extract(text, '尊敬的', '一、'),
    '单项突出表现': extract(text, '一、', '二、'),
    '其他方面': extract(text, '二、', '以上'),
    '结尾': extract(text, '以上', '此致'),
}
for k, v in sections.items():
    n = len(re.sub(r'\s+', '', v))
    print(f'{k}: {n} 字')
```

单项突出表现 450~800 字；其他方面 150~250 字；结尾 60~100 字。任一项不达标 → 重写。

### 5.8 数据来源标注规范

涉及外部数据（市场规模、行业趋势、政策背景）须标注来源：
- ✅ "我国 5G 市场规模达 1.2 万亿元（工信部 2024 年统计公报）"
- ❌ "我国 5G 市场规模庞大"
- 申请人本人产生的数据（GPA/排名/获奖）无需标注来源
- 单项申请书以本人数据为主，外部数据 ≤3 处

### 5.9 表格标题与编号规范

每张表格上方须有标题，编号按出现顺序：
- "表 1 论文发表情况"（黑体五号，居中）
- "表 2 发明专利申请情况"
- "表 3 大创项目参与情况"
- 表格整体居中，表头加粗居中，数据居中
- 跨页表格须重复表头

### 5.10 数字与单位规范

- GPA："[X.XX]/4.0"（含基数）
- 排名："[N]/[N]"（含基数）
- 百分比："前 [X]%"（保留 1 位小数）
- 时长："[N] 小时"（不写"[N] h"）
- 金额："[N] 元"（不写"[N] 千"）
- 时间："[YYYY.MM]-[YYYY.MM]"（年.月-年.月）
- 学期："第 1 学期"（汉字数字+阿拉伯数字混排）

### 5.11 引用与参考文献规范

单项申请书一般不需参考文献。但若科研单项涉及具体方法引用：
- ✅ "提出 [你的方法名]（参照 [被引文献]），[指标] 较基线提升 [N] 个百分点"
- ❌ "采用先进的对比学习方法"
- 引用须用本人论文/专利的引用方式
- 不在申请书末尾列参考文献

## 六、4 个子方向撰写方法

### 6.1 科研单项撰写方法

**核心数据要求**：第一作者论文 1 篇（中文核心及以上）或发明专利 1 项或大创国家级立项（满足任一）。

**撰写结构**：
1. 总述句（30~50 字）："本学年科研工作围绕 XXX 方向展开，已发表 SCI 论文 1 篇、申请发明专利 1 项、主持国家级大创 1 项。"
2. 论文表：题目/期刊/级别（SCI/EI/中文核心/省级）/作者排序（第一/第二/通讯）/录用或见刊时间
3. 专利表：名称/类型（发明/实用新型）/申请号/状态（已授权/实质审查/受理）/发明人排序
4. 大创表：项目名/级别（国家级/省级/校级）/角色（主持/参与）/起止时间/产出
5. 科研小结（80~150 字）：研究内容（解决了什么问题）+研究方法（用了什么方法）+研究贡献（提升 N% 或新发现）+收获体会

**完整示例**（450 字）：

> ⚠️ **示例数据，不可照抄**：期刊名、影响因子、专利号、项目编号、样本量、准确率均为虚构占位，
> 必须替换为你真实持有的成果。论文与专利信息可在数据库中反查，编造即认定为材料造假。

"本学年科研工作围绕 [研究方向] 展开，已发表 [收录级别] 论文 [N] 篇、申请发明专利 [N] 项、主持 [项目级别] 大创 [N] 项。

### 6.5 子方向边界情况处理

**6.5.1 科研单项但论文为第二作者**：
- 第二作者论文需配合"导师指导+本人完成主要工作"说明
- 第一作者权重 30 分；第二作者降为 15 分；通讯作者等同第一作者

**6.5.2 社工单项但仅有志愿服务无学生干部职务**：
- 仅志愿服务时长 ≥80 小时亦可申报社工单项
- 履职亮点段重点写志愿服务典型事例

**6.5.3 文体单项但仅有校级获奖**：
- 校级一等奖及以上可申报；校级二等需配合训练年限 ≥5 年
- 国家级获奖直接达标；省级获奖需配合其他校级获奖

**6.5.4 进步单项但 GPA 提升幅度不足 0.5**：
- 若排名提升 ≥30% 可单独申报
- 若 GPA 仅提升 0.3~0.5，需配合具体进步方法说明

## 七、评审标准与打分维度

单项奖学金评审权重与校级奖学金显著不同：

### 7.1 评分细则

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 单项突出表现 | 70% | 该方向的具体成绩+数据+表格呈现 |
| 综合素质 | 20% | 学业基础+其他荣誉+生活作风 |
| 思想 | 10% | 政治面貌+党团活动+思想觉悟 |

### 7.2 单项突出表现评分（70%）

| 子方向 | 满分要点 | 加分项 |
|--------|----------|--------|
| 科研 | 论文 [N] 篇（30%）+专利 [N] 项（20%）+大创 [N] 项（20%） | [收录级别] 一区/通讯作者/[项目级别] 大创主持 |
| 社工 | 职务（20%）+活动 [N] 场（30%）+服务 [N] 人次（20%） | 校级优秀学生组织/服务特殊群体 |
| 文体 | 获奖 [N] 项（40%）+训练年限（15%）+团队贡献（15%） | [等级] 一等奖/独奏独唱/校队主力 |
| 进步 | GPA 提升 [X.XX]（35%）+排名提升 [N] 位（35%） | 进步方法可推广/带动班级 |

### 7.3 综合素质评分（20%）

- 学业基础：GPA 3.0+（10%）
- 其他荣誉：校级三好/优秀团员（5%）
- 生活作风：宿舍卫生/人际关系（5%）

学习进步单项的"学业基础"按本学年 GPA 评定（不重复计算提升幅度）。

### 7.4 思想评分（10%）

- 中共党员/预备党员：10 分
- 优秀团员/积极分子：8 分
- 共青团员：6 分
- 群众：5 分

党团活动加分：参加分党校培训+2 分；提交阶段汇报+1 分。

### 7.5 评分计算示例

以科研单项为例：
- 单项（70%）：SCI 论文 1 篇 30 + 发明专利 1 项 20 + 国家级大创 20 = 70 → 折算 49 分
- 综合（20%）：GPA 3.65 + 校级三好 + 文明宿舍 = 18 → 折算 3.6 分
- 思想（10%）：共青团员+分党校结业 = 8 → 折算 0.8 分
- 合计：53.4 / 60 = 89 分

### 7.6 一票否决项

- 本学年有挂科
- 本学年有违纪处分
- 单项数据造假（论文/专利/活动/获奖/GPA）
- 抄袭他人申请书
- 子方向与数据不匹配（如无任何论文却申请科研单项）
- 单项段落不足 450 字
- 附件证明不齐全（无论文录用通知/无获奖证书）

任一项触发 → 直接淘汰。

### 7.7 提分策略

- 科研单项已达上限 → 增加综合分（学生工作+志愿服务）
- 社工单项已达上限 → 增加学业分（GPA+主干课程）
- 文体单项已达上限 → 增加学业分与综合分
- 进步单项已达上限 → 强调方法可推广性（带动班级+1 分）

### 7.8 不同学校评分权重差异

| 学校类型 | 单项权重 | 综合权重 | 思想权重 |
|----------|----------|----------|----------|
| 多数高校 | 70% | 20% | 10% |
| 985/211 高校 | 60% | 25% | 15% |
| 省属高校 | 75% | 15% | 10% |

以学校下发的评审办法为准。若学校未明确，按 70/20/10 计算。

## 八、避坑指南与正反例

### 8.1 开头抒情堆砌

❌ "时光荏苒，岁月如梭。转眼间我已度过大学三年的美好时光。今天我怀着激动的心情，郑重地提出科研单项奖学金申请。"

✅ "我是 [学院全称] [专业全称] [年级]学生 [姓名]，特申请 [学年] 科研单项奖学金。本学年以第一作者在《[期刊全称]》发表 [收录级别] 论文 [N] 篇，主持 [项目级别] 大创 [N] 项。"

### 8.2 形容词代替事实

❌ "本学年科研能力突出，多次获奖，发表论文，取得丰硕成果。"

✅ "本学年以第一作者在《[期刊全称]》（[收录级别]）发表论文 [N] 篇，影响因子 [N]；申请发明专利 [N] 项（[状态]）。"

### 8.3 论文不写期刊级别与作者排序

❌ "本学年发表论文 1 篇。"

✅ "本学年以第一作者在《[期刊全称]》（[收录级别]，影响因子 [N]）发表论文《[论文题名]》。"

### 8.4 学生干部只写头衔不写履职

❌ "担任学院学生会主席，工作认真负责，深受同学好评。"

✅ "担任 [职务全称]（[起止年月]），组织 [活动名] 等大型活动 [N] 场，累计参与 [N] 人次；牵头建立 [平台/机制名]，覆盖 [模块 1]、[模块 2]、[模块 3] 等 [N] 个模块。"

### 8.5 文体获奖不写级别与角色

❌ "在文体活动中多次获奖，包括合唱比赛、钢琴比赛、运动会等。"

✅ "2025.05 [赛事全称] [等级]（[角色]，作品《[作品名]》）；[YYYY.MM] [赛事全称] [等级]（[角色]《[作品名]》）。"

### 8.6 GPA 提升不写基数与幅度

❌ "本学年学习成绩有显著进步，GPA 大幅提升。"

✅ "本学年 GPA 由 [X.XX]/4.0 提升至 [X.XX]/4.0（提升 [X.XX]），加权平均分由 [XX.X] 提升至 [XX.X]，专业排名由 [N]/[N] 提升至 [N]/[N]（提升 [N] 位）。"

### 8.7 把其他方向数据写满

❌ "本学年 GPA 3.92，专业排名第 1；主持国家级大创 1 项；担任学生会主席；获全国大学生艺术展演一等奖；志愿服务 120 小时。"（4 个方向都写，无重点）

✅ 单项段落聚焦科研：450 字科研数据 + 150 字其他方面简略。

### 8.8 单项段落不足 450 字

❌ "本学年科研方面，发表论文 1 篇，申请专利 1 项，主持大创 1 项。"（仅 30 字，无表格无展开）

✅ 总述+论文表+专利表+大创表+科研小结，合计 450~800 字。

### 8.9 结尾"恳请领导批准"

❌ "综上所述，本人在科研方面表现突出，完全符合科研单项奖学金的评选条件。恳请领导批准我的申请！"

✅ "以上是我本学年在科研方面的基本情况。无论结果如何，我都将以此为新的起点，继续努力。恳请评审委员会予以考虑。"

### 8.10 子方向与数据不匹配

❌ 无任何论文却申请科研单项；无任何文体获奖却申请文体单项；GPA 下降却申请学习进步单项

✅ 申请前核对子方向硬门槛；子方向自动判定逻辑：有论文→科研，有职务→社工，有文体获奖→文体，有 GPA 提升→进步。

### 8.11 单项段落无表格

❌ "本学年科研方面，发表论文 1 篇，申请专利 1 项，主持大创 1 项。"（仅文字，无表格，评审无法核对）

✅ 总述句后紧接表格（论文表/专利表/大创表），表格呈现题目、期刊、级别、作者排序等关键要素。

### 8.12 其他方面喧宾夺主

❌ 单项段落仅 200 字，其他方面 400 字（学业+竞赛+志愿服务+思想全写满）

✅ 单项段落 450~800 字，其他方面 150~250 字；其他方面不展开该方向数据。

### 8.13 子方向混搭申报

❌ 同时申报"科研单项"和"社工单项"（一个申请书不能跨方向）

✅ 一份申请书仅申报一个子方向；若有多个方向均突出，建议改申校级一等或国奖。

## 九、政治用语规范

### 9.1 全称规范

- "中国共产党"（不简写为"党"）

- "党的二十大"（不写"20 大"）

### 9.2 政治面貌写法

- 中共党员（正式党员）
- 中共预备党员
- 优秀团员/积极分子
- 共青团员
- 群众

### 9.3 党团活动表述

- ✅ "参加学院分党校第 8 期培训班（2024.09-2024.12）结业"
- ✅ "提交申请材料（2023.09），列为优秀团员/积极分子（2024.03）"
- ❌ "积极向党组织靠拢"（无具体行动）
- ❌ "时刻以党员标准要求自己"（评价句，非事实）

### 9.4 子方向相关规范用语

- 科研：避免"攻克世界难题""填补国内空白"等夸大表述；用"提出 X 方法""提升 N 个百分点"。
- 社工：避免"深受好评""群众基础好"等评价句；用"组织活动 X 场""服务 Y 人次"。
- 文体：避免"才华横溢""技艺精湛"等形容词；用"训练 X 年""获 Y 级奖 Z 项"。
- 进步：避免"突飞猛进""一日千里"等夸张；用"GPA 提升 X""排名提升 Y 位"。

### 9.5 党团活动按子方向取舍

- 科研单项：党团活动 1~2 句即可，重点在科研数据
- 社工单项：党团活动 2~3 句，与社工内容相辅相成
- 文体单项：党团活动 1 句即可，重点在文体成绩
- 进步单项：党团活动 1~2 句，重点在 GPA 进步

党团活动表述规范：参加分党校第 X 期培训班+结业时间；提交申请材料+列为积极分子时间；党团活动须有具体名称与时间，禁止"积极向党组织靠拢"等空话。

## 十一、质检清单

提交前逐项检查（22 项）：

1. 标题"X 单项奖学金申请书"按子方向填充正确

### 11.2 字数自动检查脚本

```python
import re
text = open('output.txt').read()
def extract(text, start, end):
    s = text.find(start); e = text.find(end)
    return text[s:e] if s >= 0 and e > s else ''
sections = {
    '开头': extract(text, '尊敬的', '一、'),
    '单项突出表现': extract(text, '一、', '二、'),
    '其他方面': extract(text, '二、', '以上'),
    '结尾': extract(text, '以上', '此致'),
}
limits = {'开头': (80, 120), '单项突出表现': (450, 800),
          '其他方面': (150, 250), '结尾': (60, 100)}
for k, v in sections.items():
    n = len(re.sub(r'\s+', '', v))
    lo, hi = limits[k]
    flag = '✓' if lo <= n <= hi else '✗'
    print(f'{flag} {k}: {n} 字（规范 {lo}~{hi}）')
```

输出示例：
- ✓ 开头: 105 字（规范 80~120）
- ✓ 单项突出表现: 520 字（规范 450~800）
- ✓ 其他方面: 180 字（规范 150~250）
- ✓ 结尾: 75 字（规范 60~100）

任一项 ✗ → 返回修改。

## 十二、学校差异处理

### 12.1 字数差异

- 标准版：800~1500 字
- 清华/北大：1000~2000 字（更详细）
- 部分省属高校：600~1200 字（更简洁）

### 12.2 称呼差异

- 多数学校："尊敬的学院领导、评审委员会："
- 少数学校："尊敬的领导："或"尊敬的评审委员会："

### 12.3 栏目顺序差异

- 标准版：单项 → 其他方面
- 部分学校：思想 → 单项 → 其他方面（思想单独成段）

### 12.4 子方向名称差异

- 科研单项：科研创新单项 / 学术研究单项
- 社工单项：社会工作单项 / 社会实践单项
- 文体单项：文艺体育单项 / 文化艺术单项
- 学习进步单项：学业进步单项 / 学习进步单项

### 12.5 金额差异

- 多数学校：500~2000 元
- 部分学校：300~1000 元
- 重点高校：1000~3000 元

撰写前必读学校下发的申报指南，把字数/称呼/栏目顺序/子方向名称/金额等差异标出，按学校模板调整。
