# 转正申请书 Skill

本 skill 处理"转正申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 政治审查质检。转正申请书是预备党员或预备团员在预备期满前，正式向党组织/团组织递交的总结预备期内表现并申请按期转正的正式文书。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐）。

---

## 一、适用场景与触发条件

**适用**：用户提到"转正申请书""转正申请""预备党员转正""党员转正""团员转正""预备期满转正"等关键词。

**递交时机与政治规范**：
1. **递交时间**：预备期满前一周至满一个月内主动递交，不得提前或延后。
2. **基本结构**：
   - 标题《转正申请书》，称呼《尊敬的党组织：》或《尊敬的团支部：》。
   - 第一段：明确预备期起止时间及提出按期转正申请。
   - 第二段：预备期内思想政治理论提高与理想信念巩固。
   - 第三段：预备期内专业学习、科研攻关、学生工作实绩。
   - 第四段：对自身缺点的认识、整改情况及不足之处。
   - 第五段：表态与决心（无论组织能否批准转正，均服从组织决定）。
   - 落款：申请人姓名与日期。
