# 十二、学校差异处理

> 从 `subskills/graduate-recommendation/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：用户指定了具体学校、需要适配格式时。

不同学校保研推免申请书模板有差异，按学校适配：

| 学校类型 | 模板差异 | 适配方式 |
|----------|----------|----------|
| 顶尖 985（清北复交） | 含英文个人陈述 | 增设英文 PS 段落 |
| 普通 985 | 标准模板 | 直接套用 |
| 211 院校 | 字数偏少（PS 500~800） | 调整字数区间 |
| 中科院系统 | 重视科研计划（PS 1500~2000） | 第三段扩展至 800 字 |
| 海外高校 | 纯英文 PS + CV | 不适用本 skill |

**5 校保研政策差异**：

| 学校 | GPA 门槛 | 英语门槛 | PS 字数 | 特色 |
|------|----------|----------|---------|------|
| 清华大学 | 前 5% | CET-6 ≥460 | 1000~1500 | 重视科研计划 |
| 北京大学 | 前 3% | TOEFL ≥100 | 1500~2000 | 重视方向匹配 |
| 复旦大学 | 前 10% | CET-6 ≥425 | 800~1200 | 重视综合素质 |
| 上海交大 | 前 5% | CET-6 ≥425 | 1000~1500 | 重视工程能力 |
| 浙江大学 | 前 10% | CET-6 ≥425 | 800~1500 | 重视交叉学科 |

**5 校特色适配要点**：

- **清华大学**：PS 第三段（研究生计划）扩展至 500~700 字，需含具体研究问题与技术路线；附件需附导师推荐信（强推）。
- **北京大学**：PS 字数偏长，三段比例 5:5:5，每段约 500 字；强调与拟申请导师的研究方向匹配度。
- **复旦大学**：PS 简洁，三段比例 4:4:2，第三段可只写 200 字；综合素质栏可加学生工作内容。
- **上海交大**：PS 中需突出工程能力与代码贡献，建议附件加 GitHub 项目链接。
- **浙江大学**：PS 重视跨学科潜力，可提交叉研究兴趣，附件加跨院选课证明。

**适配步骤**：
1. 优先用目标院校下发的官方模板
2. 按官方模板字段顺序重新组织本 skill 生成内容
3. 字数与栏目微调以官方要求为准
4. 检查官方是否有特殊栏目（如"获奖证明清单表""英语水平证明表"）
5. 本 skill 作为内容质量参考，不替代官方模板

**通用提醒**：
- 不同渠道（夏令营/预推免/九推）材料要求可能不同，按渠道官方指南为准
- 同一学校不同学院要求可能不同（如计算机学院 vs 软件学院），按学院指南为准
- 提交前 3 天完成，留出导师修改与盖章流转时间
- 电子版提交时按官方系统要求命名，不要使用默认文件名
