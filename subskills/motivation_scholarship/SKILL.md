# 国家励志奖学金申请书 Skill

本 skill 处理"国家励志奖学金申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 质检。国家励志奖学金面向家庭经济困难且品学兼优的本科生（5000 元），评审侧重学业 + 家庭经济困难。**硬门槛：必须先获得学校家庭经济困难认定**。仅处理"励志"，国家奖学金（8000 元）与校级奖学金请走其他 skill。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐，含家庭成员表与勤工助学经历）。

---

## 一、适用场景与触发条件

**适用**：用户提到"国家励志奖学金""励志奖学金""励志奖""励志奖学金申请书""5000 元奖学金""家庭经济困难奖学金"等关键词，且本人已获学校家庭经济困难认定。

**不适用**（需走其他 skill）：
- 国家奖学金（8000 元，侧重 GPA + 国家级竞赛 + 论文，不写家庭困难）→ 走国家奖学金 skill
- 校级一等奖学金（侧重纯学习）→ 走校级奖学金 skill
- 企业专项奖学金（侧重行业兴趣）→ 走企业奖学金 skill
- 助学金（侧重纯家庭困难，不要求学业排名）→ 走助学金 skill

**硬门槛**（任一不达标直接劝退）：
- **必须先获得学校家庭经济困难认定**（一般/困难/特别困难三级之一）
- 本学年无挂科、无违纪处分
- GPA 加权平均分 ≥80 或 GPA 3.0+/4.0（比国奖门槛低）
- 专业排名一般要求前 30%（部分学校放宽至前 50%）
- 家庭经济困难佐证材料齐全（建档立卡/低保/特别困难认定/家庭重大变故）

**子类型区分**：
- 励志 vs 国奖：励志重学业 + 家庭经济困难，国奖重学业 + 综合素质（不写家庭困难）
- 励志 vs 助学金：励志要求学业排名，助学金仅看家庭困难
- 励志 vs 校级：励志要家庭困难认定 + 学业双门槛，校级仅看 GPA

**触发后第一步**：核对硬门槛。若用户未获家庭经济困难认定，告知"励志奖学金必须先获学校家庭经济困难认定，建议先去学生处申请认定"。若 GPA <3.0 或排名 >50%，告知"评审侧重学业，建议改申助学金"。

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（10~14 轮对话）**：
按"通用必采 → 学业信息 → 家庭经济信息【重点】 → 勤工助学经历 → 荣誉经历 → 实践经历"顺序采集。每轮不超过 5 个字段。家庭经济信息是励志类核心，必须采集家庭年收入、供养人数、建档立卡/低保号、勤工助学岗位等数据，禁止编造家庭收入与困难认定等级。

**阶段 2 书信体撰写（一次性产出）**：
按"标题 → 称呼 → 开头 → 思想方面 → 学习方面 → 家庭经济情况【重点】 → 科研实践方面 → 生活方面 → 结尾 → 落款"顺序撰写。正文 1200~2000 字，家庭经济情况段落必须含具体数据（年收入/供养人数/勤工助学收入），与国奖申请书的关键差异在此段。事实 + 数据原则，禁止形容词堆砌，禁止用"家境贫寒""家徒四壁"等文学化表述。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十二章。家庭经济情况段落用表格呈现（家庭成员/关系/工作/年收入/政治面貌），勤工助学经历可用表格或列表。

**阶段 4 质检**：
按第十三章清单逐项检查。任何一项不达标返回阶段 2 修改。重点核对家庭经济情况段落的"3 类硬数据"是否齐全（年收入/供养/勤工助学）。

**禁止行为**：
- 开头抒情堆砌（"时光荏苒""岁月如梭""家境贫寒"）
- 家庭经济情况只写"困难"无数据
- 不写家庭经济困难认定等级
- 不写勤工助学经历（励志类核心佐证）
- 编造家庭收入、困难认定等级、建档立卡号
- 把国奖内容（国家级竞赛、SCI 论文）作为主要素材，弱化家庭经济
- 结尾"恳请领导批准"或"减轻家庭负担"等乞求式表述
- 学生干部只写头衔不写履职

## 三、信息采集清单

### 3.1 通用必采（10 字段）

| 字段 | 说明 | 示例 | 缺失追问策略 |
|------|------|------|--------------|
| name | 申请人姓名 | 李华 | "申请人全名？" |
| student_id | 学号 | 2022123456 | "学号？" |
| gender | 性别 | 男 | "性别？" |
| college | 学院全称 | 计算机科学与技术学院 | "学院全称？" |
| major | 专业全称 | 计算机科学与技术 | "专业全称？" |
| grade | 年级 | 2022 级 大三 | "入学年份与年级？" |
| class_name | 班级 | 计科 2201 班 | "班级？" |
| political_status | 政治面貌 | 共青团员 | "政治面貌？" |
| phone | 联系电话 | 138XXXXXXXX | "手机号？" |
| apply_year | 申报学年 | 2024-2025 学年 | "申报学年？" |

### 3.2 学业信息（硬指标，6 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| gpa | GPA | 3.65/4.0 |
| weighted_avg | 加权平均分 | 85.5 |
| rank | 专业排名 | 8/87（前 10%） |
| core_courses | 主干课程成绩 4~6 门 | [{name:"高等数学",credit:5,score:88},...] |
| cet4 | CET-4 成绩 | 510 |
| cet6 | CET-6 成绩 | 425（可选，无则不写） |

励志类学业门槛低于国奖：加权 ≥80 分、GPA ≥3.0/4.0、专业排名前 30% 即可，主干课程 4~6 门（少于国奖的 5~8 门）。

### 3.3 家庭经济信息【重点，9 字段】

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| hometown | 家庭所在地（精确到县） | XX 省 XX 县农村 | 是 |
| family_income_year | 家庭年收入（元） | 25000 | 是 |
| family_income_source | 收入来源 | 父亲务农 + 母亲零工 | 是 |
| difficulty_level | 困难认定等级 | 特别困难 / 困难 / 一般困难 | 是 |
| difficulty_cert_no | 困难认定编号 / 建档立卡号 / 低保号 | 建档立卡号 XXXXX | 是 |
| family_members | 家庭成员表 | [{name,relation,job,income,political},...] | 是 |
| dependents_count | 供养人数 | 4（父、母、妹、本人） | 是 |
| work_study | 勤工助学经历 | [{position,place,duration,income},...] | 是 |
| family_event | 家庭重大变故（可选） | 父亲 2023 年因病丧失劳动能力 | 否 |

### 3.4 勤工助学经历（励志类核心，每条 4 字段）

每条勤工助学经历：岗位 + 地点 + 时间 + 月收入。

示例：
- 图书馆管理员 校图书馆 2024.09-2025.06 月收入 400 元
- 食堂帮厨 校第二食堂 2024.03-2024.07 月收入 600 元
- 家教 校外 2024.10-2025.05 月收入 800 元

勤工助学经历是励志类区别于国奖的关键佐证，必须采集至少 1 条。

### 3.5 荣誉经历（按时间倒序）

每项荣誉 4 字段：时间（YYYY.MM）、奖项全称、级别（国家/省/校/院）、颁发单位。

励志类荣誉门槛低于国奖：校级奖学金、校级三好学生、优秀共青团员等校级荣誉即可，国家级竞赛非必需。

### 3.6 科研实践经历（弱化要求）

励志类弱化科研要求，但仍需采集以下信息（任一即可）：
- 学科竞赛（校级及以上均可，不必国家级）
- 大创/科研立项（校级即可，不必国家级）
- 学生干部职务 + 任期 + 履职数据
- 志愿服务总时长
- 三下乡/社会实践参与情况

### 3.7 字段优先级与追问话术

**P0 必采**（缺则无法撰写）：name、major、grade、gpa、rank、core_courses、family_income_year、difficulty_level、family_members、work_study
**P1 重要**（缺则影响质量）：political_status、cet4、dependents_count、family_income_source、hometown、honors
**P2 可选**（缺则用占位）：student_id、phone、cet6、family_event、research

追问话术示例：
- 用户说"我家庭经济困难"→ "家庭年收入大约多少？收入来源是什么？已获学校困难认定吗？哪个等级？"
- 用户说"我家建档立卡"→ "建档立卡号是多少？家庭所在地精确到县？"
- 用户说"我勤工助学"→ "什么岗位？在哪里？什么时间？月收入多少？"
- 用户说"我成绩不错"→ "GPA 是多少？加权平均分？专业排名（X/N）？"
- 用户说"我做过学生工作"→ "职务？任期？组织了什么活动？服务多少人？"

**复述确认**：所有信息采完后，按"学业/家庭经济/勤工助学/荣誉/实践"顺序复述给用户确认，再进入撰写阶段。家庭经济信息复述时必须把家庭年收入、供养人数、困难认定等级三个核心数据复述给用户核对。

## 四、书信体结构详解

励志奖学金申请书是书信体（非表格），整体结构：

```
标题：国家励志奖学金申请书（黑体二号居中）

称呼：尊敬的学院领导、评审委员会：（顶格，全角冒号）

开头（100~150 字）：
  身份 + 申报奖项 + 已获困难认定 + 学业核心数据 2 项 + 进入正文

一、思想方面（150~250 字）
  政治立场 + 入团/团情况 + 思想觉悟 + 具体活动

二、学习方面（250~350 字）
  GPA + 排名 + 主干课程表 + 英语等级 + 学习方法 1 句

三、家庭经济情况【重点，300~450 字】
  家庭基本信息 + 家庭年收入 + 供养情况 + 困难认定等级与编号
  + 家庭成员表 + 勤工助学经历 + 家庭重大变故（如有）

四、科研与实践方面（200~300 字，弱化科研）
  学生工作 + 志愿服务 + 竞赛/大创（不必国家级）

五、生活方面（120~200 字）
  生活作风 + 勤俭节约 + 人际关系

结尾（80~150 字）：
  事实总结 + 朴素表态 + "此致/敬礼！"

落款（右对齐）：
  申请人：XXX
  XXXX 年 XX 月 XX 日
```

### 4.1 标题

格式：黑体二号，居中，段前段后 12pt。

文本：固定为"国家励志奖学金申请书"（9 字），不要写"2025 年度国家励志奖学金申请书"——标题简洁有力，与学校模板保持一致。

### 4.2 称呼

格式：顶格（首行不缩进），宋体小四，加冒号。

文本：固定为"尊敬的学院领导、评审委员会："。冒号用全角"："（非半角":"）。

部分学校要求"尊敬的评审委员会："或"尊敬的学院领导："——按学校下发模板调整。

### 4.3 开头段落

字数：100~150 字，1 段。

句式 3 句结构：
1. 身份 + 申报奖项："我是 XX 学院 XX 专业 2022 级学生 XXX，特申请 2024-2025 学年国家励志奖学金。"
2. 困难认定 + 学业核心数据 2 项："本人已获学校家庭经济困难认定（特别困难等级），本学年 GPA X.XX/4.0，专业排名第 X/N。"
3. 进入正文："现将本人情况汇报如下："

禁止：抒情开头（时光荏苒/岁月如梭/感慨万千/家境贫寒）、感谢老师培养、回顾大学时光、强调"减轻家庭负担"等乞求式表述。

### 4.4 思想方面

字数：150~250 字，1~2 段。

要素 4 项（必须真实，党支部会向辅导员核实）：
- 政治立场：拥护党的领导、学习习近平新时代中国特色社会主义思想
- 入团/团情况：入团时间、优秀团员/积极分子培养阶段、共青团员
- 思想觉悟：党课学习次数、理论学习、时政关注
- 具体活动：主题党日、志愿服务、阶段汇报篇数

句式："作为一名中共党员/共青团员，我始终坚持……，积极参加……"

### 4.5 学习方面

字数：250~350 字，2~3 段。评审权重 40%。

要素 5 项：
1. GPA 表达："本学年 GPA 3.65/4.0，加权平均分 85.5，专业排名第 8/87（前 9.2%）"
2. 主干课程表（4~6 门，表格呈现，含课程名/学分/成绩）
3. 主干课程亮点描述："高等数学 88、数据结构 90、操作系统 87，专业核心课平均 88 分"
4. 英语等级："CET-4 510 分"（CET-6 可选，无则不写）
5. 学习方法（1~2 句，不要长篇）："注重课前预习与课后总结，建立知识体系"

励志类学业门槛低于国奖：加权 ≥80、排名前 30% 即可，主干课程允许 80~89 分占多数。

禁止：形容词堆砌、不写具体数据、写"成绩优异"。

### 4.6 家庭经济情况【重点】

字数：300~450 字，3~4 段。**励志类核心段，评审权重 30%**。

要素 5 项：

1. 家庭基本信息："我来自 XX 省 XX 县农村家庭"（精确到县，城乡属性写明）
2. 家庭年收入与来源："家庭年收入约 2.5 万元，主要来源为父亲务农 + 母亲零工"
3. 供养情况："供养我及妹妹 2 人读书，妹妹就读 XX 县一中高二"
4. 困难认定等级与编号："已获学校家庭经济困难认定（特别困难等级），建档立卡号 XXXXX"
5. 家庭成员表（表格，含姓名/关系/工作/年收入/政治面貌 5 列）
6. 勤工助学经历（列表或表格，含岗位/地点/时间/月收入 4 字段）
7. 家庭重大变故（如有）："2023.06 父亲因病丧失劳动能力，医疗支出累计 8 万元"

句式："我来自 XX 省 XX 县农村家庭，父亲 XX，母亲 XX，家庭年收入约 XX 万元。"

禁止：
- "家境贫寒""家徒四壁""生活拮据"等文学化表述
- 家庭年收入用"几千元""较低"等模糊词
- 不写困难认定等级（必须写明特别困难/困难/一般困难）
- 不写勤工助学经历（励志类核心佐证，至少 1 条）

### 4.7 科研与实践方面

字数：200~300 字，1~2 段。**弱化科研要求**，评审权重 20%。

要素 3 类：

**学生工作**：职务 + 任期 + 履职数据。例："担任班级学习委员（2024.09-2025.06），组织 5 次学习经验交流会，服务同学 30 余人次"。

**志愿服务**：时长 + 服务对象 + 频次。例："累计志愿服务时长 80 小时，参与三下乡 1 次，支教 8 课时"。

**学科竞赛/大创**（可选，校级即可）：竞赛全称 + 奖项 + 时间。例："2024.11 校级程序设计竞赛二等奖；2024.05 主持校级大创项目《XX》1 项"。

励志类不要求国家级竞赛或 SCI 论文，校级荣誉与日常学生工作即可。如确有国家级成果可写，但不应作为主体段。

### 4.8 生活方面

字数：120~200 字，1 段。

要素 3 项：
- 生活作风（勤俭节约、作息规律、自律）
- 勤俭具体表现（节俭开支、自购教材、利用图书馆等）
- 人际关系（团结同学、乐于助人，举 1 个具体例子）

句式："生活中我注重勤俭节约，每月生活费控制在 800 元以内，教材均通过二手或图书馆借阅获取。担任宿舍长期间，组织宿舍 6 次集体活动，宿舍连续两学期获评'文明宿舍'。"

励志类生活方面强调勤俭节约的具体表现，与家庭经济情况段呼应，但不要重复家庭收入数据。

### 4.9 结尾

字数：80~150 字，1 段。

结构 3 部分：
1. 事实总结："以上是我本学年的基本情况。"
2. 朴素表态："无论结果如何，我都将以此为新的起点，继续努力学习、自强不息，以实际行动回报学校与社会。"
3. 礼貌收尾："恳请评审委员会予以考虑。"
4. "此致"另起一行，空两格
5. "敬礼！"另起一行，顶格

禁止："完全符合""恳请领导批准""倍感荣幸""减轻家庭负担"等绝对化/乞求/抒情词。

### 4.10 落款

格式：右对齐，宋体小四。

文本：
```
                                              申请人：李华
```

## 五、各段落撰写规范

### 5.1 字数配比

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 开头 | 100~150 | 8% |
| 思想方面 | 150~250 | 13% |
| 学习方面 | 250~350 | 22% |
| 家庭经济情况 | 300~450 | 27% |
| 科研与实践 | 200~300 | 18% |
| 生活方面 | 120~200 | 8% |
| 结尾 | 80~150 | 7% |
| 合计 | 1200~2000 | 100% |

家庭经济情况段 + 学习方面段合计应占总字数 50% 以上（评审重点）。

### 5.2 句式规范

**事实句**（核心）："主语 + 动词 + 数据 + 时间/范围"
- ✅ "家庭年收入约 2.5 万元，供养我及妹妹 2 人读书"
- ✅ "本学年 GPA 3.65/4.0，专业排名第 8/87"

**禁止抒情句**：
- ❌ "时光荏苒，岁月如梭"
- ❌ "家境贫寒，生活拮据"
- ❌ "怀着感恩的心情"

**禁止评价句**：
- ❌ "我家庭经济十分困难"
- ❌ "我学习成绩优异"
- ❌ "我热心公益"

**慎用副词**：
- 禁用：特别/非常/极其/深感/深切/深刻/十分/格外
- 可用：曾/已/将/在/于（事实描述）

### 5.3 事实+数据原则

每段必须含 3 个以上可验证事实或数据：
- 思想方面：党课 X 次、阶段汇报 X 篇、志愿活动 X 次
- 学习方面：GPA X.XX、排名 X/N、主干课程 X 门 80+、CET-4 X 分
- 家庭经济：年收入 X 元、供养 X 人、困难等级 X、勤工助学 X 元/月
- 科研实践：学生工作 X 月、志愿 X 小时、竞赛 X 项
- 生活方面：月支出 X 元、宿舍评比 X 次、集体活动 X 次

无数据则不写——评审查不到证据等于没写。

### 5.4 段落衔接

段落之间用"在……方面""此外""同时"等过渡词，不要用"如下所示""现汇报如下""具体情况如下"等指代。

✅ "在思想方面，我……"
✅ "学习上，我……"
✅ "在家庭经济方面，我……"

❌ "现将学习情况汇报如下："
❌ "具体情况如下："
❌ "如下表所示："

### 5.5 时态与时间表达

- 过去事实用"已完成""已发表""已获得""已获认定"
- 持续状态用"担任""参与""供养"
- 时间格式统一为"YYYY.MM"或"YYYY 年 MM 月"
- 时间倒序排列（最近的在前）

### 5.6 段落字数自检

撰写完成后用脚本核对各段字数（脚本见第十二章 12.1 节），各段字数区间：开头 100~150、思想 150~250、学习 250~350、家庭经济 300~450、科研实践 200~300、生活 120~200、结尾 80~150。

### 5.7 高频词禁用清单

撰写完成后全文检索以下词汇，命中即修改：

- 抒情类：时光荏苒/岁月如梭/感慨万千/怀着激动/倍感荣幸/家境贫寒/家徒四壁/生活拮据
- 评价类：优异/突出/积极/热心/认真/刻苦/努力/深感/深切/深刻/十分困难/非常困难
- 程度类：特别/非常/极其/十分/格外
- 乞求类：恳请领导批准/恳请批准/无论如何/完全符合/减轻家庭负担
- 模糊类：若干/一定/相关/多次/部分/有些/较低/较少

### 5.8 段落首句规范

每段第一句必须是事实陈述句，不要用"在……方面，我……"以外的句式开头：

✅ "我来自 XX 省 XX 县农村家庭，家庭年收入约 2.5 万元。"
✅ "本学年 GPA 3.65/4.0，专业排名第 8/87。"
✅ "作为一名共青团员，我拥护中国共产党的领导。"

❌ "首先，我要感谢学校培养……"
❌ "说起大学三年，我有很多话想说……"
❌ "众所周知，国家励志奖学金是……"
❌ "我家境贫寒，自幼懂事……"（文学化开头）

## 六、家庭经济情况撰写方法

家庭经济情况段是励志类区别于国奖的核心段，评审权重 30%。撰写 5 要素：

### 6.1 家庭基本信息（必须精确到县）

✅ 标准表达：
> 我来自 XX 省 XX 县农村家庭，父亲李 XX 在家务农，母亲王 XX 身体不好长期服药。

❌ 错误表达：
> 我来自农村家庭。（无省份、无县市）
> 我家在西部某县。（"某"字让评审怀疑真实性）

城乡属性必须写明：农村 / 县城 / 地级市，不同属性对应不同困难认定标准。

### 6.2 家庭年收入数据（必须具体到元或万元）

✅ 标准表达：
> 家庭年收入约 2.5 万元，主要来源为父亲务农（年收入约 1.8 万元）与母亲零工（年收入约 0.7 万元）。

❌ 错误表达：
> 家庭年收入较低。（无数据）
> 家庭年收入几千元。（数据不合理，无法供养大学生）
> 家庭年收入约 5 万元。（5 万元家庭不属于困难，建议改申国奖）

**家庭年收入合理性区间**（参考多所高校困难认定标准）：
- 特别困难：< 2 万元/年
- 困难：2~4 万元/年
- 一般困难：4~6 万元/年
- > 6 万元：不符合励志奖学金困难认定要求

### 6.3 供养情况（必须含供养人数）

✅ 标准表达：
> 家庭需供养 4 人：父亲、母亲、本人（大学在读）、妹妹（XX 县一中高二在读）。妹妹学费与生活费年支出约 1.2 万元。

❌ 错误表达：
> 家里人口多。（无具体人数）
> 还有弟弟妹妹在读书。（无年龄/学段/学费数据）

**供养人数必须包含申请人本人**。若有兄弟姐妹同时读书，需写明学段与学费支出，强化"家庭负担重"的事实。

### 6.4 困难认定等级与编号

**必须写明 3 类信息**：
1. 困难认定等级：特别困难 / 困难 / 一般困难
2. 认定时间：如"2024.09 获学校家庭经济困难认定"
3. 佐证编号：建档立卡号 / 低保号 / 特困证号（任一即可）

✅ 标准表达：
> 本人于 2024.09 获学校家庭经济困难认定（特别困难等级），家庭为建档立卡贫困户（编号：XX 省 XX 县建档立卡户 XXXXXXXX）。

❌ 错误表达：
> 我已获家庭经济困难认定。（无等级）
> 我家是低保户。（无低保证号）
> 我家庭经济困难，符合申请条件。（无任何佐证）

**困难认定等级与励志奖学金匹配**：
- 特别困难：优先评审，重点考虑
- 困难：符合条件，正常评审
- 一般困难：部分学校要求 GPA 前 10% 才能申请

### 6.5 家庭成员表（必须用表格）

5 列固定格式：姓名 / 与本人关系 / 工作单位/职务 / 年收入（元）/ 政治面貌

| 姓名 | 与本人关系 | 工作单位/职务 | 年收入（元） | 政治面貌 |
|------|------------|---------------|--------------|----------|
| 李 XX | 父亲 | XX 县务农 | 18000 | 群众 |
| 王 XX | 母亲 | 在家（长期服药） | 7000 | 群众 |
| 李 X | 妹妹 | XX 县一中高二 | - | 共青团员 |
| 李华 | 本人 | XX 大学大三 | - | 共青团员 |

**填写规范**：
- 无收入成员（学生、丧失劳动能力者）：填"-"
- 政治面貌：群众/共青团员/中共党员/中共预备党员
- 姓名：父亲母亲可用"李 XX"部分隐去，避免隐私泄露
- 工作单位：务农写"XX 县务农"，外出务工写"XX 厂工人"

### 6.6 勤工助学经历（必须含月收入）

勤工助学是励志类的核心佐证，体现"自强不息"，必须采集至少 1 条。

✅ 标准表达：
> 入学以来积极参加勤工助学，累计月收入约 1600 元：担任校图书馆管理员（2024.09-2025.06，每月 400 元）；担任校第二食堂帮厨（2024.03-2024.07，每月 600 元）；担任校外家教（2024.10-2025.05，每月 600 元）。勤工助学收入用于覆盖教材费、生活日用品支出，减轻家庭负担。

❌ 错误表达：
> 积极参加勤工助学。（无岗位、无收入）
> 课余时间打工补贴家用。（无具体岗位）
> 勤工助学收入用于生活。（无金额）

**勤工助学经历表述必须含 4 要素**：岗位 + 地点 + 时间 + 月收入。多条经历列表呈现，最后用一句话总结用途。

### 6.7 家庭重大变故（可选，如有则必写）

家庭重大变故是励志类评审的重要加分项，包括：
- 家庭成员患重大疾病（写明病种、治疗时间、医疗支出）
- 家庭成员丧失劳动能力（写明时间、原因）
- 家庭主要经济来源中断（如父亲失业、家遇自然灾害）
- 单亲家庭（写明何时单亲、抚养情况）

✅ 标准表达：
> 2023.06 父亲因突发脑溢血住院治疗 3 个月，累计医疗支出约 8 万元，出院后丧失部分劳动能力，家庭收入骤减 60%。

❌ 错误表达：
> 家庭遭遇重大变故。（无具体事件）
> 父亲身体不好。（无病种、无医疗支出）

### 6.8 完整示例（家庭经济情况段 400 字）

> 三、家庭经济情况
>
> 我来自 XX 省 XX 县农村家庭，家庭年收入约 2.5 万元，主要来源为父亲务农与母亲零工。家庭需供养 4 人：父亲、母亲、本人（XX 大学大三在读）、妹妹（XX 县一中高二在读），妹妹学费与生活费年支出约 1.2 万元。本人于 2024.09 获学校家庭经济困难认定（特别困难等级），家庭为建档立卡贫困户（编号：XX 省 XX 县建档立卡户 XXXXXXXX）。

## 七、学习方面撰写方法

学习方面是励志类评审的"硬指标段"（权重 40%），但门槛低于国奖。撰写 4 要素：

### 7.1 GPA 表达

**必须 3 项齐全**：GPA 绝对值 + 加权平均分 + 专业排名。

✅ 标准表达：
> 本学年 GPA 3.65/4.0，加权平均分 85.5，专业排名第 8/87（前 9.2%）

❌ 错误表达：
> 学习成绩优异，名列前茅
> GPA 3.6（缺排名）
> 排名专业前十（缺基数 1/N）

**GPA 制度差异处理**：
- 4.0 制：写"3.65/4.0"
- 5.0 制：写"4.55/5.0"
- 百分制：写"加权平均分 85.5"

学校使用何种制度，按成绩单原始数据填写，不要换算。

### 7.2 主干课程展示

**选课原则**：4~6 门，专业核心课优先，分数 80+，含 1~2 门基础课（如高等数学）。励志类允许 80~89 分占多数（国奖要求 90+）。

**表格格式**（必须用表格）：

| 课程名称 | 学分 | 成绩 |
|----------|------|------|
| 高等数学（上） | 5 | 88 |
| 数据结构 | 4 | 90 |
| 操作系统 | 4 | 87 |
| 计算机网络 | 3 | 86 |
| 数据库原理 | 3 | 89 |

**描述句式**：表格后用 1~2 句话概括
✅ "高等数学 88、数据结构 90、操作系统 87，专业核心课平均 88 分，全部 80+。"

❌ "主干课程成绩如下表所示："（指代）
❌ "成绩优异，多门课程 80+。"（无数据）

### 7.3 英语等级

励志类不要求 CET-6，CET-4 ≥425 即可：
- ✅ "CET-4 510 分（2023.06）"
- ✅ "CET-6 460 分（2024.06）"（若有则写）
- 无证书：不写英语段，或写"具备基本英文文献阅读能力"

### 7.4 学习方法（1~2 句）

学习方面末尾用 1~2 句话讲学习方法，**不要长篇大论**：

✅ "学习上注重课前预习与课后总结，建立知识体系；遇到问题主动与老师、同学讨论。"

❌ "我学习刻苦努力，每天早起晚睡，泡在图书馆，是我大学生活的真实写照。"

### 7.5 与国奖的关键区别

| 维度 | 国家奖学金 | 国家励志奖学金 |
|------|-----------|----------------|
| GPA 门槛 | 3.7+/4.0 | 3.0+/4.0 |
| 加权平均分 | ≥85 | ≥80 |
| 专业排名 | 前 5% | 前 30%（部分学校前 50%） |
| 主干课程数 | 5~8 门 90+ | 4~6 门 80+ |
| CET-6 | 必须 ≥425 | 可选，CET-4 即可 |
| 科研要求 | 国家级竞赛/论文必需 | 校级即可，无强制 |
| 学习方法段 | 强调"独立思考" | 强调"勤勉自学" |

### 7.6 完整示例（学习方面 300 字）

> 二、学习方面
>
> 本学年 GPA 3.65/4.0，加权平均分 85.5，专业排名第 8/87（前 9.2%）。修读 12 门课程，9 门 80 分以上。主干课程成绩：
>
> | 课程名称 | 学分 | 成绩 |
> |----------|------|------|
> | 高等数学（上） | 5 | 88 |
> | 数据结构 | 4 | 90 |
> | 操作系统 | 4 | 87 |
> | 计算机网络 | 3 | 86 |
> | 数据库原理 | 3 | 89 |
>
> 高等数学 88、数据结构 90、操作系统 87，专业核心课平均 88 分，全部 80+。CET-4 510 分（2023.06），计算机二级 C 语言（合格）。学习上注重课前预习与课后总结，遇到问题主动与老师、同学讨论。

### 7.7 GPA 制度差异与转专业处理

- 4.0 制（多数 985/211）：直接写"3.65/4.0"
- 5.0 制（部分高校）：直接写"4.55/5.0"，不要换算成 4.0 制
- 百分制（部分老牌院校）：写"加权平均分 85.5"，并备注"百分制"
- 排名一定要写基数："8/87"而非"专业前十"
- 转专业学生：按现专业排名填写，注明"原 XX 专业转入，排名按现专业计算"

## 八、评审标准与打分维度

励志奖学金评审 4 维度（参考教育部《国家励志奖学金评审办法》与多所高校实施细则）：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 学业 | 40% | GPA 排名、主干课程、英语等级（门槛低于国奖） |
| 家庭经济 | 30% | 困难认定等级、家庭年收入、勤工助学、家庭变故 |
| 综合素质 | 20% | 学生工作、志愿服务、社会实践、竞赛 |
| 思想 | 10% | 政治面貌、入团情况、阶段汇报、党团活动 |

### 8.1 学业 40% 评分细则

- 排名前 5%：满分
- 排名前 10%：扣 3 分
- 排名前 20%：扣 8 分
- 排名前 30%：扣 15 分
- 排名 >30%：直接淘汰
- 主干课程 80+ 占比 ≥80%：满分
- CET-4 ≥425：基础分；CET-6 ≥425：加分
- 加权平均分 ≥85：加分

### 8.2 家庭经济 30% 评分细则

- 特别困难（建档立卡/低保/特困证）：满分
- 困难（家庭年收入 2~4 万，有困难认定）：85 分
- 一般困难（家庭年收入 4~6 万，有困难认定）：70 分
- 有家庭重大变故（医疗支出/丧失劳动能力）：加 5~10 分
- 勤工助学经历（≥1 条，含月收入）：加 5~10 分
- 无勤工助学经历：扣 10 分
- 无困难认定等级：直接淘汰

### 8.3 综合素质 20% 评分细则

- 校级学生干部 + 评优：85 分
- 班长/团支书 + 评优：80 分
- 志愿服务 ≥80 小时：满分
- 志愿服务 50~80 小时：80 分
- 三下乡参与 ≥1 次：加分
- 校级竞赛获奖：加分（国家级非必需）
- 文体特长（校级以上奖项）：加分

### 8.4 思想 10% 评分细则

- 中共党员：满分
- 优秀团员/积极分子（培养 1 年+）：85 分
- 共青团员 + 优秀团员：75 分
- 共青团员：60 分
- 阶段汇报 ≥4 篇/年：加分

### 8.5 评分计算示例

> 李华：学业 88 分×40% + 家庭经济 95 分×30% + 综合素质 80 分×20% + 思想 75 分×10%
> = 35.2 + 28.5 + 16 + 7.5 = 87.2 分

**提分策略**：
- 学业已达上限（排名前 10）→ 重点提家庭经济佐证（勤工助学+变故材料）
- 家庭经济已达上限 → 重点提综合素质（学生工作+志愿服务）
- 思想分普遍不高 → 入团是关键加分项

### 8.6 一票否决项

- 本学年有挂科
- 本学年有违纪处分
- GPA 排名 >30%（部分学校 >50%）
- 未获学校家庭经济困难认定（**励志类独有**）
- 家庭经济情况造假（收入/等级/编号）
- 抄袭他人申请书

任一项触发 → 直接淘汰，不再评审。

### 12.1 字数自动检查

```python
import re
text = open('output.txt').read()
def extract(text, start, end):
    s = text.find(start); e = text.find(end)
    return text[s:e] if s >= 0 and e > s else ''
sections = {
    '开头': extract(text, '申请书', '一、思想'),
    '思想': extract(text, '一、思想', '二、学习'),
    '学习': extract(text, '二、学习', '三、家庭'),
    '家庭经济': extract(text, '三、家庭', '四、科研'),
    '科研实践': extract(text, '四、科研', '五、生活'),
    '生活': extract(text, '五、生活', '此致'),
    '结尾': extract(text, '此致', '申请人'),
}
limits = {
    '开头': (100, 150), '思想': (150, 250), '学习': (250, 350),
    '家庭经济': (300, 450), '科研实践': (200, 300),
    '生活': (120, 200), '结尾': (80, 150),
}
for name, content in sections.items():
    n = len(re.sub(r'[\s\W]', '', content))
    lo, hi = limits[name]
    status = '✅' if lo <= n <= hi else '❌'
    print(f'{status} {name}: {n} 字（{lo}~{hi}）')
```

## 十三、学校差异处理

不同学校励志奖学金申请书模板有微调：

**字数差异**：多数学校要求 1200~2000 字，少数要求 1500~2500 字。按学校要求调整字数区间。

**称呼差异**：默认"尊敬的学院领导、评审委员会："，部分学校改为"尊敬的评审委员会："或"尊敬的学院领导："。

**栏目顺序**：极少数学校把"家庭经济情况"前移到"思想方面"后，或后移到"科研实践"后。按学校模板调整 build.py 调用顺序。

**家庭成员表列数**：默认 5 列（姓名/关系/工作/年收入/政治面貌），部分学校要求 6 列（增加"健康状况"）或 4 列（省略"政治面貌"）。

**字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。

**勤工助学表呈现**：表格（推荐，本 skill 默认）或列表文字。

**附件清单**：所有学校均要求附"家庭经济困难认定证明"（必备），部分学校还要求附"建档立卡证/低保证复印件""父母收入证明""医疗支出票据"（家庭变故者）。提醒用户在 docx 后附纸质材料。

适配流程：先问"学校下发的励志奖学金申请书模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按本 skill 默认处理。

**家庭经济情况段位置差异**：90% 学校要求放在"学习方面"后"科研实践"前；少数学校（如部分财经类院校）要求放在"思想方面"后，作为第二大段；个别学校要求附在末尾"补充说明"中。本 skill 默认放第三段。

本 skill 执行流程：触发 → 核对硬门槛（含困难认定）→ 信息采集（含家庭经济 + 勤工助学）→ 书信体撰写 → 调 build.py 生成 docx → 29 项质检 → 提交。
