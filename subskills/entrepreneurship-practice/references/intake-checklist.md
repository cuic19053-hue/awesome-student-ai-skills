# 三、信息采集清单

> 从 `subskills/entrepreneurship-practice/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要逐条向用户提问采集信息时。

| 字段 | 说明 | 示例 | 缺失追问策略 |

| leader_name | 负责人姓名（须与公司法定代表人或大股东一致） | 张三 | "负责人全名？是否为公司法人或大股东？" |
| leader_id | 负责人学号 | 202212345 | "学号？" |
| leader_major | 负责人专业 | 工商管理 | "专业全称？创业实践建议商科或交叉学科" |
| leader_grade | 负责人年级 | 2022 级 大三 | "入学年份与年级？" |
| leader_phone | 联系电话 | 138XXXXXXXX | "手机号？" |
| college | 学院全称 | 工商管理学院 | "学院全称？" |
| apply_date | 申报日期 | 2025 年 3 月 15 日 | "申报提交日期？" |

| register_date | 注册日期 | 2024 年 6 月 18 日 |
| register_capital | 注册资本（认缴 / 实缴） | 100 万元（实缴 30 万元） |
| legal_person | 法定代表人 | 张三 |
| company_type | 企业类型 | 有限责任公司 |
| registered_address | 注册地址 | 浙江省杭州市余杭区 XX 路 XX 号 X 室 |
| business_scope | 经营范围（精简） | 技术服务、软件开发、互联网信息服务 |

### 3.3 股权结构与团队（含薪资）

| 字段 | 说明 | 示例 |
|------|------|------|
| shareholders | 股东列表，每人：姓名 / 出资额（万元）/ 出资比例 / 出资形式 | 张三 60 万元 60% 货币；李四 25 万元 25% 货币；王五 15 万元 15% 技术 |
| equity_pool | 期权池预留比例 | 10%（员工激励） |
| team_members | 团队 4~6 人，含姓名 / 学号 / 专业 / 公司职务 / 联系方式 | 张三 CEO / 李四 CTO / 王五 CMO / 赵六 CFO / 孙七 COO |
| team_salary | 团队薪资情况（创业实践必填） | 全员暂领基本生活费 3000 元/月，正式融资后调整为市场价 70% |
| part_time_status | 兼职情况 | 全职 3 人、兼职 2 人（在校生） |

### 3.4 实际运营数据（10 字段，KPI 核心）

| 字段 | 说明 | 示例 |
|------|------|------|
| users_total | 累计用户数 | 5800 人 |
| users_active | 月活 / 周活 | 月活 2300 |
| gmv | GMV（成交总额） | 累计 GMV 86 万元 / 月均 GMV 9.5 万元 |
| revenue | 月营收 / 累计营收 | 月营收 8.2 万元 / 累计营收 73.8 万元 |
| arr | ARR（年化经常性收入） | ARR 约 98 万元 |
| mrr | MRR（月度经常性收入） | MRR 6.8 万元 |
| gross_margin | 毛利率 | 45% |
| repurchase_rate | 复购率 | 32%（30 日内复购） |
| churn_rate | 流失率 | 月流失率 8% |
| cac_ltv | CAC / LTV | CAC 12 元，LTV 56 元，LTV/CAC = 4.7 |

### 3.5 财务数据（3 年）

- 利润表 3 年：营业收入、营业成本、销售费用、管理费用、研发费用、财务费用、营业利润、净利润
- 现金流量表关键科目：经营性现金流净额、投资性现金流净额、筹资性现金流净额、期末现金余额
- 资产负债表关键科目：货币资金、应收账款、固定资产、无形资产、短期借款、应付账款、实收资本、未分配利润
- Burn rate（月度消耗）：8 万元/月
- Runway（资金可支撑月数）：12 个月
- 盈亏平衡点：月营收达 15 万元时毛利率覆盖固定成本

### 3.6 融资历史与计划

- 历史融资轮次：种子轮 / 天使轮 / Pre-A，每轮含时间、金额、估值、投资方、出让股权
- 本轮融资需求：金额、估值方法（DCF / 可比公司 / 成本加成）、出让股权、资金用途分解
- Term sheet 关键条款：估值类型（投前 / 投后）、清算优先权、反稀释条款、董事会席位、回购条款
- 战略投资人 / 财务投资人偏好

### 3.7 字段优先级

| 优先级 | 字段 | 缺失影响 |
|--------|------|----------|
| P0 必填 | project_name / leader_name / company_name / credit_code / register_date | 申报书无法生成 |
| P0 必填 | users_total / gmv / revenue / gross_margin | 运营数据空白，评审直接否决 |
| P0 必填 | shareholders / equity_pool / financial_3year / financing_history | 核心栏目空白 |
| P1 强烈建议 | team_members 含公司职务 / cac_ltv / arr_mrr / burn_runway | 评审会扣分 |
| P2 建议 | team_salary / part_time_status / social_benefit | 影响评分但可补 |
| P3 可选 | patent_status / ip_status / esg_metrics | 看学校模板是否要求 |

P0 缺失：必须追问到底，不允许"先放空"。P1 缺失：追问 2 次，仍无则用合理默认值并告知用户。P2/P3 缺失：1 次追问后无则跳过。

### 3.8 追问话术

| 场景 | 话术 |
|------|------|
| 公司未注册 | "公司尚未注册？请提供 6 个月以上实际运营证据：流水截图、用户合同、收入凭证" |
| 股权结构模糊 | "股东具体出资比例？是货币出资还是技术出资？是否预留期权池？" |
| 运营数据无依据 | "5800 用户数来自后台哪个统计口径？月活定义？复购率如何计算？" |
| 财务数据全整数 | "月营收 8 万的算法是？用户数 × 客单价？请给具体数" |
| 融资估值无方法 | "500 万估值是怎么算的？DCF / 可比公司 / 成本加成？" |
| Burn rate / Runway 缺失 | "月度消耗多少？现有资金能支撑几个月？Runway < 6 个月需立即融资" |
| 团队全兼职无说明 | "团队几位全职？几位在校兼职？薪资水平？是否缴纳社保？" |
| CAC/LTV 缺失 | "获客成本多少？LTV/CAC 比值？建议 ≥3 才健康" |

### 3.9 复述确认

全部采集完后，按申报书栏目顺序复述给用户："已采集所有信息，按申报书顺序复述：① 项目名称 ② 公司工商信息 ③ 股权结构 ④ 实际运营数据（5800 用户 / 月营收 8.2 万 / 毛利率 45%）⑤ 3 年财务 ⑥ 融资历史与本轮计划 ⑦ 团队组织 ⑧ 风险与社会效益 ⑨ 预期成果。请确认或补充修正。"

用户确认后才进入撰写阶段。任何字段"待定""之后再说"——必须当场追问，不允许留空。
