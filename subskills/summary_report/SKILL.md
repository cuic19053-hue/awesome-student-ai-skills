# 阶段汇报 / 思想汇报 Skill

本 skill 处理"阶段汇报/思想汇报"全流程：信息采集 → 规范化撰写 → docx 生成 → 政治与公文规范质检。思想与阶段汇报是学生向党团组织、导师或主管单位书面汇报一定时期内思想政治、专业学习、岗位工作与道德作风情况的正式文书。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐）。

> 使用方式（一句话）：把下面的"信息采集清单"尽量答全 → 由本 skill 撰写正文 → `python build.py --data data.json --out 阶段思想汇报.docx` 生成 docx。全流程无需用户懂排版。

## 一、适用场景与触发条件

### 1.1 适用

用户提到"阶段汇报""思想汇报""季度思想汇报""阶段总结""思想工作汇报"等关键词时触发。

**核心板块**：
1. **标题与称呼**：如《2026年第三季度思想汇报》或《项目阶段性进展与思想汇报》，称呼《尊敬的党组织：》或《尊敬的导师与组织领导：》。
2. **思想政治与理论学习**：对党的创新理论、时事热点的学习心得与政治觉悟提升。
3. **专业学习与科研工作**：阶段内学业成绩、科研课题、竞赛实践取得的实质成果。
4. **社会服务与日常作风**：群众基础、志愿服务、班级与社团履职表现。
5. **存在不足与改进方向**：客观看待自身缺点，提出明确的下一步改进措施。
6. **落款**：汇报人姓名与日期。

### 1.2 不适用（应走其他 skill）

| 场景 | 应改用 |
|---|---|
| 首次申请入团，尚未取得入团身份 | `youth_league_application`（入团申请书） |
| 预备党员/预备团员预备期满申请转正 | `youth_league_conversion`（转正申请书） |
| 申请入党（提交入党申请书） | 入党申请书类 skill（本仓库同族） |
| 项目结题报告、实验报告 | 技术/科研报告类，非书信体政治文书 |

判断口诀：**"汇报既有表现看本 skill，申请获得身份看申请类 skill"**。

### 1.3 触发后第一句话：前置确认（6 项硬门槛）

生成前**必须先确认**以下 6 项，任一缺失先追问，不得直接开写：

1. **文书类型**：思想汇报 / 阶段工作总结汇报 / 项目进展汇报？（决定必引理论段是否必须）
2. **呈交对象**：党组织 / 团支部 / 导师 / 主管部门？（决定称呼与落款）
3. **覆盖时段**：如"2026 年第三季度""入党积极分子考察期第 2 季度"？
4. **身份状态**：入党积极分子 / 预备党员 / 团员 / 群众？（决定是否必须写"以党员标准要求自己"）
5. **本阶段可写实的成果**：成绩排名、竞赛获奖、科研进展、任职履职（**至少 3 条实数据**，否则正文会空）
6. **是否需要手写**：多数支部要求本人手写提交，docx 仅作草稿底稿。

### 1.4 与其他文书的区别（一句话）

- 与**思想汇报**：本 skill 已含思想汇报子类型，无需另找 skill。
- 与**转正申请书**：转正有明确的"申请→批准"诉求和固定五段式，且提交时机受预备期约束；本 skill 是"汇报为主、不诉求审批"。
- 与**工作总结**：工作总结可带小标题、可量化考核，本 skill 保持书信体纯段落，不出现"综上所述/一是二是三是"以外的条列编号。

## 二、红线提示（生成前必读，违反任一项即退回重写）

### 2.1 政治表述必须准确，不得杜撰

理论名称、会议名称、政策表述**必须使用官方原词**，不得自造简称或拼接。例如不得把"习近平新时代中国特色社会主义思想"简写成"习近平新时代思想"。凡引用必核对官方通稿原文（详见 §七）。

### 2.2 不得出现消极、抱怨、功利化动机

红线词示例（命中即重写）：把入党/入团动机写成"为了评奖评优、保研加分、找工作方便"；抱怨组织、抱怨学校、抱怨同学；表达对学习或集体的消极情绪。

### 2.3 时间线不得前后矛盾

标题时段、正文所述事由时间、落款日期三者必须在同一时间轴上，且**落款日期不得早于正文所述最晚事件**。季度汇报落款一般取该季度末（如 Q3 → 09月30日）。

### 2.4 数据必须真实，不得虚构

成绩排名、获奖名称、志愿服务时长、任职职务等必须来自用户真实提供。**信息缺失时留占位或追问，绝不编造**。虚构成果一经提交即构成学术/政治诚信问题。

### 2.5 抄袭后果

思想汇报属组织考察材料，抄袭或全文代写（含机器全文生成后原样提交）一旦被支部发现，会被退回并影响考察评价。本 skill 产出的是**草稿底稿**，用户须用自己的语言复述、补充个人真实细节后手写提交。

## 三、工作流程总览

```
① 触发 → 前置确认 6 项（§1.3，缺则追问）
② 信息采集（P0 必采 → P1 重要 → P2 可选，§五）
③ 复述确认（把采集结果按结构复述给用户核对）
④ 选字数档（compact / standard / full，§4.2）
⑤ 逐段撰写（§六 结构 + §七 必引理论 + §八 规范）
⑥ 质检（§十 25 项；不达标回 ⑤ 重写对应段）
⑦ 生成 docx：python build.py --data data.json --out 阶段思想汇报.docx
⑧ 字数自检脚本复跑一次，交付用户校对
```

服务端/Agent 调用时同样按此顺序；②与⑤之间**不得跳过复述确认**。

## 四、类型与字数分级

### 4.1 三类常见用途

| 类型 | 典型标题 | 是否必写理论段 | 常见字数 |
|---|---|---|---|
| 思想汇报 | 《2026年第三季度思想汇报》 | 必写 | 1200~2000 |
| 阶段工作总结汇报 | 《2026年上半年学习工作总结汇报》 | 可弱化为一句 | 1000~1600 |
| 项目进展汇报 | 《XX项目阶段性进展汇报》 | 一般不写 | 800~1500 |

### 4.2 字数下限分级表（3 档）

| 档位 | 英文标识 | 中文字符下限 | 适用 |
|---|---|---|---|
| 精简 | `compact` | 1000 | 项目进展汇报、月报 |
| 标准 | `standard` | 1200 | 季度思想汇报（默认） |
| 完整 | `full` | 1800 | 年度总结、重点考察期汇报 |

### 4.3 字数自检脚本（生成后必跑）

```python
# 统计中文字符数（排除标点、空格、英文数字）
import re
text = open("阶段思想汇报.txt", encoding="utf-8").read()
n = len(re.findall(r"[\u4e00-\u9fff]", text))
print("中文字符数：", n)
assert n >= 1200, f"字数不足（{n}/1200），请补充实绩段与不足段"
```

> 注意：docx 内的 `paragraphs` 拼接后再统计；标题、称呼、此致敬礼、落款**不计入**正文下限。

### 4.4 字数不达标的处理

不达标时按以下优先级补：① 实绩段补量化细节（排名、时长、数量）→ ② 认识段补"从……到……"的认识变化 → ③ 不足段补具体改进措施与时间节点。**禁止用重复套话灌水**（如连续堆砌"不忘初心、牢记使命"而不落到自己的事）。

### 4.5 字数档与段落配比

| 段落 | standard（1200）占比 | 建议字数 |
|---|---|---|
| 开头导语 | ~10% | 100~130 |
| 思想政治与理论学习 | ~25% | 280~320 |
| 学习/科研/工作实绩 | ~35% | 400~450 |
| 社会服务与日常作风 | ~15% | 170~200 |
| 不足与改进 | ~15% | 170~200 |

## 五、信息采集清单

### 5.1 字段优先级

- **P0（必采）**：缺一不可，直接影响能否成文。
- **P1（重要）**：缺则正文偏空，须尽量追问。
- **P2（可选）**：有则增色，无则省略不写。

### 5.2 P0 字段清单（9 项，必采）

| 字段 | 说明 | 示例 |
|---|---|---|
| `title` | 标题（含时段） | 2026年第三季度思想汇报 |
| `salutation` | 称呼 | 尊敬的党组织： |
| `reporter_name` | 落款（含"汇报人："前缀） | 汇报人：李明 |
| `report_date` | 落款日期 | 2026年09月30日 |
| 身份状态 | 积极分子/预备党员/团员 | 入党积极分子 |
| 覆盖时段 | 起止 | 2026.07.01—2026.09.30 |
| 思想学习内容 | 本阶段读的书/学的理论/参加的党课 | 通读《党章》+ 参加支部党纪学习教育 |
| 至少 3 条实绩 | 学习/科研/工作 | 绩点 3.7、专业前 5%、省赛二等奖 |
| 至少 1 条不足 | 真实短板 | 理论联系实际不够、时间管理待改进 |

### 5.3 P1 字段清单（6 项，重要）

- 具体成绩数据（绩点/排名/均分）
- 科研或项目进展（课题名、阶段成果）
- 竞赛获奖（名称、级别、名次、时间）
- 担任职务与履职（班长/团支书/社团）
- 志愿服务（时长、项目）
- 群众评价或受助同学反馈

### 5.4 P2 字段清单（5 项，可选）

- 时政学习的具体文章/会议精神
- 一次印象深刻的支部活动
- 帮助同学的典型事例
- 阶段目标与计划
- 曾受表扬或批评的情况

### 5.5 信息采集追问话术

- "这次汇报覆盖哪一段时间？落款日期按季末还是报送当天？"
- "你目前是入党积极分子、预备党员还是团员？这会影响第一段怎么写。"
- "这一阶段最有分量的 2~3 件事是什么？尽量给数字，比如排名、时长、第几名。"
- "有没有哪一件事让你对理论/责任有了新的认识？"（用于认识段，避免空话）
- "自己觉得还有哪些不足？支部上次有没有提过什么意见？"

### 5.6 复述确认（生成前最后一步）

把采集结果按 §六 结构复述一遍给用户，例如：

> 我准备这样写：标题《2026年第三季度思想汇报》，称呼"尊敬的党组织"，第一段交代身份与时段，第二段写党纪学习教育与《党章》学习心得，第三段写绩点 3.7 / 专业前 5% / 省赛二等奖，第四段写班长履职与 32 小时志愿，第五段写理论联系实际不足并给整改计划，落款"汇报人：李明 / 2026年09月30日"。可以吗？

用户确认后再进入撰写。

## 六、书信体结构详解（逐段）

### 6.1 结构总览（5 段 + 落款）

```
标题（黑体二号居中）
称呼（顶格，全角冒号）
① 开头导语
② 思想政治与理论学习
③ 学习 / 科研 / 工作实绩（重点段）
④ 社会服务与日常作风
⑤ 存在不足与改进方向
此致（空两格）
敬礼！（顶格）
落款（右对齐：汇报人：XXX / 年 月 日）
```

### 6.2 标题

- 格式：`{时段}{文种}`，如《2026年第三季度思想汇报》。
- 不带书名号时也可，但全文统一；build.py 直接取 `title` 字段。
- 常见错误：标题含"我的"（《我的思想汇报》）——正式文书不加第一人称定语。

### 6.3 称呼

- 呈交党组织/团支部：`尊敬的党组织：` / `尊敬的团支部：`（全角冒号）。
- 呈交导师/主管部门：`尊敬的导师：` 或 `尊敬的学院党委：`。
- 顶格、独立成行、冒号必须是中文全角。

### 6.4 开头导语（100~130 字）

交代**身份 + 时段 + 汇报事由**三要素。模板：

> 自被确定为入党积极分子以来，在党组织的悉心培养和支部同志的热情帮助下，我时刻以党员标准严格要求自己。现将 2026 年第三季度在思想、学习、工作和作风方面的情况向党组织汇报如下。

- 身份状态要与 §1.3 确认一致（团员不能写"以党员标准"）。
- 不要一上来就堆口号。

### 6.5 思想政治与理论学习段（280~320 字）

必须落到**具体学了什么 + 有什么新认识**，而非罗列理论名。结构：

1. 本阶段学习了什么（《党章》/党纪学习教育/党的创新理论/会议精神）；
2. 结合自身的一个具体触动（一次党课、一次讨论、一件身边事）；
3. 认识上的提升（从"知道"到"认同"到"践行"）。
- 必引表述见 §七，且**至少一处落到自己的事**。

### 6.6 学习 / 科研 / 工作实绩段（400~450 字，重点）

**本段是整篇的含金量所在**，务必量化：
- 学习：绩点/排名/均分/课程难点突破；
- 科研：课题名 + 阶段产出（数据、代码、阶段结论）；
- 竞赛：赛事名 + 级别 + 名次 + 时间；
- 工作：职务 + 具体履职（组织了几次活动、多少人次）。
- 数据必须有来源、可核对；无数据则写"可靠的事实"（如"独立完成 XX 模块"）。

### 6.7 社会服务与日常作风段（170~200 字）

写群众基础与作风：志愿服务时长与项目、帮助同学的具体事例、是否主动承担集体事务。避免"乐于助人、团结同学"这类不可验证的套话，尽量给一个人名/一件事（可匿名化）。

### 6.8 存在不足与改进方向段（170~200 字）

- 不足要**真实且非致命**（如"理论联系实际不够""时间统筹能力待提升""面对困难有时急躁"），不写原则性政治问题。
- 每条不足配**可检验的改进措施 + 时间节点**：
  > 针对理论联系实际不够的问题，我计划今后每学一个理论观点，就结合一次课程设计或支部活动撰写一页学习心得，坚持到本学期末。

### 6.9 结尾与落款

- 致敬语固定：`此致`（另起一行空两格）+ `敬礼！`（另起一行顶格，带叹号）。
- 落款右对齐两行：`汇报人：XXX` 换行 `2026年09月30日`。
- 日期口径：与 build.py 一致使用阿拉伯数字、月份补零（如 `2026年09月30日`）；若支部明确要求汉字"二〇二六年九月三十日"，生成后手工替换。

## 七、必引理论表述清单（思想汇报类须覆盖）

### 7.1 党的创新理论（至少 1 处）

- 习近平新时代中国特色社会主义思想（**须写全称，不得简称**）
- 党的二十大精神 / 二十届三中全会精神（按当期实际会议更新）

### 7.2 党章相关内容（积极分子/预备党员建议引）

- 党章关于党员义务的规定（"贯彻执行党的基本路线和各项方针、政策"）
- 入党誓词（如为预备党员）

### 7.3 时政热点（须核对最新官方表述）

- 引用会议精神、领导人重要讲话时，**以新华社/人民日报通稿原文为准**；
- 党员/团员数据须引用中共中央组织部或共青团中央**最新年度统计公报**，不得使用过时数字；
- 不引用来源不明的网传表述。

### 7.4 理论表述自检脚本

```python
# 至少出现 1 个必引表述，且不出现自造简称
import re
text = open("阶段思想汇报.txt", encoding="utf-8").read()
required = ["习近平新时代中国特色社会主义思想"]
banned = ["习近平新时代思想", "习思想"]   # 自造简称示例
assert any(k in text for k in required), "缺少必引理论表述"
for b in banned:
    assert b not in text, f"出现自造简称：{b}"
print("理论表述检查通过")
```

## 八、撰写规范

### 8.1 事实 + 数据原则

每个观点后用事实或数据支撑；写不出数据就写可核对的事实。禁止"表现优异、成绩突出、深受好评"三连。

### 8.2 人称与时态

- 第一人称"我"，不用"本人"（除落款外全文统一"我"）。
- 时态为回顾式："本阶段我……""近三个月来我……"。
- 不使用"将继续努力"作为唯一表态，须落到具体动作。

### 8.3 标点与序号

- 正文不出现 Markdown 语法（`-`、`**`）——docx 需要纯文本段落。
- 确需分点时用"① ② ③"或"一是……二是……"，不用"1. 2. 3."（书信体忌阿拉伯列表）。
- 全角标点；引号用中文引号。

### 8.4 避免空话套话

把抽象表述换成自述体验。对照：

| 空话 | 改写 |
|---|---|
| 我的思想觉悟有了很大提高 | 学完党纪学习教育专题后，我第一次把"纪律"和日常实验数据记录规范联系起来 |
| 我积极参加社会实践活动 | 本季度我参加了 3 次图书馆志愿服务，累计 32 小时 |

### 8.5 段落衔接

段与段之间至少有一句逻辑过渡（"在抓好理论学习的同时，我也注重把功夫下在专业学习上"），避免 5 段各自孤立。

### 8.6 字数配比

按 §4.5 配比控制，写完后用 §4.3 脚本核对总字数。

## 九、避坑指南与正反例（10 条）

1. **杜撰理论简称** ❌"学习习思想" → ✅"学习习近平新时代中国特色社会主义思想"。
2. **时段与落款矛盾** ❌标题写 Q3、落款写 12月 → ✅ 落款取 09月30日。
3. **空话堆砌** ❌"不忘初心、牢记使命，砥砺前行，久久为功"连排 → ✅ 每句后落到自己的事。
4. **无数据** ❌"成绩名列前茅" → ✅"绩点 3.7，专业前 5%"。
5. **身份错位** ❌团员写"以党员标准严格要求自己" → ✅ 按实际身份表述。
6. **动机功利化** ❌"为了保研加分" → ✅ 写认识与责任。
7. **不足段写成自我表扬** ❌"我几乎没有缺点" → ✅ 给真实短板 + 整改措施。
8. **称呼/冒号错误** ❌"尊敬的党组织:"（半角冒号）→ ✅ 全角"："。
9. **加小标题** ❌正文用"一、思想政治方面"分节 → ✅ 纯段落书信体（除非用户要总结体）。
10. **机器腔太重** ❌全文排比对仗、无个人细节 → ✅ 至少 2 处只属于本人的具体细节。

## 十二、常见问题 FAQ

**Q1：思想汇报要手写吗？**
多数支部要求本人手写并签名。本 skill 产出 docx 草稿，用户誊抄并补充个人细节后提交。

**Q2：多久汇报一次？**
积极分子/预备党员一般每季度一次，重点考察期可能每月一次。以支部要求为准。

**Q3：可以和上一次汇报内容重复吗？**
不得整段照抄上一次。时段不同、实绩不同，理论上也应有认识深化。

**Q4：没有突出的成果怎么办？**
写"扎实完成的基础工作 + 认识提升"，如独立完成某个课程设计、坚持每周自习时长等，不要硬编。

**Q5：呈交导师而不是党组织，理论段还要写吗？**
可弱化为一句，重点放在科研/工作进展与改进计划（见 §4.1）。

**Q6：字数总是差一点？**
按 §4.4 优先级补实绩细节与整改措施，不要重复套话。
