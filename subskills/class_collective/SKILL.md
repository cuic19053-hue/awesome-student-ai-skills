# 班集体 / 团支部集体申报 Skill

本 skill 处理"先进班集体""优良学风班""五四红旗团支部""文明班级"四类集体申报全流程：信息采集 → 6 段结构撰写 → docx 生成 → 质检 → 答辩 PPT 框架。

**核心定位**：班集体申报是中国高校面向集体（非个人）的最高荣誉体系，由教育部、团中央、各级学联与各高校分层设立。先进班集体为校级综合性集体荣誉（年均获奖率约 5%~10%）；优良学风班侧重学习风气（部分高校称"学风建设先进班级"）；五四红旗团支部由团中央 1999 年发起、面向团支部（含团支委建制），侧重团建与思想引领；文明班级侧重文明素养与日常行为规范。四类集体申报均评审**本学年表现**（个别学校要求连续 2 学年），正文 3000~5000 字，由班长 / 团支书代表班级集体撰写，落款为"全体班委 + 班主任 / 辅导员"。

**输出文件**：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、5 维度量化表 + 班委建制表 + 班级荣誉表自动嵌入、落款含班主任 / 辅导员签字位）。

## §0 适用场景与定位

### 0.1 适用范围

**适用**：用户提到"班集体""班集体申报""先进班集体""优良学风班""五四红旗团支部""文明班级""优秀班集体""文明班集体""红旗团支部""班级申报""班级申请书""集体申报"等关键词，且申报主体为整个班级 / 团支部（不是个人）。

**四类集体荣誉定位对照**：

| 荣誉类别 | 评审主体 | 评审跨度 | 字数 | 主导维度 | 主办单位 |
|---------|---------|---------|------|---------|---------|
| 先进班集体 | 学生处 / 学工部 | 本学年 | 3000~5000 | 综合（思想 + 学风 + 活动 + 纪律 + 卫生 5 维度全优） | 学校（部分省级） |
| 优良学风班 | 教务处 / 学工部 | 本学年 | 3000~4500 | 学风（GPA + 及格率 + 竞赛获奖 + 考研率） | 学校教务系统 |
| 五四红旗团支部 | 团委 | 本学年 | 3000~4500 | 团建（团组织生活 + 团费 + 主题活动 + 团员发展） | 校团委（部分省级 / 国家级） |
| 文明班级 | 学生处 / 后勤 | 本学年 | 3000~4000 | 文明（宿舍卫生 + 课堂纪律 + 网络文明 + 道德品质） | 学校（部分市级） |

### 0.2 不适用场景（需走其他 skill）

- **个人评优**：三好学生 / 优秀学生 / 优秀团员 → 走 `outstanding_student` skill
- **个人奖学金**：国奖 / 励志 / 校级 / 单项 → 走对应奖学金 skill
- **个人毕业荣誉**：优秀毕业生 → 走 `outstanding_graduate` skill
- **社会实践团队**：三下乡 / 暑期社会实践 → 走 `three_rural` skill（团队获奖但非班集体建制）
- **学生组织 / 社团**：优秀学生会 / 优秀社团 → 不属班集体范畴，需走社团评优 skill（如有）
- **党支部 / 党小组**：先进党支部 / 优秀党小组 → 由党委组织，非团委或学工系统，本 skill 不适用

### 0.3 四类集体荣誉关系

中国高校集体荣誉体系中，四类班集体荣誉关系如下：

1. **先进班集体**：综合性最高集体荣誉，年均获奖率 5%~10%，需 5 维度全面优秀，部分省级（如江苏省"先进班集体"）会从校级中遴选推荐。
2. **优良学风班**：单维度专项荣誉，侧重学习风气与学业成绩，部分高校与先进班集体互不冲突（可同年兼得），但部分高校规定优良学风班为先进班集体的前置条件。
3. **五四红旗团支部**：团支部专项荣誉，由团中央 1999 年发起（团字号〔1999〕13 号），面向团支委建制完整的团支部，分国家级 / 省级 / 校级三档，校级由校团委组织评审。
4. **文明班级**：单维度专项荣誉，侧重文明素养与日常行为规范，部分高校将文明班级作为先进班集体的前置条件或同年度互斥。

**触发后第一步**：核对申报类别。若学校使用"先进班集体"称谓，标题与正文用"先进班集体申请书"；若申报优良学风班，标题与正文用"优良学风班申请书"并强化学风段；若申报五四红旗团支部，标题用"五四红旗团支部申请书"并强化团建段（团费 / 团组织生活 / 主题活动）；若申报文明班级，标题用"文明班级申请书"并强化文明段（宿舍 / 课堂 / 网络）。四类共用本 skill，通过 `collective_type` 字段统一处理。

### 0.4 评审周期与申报窗口

- **本学年评优**：次年 4-5 月启动，5 月底前提交，6 月初学院评审，6 月中公示
- **五四红旗团支部专项**：每年 4 月底至 5 月初启动（纪念五四运动节点），5 月 20 日前后提交
- **申报窗口期**：约 2-3 周，错过则等下一年度
- **同年度多奖**：同一班级同年度可同时申报先进班集体 + 优良学风班 + 五四红旗团支部（若分别由学工 / 教务 / 团委组织），但需分别提交，内容侧重不同
- **答辩评审**：先进班集体与五四红旗团支部校级及以上层级通常需班级代表（班长 / 团支书）现场答辩，文明班级与优良学风班多为材料评审

## §2 班级建设 5 维度量化体系（必加章节 2）

本 skill 的核心创新点：将班级建设拆解为 **思想 / 学习 / 活动 / 纪律 / 卫生** 5 维度，每维度量化打分，总分 100，写入申请书正文与量化表。**5 维度量化是本 skill 与其他评优 skill 的核心区别**——其他评优 skill 侧重个人 3 维度（思想 / 学习 / 身体），本 skill 侧重集体 5 维度。

## §3 6 段结构（必加章节 3）

班集体申报书采用 **6 段结构**，固定顺序，不可调换：

1. **班级概况**（300~500 字）—— 班级建制 / 班委组成 / 班主任 / 班级口号
2. **思想建设**（500~800 字）—— 党团建设 / 主题班会 / 思政成绩 / 青年大学习
3. **学风建设**（600~900 字）—— 平均 GPA / 及格率 / 竞赛获奖 / 考研率 / 学习互助
4. **班级活动**（500~800 字）—— 集体活动 / 文体活动 / 志愿服务 / 社会实践
5. **班级荣誉**（300~500 字）—— 集体荣誉 + 个人荣誉汇总 + 5 维度量化自评
6. **工作展望**（300~500 字）—— 不足反思 + 下学年目标 + 改进措施

### 3.1 第 1 段：班级概况（300~500 字）

**写作要点**：
- 开头固定句式："XX 学院 XX 专业 XX 班，成立于 XXXX 年 9 月，现有学生 XX 人，其中男生 XX 人、女生 XX 人，团员 XX 人、党员（含预备）XX 人、优秀团员/积极分子 XX 人。"
- 班主任 / 辅导员信息："班主任 XXX 老师（XX 学院 XX 系副教授），辅导员 XXX 老师"
- 班委建制：班长 / 副班长 / 学习委员 / 生活委员 / 文体委员 / 心理委员 + 团支书 / 组织委员 / 宣传委员（共 9~12 人）
- 班级口号 / 班训："班级口号：'XXX，XXX'，源自 XXXX，体现 XXX 精神。"
- 班级定位："本班以'XXXX'为建设目标，秉持'XXXX'的班风，本学年在思想、学习、活动、纪律、卫生 5 维度全面推进班级建设。"

**字数控制**：300 字版本精简到建制 + 班主任 + 班委 + 班训 4 项；500 字版本补充班级历史 + 班级定位 + 5 维度引言。

### 3.2 第 2 段：思想建设（500~800 字）

**写作要点**：
- 党团建设："本班共有团员 XX 人（占比 XX%）、党员（含预备）XX 人（占比 XX%）、优秀团员/积极分子 XX 人，本学年新发展团员 XX 人、推优评特 XX 人。"
- 主题班会 / 团日活动："本学年共开展主题班会 XX 次、主题团日 XX 次，覆盖'党史学习''国家安全''心理健康''职业规划'等主题，平均出勤率 XX%。"
- 青年大学习："青年大学习完成率学年累计达 XX%，连续 XX 期位列学院前 3。"
- 思政成绩："本班思政课（马原 / 毛概 / 形势与政策）平均成绩 XX 分，位列专业第 X。"
- 思想引领："本班开展'XX 主题'分享会 X 次、参观 XX 纪念馆 / 博物馆 X 次、观看 XX 影片 X 部，引导学生树立正确的世界观、人生观、价值观。"

**五四红旗团支部申报强化**：本段为五四红旗团支部申报的核心段，需扩充至 800~1000 字，补充团费缴纳（100% 缴纳率）、智慧团建系统维护（XX% 完成）、团员发展流程（XX 人积极分子 → XX 人发展对象 → XX 人预备党员）、推优评特情况（XX 人推优、XX 人入团）。

### 3.3 第 3 段：学风建设（600~900 字）

**写作要点**：
- 平均学分绩点："本学年班级平均学分绩点 X.XX/4.0，位列专业第 X，较上学年提升 X.XX；GPA ≥3.5 的同学 XX 人（占比 XX%），GPA ≥3.0 的同学 XX 人（占比 XX%）。"
- 课程及格率："本学年所有课程及格率 XX%，核心课程（高数 / 英语 / 专业课）及格率 100%，无重修。"
- 学科竞赛获奖："本学年班级同学在'挑战杯''互联网+''数学建模''英语竞赛'等学科竞赛中获国家级 XX 项、省级 XX 项、校级 XX 项，累计 XX 人次。"
- 四六级 / 计算机等级："英语四级通过率 XX%，六级通过率 XX%，计算机二级通过率 XX%。"
- 考研 / 就业情况（高年级适用）："考研报名 XX 人、上岸 XX 人（升学率 XX%），就业签约 XX 人（就业率 XX%）。"
- 学习互助："班级建立'学习互助小组' X 个，开展'一帮一'结对 XX 对，组织学习经验分享会 X 次，编制复习资料 X 套。"

**优良学风班申报强化**：本段为优良学风班申报的核心段，需扩充至 900~1200 字，补充每门核心课程平均分（高数 XX、英语 XX、专业课 XX）、学业预警学生帮扶记录（XX 名预警学生，帮扶后 XX 名脱警）、学习委员组织的学习打卡（XX 天打卡率 XX%）、班级学习公约。

### 3.4 第 4 段：班级活动（500~800 字）

**写作要点**：
- 集体活动："本学年共组织班级集体活动 XX 次，包括'迎新晚会''冬至包饺子''春季踏青''班级生日会'等，参与率平均 XX%。"
- 文体活动："班级组队参加校运动会，获男子 4×100 米接力第 X 名、女子跳远第 X 名；参加'校园十佳歌手'比赛，XX 同学获优胜奖；参加院篮球联赛，获第 X 名。"
- 志愿服务："全班同学注册志愿者 XX 人（占比 XX%），本学年累计志愿服务时长 XX 小时，参与'XX 公益''XX 支教''XX 社区服务'等项目。"
- 社会实践："寒暑假社会实践参与率 XX%，组建实践团队 X 支，赴 XX、XX 等地开展调研，撰写调研报告 X 份，获校级优秀团队 X 项。"
- 主题特色活动："班级打造'XX 主题'特色活动品牌，已连续开展 X 期，获学院官网 / 校团委公众号报道 X 次。"

### 3.5 第 5 段：班级荣誉（300~500 字）

**写作要点**：
- 集体荣誉："本学年班级获校级荣誉 X 项、院级荣誉 X 项，包括'XXXX 先进班集体''XXXX 优秀团支部''XXXX 文明宿舍楼'等。"
- 个人荣誉汇总："班级同学获国家级荣誉 X 项（含国家奖学金 X 人、国家级竞赛 X 人次）、省级 X 项、校级 X 项，累计 XX 人次。"
- 5 维度量化自评："依据本 skill §2 5 维度量化体系，本班自评如下：思想建设 XX 分、学习建设 XX 分、活动建设 XX 分、纪律建设 XX 分、卫生建设 XX 分，合计 XX 分，达到 XX 申报门槛（≥85 分）。"
- 突出亮点："班级获 XX 级 XX 荣誉为专业首个 / 学院首个，XXX 同学作为学生代表在 XX 大会发言。"

### 3.6 第 6 段：工作展望（300~500 字）

**写作要点**：
- 不足反思："回顾本学年，班级建设仍存在以下不足：① 学习互助覆盖面不够广，部分后进同学仍未脱警；② 班级特色活动品牌尚未成型；③ 团日活动形式较为单一。"
- 下学年目标："下一学年，班级将围绕'XXXX'建设目标，重点推进：① 学习维度冲刺 GPA 3.X；② 打造'XX 主题'特色活动品牌；③ 创新团日活动形式，引入沉浸式 / 实践式活动。"
- 改进措施："具体措施：① 建立'XX 制度'；② 设立'XX 基金'；③ 落实'XX 考核'。"
- 结语："本班全体师生将以本次申报为新的起点，珍惜荣誉、戒骄戒躁，争取在下一学年取得更大进步，恳请评审委员会予以批准。"

## §5 雷区 10 条（必加章节 5）

### 雷区 1：用个人评优模板套班集体申报

**错误**：将"我""本人""我的"贯穿全文。
**正确**：班集体申报必须用"本班""我班""全班同学""我们"作为主语，落款为"全体班委 + 班主任"。

### 雷区 2：5 维度量化数据造假

**错误**：5 维度量化自评全部满分或全部 90+，与班级实际数据脱节。
**正确**：5 维度量化必须有据可查，单项维度允许有不足（如卫生建设 13/15 比满分 15 更真实），总分控制在 85~92 分区间。

### 雷区 3：荣誉时间线混乱

**错误**：将本学年荣誉与上学年 / 大一荣誉混列，或时间顺序颠倒。
**正确**：严格按本学年（9 月至次年 6 月）荣誉列项，时间从早到晚排列，避免跨学年。

### 雷区 4：班级人数与硬门槛不符

**错误**：班级人数 <30 人（部分学校硬门槛），但仍申报先进班集体。
**正确**：申报前核对硬门槛（§1.3），班级人数 <30 人时应申报"小班集体"或"先进小组"专项。

### 雷区 5：四类荣誉申报内容雷同

**错误**：同年度申报先进班集体 + 五四红旗团支部，两份申请书内容 80% 相同。
**正确**：四类荣誉申报内容应有差异化侧重——先进班集体重综合、优良学风班重学业、五四红旗团支部重团建、文明班级重文明素养。同年度多奖时各申请书重复率 <40%。

### 雷区 6：缺少班主任 / 辅导员签字

**错误**：落款仅有班长 / 团支书签字。
**正确**：班集体申报必须含班主任 / 辅导员签字位（部分学校还要求学院副书记签字）。

### 雷区 7：数据前后矛盾

**错误**：§1 班级概况写 38 人，§3 学风建设写 35 人参加考试，§5 班级荣誉写 40 人次获奖。
**正确**：所有人数数据必须前后一致，建议先在 §1 班级概况确定班级总人数 N，后续所有数据以 N 为分母计算占比。

### 雷区 8：照搬网络模板未本地化

**错误**：直接照搬网络班集体申报模板，活动名称、荣誉名称与本校实际不符。
**正确**：所有活动名称、荣誉名称必须为本校实际名称（如"XX 大学 XX 学院第 X 届 XX 杯"），辅导员 / 班主任真实姓名。

### 雷区 9：5 维度量化未与正文呼应

**错误**：§5 班级荣誉段列出 5 维度量化自评分数，但 §2~§4 正文未对应展开。
**正确**：5 维度量化每一项分数必须在 §2（思想）/ §3（学习）/ §4（活动）/ 纪律段 / 卫生段中有对应数据支撑，正文与表格交叉印证。

### 雷区 10：答辩 PPT 与申报书脱节

**错误**：答辩 PPT 与申报书内容不一致，PPT 上数据申报书没有，申报书上数据 PPT 没体现。
**正确**：答辩 PPT 必须严格基于申报书内容，10 页 PPT 对应 6 段结构 + 封面 + 总结，所有数据与申报书一致。

## §7 build.py 接口说明（必加章节 7）

### 7.1 命令行接口

```bash
# 方式 1：使用 demo 数据生成示例文档
python build.py --demo --out demo.docx

# 方式 2：使用用户提供的数据生成正式文档
python build.py --data data.json --out output.docx

# 方式 3：同时指定字数版本（覆盖 data.json 中的 word_count_version）
python build.py --data data.json --out output.docx --word-count 5000
```

### 7.2 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `--demo` | 二选一 | 使用内置 DEFAULT_DATA 生成示例文档 |
| `--data` | 二选一 | 用户数据 JSON 文件路径 |
| `--out` | 是 | 输出 docx 文件路径 |
| `--word-count` | 否 | 字数版本（3000/4000/5000），覆盖 JSON 中的设置 |

### 7.3 输出格式标准

- **纸张**：A4（21.0 × 29.7 cm）
- **页边距**：上下 2.54 cm，左右 2.5 cm
- **标题**：黑体二号（22pt），居中
- **正文**：宋体小四（12pt），1.5 倍行距，首行缩进 2 字符
- **段落标题**：黑体小三（15pt），加粗
- **表格**：宋体五号（10.5pt），居中，表头加粗
- **落款**：右对齐，含班长 / 团支书 / 班主任签字位
- **页眉页脚**：页脚居中页码

### 7.4 输出文档结构

1. **封面**（首页）：标题（"XX 班集体申报书"）+ 班级全称 + 申报类别 + 申报日期
2. **正文 6 段**：班级概况 → 思想建设 → 学风建设 → 班级活动 → 班级荣誉 → 工作展望
3. **5 维度量化表**（嵌入 §5 班级荣誉段或附录）
4. **班委建制表**（嵌入 §1 班级概况段）
5. **班级荣誉表**（嵌入 §5 班级荣誉段）
6. **落款**：班长签字 + 团支书签字 + 班主任签字 + 学院盖章位 + 日期

### 7.5 错误处理

- JSON 字段缺失：报错并提示缺失字段名
- 字数版本非法：报错"word_count_version 必须为 3000/4000/5000"
- collective_type 非法：报错"collective_type 必须为 advanced_class/good_study_class/may_fourth_flag/civilized_class"
- 5 维度分数超限：报错并提示具体超限项
- 班级人数与硬门槛不符：警告（不阻塞生成）

## §8 质检清单（必加章节 8）

### 8.1 字数与结构质检

- [ ] 总字数在 3000~5000 字之间（与 word_count_version 一致）

## §9 集体答辩 PPT 框架（必加章节 9）

校级及以上先进班集体、五四红旗团支部需现场答辩（10 分钟陈述 + 5 分钟答辩），以下为 10 页 PPT 框架。

### 9.1 10 页 PPT 框架

| 页码 | 标题 | 内容要点 | 时长 |
|------|------|---------|------|
| P1 | 封面 | 班级全称 + 申报类别 + 班训 + 班主任 + 班长姓名 + 日期 | 30s |
| P2 | 班级概况 | 班级建制（人数 / 党团员 / 班委）+ 班训 + 班级定位 + 班级合影 | 1min |
| P3 | 思想建设 | 党团建设 + 主题班会 + 青年大学习 + 思政成绩（五四红旗团支部需扩充至 P3-P4 两页） | 1.5min |
| P4 | 学风建设 | 平均 GPA + 及格率 + 竞赛获奖 + 四六级 + 学习互助（优良学风班需扩充至 P4-P5 两页） | 1.5min |
| P5 | 班级活动 | 集体活动 + 文体活动 + 志愿服务 + 社会实践（配照片） | 1.5min |
| P6 | 班级荣誉 | 集体荣誉 + 个人荣誉汇总 + 荣誉墙照片 | 1min |
| P7 | 5 维度量化 | 5 维度雷达图 + 总分 + 维度单项得分 | 1min |
| P8 | 亮点展示 | 3 个班级亮点（特色活动 / 重大荣誉 / 突出个人） | 1min |
| P9 | 工作展望 | 3 不足 + 3 目标 + 3 措施 | 1min |
| P10 | 致谢 | "恳请评审委员会予以批准" + 班训 + 全体班委合影 | 30s |

### 9.2 答辩 PPT 制作要点

1. **数据可视化**：5 维度量化必须用雷达图展示，平均 GPA / 及格率用柱状图，荣誉时间线用时间轴
2. **照片占比**：每页至少 1 张班级活动照片，照片清晰、内容正面
3. **文字精简**：每页正文 ≤80 字，关键数据加粗放大
4. **配色统一**：建议使用学校 VI 色（如北大红、清华紫），全 PPT 配色不超过 3 种
5. **动画克制**：仅用淡入淡出，避免飞入、旋转等花哨动画
6. **节奏控制**：10 页 / 10 分钟，平均每页 1 分钟，P3-P5 重点段适当延长

### 9.3 答辩问题预判（10 大高频问题）

1. 你们班最大的亮点是什么？（答：5 维度量化 XX 分 + 特色活动品牌 + 重大荣誉）
2. 5 维度量化中哪个维度最弱？如何改进？（答：诚实承认最弱维度 + 具体改进措施）
3. 班级学习互助如何开展？（答：学习互助小组 X 个 + 一帮一结对 X 对 + 学习打卡）
4. 团日活动如何创新？（答：沉浸式 / 实践式 / 联合团日，举例说明）
5. 班级违纪 0 起是如何做到的？（答：班规 + 考核 + 班委带头 + 同学监督）
6. 宿舍卫生如何保持？（答：值日表 + 周检查 + 月评比 + 文明宿舍奖励）
7. 班委如何分工协作？（答：班委建制表 + 周例会 + 月总结 + 学期换届）
8. 班主任在班级建设中的作用？（答：思想引领 + 学业指导 + 心理关怀 + 资源对接）
9. 下一学年最重要的目标是什么？（答：1 个核心目标 + 量化指标 + 时间节点）
10. 与同专业其他班级相比，你们班的差异化优势？（答：差异化亮点，避免泛泛而谈）

### 9.4 答辩评分维度

| 评分维度 | 权重 | 评分要点 |
|---------|------|---------|
| 班级建设成效 | 40% | 5 维度量化数据 + 实际成效 |

## §10 写作流程（端到端）

### 10.1 流程概览

```
触发 skill → 核对 collective_type → 信息采集（21 项必填 + 8 项选填）
→ 5 维度量化自评 → 6 段正文撰写 → 选择字数版本
→ 调用 build.py 生成 docx → 质检清单 7 大项 → 输出可提交文档
→ （可选）生成答辩 PPT 框架
```

### 10.2 第 1 步：核对申报类别

询问用户申报的具体类别：
- "先进班集体"（advanced_class）
- "优良学风班"（good_study_class）
- "五四红旗团支部"（may_fourth_flag）
- "文明班级"（civilized_class）

若用户不确定，根据学院 / 学校通知判断：
- 学工部 / 学生处组织 → 先进班集体
- 教务处组织 → 优良学风班
- 团委组织 → 五四红旗团支部
- 学生处 / 后勤组织 → 文明班级

### 10.3 第 2 步：信息采集

按 §6.1 信息采集清单逐项询问用户，缺失字段用合理默认值填充（标注"待用户确认"）。

**信息采集话术示例**：
```
请提供以下班级基本信息：
1. 班级全称（如"计算机科学与技术 2023 级 1 班"）
2. 学院全称
3. 班级总人数 / 男生人数 / 女生人数
4. 团员人数 / 党员（含预备）人数
5. 班主任姓名 + 职称 + 所在单位
6. 班委建制（职务 + 姓名 + 任期，至少 5 人）
7. 5 维度量化自评（按 §2.2 标准逐项打分）
8. 班级核心数据（平均 GPA / 及格率 / 竞赛获奖 / 四六级通过率）
9. 6 段正文（可由本 skill 辅助生成）
10. 班级荣誉清单（集体 + 个人汇总）
```

### 10.4 第 3 步：5 维度量化自评

引导用户按 §2.2 标准逐项打分，计算 5 维度总分：
- 若总分 <85 分：提示"未达申报门槛，建议补强 XX 维度"
- 若总分 85~92 分：正常生成
- 若总分 >92 分：提示"5 维度量化数据可能偏高，建议复核避免造假嫌疑"

### 10.5 第 4 步：6 段正文撰写

按 §3 6 段结构逐段撰写：
- 每段先列写作要点（§3.1~§3.6）
- 根据用户数据填充量化指标
- 根据字数版本（§4）调整详略
- 五四红旗团支部 / 优良学风班需强化对应段落

### 10.6 第 5 步：调用 build.py

```bash
python build.py --data user_data.json --out output.docx --word-count 4000
```

### 10.7 第 6 步：质检

按 §8 质检清单 7 大项逐项检查，发现问题反馈用户修正。

### 10.8 第 7 步：输出与可选 PPT

- 输出可提交 .docx
- 若 defense_needed=true，按 §9 生成 10 页 PPT 框架（建议用户用 PowerPoint / WPS 完成）

## §15 历年申报常见问题

### 15.1 评审委员会反馈高频问题

1. **"5 维度量化数据缺乏支撑"**：建议每项量化得分在 §2~§4 正文有对应数据
2. **"班级特色不突出"**：建议打造 1~2 个特色活动品牌，避免泛泛而谈
3. **"班主任参与度不足"**：建议在 §1 / §6 段体现班主任具体指导（如"班主任 XX 老师每周参加班委会"）
4. **"答辩 PPT 与申报书脱节"**：建议答辩 PPT 严格基于申报书，避免新增数据
5. **"同年度多奖内容雷同"**：建议按 §14 差异化撰写

### 15.2 评审委员会淘汰高频原因

1. **5 维度总分 <85 分**：硬门槛淘汰
2. **班级违纪 0 起造假**：经核实有违纪记录
3. **班级人数 <30 人**：硬门槛淘汰
4. **数据前后矛盾**：班级人数 / GPA / 及格率等关键数据不一致
5. **缺少班主任签字**：格式不合格

- youth_league_application：个人申请，书信体
- class_collective：班集体申报，6 段结构（非书信体）

### 16.4 与 summary_report skill 的区别

- summary_report：个人阶段汇报，季度提交
