# 优秀毕业生申请书 Skill

本 skill 处理"优秀毕业生申请书"全流程：信息采集 → 4 年成长叙事撰写 → docx 生成 → 质检。优秀毕业生是本科生毕业前最高规格的综合荣誉，评审跨度为大学 4 年（与"优秀学生"一学年跨度不同），要求总结 4 年综合表现与毕业去向。支持省级与校级两种规格。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐、4 年 GPA 表与科研竞赛成果表自动嵌入）。

---

## 一、适用场景与触发条件

**适用**：用户提到"优秀毕业生""省优毕业生""校优毕业生""省级优秀毕业生""校级优秀毕业生""毕业生评优"等关键词，且本人应届毕业（大四下学期）。

**不适用**（需走其他 skill）：
- 优秀学生 / 优秀团员 / 文明大学生（一学年跨度，1500~2000 字）→ 走评优其他 skill
- 国家奖学金（一学年跨度，1200~2000 字，侧重本学年表现）→ 走 national_project_eval
- 保研推免申请书（侧重研究生申请，含推荐信）→ 走推免相关 skill

**省校规格区分**：
- 省级：规格高，配额 3%~5%，需校级优秀毕业生资格 + 学校择优推荐
- 校级：常规规格，配额 5%~10%，学院初审 + 学校终审
- 同一学生同年度可同时申报省校两级，但申请书须分别按规格调整数据展示

**硬门槛**（任一不达标直接劝退）：
- 大学 4 年加权 GPA ≥85 或 GPA 3.5+/4.0
- 4 年内无挂科、无违纪处分
- 已通过毕业论文/设计开题，且进入中期以上阶段
- 至少 2 项校级及以上荣誉（含奖学金、竞赛、三好学生等）
- 毕业去向明确（升学/就业/创业/西部计划/选调/留学，须有录取或签约证明）

**触发后第一步**：核对硬门槛与申报规格。若用户 GPA 不达 4 年综合门槛或无 2 项校级荣誉，告知"优秀毕业生评审侧重 4 年综合表现与毕业去向，建议补足荣誉后再申"。区分省校规格，省校分别出具。

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（10~15 轮对话）**：
按"通用必采 → 4 年学业信息 → 思想品德 → 科研创新 → 社会实践 → 综合素质 → 毕业去向"顺序采集。每轮不超过 5 个字段。关键缺失字段必须追问，禁止编造 GPA/排名/竞赛/论文/志愿服务时长/毕业去向。

**阶段 2 4 年成长叙事撰写（一次性产出）**：
按"标题 → 称呼 → 开头 → 思想品德 → 学业成绩 → 科研创新 → 社会实践 → 综合素质 → 结尾 → 落款"顺序撰写。正文 2000~3000 字，每段严格控制在规范区间。必须体现 4 年成长轨迹（不是简单罗列事项）。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十二章。

**阶段 4 质检**：
按第十三章 30 项清单逐项检查。任何一项不达标返回阶段 2 修改。

**禁止行为**：
- 开头抒情堆砌（"时光荏苒""岁月如梭""四年光阴转瞬即逝"）
- 形容词代替事实（"成绩优异""积极参加""全面发展"）
- 获奖不写级别与时间
- 学生干部只写头衔不写履职
- 4 年成长叙事变成按时间流水账
- 毕业去向一笔带过（"已保研至清华大学"）
- 结尾"恳请领导批准"
- 编造 GPA/排名/竞赛/论文/志愿服务时长/毕业去向

### 3.1 通用必采（12 字段）

| 字段 | 说明 | 示例 | 缺失追问策略 |

| student_id | 学号 | 2021123456 | "学号？" |
| gender | 性别 | 男 | "性别？" |
| college | 学院全称 | 计算机科学与技术学院 | "学院全称？" |
| major | 专业全称 | 计算机科学与技术 | "专业全称？" |
| grade | 年级 | 2021 级 大四 | "入学年份？" |
| class_name | 班级 | 计科 2101 班 | "班级？" |
| political_status | 政治面貌 | 中共党员 | "政治面貌？" |
| phone | 联系电话 | 138XXXXXXXX | "手机号？" |
| apply_level | 申报规格 | provincial / school | "省级还是校级？" |
| apply_year | 毕业年份 | 2025 届 | "毕业年份？" |
| apply_date | 申报日期 | 2025 年 5 月 20 日 | "申报日期？" |

### 3.2 4 年学业信息（硬指标，10 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| gpa_4yr | 大学 4 年加权 GPA | 3.85/4.0 |
| weighted_avg_4yr | 4 年加权平均分 | 90.5 |
| rank_4yr | 4 年综合专业排名 | 1/87 |
| yearly_gpa | 分学年 GPA 列表 | [{year:"大一",gpa:"3.6",weighted:"85.2",rank:"5/87"},...] |
| core_courses | 主干课程成绩 5~8 门 | [{name:"数据结构",credit:4,score:92},...] |

| cet6 | CET-6 成绩 | 542 |

| scholarship_summary | 4 年奖学金汇总 | 国家奖学金 1 次、校级一等奖学金 3 次 |

### 3.3 思想品德信息

**入团轨迹**：递交申请书时间、列为优秀团员/积极分子时间、转预备党员时间、转正时间。每个节点须有具体日期。

**学生干部经历**（按时间正序）：职务、任期、履职数据（组织活动数、服务人次、推动的具体成果）。

**荣誉列表**（按时间倒序）：时间、奖项全称、级别（国家/省/校/院）、颁发单位。

### 3.4 科研创新信息

**大创/科研立项**（每个）：项目名称、级别（国家级/省级/校级）、角色（负责人/参与）、起止时间、产出（论文/专利/系统/报告）。

**论文**（含期刊级别、作者排序）：题目、期刊名、级别（SCI/EI/中文核心/普刊）、作者排序（第一/第二/通讯）、录用或见刊时间、影响因子（如有）。

**专利**：名称、类型（发明/实用新型/外观）、申请号、状态（受理/授权）、本人排序。

**学科竞赛**（每个）：竞赛全称、奖项（国家一等奖/国家二等奖/省级一等奖）、时间、角色（队长/队员）、参赛规模（如 12000 队参赛）。

### 3.5 社会实践信息

- 学生干部职务 + 任期 + 履职数据
- 志愿服务总时长（小时）+ 主要服务对象
- 三下乡/社会实践参与次数、地点、角色
- 实习经历（单位/岗位/时长/产出）

### 3.6 综合素质信息

- 文体特长（乐器/体育/书法/演讲等）+ 等级证书 + 比赛/演出经历
- 班级评价（同学关系、宿舍文明）
- 兴趣爱好（与综合素质相关的，不要堆砌）

### 3.7 毕业去向信息（必填）

| 类型 | 必填字段 | 示例 |
|------|----------|------|
| 升学（保研/考研） | 录取学校、学院、专业、方向 | 清华大学计算机科学与技术系，人工智能方向 |
| 就业 | 签约单位、岗位、城市 | 字节跳动，后端开发工程师，北京 |
| 创业 | 项目名称、注册公司、领域 | "智学科技"，XX 信息技术有限公司，AI 教育 |
| 西部计划/选调 | 服务地、岗位 | 新疆维吾尔自治区 XX 县，基层治理 |
| 留学 | 录取学校、专业、学位 | 卡内基梅隆大学，计算机科学，硕士 |

### 3.8 字段优先级与追问话术

**P0 必采**（缺则无法撰写）：name、major、grade、gpa_4yr、rank_4yr、yearly_gpa、political_status、competitions、destination
**P1 重要**（缺则影响质量）：party_history、position_history、research_projects、papers、volunteer_hours、talent
**P2 可选**（缺则用占位）：student_id、phone、internship、toefl

追问话术示例：
- 用户说"我成绩不错"→ "4 年加权 GPA？4 年综合专业排名（X/N）？分学年 GPA 各是多少？"
- 用户说"我参加过科研"→ "什么项目？负责人还是参与？多长时间？产出什么？"
- 用户说"我发表过论文"→ "题目？期刊名？期刊级别（SCI/EI/核心）？你是第几作者？"
- 用户说"我担任过学生干部"→ "职务？任期？组织了什么活动？服务多少人？"
- 用户说"我毕业保研了"→ "录取学校全称？学院？专业方向？导师联系了吗？"

**复述确认**：所有信息采完后，按"学业/思想/科研/实践/素质/去向"顺序复述给用户确认，再进入撰写阶段。

## 四、书信体结构详解

优秀毕业生申请书是书信体（非表格），整体结构：

```
标题：省级优秀毕业生申请书 / 校级优秀毕业生申请书（黑体二号居中）

称呼：尊敬的领导：（顶格，全角冒号）

开头（150~200 字）：
  身份 + 申报规格 + 4 年综合数据 3 项 + 毕业去向 + 进入正文

一、思想品德（300~400 字）
  政治面貌 + 入团轨迹 + 学生干部履职 + 荣誉

二、学业成绩（400~600 字，重点）
  4 年加权 GPA + 专业排名 + 分学年 GPA 表 + 英语计算机等级 + 奖学金汇总

三、科研创新（400~600 字）
  大创/科研立项 + 论文 + 专利 + 学科竞赛表

四、社会实践（300~500 字）
  学生工作 + 三下乡/志愿服务 + 实习经历

五、综合素质（200~300 字）
  文体特长 + 班级评价 + 兴趣爱好

结尾（80~150 字）：
  4 年成长总结 + 毕业去向呼应 + 朴素表态 + "此致/敬礼！"

落款（右对齐）：
  申请人：XXX
  XXXX 年 XX 月 XX 日
```

### 4.1 标题

格式：黑体二号，居中，段前段后 12pt。

文本：根据规格动态填充——省级填"省级优秀毕业生申请书"（9 字），校级填"校级优秀毕业生申请书"（9 字），不要写"2025 届省级优秀毕业生申请书"。标题简洁有力，与学校下发模板保持一致。

### 4.2 称呼

格式：顶格（首行不缩进），宋体小四，加冒号。

文本：固定为"尊敬的领导："。冒号用全角"："。部分学校要求"尊敬的评审委员会："或"尊敬的学院领导、评审委员会："——按学校下发模板调整。

### 4.3 开头段落

字数：150~200 字，1 段。

句式 3 句结构：
1. 身份 + 申报规格："我是 XX 学院 XX 专业 2021 级学生 XXX，特申报 2025 届省级/校级优秀毕业生。"
2. 4 年综合数据 3 项："大学 4 年加权 GPA 3.85/4.0，专业排名第 1/87；主持国家级大创 1 项，以第一作者发表 SCI 论文 1 篇；保研至清华大学计算机系。"
3. 进入正文："现将大学四年情况汇报如下："

禁止：抒情开头（时光荏苒/岁月如梭/四年光阴转瞬即逝/感慨万千）、感谢母校培养、回顾大学时光、套用"白驹过隙"等成语。

### 4.4 一、思想品德（300~400 字）

撰写要点：
1. 政治面貌与入团轨迹（如适用）：递交申请书时间、列为优秀团员/积极分子时间、转预备党员时间。每节点带具体日期。
2. 学生干部履职：至少 1 段，含职务、任期、组织活动数、服务人次、推动的具体成果。
3. 思想觉悟：结合本人参加的党课、主题党日、理论学习活动，不要空喊口号。
4. 荣誉列表：三好学生、优秀团员、优秀学生干部等（与科研类荣誉区分，科研类放在第三段）。

正面示例（约 80 字）：
> 大一递交申请材料，2023.03 列为优秀团员/积极分子，2024.06 转为中共预备党员。担任班级团支书 4 学期，组织主题团日活动 12 场，覆盖同学 600 余人次，所在团支部获评 2024 年度校级五四红旗团支部。

反面示例：
> 我思想进步，积极向党组织靠拢。担任学生干部期间工作认真负责，深受师生好评。（无具体时间节点、无履职数据）

### 4.5 二、学业成绩（400~600 字，重点）

撰写要点：
1. 4 年加权 GPA 与专业排名：大学 4 年加权 GPA X.XX/4.0，加权平均分 XX.X，专业排名 X/N（前 X.X%）。
2. 分学年 GPA 表（必填表格）：学年/GPA/加权平均分/排名 4 列，体现 4 年成长轨迹。
3. 主干课程亮点：列举 3~5 门 90+ 课程。
4. 英语计算机等级：CET-4、CET-6、计算机等级。
5. 奖学金汇总：4 年获国家奖学金 X 次、校级一等奖学金 X 次等。
6. 毕业论文/设计：题目 + 进展 + 导师（一句话即可）。

分学年 GPA 表示例：
| 学年 | GPA | 加权平均分 | 专业排名 |
|------|-----|-----------|----------|
| 大一 | 3.60 | 85.2 | 5/87 |
| 大二 | 3.80 | 88.5 | 3/87 |
| 大三 | 3.90 | 91.0 | 1/87 |
| 大四 | 3.95 | 92.5 | 1/87 |

### 4.6 三、科研创新（400~600 字）

撰写要点：
1. 大创/科研立项：项目名称、级别、角色、起止时间、产出（含可量化数据）。
2. 论文：题目、期刊名、级别（SCI/EI/中文核心）、作者排序、录用或见刊时间。多篇用列表。
3. 专利：名称、类型、申请号、状态、本人排序。
4. 学科竞赛：竞赛全称、奖项、时间、角色。多个用表格。

科研创新成果表示例：
| 类别 | 名称 | 级别 | 角色 | 时间 |
|------|------|------|------|------|
| 大创 | 分布式光伏故障智能诊断系统 | 国家级 | 主持 | 2024.03-2025.03 |
| 论文 | 基于对比学习的法律问答系统 | SCI | 第一作者 | 2025.03 见刊 |
| 竞赛 | 全国大学生数学建模竞赛 | 国家二等奖 | 队长 | 2025.05 |

禁止：
- "首次""先进""填补空白"等无支撑词
- 论文不写期刊级别
- 竞赛不写奖项级别
- 大创不写角色（主持 vs 参与）

### 4.7 四、社会实践（300~500 字）

撰写要点：
1. 学生工作：学生干部职务、任期、履职数据。
2. 三下乡/志愿服务：参与次数、地点、角色、服务时长、服务对象。
3. 实习经历：单位、岗位、时长、产出（用 1~2 句话）。

正面示例（约 120 字）：
> 大学 4 年累计志愿服务时长 320 小时。参与三下乡 2 次：2023.07 赴云南怒江开展教育扶贫支教 14 天，授课 32 课时；2024.07 赴甘肃定西开展电商助农调研，撰写调研报告 1 份（约 1.5 万字）。2024.07-2024.09 在字节跳动实习，参与推荐系统优化项目，提升 CTR 3.2%。

### 4.8 五、综合素质（200~300 字）

撰写要点：
1. 文体特长：乐器、体育、书法、演讲等，含等级证书与比赛/演出经历。
2. 班级评价：同学关系、宿舍文明、班级集体荣誉。
3. 兴趣爱好：与综合素质相关的，不堆砌。

禁止：纯抒情（"我兴趣广泛，热爱生活"），用具体经历代替。

### 4.9 结尾（80~150 字）

句式 3 句结构：
1. 4 年成长总结："以上是我大学四年的成长汇报。"
2. 毕业去向呼应："即将前往清华大学攻读研究生，我将带着母校的教诲继续努力。"
3. 朴素表态："无论评选结果如何，我都将以优秀毕业生的标准严格要求自己。"

加固定格式：
> 此致
> 敬礼！

禁止：
- "恳请领导批准"
- "完全符合评选条件"
- "深感母校培养之恩"等抒情

### 4.10 落款

格式：右对齐，宋体小四。

文本：
> 申请人：XXX
> XXXX 年 XX 月 XX 日

日期用阿拉伯数字（与全文统一），不要中文大写。

### 4.11 整篇范文结构示例

以下是省级优秀毕业生申请书的完整结构示意（仅展示段落骨架，实际字数需达 2000~3000 字）：


## 五、各段落撰写规范

### 5.1 字数配比

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 标题 + 称呼 | 不计 | — |
| 开头 | 150~200 | 7% |
| 思想品德 | 300~400 | 14% |
| 学业成绩 | 400~600 | 21% |
| 科研创新 | 400~600 | 21% |
| 社会实践 | 300~500 | 16% |
| 综合素质 | 200~300 | 9% |
| 结尾 | 80~150 | 5% |
| 落款 | 不计 | — |
| **合计** | **2000~3000** | 100% |

学业成绩与科研创新合计占 42%，是评审打分重点，必须详实。

### 5.2 事实+数据原则

每段都要落到具体事实与数据：
- ❌ "我学习成绩优异" → ✅ "大学 4 年加权 GPA 3.85/4.0，专业排名第 1/87"
- ❌ "积极参与科研" → ✅ "主持国家级大创 1 项（《分布式光伏故障智能诊断系统》），以第一作者发表 SCI 论文 1 篇"
- ❌ "热心公益" → ✅ "累计志愿服务时长 320 小时，参与三下乡 2 次"
- ❌ "学生工作出色" → ✅ "担任学院学生会主席 1 学年，组织大型活动 8 场，累计参与 2000+ 人次"

### 5.3 序号体系

按申报书规范：
- 一级：一、二、三…（中文数字 + 顿号）
- 二级：（一）（二）…（中文数字 + 括号）
- 三级：1. 2. 3.…（阿拉伯数字 + 点）
- 四级：（1）（2）…

不要混用 1.1 / 1.1.1（论文写法）。

### 5.4 标点规范

- 中文标点用全角："，。：；！？"
- 括号统一用中文全角：（）【】《》
- 英文内容用半角
- 不混用中英文标点

### 5.5 时态与人称

- 时态：过去时（已发生）为主，结尾可换将来时
- 人称：第一人称"我"
- 避免"本人"（过于书面化）、"学生"（过于疏离）

### 5.6 段落衔接

段间用"现将四年情况汇报如下：""在科研创新方面，""在社会实践方面，"等过渡语衔接，不要硬切。

### 5.7 表格使用

必用表格：
1. 分学年 GPA 表（4 列：学年/GPA/加权平均分/专业排名）
2. 科研创新成果表（5 列：类别/名称/级别/角色/时间）

可选表格：
- 主干课程成绩表（3 列：课程名称/学分/成绩）
- 荣誉列表（4 列：时间/奖项/级别/颁发单位）

### 5.8 字数控制示例

以省级优秀毕业生申请书 2500 字为目标，各段字数控制：

| 段落 | 目标字数 | 实际写法 |
|------|----------|----------|
| 开头 | 180 字 | 身份+规格+数据 3 项+去向+进入正文，3 句话 |
| 思想品德 | 350 字 | 入团轨迹 80 字 + 学生干部履职 150 字 + 荣誉 80 字 + 思想觉悟 40 字 |
| 学业成绩 | 500 字 | 4 年 GPA + 分学年 GPA 表 + 主干课程 + 英语计算机 + 奖学金 + 毕设 |
| 科研创新 | 500 字 | 大创 150 字 + 论文 150 字 + 竞赛 100 字 + 成果表 |
| 社会实践 | 400 字 | 学生工作 150 字 + 三下乡 150 字 + 实习 100 字 |
| 综合素质 | 250 字 | 文体特长 150 字 + 班级评价 100 字 |
| 结尾 | 120 字 | 4 年成长总结 + 去向呼应 + 朴素表态 |
| 合计 | 2300 字 | + 表格不计字数 |

### 5.9 表格与正文衔接

表格前用 1 句话引导："大学四年加权 GPA 3.85/4.0，专业排名第 1/87。分学年情况："

表格后用 1 句话总结："四年 GPA 呈持续上升趋势，专业排名从大一的第 5 名提升至大四的第 1 名。"

## 六、4 年成长叙事方法

优秀毕业生与"优秀学生"最大差异：要求呈现 4 年成长叙事，不是按时间流水账。

### 6.1 三种叙事结构

**按时间线叙事**（适合 GPA 持续上升、有明确成长轨迹者）：
- 大一：基础扎实，GPA 3.6
- 大二：进入实验室，开始科研
- 大三：主持大创，发表论文
- 大四：保研清华，继续深耕

**按维度叙事**（适合多维度均有突出表现者）：
- 学业：4 年 GPA 3.85
- 科研：主持大创 + SCI 论文
- 实践：三下乡 + 实习
- 素质：文体特长

**按里程碑叙事**（适合有标志性事件者）：
- 大二参加数学建模获国二
- 大三发表 SCI 一作
- 大四保研清华

### 6.2 时间线叙事示例（约 150 字）

> 回顾大学四年，我的成长呈现明显的台阶式上升。大一专注于打牢数理基础，GPA 3.60；大二进入张教授实验室接触自然语言处理，主持校级大创 1 项；大三主持国家级大创，以第一作者在《XX》发表 SCI 论文 1 篇，GPA 提升至 3.90；大四完成毕业设计并保研至清华大学计算机系人工智能方向，GPA 3.95。四年加权 GPA 3.85，专业排名第 1/87。

### 6.3 维度叙事示例（约 120 字）

> 大学四年，我在学业、科研、实践、素质四维度同步推进。学业方面，4 年加权 GPA 3.85/4.0，专业排名第 1/87；科研方面，主持国家级大创 1 项，发表 SCI 论文 1 篇（第一作者）；实践方面，累计志愿服务 320 小时，参与三下乡 2 次；素质方面，钢琴十级，担任校合唱团团长 2 学期。

### 6.4 里程碑叙事示例（约 100 字）

> 大学四年有三个里程碑。大二参加全国大学生数学建模竞赛获国家二等奖，确立了"用算法解决实际问题"的研究方向；大三主持国家级大创《分布式光伏故障智能诊断系统》，以第一作者发表 SCI 论文 1 篇，找到对比学习的研究兴趣；大四保研至清华大学计算机系，将在人工智能方向继续深耕。

### 6.5 选择建议

- GPA 持续上升（如 3.6→3.95）→ 时间线叙事
- 多维度均衡发展 → 维度叙事
- 有 2~3 个标志性事件 → 里程碑叙事
- 不确定 → 维度叙事最稳妥

### 6.6 反面：流水账叙事

❌ 反面示例：
> 大一我参加了新生入学教育。大一下学期我加入了学生会。大二我参加了数学建模竞赛。大二下学期我开始进实验室。大三我主持了大创。大四我保研了。

问题：每个事件孤立、无主线、无成长逻辑、无数据。

### 6.7 三种叙事结构对比

| 维度 | 时间线叙事 | 维度叙事 | 里程碑叙事 |
|------|-----------|----------|-----------|
| 适用对象 | GPA 持续上升者 | 多维度均衡发展者 | 有 2~3 个标志性事件者 |
| 主线 | 时间（大一→大四） | 维度（学业/科研/实践/素质） | 事件（国二/SCI/保研） |
| 字数 | 150~200 字 | 120~150 字 | 100~150 字 |
| 优点 | 体现成长轨迹 | 突出多维度均衡 | 聚焦高光时刻 |
| 缺点 | 易变流水账 | 缺乏时间感 | 可能遗漏中等表现 |
| 适用 GPA | 3.6→3.95 上升型 | 3.85+ 稳定型 | 3.7+ 突破型 |

### 6.8 4 年成长叙事常见误区

**误区 1：把"成长"等同于"成绩上升"**。成长不仅是 GPA，还包括科研角色升级（参与→主持）、实践深度提升（参与→组织）、思想成熟（团员→党员）。

**误区 2：4 年叙事变成 4 段独立陈述**。每段必须有内在逻辑（如"大二进实验室 → 大三主持大创 → 大四保研"是因果链，不是并列）。

**误区 3：忽略"未达成"的部分**。如大二某次竞赛未获奖但学到经验，可作为成长节点，比纯罗列成功更有说服力。

**误区 4：4 年叙事与毕业去向脱节**。叙事应自然导向毕业去向（如叙事提到大三找到对比学习兴趣，结尾呼应保研清华人工智能方向）。

## 七、毕业去向撰写方法

毕业去向是优秀毕业生申请书的必填项，与奖学金类申请书的核心差异。

### 7.1 五类毕业去向

| 类型 | 撰写重点 | 字数 |
|------|----------|------|
| 升学（保研/考研） | 录取学校全称、学院、专业方向、导师联系情况 | 30~50 字 |
| 就业 | 签约单位全称、岗位、城市、与本科专业匹配度 | 30~50 字 |
| 创业 | 项目名称、注册公司、领域、与本科科研关联 | 40~60 字 |
| 西部计划/选调 | 服务地、岗位、服务期、报考初心 | 40~60 字 |
| 留学 | 录取学校、专业、学位、回国规划 | 30~50 字 |

### 7.2 升学类示例

正面示例：
> 即将前往清华大学计算机科学与技术系攻读硕士研究生，方向为人工智能，已与导师 XX 教授（研究方向：对比学习与知识蒸馏）建立联系，将在表征学习方向继续深入研究。

反面示例：
> 已保研至清华大学。（信息过于简略，评审无法判断匹配度）

### 7.3 就业类示例

正面示例：
> 即将入职字节跳动担任后端开发工程师，工作地点北京。本科阶段在分布式系统方向的科研积累（含国家级大创主持经历）与岗位高度匹配，将在工业界继续打磨工程能力。

### 7.4 创业类示例

正面示例：
> 与团队联合创立"智学科技"，注册为 XX 信息技术有限公司，主攻 AI 教育领域。项目源于大三主持的国家级大创《XX》，已获得天使轮 50 万元融资，将在毕业后全职运营。

### 7.5 西部计划/选调类示例

正面示例：
> 已入选 2025 届大学生志愿服务西部计划，将赴新疆维吾尔自治区喀什地区疏附县开展基层治理服务，服务期 1~3 年。本人出生于西部农村，立志用所学回馈家乡。

### 7.6 留学类示例

正面示例：
> 已获卡内基梅隆大学计算机科学硕士项目录取，方向为机器学习。计划硕士毕业后回国攻读博士，将所学应用于国内人工智能产业。

### 7.7 与本科经历的呼应

毕业去向段必须与本科 4 年经历呼应：
- 升学：呼应本科科研方向与导师选择
- 就业：呼应本科实习经历与岗位匹配
- 创业：呼应本科大创项目
- 西部计划：呼应本科志愿服务经历
- 留学：呼应本科科研兴趣与回国规划

### 7.8 禁止

- 一笔带过（"已保研至清华大学"）
- 虚假去向（评审会查录取通知/签约证明）
- 与本科经历脱节（如本科是文科却声称保研清华计算机系）
- 抒情化（"将带着母校的祝福走向远方"）

### 7.9 五类去向选择考量

| 去向 | 评审加分点 | 撰写风险 |
|------|-----------|----------|
| 升学 | 学校层次（C9/985/211）、与本科专业匹配 | 导师未联系、方向含糊 |
| 就业 | 单位知名度（大厂/央企）、岗位匹配 | 与本科科研脱节 |
| 创业 | 已注册公司、有融资 | 项目未落地、无团队 |
| 西部计划/选调 | 服务地艰苦程度、服务期承诺 | 与本科志愿服务脱节 |
| 留学 | 学校排名（QS 前 50）、回国规划 | 无回国规划、纯为出国 |

### 7.10 毕业去向与本科经历呼应模板

**升学呼应**："本科阶段在 XX 方向的科研积累（含 XX 大创/XX 论文）与保研至 XX 学校 XX 方向高度契合，将在 XX 教授指导下继续深入研究。"

**就业呼应**："本科 XX 段实习经历（在 XX 公司参与 XX 项目）使我确认对 XX 行业的兴趣，即将入职 XX 公司担任 XX 岗位，与本科专业高度匹配。"

**创业呼应**："本科阶段主持的 XX 大创项目已孵化为创业项目，与团队联合创立 XX 公司，主攻 XX 领域，已获 XX 轮融资。"

**西部计划呼应**："本科 4 年累计志愿服务 XX 小时，赴 XX 地三下乡的经历坚定了我投身基层的决心，已入选西部计划赴 XX 地开展服务。"

**留学呼应**："本科阶段在 XX 方向的科研兴趣驱动我申请 XX 学校硕士项目，计划毕业后回国攻读博士，将所学应用于国内 XX 产业。"

## 八、评审标准与打分维度

优秀毕业生评审采用 5 维度打分，权重固定：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 学业成绩 | 30% | 4 年加权 GPA、专业排名、英语六级、奖学金 |
| 科研创新 | 25% | 大创级别与角色、论文级别与作者排序、竞赛级别 |
| 社会实践 | 20% | 学生干部履职、三下乡、志愿服务时长、实习 |
| 综合素质 | 15% | 文体特长、班级评价、人际关系 |
| 思想品德 | 10% | 入团情况、思想觉悟、政治立场 |

> 省级优秀毕业生通过率约 30%（校级推荐后省级评审），校级约 60%。评审专家 5 人/项目，去掉最高最低分后取平均。

### 8.1 学业成绩打分细则（30%）

- 4 年加权 GPA 3.9+/4.0 或加权 93+：满分
- GPA 3.8~3.9 或加权 90~93：25~28 分
- GPA 3.7~3.8 或加权 87~90：20~24 分
- GPA 3.5~3.7 或加权 85~87：15~19 分
- 专业排名前 1%：+2 分；前 5%：+1 分
- CET-6 ≥550：+1 分

### 8.2 科研创新打分细则（25%）

- 国家级大创主持 + SCI 一作：满分
- 国家级大创参与 + 中文核心一作：20~22 分
- 省级大创主持 + 省级竞赛一等奖：15~18 分
- 校级大创 + 校级竞赛：10~14 分
- 无科研经历：0~5 分

### 8.3 社会实践打分细则（20%）

- 学生会主席 + 三下乡 2 次 + 志愿服务 200+ 小时：满分
- 部长级 + 三下乡 1 次 + 志愿 100~200 小时：15~17 分
- 班委 + 志愿 50~100 小时：10~14 分
- 仅志愿服务 < 50 小时：5~9 分

### 8.4 综合素质打分细则（15%）

- 文体特长省级以上获奖 + 班级评价优秀：满分
- 校级文体特长 + 班级评价良好：10~12 分
- 班级评价合格：6~9 分

### 8.5 思想品德打分细则（10%）

- 中共党员 + 党课结业 + 主题团日组织：满分
- 预备党员 + 党课结业：8 分
- 优秀团员/积极分子：6 分
- 共青团员 + 主题团日参与：4~5 分

### 8.6 评分计算示例

> 学业 28（GPA 3.85，专业 1/87，CET-6 542）+ 科研 23（国家级大创主持 + SCI 一作）+ 实践 18（学生会主席 + 三下乡 2 次 + 志愿 320 小时）+ 素质 12（钢琴十级）+ 思想 9（预备党员）= 90 分，达到省级优秀毕业生线（85+）。

### 8.7 省校规格与评分线对应

| 规格 | 评审线 | 推荐线 | 数据展示要求 |
|------|--------|--------|--------------|
| 省级优秀毕业生 | 85 分 | 90 分 | 论文含 IF、竞赛含参赛规模、奖学金含次数与级别 |
| 校级优秀毕业生 | 75 分 | 80 分 | 论文含期刊级别、竞赛含奖项级别、奖学金含次数 |

### 8.8 评分不达标补救方向

- 学业不达 25 分：补充分学年 GPA 上升轨迹、CET-6 高分、主干课程亮点
- 科研不达 20 分：补充大创角色（主持 vs 参与）、论文作者排序、专利状态
- 实践不达 15 分：补充学生干部任期与履职数据、志愿服务时长
- 素质不达 10 分：补充文体特长等级证书、班级集体荣誉
- 思想不达 8 分：补充党课结业证书、主题党日组织经历

### 8.9 评分自检方法

撰写完成后，按 8.1~8.5 自评 5 维度得分，加总后与目标规格线（省级 85+/校级 75+）对比。低于线则按 8.8 补救方向补充数据。

## 十、政治用语规范

- "中国共产党"（不能简写为"党"，首次出现用全称）
- "习近平新时代中国特色社会主义思想"（必须全称，不能简写为"习近平思想"）
- "党的二十大和二十届三中全会精神"（不能写"20 大"）
- "中共预备党员"（不能写"预备党员"省略"中共"）
- "优秀团员/积极分子"（不能写"积极分子"）
- "党支部"（不能写"党组织"过于笼统）
- "三下乡"（首现需加引号，后续可不加）
- 不混用网络用语（YYDS、绝绝子等）
- 不使用英文混排（如 "I love this party"）
- 不抄党章原文，用自己话表达对党的认识

### 10.1 入团轨迹表述规范

## 十一、docx 生成调用方式

```bash
# 方式 1：使用 JSON 数据文件
python build.py --data data.json --out output.docx

# 方式 2：使用内置示例数据（演示用）
python build.py --demo --out /tmp/test_outstanding_graduate.docx

# 方式 3：查看帮助
python build.py --help
```

data.json 字段定义见第三章信息采集清单，所有字段均可选填，缺字段会触发校验警告但不阻断生成。

生成流程：
1. 解析 JSON → 2. 校验数据完整性（输出 warnings）→ 3. 构建 docx（标题→称呼→开头→思想→学业→科研→实践→素质→结尾→落款）→ 4. 保存到指定路径

输出文件：A4 纸张，上下 2.54cm 左右 2.5cm 页边距，黑体二号标题居中，宋体小四正文 1.5 倍行距首行缩进 2 字符，分学年 GPA 表与科研创新成果表自动嵌入，"此致/敬礼！"格式，落款右对齐，页脚居中页码。

### 11.1 输出文件命名建议

- 省级：`省级优秀毕业生申请书_张明_2025.docx`
- 校级：`校级优秀毕业生申请书_张明_2025.docx`

文件名包含规格、姓名、毕业年份，便于学院归档。

### 11.2 缺失字段处理

- P0 必采字段缺失：触发 warning，仍生成 docx，但对应段落用占位符 `___` 标注，提醒用户补全
- P1 重要字段缺失：触发 warning，对应段落省略或简化
- P2 可选字段缺失：不触发 warning，直接省略

## 十三、学校差异处理

### 13.1 常见学校差异速查

| 学校类型 | 字数要求 | 标题写法 | 称呼 |
|----------|----------|----------|------|
| 综合性大学 | 2000~3000 字 | 省级/校级优秀毕业生申请书 | 尊敬的领导： |
| 理工类院校 | 2000~2500 字 | 同上 | 尊敬的评审委员会： |
| 师范类院校 | 2500~3000 字 | 同上 | 尊敬的学院领导： |
| 财经类院校 | 2000 字 | 同上 | 尊敬的领导、评审委员会： |
| 医学类院校 | 2000~2500 字 | 同上 | 尊敬的领导： |
| 农林类院校 | 2000~2500 字 | 同上 | 尊敬的评审委员会： |
| 政法类院校 | 2500~3000 字 | 同上 | 尊敬的领导： |
| 民族类院校 | 2000~3000 字 | 同上 | 尊敬的领导、评审委员会： |
| 军事类院校 | 1500~2000 字 | 同上 | 尊敬的首长： |

### 13.2 处理原则

1. **优先用学校下发模板**：栏目顺序、字数要求、称呼写法以学校模板为准
2. **省级与校级规格差异**：省级数据展示更详尽（如论文须含 IF、竞赛须含参赛规模），校级可适度简化
3. **本科 4 年 vs 专科 3 年**：专科院校按 3 年叙事，分学年表相应改为 3 行
4. **学年制 vs 学期制**：学期制学校（如部分医学类）按 8 学期叙事

### 13.3 触发学校差异处理

如用户在信息采集阶段提到学校名称，主动询问：
- "学校下发的优秀毕业生申请书模板有没有特殊要求？"
- "字数是 2000 字还是 3000 字？"
- "称呼是'尊敬的领导：'还是'尊敬的评审委员会：'？"

不主动询问则按默认（综合性大学标准）处理，生成后提示"如学校模板有特殊要求，可告知后调整"。

### 13.4 省级规格额外要求

省级优秀毕业生除申请书外，部分省份还要求：
- 学校推荐信（学院 + 学校两级签字盖章）
- 4 年完整成绩单（教务处盖章）
- 获奖证书复印件装订成册
- 毕业去向证明（保研拟录取通知/就业协议/西部计划录取通知）

撰写阶段须提醒用户提前准备上述材料，避免申报截止时缺材料。

### 13.5 校级规格简化处理

校级优秀毕业生评审相对宽松，可适度简化：
- 论文可只列期刊级别（不要求 IF）
- 竞赛可只列奖项级别（不要求参赛规模）
- 学生干部可只列职务与任期（履职数据可简化为 1~2 项）
- 志愿服务时长可只列总数（不要求详细分类）

但 4 年成长叙事与分学年 GPA 表仍为必填项，不可省略。

### 13.6 专科院校特殊处理

专科院校（3 年制）的优秀毕业生申请须调整：
- 4 年叙事改为 3 年叙事
- 分学年 GPA 表改为 3 行（大一/大二/大三）
- 字数可适度缩减至 1500~2500 字
- 毕业去向多为就业/专升本，去向呼应模板相应调整
