# 优秀班干部 / 优秀学生干部申请书 Skill

本 skill 处理"优秀班干部申请书""优秀学生干部申请书""班干部评优申请书""学生干部评优申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 质检。

**核心定位**：优秀班干部（亦称"优秀学生干部"）是中国高校针对担任班长、团支书、学习委员、宣传委员、体育委员、心理委员、宿舍楼长等学生干部职务的在校学生设立的评优项目，遵循"职务履职 + 服务同学 + 综合表现"三维度框架。评审跨度为本学年（与优秀毕业生 4 年综合跨度不同），正文 1500~2000 字，侧重本学年学生干部职务履职的量化成效、服务同学的具体行动与综合表现（学业、思想、身心）的稳定表现。与"优秀学生"评优相比，优秀班干部评审更强调职务履职（占 35-40%）、服务同学（占 20-25%），学业与体测门槛放宽（学业仅要求前 50%、体测合格即可）。

**输出文件**：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐、学生干部履职表与履职量化清单表自动嵌入）。

## §0 适用场景与定位

### 0.1 适用范围

**适用**：用户提到"优秀班干部""优秀班干部申请书""优秀学生干部""优秀学生干部申请书""班干部评优""学生干部评优""院级优秀学生干部""校级优秀学生干部""优秀班委"等关键词，且本人担任班长/团支书/学委/宣委/体委/心理委员/楼长等学生干部职务满 1 学年（部分学校要求满 1 学期），且年级为大二至大四在校生（非应届毕业生评毕业荣誉）。

**适用职务清单**（详见 §2 7 类学生干部职务对照表）：
- 班级职务：班长、副班长、学习委员、宣传委员、体育委员、文艺委员、生活委员、心理委员、组织委员
- 团内职务：团支部书记、团支部副书记、团支部组织委员、团支部宣传委员
- 宿舍职务：宿舍长、楼长、副楼长、层长
- 学院职务：学院学生会主席/副主席、学院学生会各部部长/副部长、学院团委副书记、学院团委各部部长/副部长
- 学校职务：校学生会主席/副主席、校学生会各部部长/副部长、校团委副书记、校团委各部部长/副部长

**注意**：班长 / 团支书 / 学委为最常见的 3 类优秀班干部申报职务；宣委 / 体委 / 心理委员 / 楼长需在"职务履职"段强化日常工作的频次与覆盖面（详见 §2）。

### 0.2 不适用场景（需走其他 skill）

- **优秀学生 / 三好学生**：本学年 1 学年跨度，侧重思想 + 学习 + 身体三维度，学业前 30%、体测良好 → 走 `outstanding_student` skill
- **优秀团员**：本学年跨度，侧重政治表现 + 团务工作 + 志愿活动 → 走 `outstanding_student` skill（category=outstanding_youth_league）
- **优秀毕业生**：4 年综合跨度，应届毕业生专属 → 走 `outstanding_graduate` skill
- **文明大学生**：侧重文明素养与道德品质 → 走 `civilized_student` skill
- **国家奖学金 / 国家励志奖学金**：侧重学业成绩与全国级成果 → 走对应奖学金 skill
- **优秀团员 / 团干部专项评优**：若学校团委单列"优秀团干部"评优（非"优秀学生干部"），侧重团务工作与团组织生活，建议在 `outstanding_student` skill 中按优秀团员变体处理

### 0.3 优秀班干部 vs 优秀学生干部 称谓关系

中国高校评优体系中，两者关系如下：

1. **优秀班干部**：教育部 1980 年代起设立的经典荣誉称号，原始定义为"班级层面的学生干部"，涵盖班长、副班长、学习委员、宣传委员、体育委员、文艺委员、生活委员、心理委员、组织委员、团支部书记、团支部副书记、团支部组织委员、团支部宣传委员、宿舍长等班级内职务。
2. **优秀学生干部**：1990 年代部分高校（尤其综合性大学与 985/211 高校）将"优秀班干部"扩展为"优秀学生干部"，覆盖范围扩大至学院学生会、校学生会、学院团委、校团委等各级学生组织干部。
3. **两者关系**：本 skill 视为同义词处理，统称"优秀班干部"。用户使用"优秀班干部"称谓时，标题与正文用"优秀班干部"；用户使用"优秀学生干部"称谓时，标题与正文用"优秀学生干部"。
4. **触发后第一步**：核对申报类别。若学校使用"优秀班干部"称谓，标题与正文用"优秀班干部"；若学校使用"优秀学生干部"称谓，标题与正文用"优秀学生干部"；若学校使用"优秀班委"称谓（部分高职高专），标题与正文用"优秀班委"。

### 0.4 评审周期与申报窗口

- **本学年评优**：次年 4-5 月启动，5 月底前提交，6 月初学院评审，6 月中公示
- **申报窗口期**：约 2-3 周，错过则等下一年度
- **同年度多奖**：同一学生同年度可同时申报优秀班干部 + 优秀学生（若学校允许），但需分别提交两份申请书，内容侧重不同
- **校级 vs 院级**：通常先评院级优秀班干部，再从中遴选校级优秀班干部，部分学校要求校级评审需额外提交事迹材料与答辩

## §1 优秀班干部 vs 优秀学生 5 维度区分表（必加章节 1）

优秀班干部（本 skill）与优秀学生（`outstanding_student` skill）最容易混淆，必须 5 维度逐项核对。**核心区别**：优秀班干部看本学年学生干部职务履职与服务同学成效，学业与体测门槛放宽；优秀学生看本学年思想 + 学习 + 身体三维度，学业前 30%、体测良好为硬门槛。

| 维度 | 优秀班干部 / 优秀学生干部（本 skill） | 优秀学生 / 三好学生（outstanding_student） |
|------|----------------------------------|--------------------------------|
| ① 评审侧重 | 职务履职（35-40%）+ 服务同学（20-25%）+ 综合表现（35-45%） | 思想品德（30%）+ 学业（50%）+ 身心（20%） |
| ② 材料重点 | 履职情况表（职务/任期/主要工作/量化成效）+ 服务同学量化 + 工作成绩 | 主干课程表 + 学生干部履职表（学业为重）+ 体测佐证 |
| ③ 适用人群 | 担任班长/团支书/学委等学生干部满 1 学年的在校生 | 学业排名前 30%、体测良好的在校生（不限是否学生干部） |
| ④ 职务要求 | 必须担任学生干部职务（满 1 学年，部分学校要求满 1 学期） | 不强制（学生干部履职为加分项） |
| ⑤ 推免加分 | 部分高校推免加 0.3-1.0 分（按校级/院级、班长/学生会主席分级） | 不直接推免加分（但综合排名提升） |

## §2 7 类学生干部职务对照表（必加章节 2）

优秀班干部评审中，不同职务的"主要工作"与"量化成效"差异显著。本节列出 7 类常见学生干部职务的对照表，撰写时必须按职务类型选择对应的履职侧重点。

### 2.1 7 类职务对照总表

| 职务类型 | 核心职责 | 量化指标建议 | 常见成效表述 |
|---------|---------|------------|------------|
| ① 班长 | 班级日常管理、协调班委、传达学院通知、组织班会 | 班会次数、通知转发数、班委会议数 | 班级获评先进班集体、班级加权平均分提升 |
| ② 团支书 | 团支部建设、团日活动组织、团费收缴、智慧团建维护 | 团日活动场次、团费收缴率、智慧团建完成率 | 团支部获评先进团支部、团员评议通过率 100% |
| ③ 学习委员（学委） | 收发作业、组织学习互助、传达教学通知、学风建设 | 学习互助场次、作业收发次数、辅导人次 | 班级挂科率下降、加权平均分提升 |
| ④ 宣传委员（宣委） | 班级宣传稿件、班级公众号/群运营、活动摄影记录 | 推文篇数、稿件数、活动记录数 | 班级公众号粉丝增长、稿件被院级平台采用 |
| ⑤ 体育委员（体委） | 组织体育锻炼、体育竞赛报名、体测组织、运动队管理 | 体育活动次数、竞赛报名人次、体测组织次数 | 体测合格率提升、运动会获奖人数 |
| ⑥ 心理委员 | 心理健康宣传、心理排查、危机预警、心理活动组织 | 心理排查次数、心理活动场次、谈心谈话人次 | 班级心理排查覆盖率 100%、危机预警 0 漏报 |
| ⑦ 楼长 / 宿舍长 | 宿舍卫生检查、宿舍安全巡查、宿舍活动组织、矛盾调解 | 卫生检查次数、安全巡查次数、矛盾调解数 | 宿舍获评文明宿舍、宿舍卫生检查优秀率 |

### 2.2 各职务履职侧重点详解

**① 班长（班级最高行政职务）**

- **核心职责**：班级日常管理（出勤、纪律、卫生）、协调 8-10 名班委分工、传达学院/学校通知、组织主题班会与班级活动
- **量化指标**：本学年组织主题班会 ≥10 次、转发学院通知 ≥50 条、召开班委例会 ≥15 次、组织班级集体活动 ≥6 场
- **常见成效**：班级加权平均分由 X.X 提升至 X.X、班级获评"校级先进班集体"/"校级文明班级"、班级出勤率 ≥98%、班级违纪事件 0 起
- **撰写侧重点**：突出"统筹协调 + 全局管理"，含班委分工、班级整体成效、与其他班委的协作

**② 团支书（团支部最高领导职务）**

- **核心职责**：团支部思想建设、组织建设、团日活动组织、团费收缴、智慧团建系统维护、团员发展
- **量化指标**：本学年组织团日活动 ≥6 场、团费按时收缴率 100%、智慧团建信息维护完成率 100%、推优评特 X 人、团员评议参与率 100%
- **常见成效**：团支部获评"校级先进团支部"/"五四红旗团支部"、推优评特 X 人、团员先进性评议"优秀"X 人
- **撰写侧重点**：突出"政治引领 + 团务规范"，含团日活动主题、团费收缴情况、推优评特成效、智慧团建维护

**③ 学习委员（学委，班级学风建设核心职务）**

- **核心职责**：收发作业、传达教学通知、组织学习互助、班级学风建设、与任课教师沟通
- **量化指标**：本学年收发作业 ≥40 次、组织学习互助 ≥8 场、辅导同学 ≥30 人次、组织考前复习串讲 ≥4 场
- **常见成效**：班级加权平均分由 X.X 提升至 X.X、班级挂科率由 X% 降至 X%、班级高分（90+）人数增加 X 人
- **撰写侧重点**：突出"学风建设 + 帮扶成效"，含作业收发情况、学习互助活动、班级学业数据提升

**④ 宣传委员（宣委，班级宣传与新媒体职务）**

- **核心职责**：班级宣传稿件撰写、班级公众号/班级群运营、班级活动摄影记录、院级宣传稿件报送
- **量化指标**：本学年撰写班级宣传稿件 ≥20 篇、班级公众号推文 ≥15 篇、活动摄影 ≥10 场、向院级平台报送稿件 ≥5 篇
- **常见成效**：班级公众号粉丝由 X 增至 X、稿件被院级平台采用 X 篇、班级活动报道覆盖率 100%
- **撰写侧重点**：突出"宣传覆盖 + 内容产出"，含稿件数量、公众号数据、稿件采用情况

**⑤ 体育委员（体委，班级体育活动组织职务）**

- **核心职责**：组织班级体育锻炼、体育竞赛报名、体测组织、班级运动队管理、运动会筹备
- **量化指标**：本学年组织班级体育活动 ≥8 次、运动会报名 ≥25 人次、体测组织 ≥2 次、班级运动队训练 ≥10 次
- **常见成效**：班级体测合格率 ≥95%、运动会获奖 X 人次、班级篮球队/排球队获院级比赛 X 名
- **撰写侧重点**：突出"体育组织 + 体测推动"，含体育活动次数、运动会成绩、体测合格率提升

**⑥ 心理委员（班级心理健康职务）**

- **核心职责**：班级心理健康宣传、心理排查与危机预警、心理活动组织、与心理中心对接、谈心谈话
- **量化指标**：本学年组织心理活动 ≥4 场、心理排查 ≥6 次（每学期 3 次）、谈心谈话 ≥15 人次、向心理中心报送情况 ≥4 次
- **常见成效**：班级心理排查覆盖率 100%、危机预警 0 漏报、班级获评"心理健康先进班级"、组织活动获心理中心表彰
- **撰写侧重点**：突出"心理排查 + 危机预警"，含排查次数、谈心人次、危机预警成效

**⑦ 楼长 / 宿舍长（宿舍管理职务）**

- **核心职责**：宿舍卫生检查、宿舍安全巡查、宿舍活动组织、宿舍矛盾调解、与宿管中心对接
- **量化指标**：本学年组织宿舍卫生检查 ≥20 次（每周 1 次）、安全巡查 ≥10 次、宿舍活动 ≥6 场、调解宿舍矛盾 ≥3 次
- **常见成效**：宿舍获评"校级文明宿舍"/"院级文明宿舍"、宿舍卫生检查优秀率 ≥80%、宿舍安全零事故、所在楼层获评"文明楼层"
- **撰写侧重点**：突出"卫生安全 + 矛盾调解"，含检查次数、巡查次数、文明宿舍荣誉、矛盾调解案例

### 2.3 职务组合撰写建议

部分学生担任多个学生干部职务，撰写时按以下原则：

1. **主职务优先**：以主要职务（任期最长、级别最高）为主，副职务简要带过
2. **不重复量化**：同一活动不要在不同职务中重复量化（如班长组织班会 + 宣委报道班会，分别写"组织 12 次班会"与"报道 12 次班会"，不重复计算）
3. **履职表分条**：学生干部履职表中每条职务独立成行，含职务/任期/主要工作/成效
4. **跨职务统筹**：在"工作成绩"段可写跨职务的整体成效（如"在班长与团支书双重职务中，统筹班级建设与团支部建设，所在班级与团支部均获评校级先进"）

### 2.4 职务级别与推免加分对照

部分高校推免时按职务级别加分，撰写时可在"工作成绩"段末尾点明职务级别：

| 职务级别 | 常见职务 | 推免加分（参考，各校不同） |
|---------|---------|----------------------|
| 校级正职 | 校学生会主席、校团委副书记 | 0.8-1.0 分 |
| 校级副职 | 校学生会副主席、校团委各部部长 | 0.5-0.8 分 |
| 院级正职 | 院学生会主席、院团委副书记 | 0.4-0.6 分 |
| 院级副职 | 院学生会副主席、院团委各部部长 | 0.3-0.5 分 |
| 班级正职 | 班长、团支书 | 0.2-0.4 分 |
| 班级副职 | 副班长、团支部副书记、学委、宣委、体委、心理委员 | 0.1-0.3 分 |
| 宿舍职务 | 宿舍长、楼长、层长 | 0.05-0.2 分 |

**注意**：推免加分各校政策差异大，撰写时仅作"职务级别"客观描述，不写"加分多少分"（避免政策不符）。如需说明推免加分，建议在"工作成绩"段末尾写"担任 XX 职务期间所获荣誉符合学校推免政策加分要求"。

## §3 班干部评审硬门槛（思想 + 学业 + 履职三维度）

优秀班干部评审遵循"思想品德 + 学业表现 + 职务履职"三维度硬门槛，任一维度不达标直接劝退。注意：学业与体测门槛均低于优秀学生（学业前 50%、体测合格即可），但履职门槛是硬性要求。

### 3.1 思想品德维度硬门槛

- **政治立场**：拥护中国共产党的领导，热爱社会主义祖国
- **无违纪记录**：本学年无任何违纪处分（含考试违纪、宿舍违纪、网络违纪、学术不端）
- **无违法记录**：无治安处罚、刑事处罚记录
- **诚信记录**：无学术不端、无考试作弊、无贷款违约
- **团员评议合格**：政治面貌为共青团员者，本学年团员先进性评议结果为"合格"及以上
- **履职评议合格**：班级同学对本职务履职的评议满意度 ≥80%（部分学校要求 ≥85%）

### 3.2 学业维度硬门槛

| 学校类型 | GPA（4.0 制） | 加权平均分 | 专业排名 | 主干课程 | 英语 | 挂科 |
|---------|--------------|----------|---------|---------|------|------|
| 985/211 重点高校 | ≥3.0/4.0 | ≥75 | 前 50% | 4~6 门 75+ | CET-4 ≥425 | 本学年无挂科 |
| 普通本科 | ≥2.8/4.0 | ≥75 | 前 50% | 4~6 门 75+ | 无强制 | 本学年无挂科 |
| 省属重点 | ≥3.0/4.0 | ≥78 | 前 40% | 4~6 门 78+ | CET-4 ≥425 | 本学年无挂科 |
| 高职高专 | ≥2.8/4.0 | ≥75 | 前 50% | 4~6 门 75+ | 无强制 | 本学年无挂科 |
| 校级优秀班干部（额外） | ≥3.2/4.0 | ≥80 | 前 30% | 5~6 门 80+ | CET-4 ≥425 | 本学年无挂科 |

**说明**：
- "本学年无挂科"指本学年所有课程（含必修、选修、体育、思政）均一次性通过，补考通过也算挂科记录
- 排名按专业或班级计算（按学校评优通知），必须含基数（如"30/87"而非"第 30"）
- 主干课程指专业核心课与专业基础课，不含公共选修课
- 5.0 制 GPA 换算：3.0/4.0 ≈ 3.75/5.0；3.2/4.0 ≈ 4.0/5.0

### 3.3 履职维度硬门槛（优秀班干部专属）

| 履职要素 | 硬门槛 | 说明 |
|---------|-------|------|
| 职务任期 | 满 1 学年（部分学校要求满 1 学期） | 必须在本学年完整担任学生干部职务 |
| 职务级别 | 班级职务及以上 | 班长/团支书/学委/宣委/体委/心理委员/楼长及以上 |
| 履职工作量 | 主要工作 ≥6 项 | 含班会、活动、检查、收发等日常工作 |
| 量化成效 | ≥3 项量化成效 | 含数据/荣誉/影响三类至少各 1 项 |
| 同学评议 | 满意度 ≥80% | 部分学校要求 ≥85%，由班委会组织评议 |
| 职务考核 | "合格"及以上 | 由班主任/辅导员考核 |

### 3.4 一票否决项

任一项触发即直接取消参评资格，不接受补正：

1. 本学年有挂科（含补考通过）
2. 本学年有违纪处分（含考试违纪、宿舍违纪、网络违纪、学术不端）
3. 本学年学生干部职务考核"不合格"
4. 学生干部职务任期末满 1 学年（部分学校放宽至 1 学期）
5. 同学评议满意度低于 80%（部分学校要求 85%）
6. 编造 GPA / 排名 / 学生干部职务 / 任期 / 主要工作 / 量化成效 / 获奖情况
7. 学生干部履职表无量化成效（"取得良好效果"等空话）
8. 履职量化清单数据与履职表不一致（如履职表写"组织班会 12 次"，量化清单写"10 次"）
9. 抄袭他人申请书（评审委员会比对）
10. 服务同学段无具体行动（仅写"为同学服务"而无具体案例）

**申诉机制**：若一票否决项触发，可向学院评审委员会提交书面申诉，提供相关证明材料（如挂科补考通过证明、违纪处分撤销证明、职务考核复核表等），由评审委员会审议后决定是否恢复参评资格。

|------|---------|-------------------|-------------------|---------|

### 4.3 4 段结构详细分解

**第一段：个人基本情况（20%）**

按 5 要素撰写，缺一不可：
1. 身份介绍句（姓名 + 学院 + 专业 + 年级 + 班级）
2. 学生干部职务与任期（含具体年月与级别）
3. 学业成绩（本学年 GPA + 加权平均分 + 专业排名）
4. 政治面貌与思想表现（含入团/入团轨迹简述）
5. 申报奖项句（"特申请 2024-2025 学年优秀班干部"）

**第二段：履职情况（40%，核心段）**

按 4 要素撰写：
1. 职务履职概况（核心职责 + 本学年工作量概述）
2. 学生干部履职表（4 列：职务/任期/主要工作/量化成效，≥1 条）
3. 履职量化清单表（4 维度：活动数/服务时长/获奖情况/同学评议）
4. 服务同学案例（2-3 个具体案例，含案例背景 + 行动 + 成效）

**第三段：工作成绩（25%）**

按 3 要素撰写：
1. 班级/团支部/宿舍整体成效（含数据、荣誉、影响）
2. 个人荣誉与表彰（含校级/院级荣誉，含级别与时间）
3. 跨职务统筹成效（担任多职务者必含，单一职务者可省略）

**第四段：不足与改进（15%）**

按 3 要素撰写：
1. 1-2 条具体不足（不含空话，须对应履职中的具体短板）
2. 对应改进措施（可执行、可量化，含具体行动与时间节点）
3. 朴素表态 + 恳请评审（"以上是我本学年的基本情况，恳请评审委员会予以考虑"）

### 4.4 开头与结尾配比

开头与结尾不计入 4 段配比，独立计算：

| 段落 | 字数占比 | 字数区间（1500 字版） | 字数区间（2000 字版） |
|------|---------|-------------------|-------------------|
| 开头（称呼后引语） | 5%~7% | 80~120 字 | 100~140 字 |
| 一、个人基本情况 | 20% | 300 字 | 400 字 |
| 二、履职情况 | 40% | 600 字 | 800 字 |
| 三、工作成绩 | 25% | 375 字 | 500 字 |
| 四、不足与改进 | 15% | 225 字 | 300 字 |
| 结尾（此致敬礼前表态） | 3%~5% | 60~100 字 | 80~120 字 |
| **合计** | 100% | **1500 字** | **2000 字** |

## §5 履职量化清单（必加章节 4）

履职量化清单是优秀班干部申请书的核心特色，必须以表格形式呈现，包含 4 个维度的量化数据。清单数据必须与学生干部履职表保持一致，不得出现数据冲突。

### 5.1 履职量化清单 4 维度

| 维度 | 含义 | 数据要求 | 示例 |
|------|------|---------|------|
| ① 活动数 | 本学年组织/参与的活动总数 | 必须含具体场次与类型 | "组织主题班会 12 次、班级活动 6 场、团日活动 4 场" |
| ② 服务时长 | 本学年服务同学的总时长 | 必须含小时数与构成 | "累计服务时长 280 小时（含日常履职 200 小时、活动组织 80 小时）" |
| ③ 获奖情况 | 本学年因学生干部工作所获荣誉 | 必须含级别与时间 | "校级优秀学生干部（2024.11）、院级优秀团干部（2025.05）" |
| ④ 同学评议 | 本学年班级同学对履职的评议 | 必须含满意度与基数 | "满意度 92%（46/50 人评议）" |

### 5.3 各职务履职量化清单示例

**班长**：活动数 33 场（主题班会 12、班级活动 6、班委例会 15）；服务时长 320h（日常履职 240h、活动组织 80h）；获奖 班级获"校级先进班集体"（2025.05）、个人获"院级优秀学生干部"（2024.11）；同学评议 满意度 94%（47/50）。

**团支书**：活动数 16 场（团日活动 6、团支部会议 8、推优评特会议 2）；服务时长 260h（团务工作 200h、活动组织 60h）；获奖 团支部获"校级先进团支部"（2025.05）、个人获"校级优秀团干部"（2024.11）；同学评议 满意度 91%（42/46）。

**学委**：活动数 52 次（学习互助 8、考前串讲 4、作业收发 40）；服务时长 220h（作业收发 100h、辅导同学 80h、活动组织 40h）；获奖 班级加权平均分由 84.2 提升至 87.6、挂科率由 8% 降至 2%；同学评议 满意度 90%（45/50）。

**宣委**：活动数 45 次（班级稿件 20、公众号推文 15、活动摄影 10）；服务时长 180h（稿件撰写 100h、公众号运营 50h、活动记录 30h）；获奖 稿件被院级平台采用 5 篇、公众号粉丝由 120 增至 350；同学评议 满意度 88%（44/50）。

**体委**：活动数 12 次（体育活动 8、运动会组织 2、体测组织 2）；服务时长 150h（活动组织 80h、运动会筹备 40h、体测组织 30h）；获奖 班级体测合格率 95%（提升 5%）、运动会获奖 8 人次；同学评议 满意度 89%（44/50）。

**心理委员**：活动数 25 次（心理活动 4、心理排查 6、谈心谈话 15）；服务时长 160h（心理排查 60h、谈心谈话 60h、活动组织 40h）；获奖 班级获"心理健康先进班级"（2025.05）、危机预警 0 漏报；同学评议 满意度 93%（46/50）。

**楼长**：活动数 36 次（卫生检查 20、安全巡查 10、宿舍活动 6）；服务时长 200h（卫生检查 80h、安全巡查 60h、活动组织 60h）；获奖 所在楼层 2 个宿舍获"校级文明宿舍"（2025.05）、所在楼层获"文明楼层"；同学评议 满意度 90%（45/50）。

### 5.4 履职量化清单与履职表的数据一致性

**强制要求**：履职量化清单中的"活动数"必须与学生干部履职表中的"主要工作"对应。例如：履职表写"组织班会 12 次"，量化清单必须写"主题班会 12 次"，不得写"10 次"。若数据冲突，统一以履职表为准。**质检清单第 23 项**：履职表数据与量化清单数据一致性检查，任一不一致返回修改。

### 5.5 履职量化清单撰写雷区

1. **数据空泛**：仅写"积极开展活动"而无具体场次，触犯雷区 3（用形容词代替事实）
2. **数据冲突**：履职表与量化清单数据不一致，触犯雷区 8（数据前后不一致）
3. **服务时长虚高**：写"累计 500 小时"而未拆解构成，触犯雷区 9（数据无来源）
4. **同学评议造假**：写"满意度 100%"而未说明评议方式，触犯雷区 10（评议无依据）
5. **获奖级别模糊**：仅写"获评先进"而无级别与时间，触犯雷区 5（获奖不写级别与时间）

## §7 学年表现撰写规范（不是大学四年）

### 7.1 学年口径红线

- 所有数据必须为本学年（9 月至次年 6 月）数据，禁用大学 4 年综合数据
- "本学年 GPA""本学年加权平均分""本学年专业排名"为本学年口径
- "本学年累计志愿服务时长""本学年组织活动数"为本学年口径
- 跨学年活动归错类（如 2024.07 三下乡属 2023-2024 学年），需用户核对
- 禁用"大学期间累计""4 年加权 GPA""4 年累计"等表述

### 7.2 学年数据时间窗口

| 学年 | 时间窗口 | 数据归属 |
|------|---------|---------|
| 2024-2025 学年 | 2024.09.01 ~ 2025.06.30 | 本学年数据 |
| 2023-2024 学年 | 2023.09.01 ~ 2024.06.30 | 上学年数据（不写） |
| 2024.07-2024.08 暑期 | 跨学年 | 归属 2023-2024 学年（不写） |

### 7.3 学年数据常见错误

1. **4 年综合代替本学年**：写"大学 4 年加权 GPA 3.85" → 应写"本学年 GPA 3.65/4.0"
2. **跨学年活动归错**：写"2024.07 三下乡" → 不应写入 2024-2025 学年申请书
3. **职务任期跨学年**：写"担任班长 2023.09-2025.05" → 应写"本学年 2024.09-2025.05 担任班长"（上学年可单独说明）
4. **荣誉时间跨学年**：写"2024.05 院级优秀学生干部" → 不应写入 2024-2025 学年申请书（属 2023-2024 学年荣誉）

### 9.6 3 档字数版本切换方法

build.py 通过 `word_count_target` 字段（P2 可选）切换档位，但实际生成时主要靠用户提供完整字段自然达到字数。建议：

- **短版**：仅提供 P0 字段，P1 字段省略（如 service_cases 仅 1 个、cross_position 省略等）
- **标准版**：提供 P0 + 关键 P1 字段（service_cases 2 个、cross_position 提供）
- **长版**：提供 P0 + 全部 P1 + P2 自定义段落（service_cases 3 个、cross_position 详细展开）

**字数自检**：生成后必须用 §13 质检清单的字数检查项验证。

## §11 雷区 10 条（必加章节 6）

以下 10 条雷区任一触犯，申请书将被评审委员会退回或评分大幅扣减。生成后必须按 §13 质检清单逐项排查。

### 11.1 雷区 1：未担任学生干部职务或任期末满 1 学年

**触犯场景**：用户实际未担任学生干部职务，或担任职务仅 1 学期（部分学校放宽至 1 学期，需先确认）。

**正确做法**：必须确认用户在本学年完整担任学生干部职务（≥1 学年或学校要求的最短任期），否则建议用户走"优秀学生"skill。

### 11.2 雷区 2：履职表无量化成效

**触犯场景**：履职表"成效"列写"取得良好效果""深受师生好评"等空话，无具体数据。

**正确做法**：成效列必须含数据（"班级加权平均分由 84.2 提升至 87.6"）/ 荣誉（"获评校级先进班集体"）/ 影响（"覆盖同学 50 人次"）三类至少 1 项。

### 11.3 雷区 3：用形容词代替事实

**触犯场景**：写"积极组织活动""热心服务同学""深受师生好评"等形容词，无具体行动与数据。

**正确做法**：每个形容词必须替换为"动词 + 对象 + 频次 + 量化"句式（"组织主题班会 12 次、服务同学 50 人次"）。

### 11.4 雷区 4：服务同学段无具体案例

**触犯场景**：服务同学段仅写"积极为同学服务"，无具体案例。

**正确做法**：必须含 2-3 个具体案例，每个案例含背景 + 行动 + 成效（如"2024.11 班级 X 同学..."）。

### 11.5 雷区 5：获奖不写级别与时间

**触犯场景**：写"获评优秀学生干部"而无级别（校级/院级）与时间。

**正确做法**：每个荣誉必须含级别 + 时间（"校级优秀学生干部（2024.11）"）。

### 11.6 雷区 6：排名不写基数

**触犯场景**：写"专业排名第 30"而无基数（"30/87"）。

**正确做法**：排名必须含基数（"专业排名第 30/87"），且基数与排名对应。

### 11.7 雷区 7：抒情开头与乞求结尾

**触犯场景**：开头写"时光荏苒，岁月如梭"，结尾写"恳请领导批准"。

**正确做法**：开头必须含身份 + 职务 + 数据 + 申报；结尾必须含"以上是我本学年的基本情况"+ 朴素表态 + "恳请评审委员会予以考虑"。

### 11.8 雷区 8：履职表与量化清单数据不一致

**触犯场景**：履职表写"组织班会 12 次"，量化清单写"组织班会 10 次"。

**正确做法**：两表数据必须完全一致，建议先填写履职表再据此填写量化清单。

### 11.9 雷区 9：服务时长虚高无来源

**触犯场景**：写"累计 500 小时"而未拆解构成，无法核实。

**正确做法**：服务时长必须含构成（"累计 280 小时（日常履职 200h、活动组织 80h）"），且构成之和等于总数。

### 11.10 雷区 10：同学评议无依据

**触犯场景**：写"满意度 100%"而未说明评议方式与基数。

**正确做法**：同学评议必须含满意度 + 基数（"满意度 92%（46/50 人评议）"），且说明评议方式（班委会组织匿名投票）。

### 11.11 雷区汇总速查表

| 雷区编号 | 雷区名称 | 关键排查点 |
|---------|---------|----------|
| 1 | 未担任学生干部或任期末满 | 职务 + 任期 ≥1 学年 |
| 2 | 履职表无量化成效 | 数据/荣誉/影响至少 1 项 |
| 3 | 形容词代替事实 | 动词 + 对象 + 频次 + 量化 |
| 4 | 服务同学无具体案例 | 2-3 个案例含背景+行动+成效 |
| 5 | 获奖不写级别与时间 | 级别 + 时间双齐全 |
| 6 | 排名不写基数 | X/N 格式 |
| 7 | 抒情开头与乞求结尾 | 数据开头 + 朴素表态结尾 |
| 8 | 履职表与量化清单不一致 | 两表数据完全一致 |
| 9 | 服务时长虚高无来源 | 拆解构成，构成之和等于总数 |
| 10 | 同学评议无依据 | 满意度 + 基数 + 评议方式 |

## §13 build.py 接口 + 质检清单（必加章节 8/9/10）

### 13.1 build.py 接口概览

build.py 位于 `/home/z/my-project/skills/awesome-student-ai-skills/subskills/outstanding_cadre/build.py`，提供 CLI 接口生成申请书 docx。

**核心类**：`ApplicationDocBuilder`

**主构建方法**：`build(data: Dict[str, Any], output_path: str) -> str`

**编排顺序**：标题 → 称呼 → 开头 → 一、个人基本情况 → 二、履职情况（含履职表 + 量化清单 + 服务案例）→ 三、工作成绩 → 四、不足与改进 → 结尾 → 落款

### 13.2 CLI 调用方式

**基础调用（用户提供 data.json）**：
```bash
python build.py --data data.json --out output.docx
```

**演示模式（使用内置示例数据）**：
```bash
python build.py --demo --out demo.docx
```

**参数说明**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `--data` | string | 否（与 --demo 二选一） | 数据 JSON 文件路径 |
| `--out` | string | ✅ | 输出 docx 文件路径 |
| `--demo` | flag | 否 | 使用内置示例数据生成演示文档 |

### 13.3 build.py 字段读取逻辑

build.py 通过 `_get()` 与 `_get_list()` 方法读取字段，关键读取逻辑如下：

| build.py 方法 | 读取字段 | 用途 |
|-------------|---------|------|
| `_add_title()` | honor_title | 决定标题（"优秀班干部申请书"或"优秀学生干部申请书"） |
| `_add_salutation()` | salutation | 称呼（默认"尊敬的学院领导、评审委员会："） |
| `_add_opening()` | name/college/major/grade/cadre_position/tenure_start/tenure_end/gpa/rank/honor_title | 开头身份句与核心数据 |
| `_add_basic_info()` | cadre_position/cadre_level/tenure_start/tenure_end/secondary_position/gpa/weighted_avg/rank/course_count/high_score_count/political_status/party_history | 个人基本情况段 |
| `_add_duty_performance()` | cadre_position/core_duties(可推断)/activity_count/service_hours + position_history + duty_performances + service_cases | 履职情况段（含两表 + 服务案例） |
| `_add_work_achievements()` | class_achievements/honors/cross_position | 工作成绩段 |
| `_add_shortcomings_section()` | shortcomings/improvements | 不足与改进段 |
| `_add_ending()` | ending | 结尾段（默认模板含"以上是我本学年的基本情况"） |
| `_add_position_table()` | position_history | 学生干部履职表 |
| `_add_duty_quantitative_table()` | duty_performances | 履职量化清单表 |

### 13.4 build.py 整段覆盖字段优先级

build.py 支持"整段覆盖"机制：若用户提供 `opening/basic_info/duty_performance/work_achievements/shortcomings_section/ending` 字段，则跳过模板拼装直接使用。**优先级**：整段覆盖字段 > 模板拼装。

**履职情况段处理**：若用户提供 `duty_performance` 整段覆盖字段，则直接使用该文本，不再插入学生干部履职表与履职量化清单表（用户须自行在文本中描述）。**建议不提供整段覆盖**，让 build.py 自动插入两表，保证表格规范。

### 13.5 build.py 数据校验（_validate_data）

build.py 内置 `_validate_data()` 方法，对缺失字段仅打印警告不阻断生成。校验项包括：

| 校验项 | 警告条件 | 警告信息 |
|-------|---------|---------|
| P0 必采字段 | name/college/major/grade/cadre_position/tenure_start/tenure_end/gpa/rank 任一缺失 | "缺少 {label}（{key}）" |
| 学生干部履职表 | position_history 缺失或不足 1 条 | "缺少 position_history 学生干部履职表（至少 1 条）" |
| 履职量化清单 | duty_performances 4 维度任一缺失 | "缺少 duty_performances.{key} 履职量化数据" |
| 不足与改进 | shortcomings 或 improvements 缺失 | "缺少 shortcomings 不足列表或 improvements 改进措施列表" |
| 排名校验 | rank 无基数且无 rank_total | "排名 '{rank}' 缺基数，应为 'X/N' 格式" |
| 学业门槛 | 排名前 X% 超过 50% | "排名前 X% 不满足优秀班干部前 50% 门槛" |
| 主干课程 | core_courses 缺失或不足 4 门 | "缺少 core_courses 主干课程表"或"主干课程仅 N 门，建议 4~6 门" |
| 任期时长 | tenure_start 与 tenure_end 间隔不足 8 个月 | "任期时长不足 1 学年（约 8 个月），请核对" |

### 13.6 质检清单（生成后必查，30 项）

生成 docx 后，按以下 30 项逐项检查。任一不达标返回撰写阶段修改：

#### 格式检查（10 项）

1. 标题按 honor_title 动态填充，黑体二号居中
2. 称呼顶格"尊敬的学院领导、评审委员会："，全角冒号
3. 正文宋体小四，1.5 倍行距，首行缩进 2 字符
4. 小节标题"一、个人基本情况"等，黑体小四加粗
5. 学生干部履职表 4 列（职务 / 任期 / 主要工作 / 成效），至少 1 条
6. 履职量化清单表 2 列（维度 / 量化数据），4 行（活动数/服务时长/获奖情况/同学评议）
7. "此致"另起一行空两格，"敬礼！"另起一行顶格
8. 落款右对齐，含"申请人：XXX"+ 日期两行
9. 页脚居中页码（宋体五号）
10. 全文无英文标点（除"CET-4""GPA"等专有名词）

#### 内容检查（12 项）

11. 开头含身份 + 职务 + GPA + 排名 + 申报 + 进入句
12. 个人基本情况含身份 + 职务与任期 + 学业 + 政治面貌
13. 履职情况含职务履职概况 + 履职表 + 量化清单 + 服务案例
14. 学生干部履职表 4 列齐全，每条含量化成效（数据/荣誉/影响至少 1 项）
15. 履职量化清单 4 维度齐全（活动数/服务时长/获奖情况/同学评议）
16. 服务同学段含 2-3 个具体案例（背景 + 行动 + 成效）
17. 工作成绩含班级整体成效 + 个人荣誉 + 跨职务统筹（多职务者）
18. 不足与改进含 1-2 条具体不足 + 对应改进措施 + 朴素表态
19. 结尾含"以上是我本学年的基本情况"+ 朴素表态 + 恳请评审
20. 全文无形容词代替事实（"积极组织""深受好评"）
21. 全文无抒情开头（"时光荏苒""岁月如梭"）
22. 全文无"恳请领导批准""完全符合评选条件"

#### 字数与学年口径检查（8 项）

23. 履职表数据与量化清单数据完全一致
24. 正文总字数 1500~2000 字（短版 1000 字；长版 2000 字）
25. 个人基本情况 300~400 字（短版 200~250；长版 400~450）
26. 履职情况 600~800 字（短版 400~450；长版 800~850）
27. 工作成绩 375~500 字（短版 200~250；长版 500~550）
28. 不足与改进 225~300 字（短版 100~150；长版 280~320）
29. 结尾 60~100 字（短版 50~70；长版 80~100）
30. 全文无 4 年综合数据（"大学 4 年加权 GPA""4 年累计"等）

## §14 红线规则与免责声明

### 14.1 数据真实性红线

**禁止编造**：GPA / 加权平均分 / 专业排名 / 排名基数 / 学生干部职务 / 职务级别 / 任期 / 主要工作 / 量化成效 / 活动数 / 服务时长 / 获奖级别 / 颁发单位 / 颁发时间 / 同学评议满意度 / 评议基数 / 服务同学案例 / 短不足 / 改进措施 / 政治面貌 / 入团轨迹。**追问原则**：关键数据缺失必须追问，禁止用"约""大概""左右"等模糊表述替代具体数据。

### 14.2 学年时间窗口红线

- 禁止使用大学 4 年综合数据代替本学年数据
- 禁止将跨学年活动归错类（如 2024.07 三下乡属 2023-2024 学年）
- 禁止使用"大学期间累计""4 年加权 GPA"等表述（应写"本学年累计""本学年 GPA"）
- 学生干部任期跨学年时，仅写本学年部分（如本学年 2024.09-2025.05）

### 14.3 履职数据一致性红线

- 履职表数据必须与履职量化清单数据完全一致
- 服务时长构成之和必须等于总数
- 同学评议满意度 = 满意人数 / 评议基数 × 100%
- 任期时长必须 ≥1 学年（约 8 个月，部分学校放宽至 1 学期约 4 个月）

### 14.4 内容禁用红线

**禁用表述**："恳请领导批准"（乞求语气）、"完全符合评选条件"（绝对化）、"为同学服务到底"（口号化）、"时光荏苒""岁月如梭"（抒情开头）、"积极组织""热心服务""深受好评"（形容词代替事实）、"取得良好效果"（无量化成效）。

**禁用结构**：4 年综合数据代替本学年数据；家庭经济困难内容（属励志奖学金范畴）；毕业去向段（属优秀毕业生范畴）；无量化成效的学生干部履职；无具体案例的服务同学段；数据不一致的履职表与量化清单。

### 14.5 学校差异处理

不同学校对优秀班干部申请书的要求略有差异。通用适配规则：985/211 字数 1800~2000、4~6 门 80+、学业前 30%、推免加分 0.5-1.0；普通本科字数 1500~1800、4~6 门 75+、学业前 50%；高职高专字数 1000~1500、4~6 门 75+、学业前 50%。称呼默认"尊敬的学院领导、评审委员会："，栏目顺序默认"个人基本情况 → 履职情况 → 工作成绩 → 不足与改进"。

**自定义适配步骤**：①询问用户所在学校；②查询学校教务处 / 学工部发布的当年评优通知；③按通知要求调整字数、称呼、栏目顺序、学业门槛；④若通知要求附加栏目（如"民族团结""创新创业"等），在对应段落后增加；⑤生成后向用户确认"是否需要按 XX 学校特殊要求调整"。

**常见学校速查表**：
- 清华大学：优秀学生干部称呼"尊敬的评审委员会："，必含"学术志趣"段
- 北京大学：优秀学生干部必含"团校学习"经历（如曾参加），称呼"尊敬的学院团委："
- 浙江大学：优秀学生干部字数 1800~2000，必含"求是"精神表述
- 复旦大学：优秀学生干部必含"通识教育"感悟
- 上海交通大学：优秀学生干部必含"思源"精神表述
- 南京大学：优秀学生干部字数 1500~1800，称呼"尊敬的学院领导："
- 北京理工大学：校级优秀学生干部需答辩评审，附事迹材料

**未匹配学校**：默认按 985/211 规则生成，向用户提示"按通用规则生成，请按学校评优通知核对字数与栏目顺序"。

8. **同年度多奖免责**：同一学生同年度可同时申报优秀班干部 + 优秀学生（若学校允许），但需分别提交两份申请书，内容侧重不同。本 skill 与 `outstanding_student` skill 各自生成侧重不同的文档。

## 附录 B：常见问题 FAQ

### B.1 同时担任多个学生干部职务，怎么写？

答：以主要职务（任期最长、级别最高）为主，副职务在"个人基本情况"段简要带过，在"工作成绩"段写跨职务统筹成效。学生干部履职表中每条职务独立成行。详见 §2.3 职务组合撰写建议。

### B.2 职务任期末满 1 学年怎么办？

答：先确认学校评优通知要求的最短任期。多数学校要求 1 学年（约 8 个月），部分学校放宽至 1 学期（约 4 个月）。若任期末满最短要求，建议本学年不申报，下学年再评。

### B.3 班级加权平均分数据怎么获取？

答：向班主任或辅导员申请班级成绩汇总表，计算本学年初（上学期开学时）与本学年末（下学期期末时）的加权平均分。若无准确数据，可写"班级加权平均分稳定在 85+ 区间"（含数据范围）。

### B.4 同学评议满意度怎么测？

答：通常由班委会组织匿名投票，评议基数 = 班级总人数（含申请人本人，部分学校排除申请人），满意度 = 满意人数 / 评议基数 × 100%。建议附班级评议表作为佐证。

### B.5 服务时长怎么计算？

答：日常履职按实际投入时间计算（如每周班委例会 1 小时 × 15 次 = 15 小时）；活动组织按活动筹备 + 执行 + 总结的总时间计算（如 1 场班会筹备 4 小时 × 12 次 = 48 小时）；服务同学案例按实际投入时间计算。建议每日 / 每周记录，期末汇总。

### B.6 没有荣誉怎么写工作成绩段？

答：若无个人荣誉，重点写班级整体成效（班级加权平均分提升、挂科率下降、体测合格率提升、集体荣誉等）。班主任评价也可作为工作成绩（如"班主任评价'工作积极主动、富有成效'"）。

### B.7 优秀班干部与优秀学生可以同时申报吗？

答：多数学校允许同时申报（需分别提交两份申请书）。优秀班干部侧重职务履职与服务同学，优秀学生侧重学业与身心。两份申请书内容侧重不同，部分内容（如学业数据、政治面貌）可重复使用。

### B.8 不足与改进段怎么写不空泛？

答：必须对应履职中的具体短板（如"班级少数同学学业帮扶成效不显著，期末仍有 2 人挂科"），改进措施必须可执行、可量化（如"下学年建立'一对一'长期帮扶机制，覆盖全部学业困难同学"）。禁用"还有不足""需要继续努力"等空话。

### B.9 服务同学案例必须有具体姓名吗？

答：不建议写真实姓名，用 X 同学、Y 同学等匿名化处理（保护隐私）。但案例的背景、行动、成效必须真实可核查，建议附班级工作日志或谈心记录作为佐证。
