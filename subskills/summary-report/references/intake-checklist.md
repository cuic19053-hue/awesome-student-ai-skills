# 五、信息采集清单

> 从 `subskills/summary-report/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要逐条向用户提问采集信息时。

> ⚠️ **下表"示例"列的绩点、排名、志愿时长等均为虚构占位，只用于说明字段格式，
> 不可写进用户的汇报**。真实数据必须由用户提供；用户给不出，就留占位并追问，
> 不得套用示例数字（见 SKILL.md §2.4）。

### 5.1 字段优先级

- **P0（必采）**：缺一不可，直接影响能否成文。
- **P1（重要）**：缺则正文偏空，须尽量追问。
- **P2（可选）**：有则增色，无则省略不写。

### 5.2 P0 字段清单（9 项，必采）

| 字段 | 说明 | 示例 |
|---|---|---|
| `title` | 标题（含时段） | 2026年第三季度思想汇报 |
| `salutation` | 称呼 | 尊敬的党组织： |
| `reporter_name` | 落款（含"汇报人："前缀） | 汇报人：[姓名] |
| `report_date` | 落款日期 | [YYYY]年[M]月[D]日 |
| 身份状态 | 积极分子/预备党员/团员 | 入党积极分子 |
| 覆盖时段 | 起止 | [YYYY.MM.DD]—[YYYY.MM.DD] |
| 思想学习内容 | 本阶段读的书/学的理论/参加的党课 | 通读《党章》+ 参加支部党纪学习教育 |
| 至少 3 条实绩 | 学习/科研/工作 | 绩点 [X.X]、专业前 [N]%、[赛事全名] [级别+等次] |
| 至少 1 条不足 | 真实短板 | 理论联系实际不够、时间管理待改进 |

### 5.3 P1 字段清单（6 项，重要）

- 具体成绩数据（绩点/排名/均分）
- 科研或项目进展（课题名、阶段成果）
- 竞赛获奖（名称、级别、名次、时间）
- 担任职务与履职（班长/团支书/社团）
- 志愿服务（时长、项目）
- 群众评价或受助同学反馈

### 5.4 P2 字段清单（5 项，可选）

- 时政学习的具体文章/会议精神
- 一次印象深刻的支部活动
- 帮助同学的典型事例
- 阶段目标与计划
- 曾受表扬或批评的情况

### 5.5 信息采集追问话术

- "这次汇报覆盖哪一段时间？落款日期按季末还是报送当天？"
- "你目前是入党积极分子、预备党员还是团员？这会影响第一段怎么写。"
- "这一阶段最有分量的 2~3 件事是什么？尽量给数字，比如排名、时长、第几名。"
- "有没有哪一件事让你对理论/责任有了新的认识？"（用于认识段，避免空话）
- "自己觉得还有哪些不足？支部上次有没有提过什么意见？"

### 5.6 复述确认（生成前最后一步）

把采集结果按 §六 结构复述一遍给用户，例如：

> 我准备这样写：标题《[时段]思想汇报》，称呼"尊敬的党组织"，第一段交代身份与时段，第二段写党纪学习教育与《党章》学习心得，第三段写绩点 `[X.X]` / 专业前 `[N]%` / `[赛事全名]` `[级别+等次]`，第四段写 `[职务]` 履职与 `[N]` 小时志愿，第五段写理论联系实际不足并给整改计划，落款"汇报人：`[姓名]` / `[YYYY]年[M]月[D]日`"。可以吗？

用户确认后再进入撰写。
