# 中国国际大学生创新大赛 红色之旅赛道（青年红色筑梦之旅）商业计划书 Skill

> 重要更名提示：自 2024 年起，"中国国际'互联网+'大学生创新创业大赛"已正式更名为"中国国际大学生创新大赛"。本 skill 专攻其中"红色之旅赛道"（即"青年红色筑梦之旅"赛道）。所有评审规则、主题方向、材料要求均以 2025 版官方规则为准。

本 skill 处理红色之旅赛道商业计划书（Business Plan，BP）全流程：信息采集 → 栏目撰写 → docx 生成 → 质检。仅处理红旅赛道 BP（必含乡村振兴/革命老区/民族团结/西部开发 4 大主题之一 + 红色基因 + 帮扶成效 + 可持续造血模式）；与高教主赛道 BP、挑战杯创业赛道、大创创业训练的差异见 §0.2 与 §0.6。

**输出文件**：可提交的 .docx（A4 纸张，宋体小四正文，黑体三号标题，1.5 倍行距，首行缩进 2 字符；含红色基因 4 维度表、乡村振兴 5 维度表、商业模式画布 9 宫格、3 年财务三表、红色帮扶成效表、团队成员表、风险矩阵表）。同时输出配套的"网评 PPT 一页一板块自解释版"提示（§10.4）。

**2025 红旅赛道评审口径**：以"立德树人 + 乡村振兴 + 调研深入 + 红色基因传承"为核心，与高教主赛道的"个人成长 + 项目创新 + 产业价值 + 团队协作"四维口径不同。最显著特征：①必须参加"红旅"活动（含老区行、乡村调研、党支部结对、红色宣讲等）；②必须服务乡村振兴/革命老区/民族团结/西部开发 4 大主题之一；③必含老区/乡村帮扶成效与可持续造血模式；④红色基因传承是评审硬指标，不是装饰；⑤产业价值让位于社会效益，BP 章节侧重需随之调整。

## §0 适用场景与赛道定位

### §0.1 适用范围

**适用**：用户提到"互联网+红旅""红旅赛道""红色之旅赛道""青年红色筑梦之旅""红色筑梦""红旅""红旅 BP""红旅商业计划书""革命老区帮扶""老区电商助农""乡村振兴助农""红色之旅项目"等关键词，且项目主题含乡村振兴/革命老区/民族团结/西部开发之一，需提交"商业计划书"形态文档。

**不适用**（走其他 skill）：
- 高教主赛道 BP（无乡村振兴主题、无红色基因）→ 走 internet_plus skill（高教主赛道）
- 挑战杯创业赛道（团中央主办）→ 走挑战杯 skill
- 大创-创业训练项目（教学项目，非参赛）→ 走创业训练 skill
- 大创-创业实践（已注册公司但非参赛）→ 走创业实践 skill
- 三下乡社会实践立项申报书（社会实践类，非创业）→ 走三下乡 skill
- 乡村振兴规划书 / 调研报告（非商业计划书形态）→ 走 social_survey skill 或乡村振兴相关 skill

### §0.2 红旅赛道 vs 高教主赛道 6 维度区分表

| 区分维度 | 红旅赛道（青年红色筑梦之旅） | 高教主赛道 |
|----------|------------------------------|------------|
| **项目主题** | 必须服务乡村振兴 / 革命老区 / 民族团结 / 西部开发 4 大主题之一 | 不限主题，可以是任意行业（科技/消费/教育/医疗等） |
| **面向地区** | 必须面向革命老区 / 脱贫地区 / 民族地区 / 西部地区 / 边疆地区之一 | 不限地域，可面向城市、校园、全国、海外 |
| **团队构成** | 3~15 人；必含 1 名党员或团员骨干；建议含涉农/思政/经济专业；可与老区党支部结对 | 3~15 人；不限政治面貌；偏技术 + 商科 + 设计复合 |
| **评审侧重** | 立德树人 + 乡村振兴 + 调研深入 + 红色基因传承（社会效益优先） | 个人成长 30% + 项目创新 30% + 产业价值 25% + 团队协作 15%（创意组） |
| **产出要求** | 必含红色帮扶成效子节 + 可持续造血模式 + 红色基因传承段落 + 至少 1 次老区行调研记录 | 4 维度齐全即可（个人成长/项目创新/产业价值/团队协作），无红色基因硬要求 |
| **奖金与晋级** | 国赛金奖另计（红旅单独通道），单项最高 30 万元；可双报高教主赛道 | 国赛金奖约 317 个（高教主赛道），单项最高 50 万元 |

**关键判断**：用户问"红旅赛道跟主赛道有啥区别"→ 答：红旅赛道是"教育属性 + 乡村振兴属性"双轮驱动，主赛道是"个人成长 + 商业价值"双轮驱动。同一项目同时报两赛，BP 必须差异化：红旅版本突出"红色基因 + 帮扶成效 + 乡村振兴 5 维度"，主赛道版本突出"个人成长 + 项目创新 + 产业价值 4 维度"。混用会导致评审口径不匹配，直接淘汰。

### §0.3 2025 红旅赛道 4 大主题对照表

2025 版红旅赛道聚焦 4 大主题，项目必须贴合其中 1 个（也可跨主题，但必含 1 个主主题）：

| 主题 | 适用场景 | 典型项目方向 | 必含要素 |
|------|----------|--------------|----------|
| **乡村振兴** | 服务脱贫地区/农村/乡镇产业发展 | 农产品电商、农业科技、乡村旅游、非遗活化、农村金融、农村教育 | 帮扶县/乡/村名称 + 带动农户数 + 增收数据 + 5 维度振兴对应 |
| **革命老区** | 服务革命老区（井冈山/延安/西柏坡/大别山/沂蒙山等）经济社会发展 | 老区红色文旅、老区农产品品牌、老区人才培训、老区数字化 | 老区名称 + 红色资源对接 + 帮扶党支部 + 红色文化传承 |
| **民族团结** | 服务民族地区（新疆/西藏/内蒙/宁夏/广西/云南等）经济社会发展 | 民族手工艺、民族文旅、民族语言服务、民族特产电商 | 民族地区名称 + 民族群体参与 + 文化尊重 + 铸牢中华民族共同体意识 |
| **西部开发** | 服务西部 12 省份（陕甘宁青新川渝云贵藏内蒙桂）经济社会发展 | 西部特色产业、西部生态保护、西部人才回流、西部教育医疗 | 西部省份/地市 + 西部特色资源 + 服务覆盖 + 东西部协作机制 |

**主题选择决策**：用户未明确主题时，必问："你的项目主要服务哪个主题？乡村振兴（最常见，覆盖 4 大主题中 70%+）、革命老区、民族团结、还是西部开发？项目落地在哪个县/乡/村？老区/民族地区/西部省份是哪里？" 主题确认后才能定调 BP 章节侧重。

### §0.4 红旅赛道与"三下乡"社会实践的区别

| 维度 | 红旅赛道（创业大赛） | 三下乡社会实践 |
|------|----------------------|----------------|
| 性质 | 创新创业大赛（教育部牵头） | 社会实践活动（团中央牵头） |
| 产出形态 | 商业计划书（含商业模式 + 财务预测 + 帮扶成效） | 立项申报书 + 总结报告（含调研记录 + 服务成效） |
| 商业属性 | 必须有商业模式（造血式） | 不要求商业模式（输血式即可） |
| 时长 | 长期项目（1~3 年） | 暑期集中实践（7~15 天） |
| 团队 | 跨学院跨年级 3~15 人 | 同校同学院 5~15 人 |
| 字数 | 8000~15000 字 BP | 3000~5000 字立项书 + 总结报告 |

**关键区别**：红旅赛道必须有"商业模式 + 财务预测 + 可持续造血模式"，三下乡不要求。红旅是"创业 + 帮扶"，三下乡是"实践 + 服务"。同一项目双报时，红旅 BP 突出"商业模式造血"，三下乡总结突出"实践育人成效"。本 skill 只处理红旅 BP。

### §0.5 赛道选择决策树

触发后第一步先确认赛道（与本 skill 是否匹配）：

1. 项目主题含老区/乡村帮扶、红色基因、乡村振兴 → 红旅赛道（本 skill 适用）。
2. 项目主题纯科技/消费/教育等，无乡村振兴要素 → 走 internet_plus skill（高教主赛道）。
3. 项目主题同时含乡村振兴 + 强商业属性 → 双报红旅 + 高教主赛道（允许，BP 需差异化）。
4. 用户问"我该报哪个赛道" → 先问"项目是否服务乡村振兴/革命老区/民族团结/西部开发？"。是 → 红旅；否 → 主赛道。

### §0.6 与挑战杯创业赛道对比速查

| 维度 | 红旅赛道（中国国际大学生创新大赛） | 挑战杯创业计划赛道 |
|------|------------------------------------|---------------------|
| 主办 | 教育部牵头，十部委共同主办 | 共青团中央 |
| 性质 | 创新创业大赛-红旅赛道 | 课外学术科技作品竞赛-创业计划类 |
| 评审核心 | 立德树人 + 乡村振兴 + 红色基因 | 创新性 35% + 商业性 30% + 团队 20% + 社会价值 15% |
| 红色基因要求 | 硬指标，必含 | 无硬性要求 |
| 帮扶成效要求 | 硬指标，必含量化数据 | 不要求 |
| 团队人数 | 3~15 人 | ≤8 人 |
| 字数 | 8000~15000 字 | 不限 |

**关键区别**：红旅赛道把"红色基因 + 帮扶成效"做成硬指标，挑战杯创业赛道不要求。本 skill 仅处理红旅版本。挑战杯创业赛道请走挑战杯 skill。

## §1 2025 红旅赛道评审口径与权重

### §1.1 评审核心四要素（与高教主赛道口径不同）

依据 2025 年 5 月 20 日全国大学生创业服务网（cy.ncss.cn）公布的《中国国际大学生创新大赛（2025）红色之旅赛道评审规则》，红旅赛道不沿用高教主赛道的"个人成长 + 项目创新 + 产业价值 + 团队协作"四维口径，而是采用以下四要素：

| 评审要素 | 权重（参考） | 评审要点 | 与高教主赛道差异 |
|----------|--------------|----------|------------------|
| **立德树人** | ~30% | 思政引领 / 红色基因传承 / 大学生受教育成效 / 党史学习教育 | 主赛道无此独立维度（仅并入"个人成长 30%"） |
| **乡村振兴成效** | ~30% | 帮扶县乡村数 / 带动农户数 / 增收数据 / 可持续造血模式 | 主赛道无此维度（仅"产业价值"含部分社会效益） |
| **调研深入** | ~20% | 老区行/乡村行调研次数 / 蹲点天数 / 访谈样本量 / 调研报告产出 | 主赛道无此独立维度 |
| **可持续造血** | ~20% | 商业模式可行性 / 财务自给率 / 不依赖输血 / 可复制可推广 | 主赛道以"产业价值"覆盖（25%/30%） |

**权重说明**：以上权重为参考口径，每年官方通知可能微调。BP 章节顺序与权重顺序对齐（执行摘要先讲立德树人，再讲乡村振兴成效，再讲调研深入，最后讲可持续造血）。

### §1.2 评审流程

红旅赛道评审流程与高教主赛道略有不同：

1. **校赛**：学校组织专家网评 + 现场答辩，按"红色基因 + 帮扶成效 + 商业可行性"打分，推荐项目进省赛。
2. **省赛**：省级赛网评 + 现场答辩，按"立德树人 + 乡村振兴 + 调研深入 + 可持续造血"四要素打分，推荐项目进国赛。
3. **国赛网评**：全国网评专家按四要素打分，决定是否进国赛现场赛。
4. **国赛现场赛**：5 分钟路演 + 3 分钟答辩，专家现场打分，产生金/银/铜奖。
5. **红旅专项活动**：国赛期间组织"红旅之夜"专项活动，含项目展示 + 老区行 + 红色教育，必须参加。

### §1.3 提分优先级（按权重 + 提分难度排序）

| 优先级 | 提分项 | 提分难度 | 建议投入 |
|--------|--------|----------|----------|
| P1 | 红色基因传承段落（党史学习/革命精神/红色文化/典型案例 4 维度齐全） | 中 | 800~1200 字 |
| P2 | 帮扶成效量化数据（县乡村名 + 农户数 + 增收金额 + 持续月数） | 高（需真实数据） | 表格 + 500 字说明 |
| P3 | 可持续造血模式（不依赖输血、可复制可推广） | 高 | 800~1000 字 + 财务自给率 |
| P4 | 调研深入证据（老区行次数 + 蹲点天数 + 访谈样本量 + 调研报告） | 中 | 表格 + 400 字说明 |
| P5 | 乡村振兴 5 维度对应（产业/人才/文化/生态/组织振兴各 1 句） | 低 | 5 段对应文字 |
| P6 | 立德树人成效（团队成员思政提升、优秀团员/积极分子发展、志愿服务时长） | 中 | 500~700 字 |

## §3 商业计划书 10 章结构

红旅赛道 BP 与高教主赛道 BP 章节相同（10 章），但各章内容侧重不同。红旅 BP 总字数 8000~15000 字（详见 §6 3 档版本），比高教主赛道（1.5 万~3 万字）短，因更聚焦帮扶成效与红色基因，财务部分可简化。

### §3.1 封面

封面含 7 行信息：大赛名称 / "红色之旅赛道商业计划书"副标题 / 项目名称 / 赛道（红色之旅赛道）/ 主题（4 选 1）/ 团队名称 / 负责人 / 学校 / 日期。大赛名称用 2025 新名"中国国际大学生创新大赛"。

### §3.2 第一章 执行摘要（800~1000 字，最重要栏目）

红旅赛道执行摘要必含 8 要素（比高教主赛道多 2 要素）：

1. **一句话项目**：为 [老区/乡村谁] 解决 [什么问题] 通过 [什么方式]，≤30 字
2. **红色基因传承**：项目对接什么红色资源 + 传承什么革命精神
3. **帮扶主题与地区**：4 大主题之一 + 帮扶县乡村全称
4. **市场机会**：老区/乡村产业规模 + 数据来源
5. **核心产品**：MVP 主要功能 + 关键指标（用户数/月活/月营收/带动农户数）
6. **商业模式**：盈利模式 + 定价 + 农户分红比例 + 财务自给率
7. **团队亮点**：复合背景 + 党员/团员骨干 + 指导教师 + 党支部结对
8. **帮扶成效**：带动农户数 + 户均增收 + 持续月数 + 可持续造血模式

执行摘要评审 30 秒决定深读还是淘汰，是 BP 最重要栏目。8 要素缺一不可。

### §3.3 第二章 红色基因传承与项目背景（1200~1500 字，红旅赛道特色章）

红旅赛道独有的章节，高教主赛道无此章。包含 4 子节：

**（一）红色基因 4 维度**（详见 §4）

- 党史学习：团队成员学习党史情况 + 学习方式 + 学习成效
- 革命精神：井冈山精神/延安精神/西柏坡精神等 + 项目中具体体现
- 红色文化：对接红色资源 + 红色文化产品开发
- 典型案例：学习的老区典型（如神山村/十八洞村/梁家河） + 项目对标

**（二）项目立项背景与红色资源对接**

- 项目立意的红色资源背景（如对接井冈山革命博物馆、神山村党支部）
- 红色资源如何转化为项目要素（如红色文创产品/红色研学路线）
- 与老区/乡村党支部的结对情况

**（三）项目立意的政策导向**

- 国家"乡村振兴"战略 + 革命老区振兴规划 + 东西部协作
- 引用《国务院关于新时代支持革命老区振兴发展的意见》《乡村振兴促进法》等
- 学校"红旅"活动支持 + 大学生"三下乡"衔接

**（四）团队思政教育与立德树人**

- 团队成员参与红旅活动 + 党史学习教育情况
- 项目过程中团队成员思政提升（如新增优秀团员/积极分子 X 人）
- 志愿服务时长 + 党支部结对活动

### §3.4 第三章 市场分析与需求验证（1500~2000 字）

**（一）行业背景与政策导向**

- 老区/乡村特色产业规模 + 数据来源（国家统计局/农业农村部/地方统计公报）
- 政策文件名：《国务院关于新时代支持革命老区振兴发展的意见》《乡村振兴促进法》《"十四五"推进农业农村现代化规划》

**（二）目标市场（TAM/SAM/SOM）**

- TAM：全国同类老区/乡村产业规模
- SAM：本省/本市同类地区规模
- SOM：本项目可获取市场（更小，因聚焦具体县乡村）

**（三）竞品分析**

- 直接竞品：同类老区助农项目 / 同类农产品电商
- 间接竞品：传统收购商 / 通用电商平台（拼多多/淘宝助农）
- 差异化定位：红色资源 + 党支部背书 + 在地化运营

**（四）用户画像与需求验证**

- 用户分两类：①老区/乡村农户（供给侧）；②城市消费者（需求侧）
- 农户画像：基本信息 + 收入来源 + 痛点（销路/价格/品质）+ 需求
- 消费者画像：基本信息 + 消费偏好 + 红色情怀 + 付费意愿
- 调研样本量 N≥50（含农户访谈 + 消费者问卷）

### §3.5 第四章 产品/服务介绍（1000~1500 字）

**（一）产品形态与核心功能**

- MVP 主要功能（5~8 个），每个含名称 + 解决什么问题 + 老区/乡村适配性
- 红色元素融入（如红色品牌包装/红色研学路线/红色文创）

**（二）核心功能演示**

- 1~2 个核心功能详细描述，含农户使用流程截图说明
- 老区/乡村用户的实际使用场景

**（三）技术实现与知识产权**

- 技术架构 + 关键第三方服务 + 研发投入估算
- 知识产权情况（软著/专利/在申）+ 红色品牌注册情况
- 适老化/低带宽/离线场景适配（老区/乡村网络环境特殊）

### §3.6 第五章 商业模式与可持续造血（1000~1300 字 + 9 宫格画布）

**（一）商业模式画布（9 要素）**

9 要素中"重要伙伴"必须含老区党支部 + 合作社 + 农户代表；"客户细分"含城市消费者 + 老区农户；"收入来源"含造血式收入（非捐赠）。

**（二）盈利模式**

- 1~3 种收入来源（造血式，如交易抽佣/品牌溢价/研学收费/服务费）
- 农户分红比例（建议≥50% 利润反哺农户）
- 与输血式（捐赠/补贴）的区分说明

**（三）定价策略**

- 成本加成 + 竞品对标 + 用户价值三方法
- 农户收购价 + 城市零售价的合理梯度
- 红色品牌溢价测算

**（四）可持续造血模式**

- 财务自给率（≥70% 为健康）：年度造血收入 / 年度总支出
- 不依赖外部捐赠的可持续路径
- 可复制可推广的标准化模式（如已复制到 X 个县乡村）
- 退出机制（如合作社独立运营能力培养）

### §3.7 第六章 运营现状与红色帮扶成效（1200~1500 字，红旅赛道核心章）

**（一）已取得成绩**

- 用户数、营收、合作客户、签约订单
- MVP 上线时间 + 内测用户数 + 首批合作意向
- 媒体报道 + 获奖情况

**（二）红色帮扶成效**（红旅赛道必填核心子节）

含 6 项量化数据：
1. 服务覆盖县乡村数（如 3 县 8 乡 25 村）
2. 带动农户数（如 156 户）
3. 户均增收金额/年（如 4800 元/户·年）
4. 持续服务月数（如 18 个月）
5. 合作社数量（如 4 个）
6. 党支部结对数（如 3 个）

附 1~2 个典型农户帮扶案例（含姓名/村组/帮扶前收入/帮扶后收入/持续时长）。

**（三）关键里程碑**

里程碑表含 MVP 上线、首批农户入驻、首笔营收、首个党支部结对、首个合作社成立、获奖等 6~10 个节点。

**（四）关键运营指标 KPI**

KPI 表含：月活跃交易用户、农户入驻数、城市消费者数、月营收、农户户均增收、财务自给率等 5~8 项。

### §3.8 第七章 团队介绍（每人 150~200 字 + 表格）

**（一）核心成员表**

5~8 人，含政治面貌列（党员/预备党员/优秀团员/积极分子/团员），商科 + 涉农 + 技术 + 思政复合。建议含 1 名党员或优秀团员/积极分子作为骨干。

**（二）核心成员简介**

每人 150~200 字：专业背景 + 项目中具体职责 + 已完成的关键动作 + 思政提升（如发展为优秀团员/积极分子）。

**（三）指导教师与顾问**

指导教师建议含 1 名涉农/经济专业 + 1 名思政教师；外部顾问可含老区党支部书记/合作社理事长。

**（四）党支部结对与志愿服务**

与老区/乡村党支部结对情况 + 团队成员累计志愿服务时长 + 党史学习教育开展情况。

### §3.9 第八章 财务预测（800~1200 字 + 3 年表格）

**（一）3 年财务预测表**

红旅赛道财务表可简化为 3 年（高教主赛道 5 年），至少含：注册用户/月活/营业收入/营业成本/毛利率/期间费用/净利润/净利率/财务自给率/农户分红。

**（二）盈亏平衡点说明**

YearX 第 Y 个月月营收达 Z 万元时毛利率覆盖固定成本。红旅赛道盈亏平衡点要求比主赛道宽松，可允许 Year3 转正。

**（三）财务合理性说明**

Year1 用户数 ≤ SOM × 5%；Year3 ≤ SOM × 30%；毛利率 30%~60%（农产品电商偏低，可放宽到 25%）；净利率 Year1 可负、Year3 转正或微利（红旅允许微利，因社会效益优先）；财务自给率 Year1 可低（依赖启动资金）、Year3 ≥ 70%。

### §3.10 第九章 风险与对策（500~700 字 + 风险矩阵表）

红旅赛道风险表必含 6 类风险（比主赛道多 2 类）：

1. **市场风险**：竞品进入 / 消费者偏好变化
2. **技术风险**：系统性能 / 数据安全
3. **运营风险**：农户配合度 / 物流成本
4. **财务风险**：现金流断裂 / 启动资金不足
5. **帮扶成效可持续风险**（红旅特色）：帮扶成效不可持续 / 政策变动 / 乡村基层组织配合度变化
6. **红色基因淡化风险**（红旅特色）：商业属性过强淡化红色基因 / 红色资源对接中断 / 团队思政教育松懈

每类风险含具体风险 + 概率 + 影响 + 应对措施。

### §3.11 第十章 个人成长与团队协作（800~1200 字）

**（一）个人成长（第一人称）**

含 5 要素：
- 角色与动作：你在项目中承担的具体角色 + 完成的具体动作
- 从 X 变为 Y：如"从'只在象牙塔里学农经的学生'变为'能在井冈山老区跑通蜂蜜产业链的助农创业者'"
- 学到的硬技能：助农政策理解/农产品供应链/电商运营/农户沟通
- 学到的软技能：跨文化沟通（与老区农户）/ 抗压能力 / 团队协作
- 失败复盘：至少 1 个具体失败案例 + 复盘收获

**（二）团队协作**

含 4 维度：分工 + 互补 + 共识 + 危机处理（同高教主赛道，但危机案例建议与老区/乡村场景相关，如农户临时毁约/党支部换届对接中断）。

### §3.12 附件清单

- 1：调研报告（老区/乡村调研记录 + 访谈纪要 + 数据统计）
- 2：合作协议（与老区党支部/合作社/农户代表）
- 3：知识产权证书（软著/商标/红色品牌注册）
- 4：媒体报道（学校官网/地方媒体/省级媒体）
- 5：获奖证书（校赛/省赛/相关助农奖项）
- 6：财务报表（如有实际运营）
- 7：团队成员学生证 + 政治面貌证明

## §4 红色基因 4 维度（红旅赛道特色章节必加）

### §4.1 维度一：党史学习

**撰写要求**：300~400 字，含 3 要素：

1. **学习内容**：团队成员学习哪些党史内容（如党在农村的奋斗史/革命老区发展史/乡村振兴战略党史脉络）
2. **学习方式**：理论学习（党课/读书会/党史学习强国）+ 实践学习（老区行/党支部结对/红色研学）
3. **学习成效**：累计学习时长 + 学习笔记篇数 + 团队成员政治面貌发展情况

**金句模板**：
- "团队组建以来，累计开展党史学习教育 12 次、学习时长 36 学时，团队成员中 2 人由优秀团员/积极分子发展为预备党员，3 人新提交申请材料。"
- "通过学习《中国共产党农村工作条例》《乡村振兴促进法》及井冈山斗争史，团队深入理解党在农村的百年奋斗历程，将'为人民服务'的宗旨内化为助农创业的行动指南。"

### §4.2 维度二：革命精神传承

**撰写要求**：300~400 字，含 3 要素：

1. **精神选型**：选择 1~2 种与项目地区匹配的革命精神（井冈山精神/延安精神/西柏坡精神/长征精神/沂蒙精神/大别山精神等）
2. **精神内涵理解**：精神内涵 + 团队如何理解
3. **项目中具体体现**：精神如何指导项目运营（如井冈山精神"坚定信念、艰苦奋斗" → 项目在低谷期坚持农户分红不动摇）

**金句模板**：
- "项目对接井冈山革命老区，团队深入学习'坚定信念、艰苦奋斗、实事求是、敢闯新路、依靠群众、勇于胜利'的井冈山精神，将'敢闯新路'内化为蜂蜜电商模式创新，将'依靠群众'内化为党支部结对 + 合作社运营的群众路线。"

### §4.3 维度三：红色文化传承

**撰写要求**：300~400 字，含 3 要素：

1. **红色资源对接**：项目对接的具体红色资源（革命博物馆/红色遗址/老区党支部/红色文创 IP）
2. **红色文化产品**：项目开发的红色文化产品（红色品牌包装/红色研学路线/红色文创衍生品）
3. **红色文化传播**：项目如何传播红色文化（短视频/直播/线下活动/校园宣讲）

**金句模板**：
- "项目对接井冈山革命博物馆与茅坪镇神山村党支部，联合开发'神山红蜜'品牌，将井冈山斗争时期的'红米饭、南瓜汤'精神融入品牌叙事，通过抖音'红土蜜语'账号发布老区故事短视频 36 条，累计播放 120 万次。"

### §4.4 维度四：典型案例对标

**撰写要求**：300~400 字，含 3 要素：

1. **学习的老区典型**：1~2 个全国典型老区振兴案例（如湖南十八洞村精准扶贫/江西神山村脱贫/陕西梁家河乡村振兴）
2. **典型经验提炼**：典型经验 + 团队如何理解
3. **项目对标**：项目如何对标典型经验（如对标十八洞村"精准扶贫"→ 项目实施"精准帮扶 156 户"）

**金句模板**：

### §4.5 红色基因 4 维度自检 8 问

1. 4 维度是否齐全？（党史学习/革命精神/红色文化/典型案例）
2. 每维度是否有 3 要素？（内容/方式/成效 或 内涵/体现 或 资源/产品/传播 或 典型/经验/对标）

## §8 雷区 10 条（命中即降档或淘汰）

### §8.1 雷区 1：无红色基因或红色基因弱化

**症状**：BP 通篇不提党史学习/革命精神/红色文化/典型案例，或仅一句带过。

**后果**：直接淘汰（红旅赛道核心评审要素缺失）。

**整改**：补齐红色基因 4 维度独立章节，每维度 300~400 字。

### §8.2 雷区 2：帮扶成效无量化数据

**症状**：只写"帮扶了大量农户""促进了老区发展"，无数农户数/增收金额/持续月数。

**后果**：降档处理（评审无法核实帮扶成效）。

**整改**：补齐 6 项量化数据（县乡村数/农户数/增收/持续月数/合作社数/党支部结对数）+ 1~2 个典型案例。

### §8.3 雷区 3：无可持续造血模式

**症状**：完全依赖捐赠/补贴/学校经费，无造血式收入，财务自给率 <30%。

**后果**：降档处理（红旅赛道要求可持续造血）。

**整改**：补齐造血式收入来源 + 财务自给率 ≥70% 路径 + 不依赖外部捐赠的退出机制。

### §8.4 雷区 4：主题与项目地区不匹配

**症状**：项目主题写"革命老区"但帮扶地区非老区（如帮扶普通农村）；项目主题写"民族团结"但帮扶地区无民族群体。

**后果**：降档处理（主题与地区错配）。

**整改**：主题与地区严格匹配。革命老区→必须是国务院认定的革命老区；民族团结→必须是民族地区；西部开发→必须是西部 12 省份。

### §8.5 雷区 5：红色基因与业务脱节

**症状**：红色基因段落写一大段党史学习，但与项目业务无任何关联（如讲延安精神但项目在井冈山）。

**后果**：降档处理（红色基因流于形式）。

**整改**：红色基因必须与项目地区匹配（井冈山项目讲井冈山精神）+ 与项目业务结合（精神如何指导运营）。

### §8.6 雷区 6：农户分红比例过低

**症状**：项目利润农户分红 <30%，平台/团队拿走大部分。

**后果**：降档处理（红旅赛道要求利益共享）。

**整改**：农户分红比例 ≥50% 利润反哺农户，并在 BP 中明确分红机制。

### §8.7 雷区 7：调研不深入

**症状**：未实地调研，仅靠网络资料；调研次数 <2 次；蹲点天数 <7 天；访谈样本量 <30 人。

**后果**：降档处理（红旅赛道要求调研深入）。

**整改**：实地调研 ≥2 次 + 蹲点 ≥7 天 + 访谈 ≥30 人 + 调研报告 1 份。

### §8.8 雷区 8：团队无党员/团员骨干

**症状**：团队 5~8 人中无党员/预备党员/优秀团员/积极分子，政治面貌全为群众。

**后果**：降档处理（红旅赛道要求团队思政要素）。

**整改**：建议含 1 名党员或优秀团员/积极分子作为骨干；团队中至少 2 人为团员；附团队成员政治面貌证明。

### §8.9 雷区 9：政治表述错误

**症状**：用"习思想"代替"习近平新时代中国特色社会主义思想"；用"20 大"代替"党的二十大"；指导思想顺序错误；提"马列""毛思想"简写。

**后果**：直接淘汰（政治红线）。

**整改**：必用规范表述（习近平新时代中国特色社会主义思想/党的二十大/两个确立/两个维护/全心全意为人民服务）；必用全称；必按党章顺序排列指导思想。

### §8.10 雷区 10：用旧版"互联网+"名称

**症状**：封面与正文用"互联网+"代替"中国国际大学生创新大赛"。

**后果**：降档处理（用旧版名称）。

**整改**：2025 起正式名为"中国国际大学生创新大赛"。封面与正文默认用新名，除非用户明确要求用旧名。

### §8.11 其他避坑（5 坑）

1. **数据编造**：农户数/增收金额/调研数据编造 → 评审核查发现直接淘汰
2. **党支部结对协议缺失**：仅口头结对无书面协议 → 附件缺失降档
3. **红色品牌侵权**：使用未授权红色 IP（如直接用"井冈山"商标）→ 法律风险
4. **适老化缺失**：APP/小程序未做适老化，老区农户无法使用 → 落地风险
5. **物流成本低估**：老区物流成本高于城市 30%~50%，财务测算偏低 → 财务不可信

### §11.4 学校差异处理

不同学校校赛模板有微调，处理规则：

- **字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。
- **页边距差异**：部分学校要求 3cm 左右边距。修改 build.py setup_page() 中的 left_margin/right_margin。
- **栏目增减**：部分学校要求"路演答辩记录"栏 → 在 build() 中追加 _add_defense_record() 方法；红色之旅赛道增加"红色基因 4 维度"独立栏 → 已在 _add_red_gene() 中内嵌。
- **级别差异**：国赛 10 章全要 + 红色基因 4 维度独立成节 + 乡村振兴 5 维度独立成节 + 3 年财务预测 + 帮扶成效 6 项数据；省赛 10 章全要 + 红色基因 4 维度合并入项目背景 + 5 维度合并入帮扶成效 + 2~3 年财务预测；校赛可省"个人成长与团队协作"独立栏（合并入团队介绍）+ 1~2 年财务预测。

适配流程：先问"学校下发的模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按国赛模板处理。
