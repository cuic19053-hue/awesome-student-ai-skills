### §9.2 字段优先级与 build.py 行为

- **P0 字段缺失**：build.py 用"（待填写）"占位 + 在控制台打印警告
- **P1 字段缺失**：build.py 跳过该栏 + 在控制台打印提示
- **P2/P3 字段缺失**：build.py 静默跳过，不影响生成

`_validate_data()` 方法会对 P0 字段做强制校验：project_name / red_theme / rural_county / executive_summary / red_gene / service_content。任一为空都会触发警告。
