# §10 build.py 接口说明

> 从 `subskills/internet-plus-red-tour/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要调用 build.py 或了解接口参数时。

### §10.1 命令行用法

```bash
# 使用用户提供的数据生成 docx
python build.py --data data.json --out output.docx

# 使用内置示例数据生成演示文档（验证 build.py 可用性）
python build.py --demo --out demo.docx
```

- `--data`：数据 JSON 文件路径（必填，与 --demo 二选一）
- `--out`：输出 docx 路径（必填，自动创建目录）
- `--demo`：使用内置示例数据生成演示文档

### §10.2 build.py 输出格式规范

- **页面**：A4（21.0cm × 29.7cm），页边距上下 2.54cm 左右 2.5cm
- **正文**：宋体小四（12pt），1.5 倍行距，首行缩进 2 字符
- **一级标题**：黑体三号（16pt），居中，段前段后 12pt
- **二级标题**：黑体小三（15pt），左对齐，段前段后 6pt
- **三级标题**：宋体四号（14pt）加粗，左对齐
- **表格**：宋体五号（10.5pt），表头加粗居中，数据居中
- **页码**：宋体五号，底部居中
- **颜色**：全文黑色字体，无彩色无高亮

### §10.3 build.py 内置示例数据

`DEFAULT_DATA` 含完整 demo（红土蜜语——井冈山老区蜂蜜电商助农平台），所有字段填充真实示例数据（虚构但合理），可直接 `python build.py --demo --out demo.docx` 生成完整 BP 用于验证。

### §10.4 网评 PPT 配套输出提示

build.py 输出的是 Word 版 BP。**2025 大赛官方必交材料是 PPT 形式 BP（转 PDF 上传）**，Word 版只是可选辅助。建议在生成 Word 后告知用户：

> 已生成 Word 版红旅赛道 BP（10 章齐全 + 红色基因 4 维度 + 乡村振兴 5 维度 + 帮扶成效 6 项数据）。请注意：2025 大赛必交材料是 PPT 形式 BP（转 PDF 上传），Word 版为可选辅助材料。请按 §3.12 附件清单 + §10 PPT 13 板块映射表，将 Word 内容拆分到 PPT，每页 1 个板块、每页能自解释。如需生成配套 PPT，请使用 pptx skill。

### §10.5 build.py 调用前自检 5 项

1. `python build.py --help` 输出正常（验证脚本可用）
2. `python build.py --demo --out /tmp/test.docx` 生成 ≥30KB docx（验证端到端流程）
3. `python -c "import ast; ast.parse(open('build.py').read())"` 无语法错误
4. data.json 中至少含 6 个 P0 字段（project_name / red_theme / rural_county / executive_summary / red_gene / service_content）
5. data.json 中 red_theme 字段值为 4 选 1（乡村振兴/革命老区/民族团结/西部开发）
