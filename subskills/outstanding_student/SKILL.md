# 优秀学生 / 优秀团员申请书 Skill

本 skill 处理"优秀学生申请书"与"优秀团员申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 质检。两类评优均评审本学年表现（与优秀毕业生 4 年跨度不同），正文 1500~2000 字（比优秀毕业生短），侧重本学年突出表现。优秀学生学业主导、学生干部履职为必填重点；优秀团员政治主导、团务工作为必填重点。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐、主干课程表与学生干部履职表自动嵌入）。

---

## 一、适用场景与触发条件

**适用**：用户提到"优秀学生""优秀团员""校级优秀学生""院级优秀学生""校级优秀团员""院级优秀团员"等关键词，且本人非应届毕业（不是大四下学期）。

**不适用**（需走其他 skill）：
- 优秀毕业生（4 年跨度，2000~3000 字，应届毕业生）→ 走 outstanding_graduate
- 国家奖学金（一学年跨度，1200~2000 字，侧重本学年全国级成果）→ 走 national_project_eval
- 国家励志奖学金（含家庭经济情况段）→ 走 motivation_scholarship
- 文明大学生（侧重文明素养、道德品质，非学业+学生工作）→ 走文明大学生 skill
- 三好学生（部分学校与优秀学生合并评选，按学校规则走）

**优秀学生 vs 优秀团员 速查区分**：

| 维度 | 优秀学生 | 优秀团员 |
|------|---------|---------|
| 主导维度 | 学业+综合素质+学生工作 | 政治表现+团组织生活+志愿活动 |
| 必填重点段 | 学生工作（含学生干部履职表） | 团务工作（含团内职务+团日活动组织） |
| 学业门槛 | GPA 前 30%、加权≥80 | GPA 前 50%、加权≥75 |
| 政治面貌 | 不限（党员/团员/群众均可） | 必须是共青团员 |
| 志愿服务 | 建议≥30 小时 | 建议≥30 小时（重点项） |
| 评审主体 | 学院评审委员会 | 学院团委 |
| 字数 | 1500~2000 字 | 1500~2000 字 |

**硬门槛**（任一不达标直接劝退）：
- 优秀学生：本学年 GPA 排名前 30%、加权平均分≥80；本学年无挂科、无违纪处分；至少 1 项校级及以上荣誉
- 优秀团员：本学年 GPA 排名前 50%、加权平均分≥75；本学年无挂科、无违纪处分；政治面貌必须为共青团员；按时足额缴纳团费、完成"智慧团建"系统信息维护

**触发后第一步**：核对硬门槛与申报类别。若用户 GPA 不达门槛或政治面貌不符，告知"优秀学生评审侧重本学年学业与学生工作，优秀团员侧重政治表现与团务活动"。区分两类评优，分别按类别调整内容侧重与字段必填项。

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（8~12 轮对话）**：
按"通用必采 → 本学年学业信息 → 思想政治信息 → 科研实践信息 → 学生工作或团务工作信息 → 生活信息"顺序采集。每轮不超过 5 个字段。关键缺失字段必须追问，禁止编造 GPA/排名/竞赛/论文/志愿服务时长/学生干部职务。

**阶段 2 书信体撰写（一次性产出）**：
按"标题 → 称呼 → 开头 → 思想方面 → 学习方面 → 科研与实践 → 学生工作（或团务工作） → 生活方面 → 结尾 → 落款"顺序撰写。正文 1500~2000 字，每段严格控制在规范区间。必须体现本学年表现（不是 4 年综合）。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十二章。必须设置 category 字段为 outstanding_student 或 outstanding_youth_league。

**阶段 4 质检**：
按第十三章 30 项清单逐项检查。任何一项不达标返回阶段 2 修改。

**禁止行为**：
- 开头抒情堆砌（"时光荏苒""岁月如梭""一学年光阴转瞬即逝"）
- 形容词代替事实（"成绩优异""积极参加""全面发展"）
- 获奖不写级别与时间
- 学生干部只写头衔不写履职
- 4 年综合表现写入本学年评优（应聚焦本学年）
- 优秀团员申请书未提团组织生活与团日活动
- 结尾"恳请领导批准"
- 编造 GPA/排名/竞赛/论文/志愿服务时长/学生干部职务

**与优秀毕业生关键区别**：本 skill 评审跨度为本学年（不是 4 年），字数 1500~2000（优秀毕业生 2000~3000），无毕业去向段，无 4 年 GPA 表，主干课程仅列本学年（5~8 门 85+ 而非 5~8 门 90+），不要求国家级成果（校级即可）。

**与文明大学生关键区别**：本 skill 侧重学业+学生工作+科研实践综合素质，文明大学生侧重文明素养（课堂纪律、宿舍卫生、网络文明）与道德品质（拾金不昧、见义勇为等具体事例）。文明大学生门槛更低（不要求 GPA 前 30%），但需要具体文明素养事例。

**与国家奖学金关键区别**：本 skill 门槛低于国奖（GPA 前 30% vs 国奖前 5%），不要求国家级成果，字数更短（1500~2000 vs 国奖 1200~2000），无主干课程学分要求，但学生干部履职表为优秀学生必填项（国奖不强制）。

**与国家励志奖学金关键区别**：本 skill 不写家庭经济情况，无家庭经济困难认定门槛；励志必含家庭情况段与勤工助学经历。

**评审周期与申报窗口**：
- 本学年评优：次年 4-5 月启动，5 月底前提交，6 月初学院评审，6 月中公示
- 申报窗口期：约 2-3 周，错过则等下一年度
- 同一学生同年度可同时申报优秀学生与优秀团员，但需分别提交两份申请书，内容侧重不同

## 四、书信体结构详解

优秀学生 / 优秀团员申请书为标准书信体，正文 1500~2000 字，结构固定如下：

```
标题：优秀学生申请书 / 优秀团员申请书（黑体二号居中）

称呼：尊敬的学院领导、评审委员会：（顶格，全角冒号）

正文：

  开头（80~120 字）：
    "我是 XX 学院 XX 专业 XX 级学生 XXX，
     特申请 2024-2025 学年优秀学生/优秀团员。
     本学年 GPA X.XX/4.0，专业排名第 X/N；
     获 XXX 奖学金；担任 YYY。现将本学年情况汇报如下："

  一、思想方面（200~300 字）
    - 政治立场、入团/入团情况、思想觉悟
    - 党员/预备党员/积极分子：理论学习与党组织生活
    - 优秀团员额外必写：团组织生活、团费缴纳、智慧团建

  二、学习方面（300~400 字，重点）
    - 本学年 GPA、加权平均分、专业排名
    - 主干课程表（5~8 门，含课程名/学分/成绩）
    - 英语四级/六级、计算机等级
    - 学习方法（一句话，不展开）

  三、科研与实践方面（250~400 字）
    - 大创项目/科研立项（含级别+角色+时长+产出）
    - 论文（含期刊级别+作者排序）
    - 学科竞赛（含全称+级别+角色）
    - 志愿服务（含时长+具体活动）

  四、学生工作（优秀学生，150~250 字，重点）
     或 四、团务工作（优秀团员，150~250 字，重点）
    - 优秀学生：学生干部职务+任期+主要工作+成效
    - 优秀团员：团内职务+团日活动组织+团支部建设
    - 学生干部履职表（4 列：职务/任期/主要工作/成效）

  五、生活方面（120~200 字）
    - 生活作风、宿舍长履职、人际关系
    - 不写家庭经济困难（与励志奖学金区别）

  结尾（60~100 字）：
    "以上是我本学年的基本情况。无论评选结果如何，
     我都将以此为新的起点，继续努力学习、全面发展，
     以更高标准要求自己，争取获评优秀学生/优秀团员。
     恳请评审委员会予以考虑。
     此致
     敬礼！"

落款（右对齐）：
  申请人：XXX
  XXXX 年 XX 月 XX 日
```

**字数配比表**（优秀学生）：

| 段落 | 字数区间 | 占比 | 撰写要点 |
|------|---------|------|---------|
| 开头 | 80~120 | 5%~7% | 身份+奖项+3 项核心数据 |
| 一、思想方面 | 200~300 | 13%~17% | 政治面貌+理论+党/团活动 |
| 二、学习方面 | 300~400 | 19%~24% | GPA+课程表+英语+方法 |
| 三、科研与实践 | 250~400 | 16%~24% | 大创+论文+竞赛+志愿 |
| 四、学生工作 | 150~250 | 9%~15% | 履职表+量化成效 |
| 五、生活方面 | 120~200 | 7%~12% | 宿舍+人际 |
| 结尾 | 60~100 | 4%~6% | 朴素表态+此致敬礼 |
| **合计** | **1500~2000** | **100%** | - |

**字数配比表**（优秀团员）：

| 段落 | 字数区间 | 占比 | 撰写要点 |
|------|---------|------|---------|
| 开头 | 80~120 | 5%~7% | 身份+团员+核心数据 |
| 一、思想方面 | 250~350 | 16%~20% | 政治表现+团组织生活+团费+智慧团建 |
| 二、学习方面 | 250~350 | 16%~21% | GPA+课程表+英语 |
| 三、科研与实践 | 200~350 | 13%~21% | 竞赛+志愿服务（重点） |
| 四、团务工作 | 200~300 | 12%~17% | 团内职务+团日活动+团支部建设 |
| 五、生活方面 | 100~180 | 6%~11% | 宿舍+人际 |
| 结尾 | 60~100 | 4%~6% | 朴素表态+此致敬礼 |
| **合计** | **1500~2000** | **100%** | - |

**段落衔接规范**：
- 开头末句固定为"现将本学年情况汇报如下："（不用"如下所示"等指代）
- 各小节标题为"一、思想方面""二、学习方面"等中文序号
- 各小节首句必须含本学年事实数据，禁用抒情开头
- 结尾首句固定为"以上是我本学年的基本情况。"

**此致敬礼格式**：
- "此致"另起一行，首行缩进 2 字符（空两格）
- "敬礼！"另起一行，顶格（不缩进），后接感叹号
- 落款"申请人：XXX" 另起一行，右对齐

## 五、各段落撰写规范

### 5.1 开头段（80~120 字）

**句式三段**：
1. 身份句："我是{college}{major}{grade}学生{name}，特申请{apply_year}{honor_name}。"
2. 数据句：本学年 GPA、专业排名、最高荣誉、学生干部职务，用"；"分隔，末尾加"。"。
3. 进入句：固定"现将本学年情况汇报如下："

**禁用**：抒情开头、形容词堆砌、4 年综合数据（如"4 年加权 GPA"）。

### 5.2 思想方面（200~300 字）

**优秀学生写法**：政治面貌开头 + 理论学习 + 党/团活动 + 思想觉悟。
- 党员/预备党员：必须提习近平新时代中国特色社会主义思想、党的二十大和二十届三中全会精神
- 优秀团员/积极分子：必须提递交申请书时间、列为积极分子时间
- 共青团员：拥护党的领导、认真学习党的创新理论

**句式模板（优秀学生·党员）**：
1. 政治面貌句："作为一名中共预备党员，我认真学习习近平新时代中国特色社会主义思想，深入学习党的二十大和二十届三中全会精神，时刻以正式党员标准要求自己。"
2. 入团轨迹句："2023.09 递交申请材料，2024.03 列为优秀团员/积极分子，2025.06 转为中共预备党员。"
3. 党活动句："参加学院分党校第 8 期培训班结业；2024.10 参与主题党日活动「红色教育基地走访」，撝写调研报告 1 份；提交阶段汇报 4 篇。"
4. 觉悟句："在日常生活中，我注重理论学习与实践结合，关注时政热点，提升思想觉悟。"

**优秀团员额外必写**：
- 团组织生活：带头参加团的组织生活，按时足额缴纳团费，完成「智慧团建」系统信息维护
- 团日活动：本学年参与 X 场团日活动，列举 2~3 项
- 团干部履职：在团组织中担任 X，组织 Y 场团日活动

**句式模板（优秀团员·共青团员）**：
1. 政治面貌句："作为一名共青团员，我拥护中国共产党的领导，认真学习党的创新理论，深入学习党的二十大和二十届三中全会精神。"
2. 入团轨迹句："2019.05 在高中入团，2024.09 转入大学团支部。"
3. 团组织生活句："在团组织中担任团支部组织委员，带头参加团的组织生活，按时足额缴纳团费，完成「智慧团建」系统信息维护。"
4. 团日活动句："本学年参与 2024.10 团日主题教育活动、2025.03 学雷锋志愿服务月、2024.12 团员先进性评议等团日活动 6 场。"
5. 觉悟句："在日常生活中，我注重理论学习与实践结合，关注时政热点，提升思想觉悟。"

**禁用**：堆砌口号、抄党章原文、无具体活动名称与时间。

### 5.3 学习方面（300~400 字，重点）

**必含 4 要素**：
1. 本学年 GPA（含满分制标注，如 3.88/4.0）
2. 加权平均分（如 90.2）
3. 专业排名（含基数与百分比，如第 2/87，前 2.3%）
4. 主干课程表（5~8 门，含课程名/学分/成绩，自动生成 docx 表格）

**主干课程表要求**：
- 课程数 5~8 门（不足 5 门触发警告）
- 必须含课程名、学分、成绩三列
- 优秀学生 5~8 门 85+，优秀团员 5~8 门 80+
- 按学分从高到低或成绩从高到低排序

**学习方面示例**（约 320 字）：
> 本学年 GPA 3.88/4.0，加权平均分 90.2，专业排名第 2/87（前 2.3%）。本学年修读 12 门课程，9 门 85 分以上。
>
> 主干课程成绩：（表格：高等数学 5 学分 94、数据结构 4 学分 93、操作系统 4 学分 92、计算机网络 3 学分 90、数据库原理 3 学分 91、计算机组成原理 4 学分 89）
>
> 高等数学 94、数据结构 93、操作系统 92，专业核心课平均 91.5 分，5 门 90+。CET-4 568 分、CET-6 532 分，能熟练阅读英文文献；计算机二级 C 语言（优秀）、三级数据库技术。学习上注重课前预习与课后总结，建立知识体系；遇到问题主动与老师、同学讨论。

### 5.4 科研与实践方面（250~400 字）

**4 类内容**（按重要性排序）：
1. 大创/科研立项：项目名+级别+角色+时长+产出（如"主持《分布式光伏故障智能诊断系统》校级大创项目，2024.03-2025.03，项目结题评估优秀，申请软件著作权 1 项"）
2. 论文：期刊级别+作者排序+题目+见刊时间（如"以第一作者在《计算机应用》（中文核心）发表论文《XXX》，2025.03 见刊"）
3. 学科竞赛：全称+级别+角色+时间（如"2024.11 全国大学生数学建模竞赛省级一等奖，队长，负责整体建模与论文主笔"）
4. 志愿服务：时长+具体活动（如"累计志愿服务时长 80 小时：担任图书馆管理员 6 个月，每月 6 小时；组织班级一对一帮扶活动，服务同学 30 余人次"）

**句式模板（大创）**："{role}《{name}》{level}大创项目（{duration}），{output}。"
**句式模板（论文）**："以{author_order}在《{journal}》（{level}）发表论文《{title}》，{time} 见刊。"
**句式模板（竞赛）**："{time} {name} {award}（{role}）。"
**句式模板（志愿）**："累计志愿服务时长 {volunteer_hours} 小时：{volunteer_detail}。"
**句式模板（三下乡）**："参与三下乡 {n} 次：{time} 赴{place}，{role}，{output}。"

**量化维度表**：

| 项 | 必含量化 | 示例 |
|---|---------|------|
| 大创 | 级别+时长+产出 | 校级主持 1 学年 软著 1 项 |
| 论文 | 期刊级别+作者排序 | 中文核心 第一作者 |
| 竞赛 | 级别+角色 | 省级一等奖 队长 |
| 志愿服务 | 时长+频次 | 80 小时 6 个月 |
| 三下乡 | 次数+覆盖人数 | 1 次 60 户访谈 |

**优秀学生**：四类均建议覆盖，至少 2 类。
**优秀团员**：志愿服务为重点段，建议必填；大创/论文可弱化。

**边界情况**：
- 无大创无论文无竞赛：仅写志愿服务+三下乡，字数不够可适当展开三下乡详情
- 有大创但未结题：写"正在推进中，预计 2025.06 结题"，不写"结题评估优秀"
- 论文未发表：写"已投稿《XX》审稿中"，不写"已发表"

### 5.5 学生工作 / 团务工作（150~250 字，重点）

**优秀学生（学生工作）**：
- 学生干部职务+任期一句话
- 主要工作概述 2~3 项，每项含量化数据
- 学生干部履职表（4 列：职务/任期/主要工作/成效）
- 详见第八章

**优秀团员（团务工作）**：
- 团内职务+任期一句话
- 主要团务工作 2~3 项，每项含量化数据
- 学生干部履职表（同上，但聚焦团内职务）
- 详见第八章

### 5.6 生活方面（120~200 字）

**3 要素**：生活作风（勤俭节约/作息规律）+ 宿舍长履职（含宿舍荣誉）+ 人际关系。

**句式模板**：
1. 生活作风句："生活中我注重勤俭节约，作息规律。"
2. 宿舍履职句："担任宿舍长期间，组织宿舍 {n} 次集体活动，宿舍{honor}。"
3. 人际句："与同学相处融洽，{specific_event}。"

**优秀学生·生活方面示例**（约 150 字）：
> 生活中我注重勤俭节约，作息规律。担任宿舍长期间，组织宿舍 6 次集体活动，宿舍连续两学期获评「文明宿舍」。与同学相处融洽，曾帮助室友完成 1 次重要实验调试。

**优秀团员·生活方面示例**（约 130 字）：
> 生活中我注重勤俭节约，作息规律。担任宿舍长期间，组织宿舍 5 次集体活动，宿舍获评「文明宿舍」。与同学相处融洽，曾协助团支部成员完成主题团日策划。

**禁用**：写家庭经济困难（与励志奖学金区别）、抒情堆砌、空泛形容。

### 5.7 结尾（80~100 字）

**句式固定**：
- "以上是我本学年的基本情况。"
- "无论评选结果如何，我都将以此为新的起点，继续努力学习、全面发展，以更高标准要求自己，争取获评优秀学生/优秀团员。"
- "恳请评审委员会予以考虑。"
- "此致"另起一行空两格
- "敬礼！"另起一行顶格

**结尾示例**（优秀学生，约 90 字）：

> 此致

- "恳请领导批准"（乞求语气）
- "完全符合评选条件"（绝对化）
- "总结陈词式"抒情结尾
- "为母校增光添彩"（口号化）
- "为同学服务到底"（口号化）

### 5.8 落款（2 行）

- "申请人：XXX" 右对齐
- "XXXX 年 XX 月 XX 日" 右对齐

**禁用**：手写签名留白（docx 自动生成时不留签名空位，提交时手签）。

两类评优评审主体、侧重维度、必填字段均不同，撰写时必须区分。

### 6.1 主导维度差异

| 维度 | 优秀学生 | 优秀团员 |
|------|---------|---------|
| 主导 | 学业+综合素质+学生工作 | 政治表现+团组织生活+志愿活动 |
| 学习方面占比 | 19%~24% | 16%~21% |
| 思想方面占比 | 13%~17% | 16%~20%（增加团组织生活） |
| 学生工作/团务工作占比 | 9%~15% | 12%~17% |
| 科研实践占比 | 16%~24% | 13%~21%（志愿服务为重点） |

### 6.2 思想方面撰写差异

**优秀学生**（200~300 字）：
- 政治面貌开头（党员/预备党员/积极分子/团员/群众均可）
- 党员/预备党员必提习近平新时代中国特色社会主义思想
- 党日活动/阶段汇报可选
- 重点在思想觉悟与理论学习

**优秀团员**（250~350 字，多出 50 字）：
- 政治面貌必须为共青团员
- 必写团组织生活：带头参加团的组织生活，按时足额缴纳团费，完成「智慧团建」系统信息维护
- 必写团日活动：列举 2~3 项本学年参与的团日活动（含时间+名称）
- 团干部额外写团务工作（详见第六.4 节）
- 思想觉悟侧重对共青团的认识与团组织的归属感

### 6.3 学习方面撰写差异

**优秀学生**：5~8 门 85+ 课程，主干课程表为加分项；CET-4/6、计算机等级齐全；学习方法简述。
**优秀团员**：5~8 门 80+ 课程即可，主干课程表为基础项；CET-4 即可（CET-6 加分）；学习方法可省略。

### 6.4 学生工作 vs 团务工作撰写差异

**优秀学生（学生工作）**：
- 必填：position（学生干部职务+任期）+ position_work（主要工作）+ position_history（履职表）
- 学生干部职务示例：班长、学生会主席、团支书、学习委员、社团负责人
- 履职表 4 列：职务/任期/主要工作/成效
- 履职表至少 1 条，建议 2~3 条
- 量化数据示例：组织 8 场活动服务 2000+ 人次

**优秀团员（团务工作）**：
- 必填：league_role（团内职务）+ league_work_detail（团务工作详情）+ position_history（团内履职表）
- 团内职务示例：团支部书记、组织委员、宣传委员、团委干事
- 履职表同 4 列，但聚焦团内职务
- 履职表至少 1 条（团内职务），学生干部职务（如班长）可作为第 2 条
- 量化数据示例：组织 6 场团日活动覆盖 240 人次

### 6.5 完整段落对照示例

**优秀学生·学生工作段示例**（约 200 字）：

## 七、学生干部履职撰写方法

学生干部履职是优秀学生申请书的必填重点，优秀团员申请书中的团务工作同样使用履职表。本节专门说明履职表撰写方法。

### 7.1 履职表 4 列定义

| 列名 | 字段 | 说明 | 示例 |
|------|------|------|------|
| 职务 | role | 含职务全称 | 学院学生会主席 |
| 任期 | term | 起止年月+学期数 | 2024.09-2025.05（1 学年） |
| 主要工作 | work | 2~3 项具体工作 | 组织大型活动 8 场，累计参与 2000+ 人次 |
| 成效 | effect | 可量化结果 | 推动学院学生会获评校级优秀学生组织 |

### 7.2 职务填写规范

- 必须使用全称（"学院学生会主席"而非"学生会主席"）
- 含所属组织（"计科 2201 班班长"而非"班长"）
- 优秀团员团内职务使用团内规范全称（"团支部书记"而非"团支书"）
- 同一职务多个任期合并（"班长 2024.09-2025.05"而非分两条）

### 7.3 任期填写规范

- 格式：YYYY.MM-YYYY.MM（N 学年/N 学期）
- 学期数计算：1 学年=2 学期
- 跨学年任职分段写（如"2023.09-2024.06 大一学年""2024.09-2025.05 大二学年"分两条）
- 临时性职务不写入（如"2024.10 校庆志愿者组长"为临时职务，不写入履职表）

### 7.4 主要工作填写规范

**4 要素齐全**：动词+对象+频次+量化。
- ❌ 反例："组织各种活动"（无频次无量化）
- ✅ 正例："组织学院迎新晚会、运动会等大型活动 8 场，累计参与 2000+ 人次"

**3 类工作示例**：
1. 活动组织类："组织主题班会 12 次、学习经验交流 5 场，建立班级学习互助群"
2. 平台建设类："牵头建立学院学生服务平台，覆盖学习辅导、心理咨询、就业指导 3 大模块"
3. 服务提升类："推动学院学生会获评 2024 年度「校级优秀学生组织」"

**禁用**：
- "工作认真负责，深受同学好评"（无量化）
- "积极组织开展各项活动"（无具体）
- "为同学服务"（空泛）

### 7.5 成效填写规范

**3 类成效**：
1. 数据成效：班级加权平均分由 84.2 提升至 87.6（必须有前后对比）
2. 荣誉成效：所在班级获评 2024 年度校级先进班集体（必须有年份+级别+全称）
3. 影响成效：累计参与 2000+ 人次、覆盖团员 240 人次（必须可量化）

**禁用**：
- "取得良好效果"（无量化）
- "获得师生一致好评"（无具体证据）
- "提升了班级凝聚力"（无前后对比）

### 7.6 履职表完整示例（3 条）

| 职务 | 任期 | 主要工作 | 成效 |
|------|------|---------|------|
| 计科 2201 班 班长 | 2024.09-2025.05（1 学年） | 组织班级主题班会 12 次、学习经验交流 5 场，建立班级学习互助群 | 班级加权平均分由 84.2 提升至 87.6，所在班级获评 2024 年度校级先进班集体 |
| 计算机学院学生会主席 | 2024.09-2025.05（1 学年） | 组织大型活动 8 场，累计参与 2000+ 人次；建立学生服务平台覆盖 3 大模块 | 推动学院学生会获评 2024 年度「校级优秀学生组织」 |
| 校园心理协会副会长 | 2023.09-2024.06（1 学年） | 组织心理健康讲座 4 场、新生心理普查 2 次 | 协会会员数由 80 人增长至 120 人 |

### 7.7 团务工作履职表示例（2 条）

| 职务 | 任期 | 主要工作 | 成效 |
|------|------|---------|------|
| 软件工程 2202 班 团支部组织委员 | 2024.09-2025.05（1 学年） | 组织主题团日活动 6 场，覆盖团员 240 人次；建立"智慧团建"信息台账 | 团费收缴率 100%，所在团支部获评 2024 年度校级五四红旗团支部 |
| 计算机学院团委组织部干事 | 2023.09-2024.06（1 学年） | 协助组织学院团员大会 2 次、团干培训 4 场 | 学院团员青年大学习完成率由 85% 提升至 95% |

### 7.8 履职表常见问题与边界处理

**问题 1：同一职务有多个任期**：合并为一条，任期写完整跨度。如"2023.09-2025.05（2 学年）"，主要工作汇总 2 年内累计成果。

**问题 2：临时性职务（如校庆志愿者组长）**：不写入履职表，可在科研实践段的志愿服务中体现。

**问题 3：校外职务（如实习公司项目组长）**：不写入学生工作履职表，可在科研实践段的实习经历中体现。

**问题 4：履职成效无量化数据**：若实在无量化数据，写"完成 XXX 工作，达到 XXX 目标"，禁用"取得良好效果""深受好评"等空话。

**问题 5：职务级别模糊**：明确写出级别（"学院学生会主席"为院级正职、"班长"为班级正职），不写"学生会干部"等模糊表述。

**问题 6：履职跨学年但本学年只有半年**：本学年评优只看本学年履职，任期写本学年时段，主要工作只列本学年成果。

### 7.9 履职表与文书正文的呼应关系

履职表是"四、学生工作"或"四、团务工作"段的附件式呈现，正文段必须先有概述，履职表紧跟其后作为详细佐证。禁止只列履职表不写概述段，也禁止只写概述段不列履职表。呼应规范：概述段 80~120 字含职务+任期+主要工作概述；履职表至少 1 条与概述段呼应；"主要工作"与"成效"列比概述段更详细含量化数据；概述段用"主要工作："引出 2~3 项工作，履职表按行展开。

### 8.5 提分策略

**优秀学生提分路径**：补足论文（中文核心第一作者加 6 分，SCI 三区及以上第一作者加 8 分）；延长学生干部任期至 2 学年（加 2 分）；增加文体特长（钢琴十级/体育项目省级以上名次，加 4 分）；增加三下乡次数至 2 次（加 4 分）；增加学科竞赛国家级奖项（加 3 分）。

**优秀团员提分路径**：
- 增加志愿时长至 80 小时：加 2 分；150 小时以上加 4 分
- 担任团内正职（团支部书记/团委书记）：加 2 分
- 组织特色团日活动并获校级报道：加 3 分；省级报道加 5 分
- 牵头创建团务品牌项目（如「团员先锋岗」）：加 4 分
- 所在团支部获评校级及以上五四红旗团支部：加 5 分

**提分优先级**：优秀学生优先补足论文（单项加分最高 8 分），其次延长学生干部任期；优秀团员优先增加志愿时长（最易达成），其次组织特色团日活动。

**不可提分项**：
- 本学年 GPA 已达 3.9+/4.0、加权 92+、排名前 3%，学业提分空间小
- 政治面貌已为中共党员/预备党员，思想表现提分空间小
- 文体特长需有实际证书或成绩证明，不可凭兴趣描述

### 8.6 一票否决项

- 本学年有挂科
- 本学年有违纪处分（含考试违纪、宿舍违纪、网络违纪）
- 优秀团员政治面貌非共青团员
- 学生干部履职表无量化成效（"取得良好效果"等空话）
- 编造 GPA/排名/竞赛/论文/志愿服务时长
- 优秀团员未完成「智慧团建」系统信息维护
- 优秀团员欠缴团费
- 学生干部职务低于班级委员（如仅为课代表、寝室长不算学生干部职务）

**申诉机制**：若一票否决项触发，可向学院评审委员会提交书面申诉，提供相关证明材料（如挂科补考通过证明、违纪处分撤销证明等），由评审委员会审议后决定是否恢复参评资格。

### 9.7 结尾"恳请领导批准"

❌ 反例：综上所述，本人完全符合优秀学生评选条件，恳请领导批准！
✅ 正例：以上是我本学年的基本情况。无论评选结果如何，我都将以此为新的起点，继续努力学习、全面发展，以更高标准要求自己，争取获评优秀学生。恳请评审委员会予以考虑。

### 9.8 主干课程不足 5 门

❌ 反例：仅列 3 门主干课程（数据结构、操作系统、计算机网络）。
✅ 正例：列 5~8 门主干课程（高等数学、数据结构、操作系统、计算机网络、数据库原理、计算机组成原理），含课程名/学分/成绩三列。

### 9.9 排名不写基数

❌ 反例：专业排名第 2。✅ 正例：专业排名第 2/87（前 2.3%）。

### 9.10 把励志奖学金的家庭困难内容写入

❌ 反例：我家庭经济困难，父亲在家务农，希望通过申请优秀学生减轻家庭负担。
✅ 正例：（优秀学生不写家庭经济情况）本学年 GPA 3.88/4.0，专业排名第 2/87；获校级一等奖学金；担任学院学生会主席。现将本学年情况汇报如下：

### 9.11 优秀学生与优秀毕业生混淆

❌ 反例：在优秀学生申请书中写"大学 4 年加权 GPA 3.85/4.0""保研至清华大学"。
✅ 正例：本学年 GPA 3.88/4.0，专业排名第 2/87。（优秀学生只看本学年表现，不写 4 年综合数据，不写毕业去向）

### 9.12 优秀团员不写团费与智慧团建

❌ 反例：作为一名共青团员，我积极参加团的活动。
✅ 正例：作为一名共青团员，我按时足额缴纳团费，完成「智慧团建」系统信息维护；本学年参与团日活动 6 场。（必须含团费与智慧团建两项硬性表述）

### 9.13 学生干部成效无量化对比

❌ 反例：担任班长期间，班级凝聚力明显提升。
✅ 正例：担任班长期间，班级加权平均分由 84.2 提升至 87.6，所在班级获评 2024 年度校级先进班集体。（必须有可量化数据或前后对比）

### 9.14 志愿服务只写时长不写具体活动

❌ 反例：累计志愿服务时长 80 小时。
✅ 正例：累计志愿服务时长 80 小时：担任图书馆管理员 6 个月，每月 6 小时；组织班级一对一帮扶活动，服务同学 30 余人次。（必须含具体活动名称与频次）

### 9.15 同一职务拆成多条履职记录

❌ 反例：班长 2024.09-2024.12 班级活动 4 次；班长 2025.01-2025.05 班级活动 8 次。
✅ 正例：班长 2024.09-2025.05（1 学年）班级活动 12 次。（同一职务多个任期合并为一条）

### 9.16 三下乡写"取得良好效果"

❌ 反例：赴甘肃定西开展三下乡，取得良好社会效果。
✅ 正例：赴甘肃定西电商助农调研，走访 5 个村、访谈 60 户，撝写调研报告 1 份（约 1.5 万字）。（必须含覆盖人数与具体产出）

## 十、政治用语规范

**全称规范**：
- "中国共产党"（不能简写为"党"，但"党组织""党员""党的领导"等固定搭配可保留"党"）
- "习近平新时代中国特色社会主义思想"（必须全称，不能简写为"习近平思想"）
- "党的二十大"（不能写"20 大"）
- "党的二十大和二十届三中全会精神"（最新表述，必须含二十届三中全会）
- "共青团"（不能写"团"作为独立名词）
- "团支部"（不能写"团支"）
- "智慧团建"（必须含书名号或引号，作专有名词处理）

**政治面貌写法**：
- 中共党员 / 中共预备党员 / 优秀团员/积极分子 / 共青团员 / 群众
- "中共党员"（不能写"党员"作为正式表述）
- "中共预备党员"（不能写"预备党员"作为正式表述）

**党团活动表述**：
- "主题党日活动"（不能写"党日活动"作为正式表述）
- "主题团日活动"（不能写"团日活动"作为正式表述，但口语化表述可接受）
- "阶段汇报"（提交 X 篇，不能写"汇报思想 X 次"）
- "三下乡"社会实践活动（必须含"社会实践活动"或"暑期'三下乡'"）

**禁用**：
- "坚决拥护党"（应写"拥护中国共产党的领导"）
- "永远跟党走"（口号化，不写入正式申请书）
- "共产主义接班人"（口号化，应写"为共产主义事业奋斗"）

## 十一、docx 生成调用方式

**基础调用**：
```bash
python build.py --data data.json --out output.docx
```

**演示模式**（使用内置示例数据）：
```bash
python build.py --demo --out demo.docx
```

**data.json 必含字段**：
- category（必填）：outstanding_student 或 outstanding_youth_league
- name / college / major / grade / gpa / rank（P0 必填）
- core_courses（5~8 门主干课程）
- position_history（学生干部履职表，至少 1 条）
- 优秀团员额外：league_role / league_activities / league_work_detail

**输出文件命名建议**：
- 优秀学生：`{name}_优秀学生申请书_{apply_year}.docx`（如`张明_优秀学生申请书_2024-2025.docx`）
- 优秀团员：`{name}_优秀团员申请书_{apply_year}.docx`（如`李华_优秀团员申请书_2024-2025.docx`）

**缺失字段处理**：build.py 内置 _validate_data 方法，对缺失字段仅打印警告不阻断生成。生成的 docx 仍可提交但需补全字段后重新生成。

**生成后人工补充**：
- 在落款"申请人：XXX"上方留 1 行手写签名空位（打印后手签）
- 附件材料（成绩单原件、荣誉证书复印件、学生干部任命书）单独装订
- 学校评审系统提交时一并上传 docx 与附件扫描件

## 十二、质检清单

生成 docx 后，按以下 30 项逐项检查。任一不达标返回阶段 2 修改：

**格式检查（10 项）**：
1. 标题为"优秀学生申请书"或"优秀团员申请书"（按 category），黑体二号居中
2. 称呼顶格"尊敬的学院领导、评审委员会："，全角冒号
3. 正文宋体小四，1.5 倍行距，首行缩进 2 字符
4. 小节标题"一、思想方面"等，黑体小四加粗
5. 主干课程表宋体五号居中，含课程名/学分/成绩三列，5~8 门
6. 学生干部履职表 4 列（职务/任期/主要工作/成效），至少 1 条
7. "此致"另起一行空两格，"敬礼！"另起一行顶格
8. 落款右对齐，含"申请人：XXX"+日期两行
9. 页脚居中页码（宋体五号）
10. 全文无英文标点（除"CET-4""GPA"等专有名词）

**内容检查（12 项）**：
11. 开头含身份+申报奖项+3 项核心数据+进入句
12. 思想方面含政治面貌+理论学习+党/团活动
13. 优秀团员思想方面含团组织生活+团费+智慧团建
14. 学习方面含 GPA+加权+排名+主干课程表+英语+计算机
15. 科研实践含大创/论文/竞赛/志愿服务至少 2 类
16. 学生干部履职表 4 列齐全，每条含量化成效
17. 优秀团员团务工作段含团内职务+团日活动+团支部建设
18. 生活方面不含家庭经济困难内容
19. 结尾含"以上是我本学年的基本情况"+朴素表态+恳请评审
20. 全文无形容词代替事实（"成绩优异""积极参加"）
21. 全文无抒情开头（"时光荏苒""岁月如梭"）
22. 全文无"恳请领导批准""完全符合评选条件"

**字数与拼写检查（8 项）**：
23. 正文总字数 1500~2000 字（用 `wc -m` 或 word 字数统计验证）
24. 开头 80~120 字
25. 思想方面 200~300 字（优秀团员 250~350 字）
26. 学习方面 300~400 字（优秀团员 250~350 字）
27. 学生工作/团务工作 150~250 字（优秀团员 200~300 字）
28. 生活方面 120~200 字
29. 结尾 60~100 字
30. 无错别字（特别注意"账"vs"帐"、"的得地"、专有名词）

**字数自检脚本**：
```bash
python -c "
from docx import Document
d = Document('output.docx')
text = ''.join(p.text for p in d.paragraphs)
print(f'正文字数：{len(text)}')
assert 1500 <= len(text) <= 2000, f'字数 {len(text)} 不在 1500~2000 区间'
print('字数达标')
"
```

## 十三、学校差异处理

不同学校对优秀学生/优秀团员申请书的要求略有差异，按以下规则适配：

| 学校类型 | 字数 | 称呼 | 栏目顺序 | 主干课程 | 字体 |
|---------|------|------|---------|---------|------|
| 985/211 | 1800~2000 | 尊敬的学院领导、评审委员会： | 思想→学习→科研→学生工作→生活 | 5~8 门 85+ | 宋体小四 |
| 普通本科 | 1500~1800 | 尊敬的学院领导： | 思想→学习→学生工作→科研→生活 | 5~6 门 80+ | 宋体小四 |
| 省属重点 | 1500~2000 | 尊敬的评审委员会： | 思想→学习→科研→学生工作→生活 | 5~8 门 85+ | 宋体小四 |
| 高职高专 | 1200~1500 | 尊敬的领导： | 思想→学习→学生工作→生活 | 4~6 门 80+ | 宋体小四 |
| 民族院校 | 1500~2000 | 尊敬的学院领导、评审委员会： | 思想（含民族团结）→学习→学生工作→生活 | 5~6 门 80+ | 宋体小四 |

**自定义适配步骤**：
1. 询问用户所在学校（如"请问你所在学校是哪所？")
2. 查询学校教务处/学工部发布的当年评优通知
3. 按通知要求调整字数、称呼、栏目顺序
4. 若通知要求附加栏目（如"民族团结""创新创业"等），在对应段落后增加
5. 生成后向用户确认"是否需要按 XX 学校特殊要求调整"

**常见学校速查表**：
- 清华大学：优秀学生称呼"尊敬的评审委员会："，必含"学术志趣"段
- 北京大学：优秀团员必含"团校学习"经历，称呼"尊敬的学院团委："
- 浙江大学：优秀学生字数 1800~2000，必含"求是"精神表述
- 复旦大学：优秀团员必含"通识教育"感悟
- 上海交通大学：优秀学生必含"思源"精神表述
- 南京大学：优秀学生字数 1500~1800，称呼"尊敬的学院领导："

**未匹配学校**：默认按 985/211 规则生成，向用户提示"按通用规则生成，请按学校评优通知核对字数与栏目顺序"。
