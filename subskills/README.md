## 怎么用

### 方式 1：让 AI 自动路由（推荐）

安装 skill 后，直接跟 AI 说人话：

```
"帮我写一份国家级项目立项逻辑评测申请书"
"我要申报大创创新训练项目"
```

AI 会自动匹配到对应子 skill。

### 方式 2：手动找到对应目录

1. 在上方表格找到你的申报类型
2. 点击链接进入对应目录
3. 阅读 `SKILL.md` 了解完整工作流

### 方式 3：用决策树

见 [根目录 SKILL.md](../SKILL.md) 的「类型识别决策树」，按问答流程找到对应子 skill。
