# 国家助学金申请书：按需采集
学生希望整理资料或正文缺项时读取。每轮只补当前任务必需信息，已知内容不重复询问。

| 信息 | 字段 | 依据与处理 |
|---|---|---|
| 学校、申请学年、材料类型 | 学校通知、apply_year | 核对学校当年表格；学年未知标待补充 |
| 姓名、学院、专业、年级 | name/college/major/grade | 保留学生原称，不扩写专业 |
| 资助档次、金额 | grant_level/grant_amount | 需学校当年明确标准；缺金额留空 |
| 困难认定情况 | difficulty_level/difficulty_cert_no/poverty_category | 只记录已发生的认定，不从家庭情况代学校认定 |
| 家庭情况与就学负担 | family_situation/family_economy | 使用愿意提供的事实；未知人口、收入、支出不填默认数 |
| 在校表现 | study_situation/course_failed/position等 | 缺少成绩不写全部及格；没有勤工、干部或志愿经历就省略 |
| 资助用途、已有安排 | application_reason | 区分实际发生与学生明确的未来计划 |
| 学号、签名、日期与证明 | 按学校模板字段 | 只在实际模板要求时采集；草稿可保留空白 |

学生选择不写收入、亲属姓名、证明编号时，尊重该选择。资料不全可先给带占位的短稿；构建器的提示不是学校审核结果。不要因缺少某种经历诱导补写，或为了凑字数编造事实。
