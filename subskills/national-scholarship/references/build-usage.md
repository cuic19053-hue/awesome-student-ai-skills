# 十二、docx 生成调用方式

> 从 `subskills/national-scholarship/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要调用 build.py 生成文档、或排查生成参数时。

### 12.1 命令

```bash
# 用数据文件生成
python subskills/national_scholarship/build.py --data data.json --out 国家奖学金申请书.docx

# 用内置演示数据快速验证环境
python subskills/national_scholarship/build.py --demo --out demo.docx
```

### 12.2 JSON 字段（依据 `build.py` 实际实现）

```json
{
  "applicant_name": "申请人：张华",
  "application_date": "2026年10月15日",
  "paragraphs": [
    "第一段正文……",
    "第二段正文……",
    "第三段正文……",
    "第四段正文……",
    "第五段正文……"
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `applicant_name` | string | 是 | 落款第一行，需自带"申请人："前缀（脚本不会自动补） |
| `application_date` | string | 是 | 落款第二行，阿拉伯数字，年份写全 |
| `paragraphs` | string[] | 是 | 正文段落数组，逐段渲染为宋体小四、1.5 倍行距、首行缩进 2 字符 |

### 12.3 段落组织建议

当前渲染器**只支持段落文本，不支持表格渲染**，因此：

- 主要获奖、科研成果以**段内分号分条**的形式写入对应段落，例如：
  `在科研方面，我……；获国家级竞赛一等奖 1 项（第 1 完成人，2025 年 5 月）；以第一作者发表会议论文 1 篇。`
- 标题（《国家奖学金申请书》）、称呼（尊敬的学校领导、评审委员会老师：）、"此致/敬礼！"、落款均由脚本自动生成，**不要写进 `paragraphs`**，否则会重复。

### 12.4 输出格式

A4 纸张，页边距上下 2.54 cm、左右 2.5 cm；标题黑体二号居中；称呼宋体小四加粗顶格；正文宋体小四、1.5 倍行距、首行缩进 2 字符；落款右对齐。

### 12.5 已知限制（待扩展，需确认后另行开发）

| 限制 | 影响 | 建议处理 |
|---|---|---|
| 不支持表格 | 无法渲染"主要获奖列表""科研成果表" | 暂以段内分条替代；如需表格需扩展 `build.py` |
| 不支持加粗/分段内的强调 | 关键数据无法突出 | 依赖措辞而非格式 |
| 固定称呼 | 学校要求不同称呼时需改脚本 | 以学校模板为准，必要时手动调整 |
