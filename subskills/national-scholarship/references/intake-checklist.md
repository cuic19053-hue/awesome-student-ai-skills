# 三、信息采集清单

> 从 `subskills/national-scholarship/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要逐条向用户提问采集信息时。

> 采集方式：先一次性列出清单让用户批量填，用户说"不知道从哪填起"时改为逐项追问（每轮 2~3 个问题）。
> 字段冲突时以用户提供的原始材料（成绩单、证书）为准。

### 3.1 通用必采（10 字段）

| # | 字段 | 说明 | 缺失后果 |
|---|---|---|---|
| 1 | 姓名 | 与学籍一致 | 无法落款 |
| 2 | 性别 | 用于表格类模板 | 部分模板必填 |
| 3 | 政治面貌 | 中共党员/预备党员/共青团员/群众 | 思想政治段无支撑 |
| 4 | 年级 | 如 2023 级（须为二年级及以上） | 硬门槛判定 |
| 5 | 专业 | 全称，如"计算机科学与技术" | 开篇段必填 |
| 6 | 学院 | 全称 | 称呼与落款 |
| 7 | 学号 | 数字串 | 部分学校模板必填 |
| 8 | 申请学年 | 如 2025—2026 学年 | 全文时间口径 |
| 9 | 专业排名 | 如 1/120 或"前 1%" | 核心论据 |
| 10 | 联系方式 | 手机号 | 学校备案 |

### 3.2 学业硬指标（8 字段）

| # | 字段 | 采集要点 |
|---|---|---|
| 1 | GPA 数值与满分制 | 明确是 4.0 制、5.0 制还是百分制；**必须说明制式**，否则评审无法判断 |
| 2 | 加权平均分 | 写清是否含公共课 |
| 3 | 专业排名（分子/分母） | 优先"1/120"这种精确写法，避免"名列前茅" |
| 4 | 综合考评排名 | 国奖要求成绩与综测**双达标**，两项都要问 |
| 5 | 主干课程及分数 | 3~5 门与专业相关的核心课，取分数最高且有代表性的 |
| 6 | 英语等级 | 四级/六级分数，或雅思/托福 |
| 7 | 本学年是否有挂科 | 硬门槛，必问 |
| 8 | 是否已获得过国家奖学金 | 同一学业阶段一般不重复获得，必问 |

### 3.3 科研与创新成果（每条 6 字段）

| 字段 | 采集要点 |
|---|---|
| 成果类型 | 论文 / 专利 / 软著 / 科研项目 / 技术报告 |
| 成果名称 | 全称（论文写题名，专利写名称+申请号） |
| 层次 | 国家级 / 省部级 / 校级 / 院级 |
| 本人位次 | 第一作者 / 第二作者 / 主持 / 参与（位次直接决定含金量） |
| 时间 | 年月（与学年口径对应） |
| 状态 | 已发表 / 已录用 / 在审 / 已授权 / 已受理 / 已结题 |

### 3.4 竞赛获奖（每条 5 字段）

| 字段 | 采集要点 |
|---|---|
| 竞赛全称 | 必须写全称，如"第十九届'挑战杯'全国大学生课外学术科技作品竞赛" |
| 竞赛级别 | 国家级 / 省部级 / 校级（注意区分"国家级"与"全国性行业赛"） |
| 获奖等级 | 特等奖 / 一等奖 / 二等奖 / 三等奖 |
| 团队位次 | 第 1 完成人 / 第 2 完成人（位次影响评分） |
| 获奖时间 | 年月 |

### 3.5 综合素质与社会工作（每条 4 字段）

| 字段 | 采集要点 |
|---|---|
| 职务 | 如"班级学习委员""院学生会科创部副部长" |
| 层级 | 校级 / 院级 / 班级 |
| 任职时长 | 如"2024 年 9 月至今" |
| 量化产出 | 组织活动的场次、参与人数、覆盖范围（有数据才算有效成果） |

### 3.6 志愿服务与社会实践（每条 3 字段）

| 字段 | 采集要点 |
|---|---|
| 项目名称 | 具体活动名，避免"参加志愿服务"这类空泛表述 |
| 累计时长 | 小时数（多数学校有最低时长要求） |
| 组织单位 | 校团委 / 学院 / 社区 / 公益机构 |

### 3.7 硬门槛预检（一票否决自查）

撰写前必须逐项确认，任一项不达标应提示用户并给出分流建议：

- [ ] 全日制本科二年级及以上
- [ ] 学习成绩排名位于前 10%（或前 10%~30% 且具备某方面特别突出成绩）
- [ ] 综合考评排名同样达标（多数学校要求双达标）
- [ ] 本学年无挂科记录
- [ ] 无违法违纪处分记录
- [ ] 未在同一学业阶段重复获得国家奖学金
- [ ] 材料真实可核验（有证书、成绩单等佐证）

### 3.8 字段优先级与追问话术

| 优先级 | 字段组 | 缺失时的追问话术 |
|---|---|---|
| P0 必填 | 排名、GPA、学年、挂科情况、违纪情况 | "你的专业排名具体是第几？分母是多少人？综合考评排名也一样吗？" |
| P0 必填 | 最高层次成果（通常 1~2 项） | "一学年里最拿得出手的一项成果是什么？它在什么级别的平台？你是第几完成人？" |
| P1 重要 | 主干课程分数、英语等级 | "你成绩最好的 3 门专业核心课是什么、分别多少分？四级/六级分别多少分？" |
| P1 重要 | 学生工作与志愿服务量化数据 | "你担任这个职务期间，组织过几次活动、大概覆盖多少人？志愿服务累计多少小时？" |
| P2 可选 | 其他荣誉、文体活动 | "除了上面这些，还有没有校级以上的荣誉称号或文体获奖？" |

**追问禁忌**：不要一次抛 10 个问题；不要用"最好""尽量"这类模糊要求让用户自己判断；用户答不上来时，改为提供选项引导（"是国家级还是省级？"）。

### 3.9 复述确认模板

信息采集完成后，用下述格式复述给用户确认，确认后再动笔：

```
我整理到的情况如下，请核对（有误请直接指出）：
· 学业：专业排名 1/120（前 0.83%），GPA 3.92/4.0，综测排名 2/120，无挂科
· 科研：主持国家级大创 1 项（已结题）；第一作者会议论文 1 篇（CCF-C，已录用）
· 竞赛：挑战杯国家级一等奖（第 1 完成人，2025 年 5 月）
· 综合素质：班级学习委员（2024.09 至今）；志愿服务 120 小时
· 政治面貌：中共预备党员
确认无误后我就开始撰写正文。
```
