# 选调生申请书 SKILL

## §0 适用场景与三类选调分流

### 0.1 本 skill 的适用范围

- 应届大学本科毕业生、应届硕士/博士研究生报考选调生
- 中央选调（中组部牵头，面向中央部委）、定向选调（省委组织部，面向双一流）、非定向选调（市委组织部，面向省内高校）三类任一
- 申请书为招录公告要求提交的"个人陈述""报名表自述栏""自荐信"等任一形式
- 涵盖线上报名系统填报、纸质材料邮寄、面试现场提交三类提交方式

### 0.2 选调生 vs 公务员考试 vs 事业编

| 维度 | 选调生 | 公务员（国考/省考） | 事业编 |
|------|--------|---------------------|--------|
| 录用主体 | 党委组织部 | 人社部门 | 用人事业单位 |
| 培养定位 | 党政领导干部后备 | 一般公务员 | 专业技术或管理岗 |
| 入职起点 | 乡镇/街道基层 | 县级以上机关居多 | 视单位而定 |
| 晋升通道 | 重点培养，副科级以上提拔快 | 按年限正常晋升 | 走职称或管理岗双轨 |
| 政治门槛 | 党员必备（部分放宽） | 不强制 | 不强制 |
| 院校门槛 | 双一流或指定院校 | 全日制本科即可 | 大专以上 |
| 服务年限 | 基层 ≥ 5 年 | 无强制 | 视合同 |
| 流动性 | 跨层级调动多（基层→县→市→省） | 跨部门调动多 | 跨单位调动较少 |

### 0.3 三类选调对照表（必读）

| 维度 | 中央选调 | 定向选调 | 非定向选调 |
|------|----------|----------|------------|
| 牵头单位 | 中央组织部 | 省委组织部 | 市委组织部（部分省份省委组织部） |
| 面向院校 | 全国 985 + 部分重点政法/财经类院校 | 双一流高校 + 部分省属重点 | 省内一本以上高校为主 |
| 门槛（学历） | 本科及以上，硕博优先 | 本科及以上 | 本科及以上 |
| 门槛（政治） | 中共党员或预备党员（强制） | 党员或预备党员（强制，少数省份放宽至积极分子） | 党员优先，部分岗位非党员可报 |
| 门槛（学生干部） | 校级以上学生干部经历 | 校级或院级学生干部经历 | 院级学生干部经历即可 |
| 门槛（获奖） | 校级以上奖学金或三好学生 | 校级以上奖励 | 院级以上奖励 |
| 报名时间 | 大四上 10~11 月 | 大四上 9~12 月（各省不同） | 大四下 3~5 月 |
| 笔试 | 中央公务员考试或单独命题 | 各省单独命题或联考 | 各省公务员考试统一 |
| 面试 | 结构化 + 半结构化 | 结构化为主 | 结构化 |
| 录用岗位 | 中央部委机关（如发改委、财政部、组织部） | 省直机关 + 市直机关 | 县直机关 + 乡镇街道 |
| 基层锻炼 | 1~2 年到基层（村/社区） | 2 年到县以下基层 | 直接在县以下基层工作 |
| 竞争度 | 极高（1:100 以上） | 高（1:30~1:50） | 中（1:10~1:30） |
| 发展前景 | 中央部委副处级以上 | 省直机关处级以上 | 县处级或乡科级 |
| 服务年限 | 基层 2 年 + 中央机关 5 年 | 基层 2 年 + 省直 5 年 | 基层 5 年以上 |

### 0.4 三类选调分流决策

申请人应**根据院校层级 + 政治面貌 + 学生干部层级**三类指标对照分流：

- **中央选调**：985 院校 + 中共党员（正式） + 校学生会主席/副主席/校团委部长以上 + 国家奖学金/校长奖学金
- **定向选调**：双一流院校 + 中共党员或预备党员 + 院级以上学生干部 + 校级以上奖学金
- **非定向选调**：省属一本以上院校 + 中共党员优先（部分岗位非党员可报） + 院级学生干部 + 院级以上奖励

**自评分流建议**：
- 院校为 985 + 政治面貌达标 + 学生干部校级以上 → 主报中央选调 + 兼报定向选调
- 院校为双一流 + 政治面貌达标 + 学生干部院级以上 → 主报定向选调（可多省投递）
- 院校为省属一本 + 政治面貌达标 + 学生干部院级以上 → 主报非定向选调（本省为主）
- 政治面貌为优秀团员/积极分子或非党员 → 仅能报非定向选调中放宽政治要求的岗位

### 0.5 触发条件与不触发场景

**触发条件**：用户提到"选调生""选调""选调生申请""定向选调""中央选调""非定向选调""选调生申请书""选调生报名表""选调生个人陈述""选调生报考""党政后备干部""基层选调""省委组织部选调""市委组织部选调""中央机关选调"任一关键词时激活。

**不触发**：
- 用户明确说"国考报名""省考报名"——属公务员考试 skill
- 用户明确说"事业编考试""教师招聘"——属事业编 skill
- 用户明确说"三支一扶""西部计划""大学生村官"——属基层服务项目 skill（与选调生定位不同）
- 用户明确说"人才引进""选聘生"——属人才引进 skill（非选调序列）

### 0.6 工作流程总览

四阶段流程，禁止跳步：

**阶段 1：信息采集（30~50 分钟）**
按 §3 信息采集清单分批采集，先采政治面貌与学生干部（决定是否能报），再采学业与获奖，最后采选调类型与目标省份。

**阶段 2：分类定位（10 分钟）**
按 §0.4 三类选调分流决策表确定主报类型，按 §2 三档字数版本确定申请书字数。

**阶段 3：内容撰写（90~120 分钟）**
按 §4 五段结构 + §5 报考动机 4 维度框架撰写。重点：报考动机段（4 维度缺一不可）、基层工作意愿段（必须具体到乡镇/村/街道，不能空泛）。

**阶段 4：质检与生成（30 分钟）**
按 §11 质检清单逐项核对，禁用句检测（§10 雷区 10 条），最后调用 build.py 生成 docx。

## §1 政策依据与必引文件

### 1.1 中组部相关文件

撰写选调生申请书必须引用以下政策依据，体现政治意识：

| 文件名 | 发布主体 | 发布时间 | 核心要点 |
|--------|----------|----------|----------|
| 《关于做好选调生工作的意见》 | 中组部 | 1983 年首版，2014 年修订 | 选调生是党政领导干部后备人选，从应届高校毕业生中选调到基层工作 |
| 《党政领导干部选拔任用工作条例》 | 中共中央 | 2014 年修订 | 党政领导干部选拔任用的根本遵循 |
| 《关于进一步加强和改进选调生工作的意见》 | 中组部 | 2018 年 | 明确选调生作为培养党政领导干部后备人选的定位 |
| 《关于加强和改进优秀年轻干部培养选拔工作的意见》 | 中共中央 | 2018 年 | 选调生是年轻干部培养的重要渠道 |
| 《中华人民共和国公务员法》 | 全国人大常委会 | 2018 年修订 | 选调生录用、管理、考核的法律依据 |
| 《党政机关公文处理工作条例》 | 中共中央、国务院 | 2012 年 | 申请书格式参考 |

### 1.2 申请书政策引用规范

申请书开头或报考动机段必须至少引用 1 条政策依据，常见表达：

> "作为应届毕业生，我深入学习了《关于做好选调生工作的意见》精神，深刻认识到选调生是党政领导干部后备人选，肩负着党的事业后继有人的神圣使命。"

> "我认真学习了中组部《关于进一步加强和改进选调生工作的意见》，明确了选调生到基层工作、为党的事业储备人才的政治定位，更加坚定了报考决心。"

### 1.3 政策引用三原则

1. **准确**：文件名、发布主体、年份必须准确无误，不可臆造
2. **切题**：引用的政策必须与选调生定位、基层工作、年轻干部培养直接相关
3. **自然**：政策引用应融入论述，不可生硬堆砌，全文政策引用不超过 3 条

## §2 三档字数版本

### 2.1 三档版本总表

| 版本 | 字数 | 适用场景 | 五段比例 | 各段字数区间 | 适用招录 |
|------|------|----------|----------|--------------|----------|
| 2000 字 | 1800~2200 | 报名表自述栏、字数受限岗位 | 2:3:3:1:1 | 400:600:600:200:200 | 非定向选调、字数限制严格的岗位 |
| 2500 字 | 2300~2700 | 个人陈述常规要求（默认） | 2:3:3:1:1 | 500:750:750:250:250 | 定向选调、多数省份选调公告 |
| 3000 字 | 2800~3200 | 个人陈述详细版、面试前提交版 | 2:3:3:1:1 | 600:900:900:300:300 | 中央选调、要求详细陈述的省份 |

### 2.2 版本选择建议

- **中央选调**：默认 3000 字版（中央部委对材料详尽度要求最高）
- **定向选调**：默认 2500 字版（多数省份标准要求）
- **非定向选调**：默认 2000 字版（字数限制较严，基层岗位要求简洁）
- **特殊场景**：招录公告明确要求字数（如"800 字以内""不超过 1500 字"）时，按公告要求选择最接近的版本，并在 build.py 中通过 `custom_word_count` 字段微调

### 2.3 五段结构字数分配（以 2500 字版为例）

| 段落 | 比例 | 字数 | 核心内容 |
|------|------|------|----------|
| 一、个人基本情况 | 20% | 500 字 | 姓名、院校、专业、政治面貌、学生干部、学业、获奖（用事实说话，不抒情） |
| 二、报考选调生动机 | 30% | 750 字 | 4 维度（政治立场 200 + 服务基层 200 + 事业追求 200 + 家乡情怀 150） |
| 三、个人能力素质 | 30% | 750 字 | 政治素质 + 学习能力 + 组织协调 + 群众工作 + 抗压能力（5 项分述） |
| 四、基层工作意愿 | 10% | 250 字 | 自愿到乡镇/村/街道工作，承诺服务年限，对艰苦环境的心理准备 |
| 五、个人发展规划 | 10% | 250 字 | 基层 5 年规划（前 2 年扎根 + 中 2 年成长 + 后 1 年担当） |

### 2.4 字数偏差容忍度

- 各段字数允许偏差 ±50 字（2000 字版）/ ±75 字（2500 字版）/ ±100 字（3000 字版）
- 总字数允许偏差 ±10%
- 超出偏差范围必须调整，避免头重脚轻或某段过短

## §3 信息采集清单

### 3.1 必采信息（10 项，缺一不可）

1. **姓名 + 性别 + 民族 + 出生年月**：基本信息栏必备
2. **籍贯 + 政治面貌 + 入团时间**：选调生政治门槛审核关键
3. **就读院校 + 学历 + 专业 + 入学时间**：院校门槛审核关键
4. **GPA + 专业排名 + 英语水平**：学业硬指标
5. **学生干部职务 + 任职起止时间 + 主要成绩**：组织能力佐证
6. **获奖经历**（校级以上奖学金、三好学生、优秀学生干部等）：必备佐证
7. **选调类型**（中央/定向/非定向）：决定申请书侧重
8. **目标省份或部委**：决定家乡情怀段的写法
9. **报考动机 4 维度**（每维度 1~2 句话）：报考动机段核心
10. **基层工作意愿具体表述**（是否接受跨市/跨县、是否接受艰苦地区）：基层意愿段核心

### 3.2 选采信息（按需采集）

- 社会实践经历（特别是与基层/农村相关的）
- 实习经历（特别是党政机关实习）
- 论文/科研（中央选调和定向选调看中）
- 兴趣特长（如文体、写作、演讲，可佐证综合素质）
- 家庭主要成员及政治面貌（部分省份报名表要求）

### 3.3 不可采集信息

- 家庭收入与财产状况（与申请无关）
- 高中及以前经历（除非是入团关键节点）
- 具体的考分（如行测、申论分数，未公布前不写）
- 其他考生的对比信息

### 3.4 信息采集话术示例

**采政治面貌**：
"请问您的政治面貌是？（中共正式党员/中共预备党员/优秀团员/积极分子/共青团员/群众）"
——选调生申请要求党员或预备党员，优秀团员/积极分子仅部分非定向岗位可报，请如实说明。

**采学生干部经历**：
"请列出您担任过的学生干部职务，按时间倒序：职务名称 + 任职起止时间 + 主要成绩（1~2 项即可）。"
——院级以上学生干部经历是选调生的硬门槛，校级优先。

**采基层意愿**：
"请问您对基层工作的接受范围？是否接受跨市/跨县分配？是否接受艰苦边远地区？"
——此信息直接决定基层工作意愿段的写法，必须如实反映。

## §4 五段结构详解

### 4.1 段一：个人基本情况（500 字 / 2500 字版）

**写作目的**：用事实说话，让审核人在 30 秒内确认申请人符合硬门槛。

**结构公式**：
姓名 + 院校 + 专业 + 政治面貌 + 入团时间 + 学生干部 + 学业排名 + 主要获奖（4 句话内）

**模板**（500 字版）：

> 我叫 XXX，男，汉族，XXXX 年 XX 月生，XX 省 XX 市人，中共党员（XXXX 年 XX 月入团），现为 XX 大学 XX 学院 XX 专业应届本科毕业生。在校期间学业成绩优异，前三年 GPA X.X/X.0，专业排名第 X/X，英语六级 XXX 分，曾获国家奖学金、校级一等奖学金、校级三好学生等荣誉。担任校学生会主席（XXXX 年 XX 月至 XXXX 年 XX 月），组织策划了 XX 活动，参与人次达 XXXX 人，获评"校级优秀学生干部"。同时担任班长、学院党支部组织委员等职务，全面锻炼了组织协调与群众工作能力。

**写作要点**：
1. **开门见山**：第一句必须包含姓名、院校、专业、政治面貌四要素
2. **量化表达**：GPA、排名、参与人次、获奖次数必须用数字
3. **身份叠加**：学生干部职务至少列 2 个（校级 + 院级或班级）

## §5 报考动机 4 维度框架

### 5.1 4 维度总览

| 维度 | 字数（2500 版） | 核心论点 | 必备要素 |
|------|------------------|----------|----------|
| 政治立场 | 200 字 | 党员的政治信仰 + 对党的事业的忠诚 | 党员身份 + 理论学习 + 政治意识 |
| 服务基层 | 200 字 | 对基层工作的真实认同 + 实践经历佐证 | 三下乡/社会实践 + 基层认知 |
| 事业追求 | 200 字 | 选调生职业定位 + 个人事业追求契合 | 职业认知 + 个人定位 |
| 家乡情怀 | 150 字 | 家乡发展关注 + 反哺家乡心愿 | 籍贯 + 家乡特点 + 回乡意愿 |

### 5.2 维度一：政治立场

**核心要素**：
1. 党员身份（正式党员 / 预备党员，入团时间）
2. 理论学习经历（党校培训、主题教育、理论学习中心组等）
3. 政治意识表述（"四个意识""四个自信""两个维护"等规范表述）

### 5.3 维度二：服务基层

**核心要素**：
1. 基层实践经历（三下乡、社会调研、志愿服务、支教等）
2. 对基层的认知（不是空泛"基层很锻炼人"，而是具体场景描述）
3. 服务基层的意愿表态

**模板片段**：

> 大学期间，我先后两次参加"三下乡"社会实践，深入 XX 省 XX 县 XX 村开展支教和乡村振兴调研，亲眼见证了脱贫攻坚和乡村振兴给农村带来的巨大变化，也深刻体会到基层干部工作的艰辛与价值。基层是国家治理的"最后一公里"，是政策落地的关键环节，是青年成长最好的课堂。我愿扎根基层，从乡镇、村、街道一级做起，在解决群众急难愁盼问题中践行初心使命。

### 5.4 维度三：事业追求

**核心要素**：
1. 对选调生职业定位的认知（党政后备 + 基层锻炼 + 长期培养）
2. 个人事业追求与选调生职业的契合度
3. 长期主义表态（不是过渡性选择）

**模板片段**：

### 5.5 维度四：家乡情怀

**核心要素**：
1. 籍贯 + 家乡特点（地理、经济、文化、革命传统等）
2. 对家乡发展的关注（具体到县/市/产业）
3. 反哺家乡的明确意愿

**模板片段**：

> 我是 XX 省 XX 市人，家乡地处 XX 地区，是 XX 革命老区/农业大市/转型发展重点区域，近年来在乡村振兴、产业升级、生态保护等方面取得了显著进展。大学四年我始终关注家乡发展，特别是 XX 县乡村振兴和基层治理工作，每年寒暑假都主动返乡调研。毕业后回到家乡、扎根家乡、建设家乡，是我一直以来的心愿。我希望以选调生身份回到 XX 省，将所学所悟用于家乡建设，为家乡的现代化事业贡献青年力量。

### 5.6 4 维度组合的常见错误

| 错误类型 | 错误示例 | 正确写法 |
|----------|----------|----------|
| 维度缺失 | 只写政治立场 + 服务基层，缺事业追求和家乡情怀 | 4 维度全部覆盖，缺一不可 |
| 维度比例失衡 | 政治立场 400 字，家乡情怀 50 字 | 各维度大致按 200:200:200:150 分配 |
| 维度混淆 | 把家乡情怀写进服务基层段 | 严格按 4 维度分类，每段只写一个维度 |
| 维度内容空泛 | "我热爱基层工作" | "我先后两次参加三下乡，深入 XX 村..." |
| 维度表述错位 | 政治立场段大谈家乡发展 | 政治立场段只讲党员身份 + 理论 + 政治意识 |

### 7.3 政策引用三原则

1. **准确**：文件名、发布主体、年份必须准确，不可臆造
2. **切题**：引用的政策必须与选调生定位、基层工作、年轻干部培养直接相关
3. **自然**：政策引用应融入论述，不可生硬堆砌，全文政策引用不超过 3 条

## §8 雷区 10 条

### 8.1 雷区 1：动机不纯用语

**禁止**：出现"镀金""跳板""过渡""备胎""曲线救国"等动机不纯用语。

**原因**：选调生定位为党政后备干部，组织部对申请人动机纯洁性要求极高，发现动机不纯直接淘汰。

**正确**：用"长期主义""扎根基层""奉献青春"等表述。

### 8.2 雷区 2：抄袭网络模板

**禁止**：直接复制网络选调生申请书模板，重复率 > 30%。

**原因**：组织部会用查重系统检测，重复率超标的申请书直接淘汰。

**正确**：基于个人信息原创撰写，可参考结构但内容必须个性化。

### 8.3 雷区 3：虚构党龄/学生干部/获奖

**禁止**：虚构入团时间、学生干部职务、获奖经历。

**原因**：组织部会与本人档案、学校学工部核实，发现虚假信息取消资格并记入诚信档案。

**正确**：所有信息必须与档案、证书一致，不确定的可不写。

### 8.4 雷区 4：回避基层

**禁止**：申请书全文未提及"基层"或提及少于 5 次。

**原因**：选调生核心定位是基层工作，回避基层说明对定位认知不清。

**正确**："基层"一词出现 ≥ 5 次，且必须具体到乡镇/村/街道。

### 8.5 雷区 5：贬低其他职业路径

**禁止**：写"考不上研才来选调""国考太难所以选调""公务员没考上选调保底"等贬低性表述。

**原因**：暴露动机不纯，组织部极为反感。

**正确**：选调生作为第一志愿或理性选择，不与其他职业做贬低性对比。

### 8.6 雷区 6：对招录省份/部委不当评价

**禁止**：对目标省份或部委做不当评价（如"XX 省经济落后""XX 部委待遇差"）。

**原因**：体现政治意识薄弱，对招录单位不尊重。

**正确**：对目标省份/部委只做正面描述，可结合发展机遇、政策导向等正面评价。

### 8.7 雷区 7：个人规划不落到基层

**禁止**：写"3 年回省直""5 年调中央""基层锻炼后回部委"等短期跳板规划。

**原因**：与选调生基层 5 年服务期要求相悖，体现短期主义。

**正确**：规划必须围绕基层，5 年扎根基层 + 后续按组织安排。

### 8.8 雷区 8：4 维度缺一不可

**禁止**：报考动机段只写政治立场 + 服务基层，缺事业追求和家乡情怀。

**原因**：4 维度是申请书评审核心维度，缺失任何一项都影响评审。

**正确**：4 维度全部覆盖，按 200:200:200:150 字数分配。

### 8.9 雷区 9：政治表述不规范

**禁止**：用"邓小平理论、'三个代表'重要思想、科学发展观、习近平新时代中国特色社会主义思想"以外的非规范表述，或漏写"习近平"前的"同志"或漏写"新时代"。

**原因**：政治表述必须严格规范，任何省略或错字都体现政治素养不足。

**正确**：严格按党中央规范表述，如"习近平新时代中国特色社会主义思想""四个意识""四个自信""两个维护"。

### 8.10 雷区 10：格式与字数不规范

**禁止**：字数严重超标或不足、段落结构混乱、字体字号不符合招录公告要求。

**原因**：体现申请人对招录公告的不重视，组织部门第一印象扣分。

**正确**：严格按招录公告字数要求（如 2000/2500/3000 字版），格式按本 skill 规范（宋体小四、1.5 倍行距、首行缩进 2 字符）。

## §11 build.py 接口说明

### 11.1 命令行用法

```bash
# 生成 demo 文档（使用内置 DEFAULT_DATA）
python build.py --demo --out demo.docx

# 使用外部 data.json 生成
python build.py --data data.json --out output.docx

# 指定字数版本（覆盖 JSON 中的 word_version）
python build.py --data data.json --out output.docx --word-version 2000

# 指定选调类型（覆盖 JSON 中的 selection_type）
python build.py --data data.json --out output.docx --selection-type central
```

### 11.2 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `--demo` | flag | 否 | 使用内置 DEFAULT_DATA 生成 demo 文档 |
| `--data` | path | 否 | 输入 JSON 文件路径 |
| `--out` | path | 是 | 输出 docx 文件路径 |
| `--word-version` | int | 否 | 覆盖字数版本（2000/2500/3000） |
| `--selection-type` | str | 否 | 覆盖选调类型（central/directional/non_directional） |

### 11.3 输出格式规范

- A4 纸张（21cm × 29.7cm）
- 页边距：上下 2.54cm，左右 2.5cm
- 一级标题：黑体三号居中
- 二级标题：黑体小三左对齐
- 正文：宋体小四，1.5 倍行距，首行缩进 2 字符
- 签字栏：宋体小四右对齐
- 输出文件：docx 格式

## §13 FAQ 常见问题

### Q1：选调生申请书与保研推免申请书有什么区别？

**A**：
- **定位不同**：选调生是党政后备干部，保研推免是学术人才培养
- **侧重不同**：选调生重政治素质 + 基层意愿 + 学生干部，保研推免重学业 + 科研 + 学术潜力
- **结构不同**：选调生 5 段（基本情况 + 报考动机 + 能力素质 + 基层意愿 + 发展规划），保研推免 3 段（学术基石 + 实践历程 + 未来展望）
- **字数不同**：选调生 2000~3000 字，保研推免 500~1800 字

### Q2：中央选调、定向选调、非定向选调如何选择？

**A**：按 §0.4 三类选调分流决策表对照。简单原则：
- 985 + 党员 + 校级学生干部 + 国家级奖励 → 中央选调
- 双一流 + 党员 + 院级以上学生干部 + 校级以上奖励 → 定向选调
- 省属一本 + 党员（部分非党员可报） + 院级学生干部 + 院级以上奖励 → 非定向选调

### Q3：报考动机 4 维度可以省略其中 1~2 个吗？

**A**：**不可以**。4 维度是申请书评审的核心维度，缺失任何一项都会影响评审。即使家乡情怀段较短（150 字），也必须有实质内容。

### Q4：非党员可以报考选调生吗？

**A**：
- 中央选调、定向选调：必须党员或预备党员
- 非定向选调：部分省份部分岗位放宽至优秀团员/积极分子或非党员（如共青团员）
- 本 skill 默认要求党员或预备党员，非党员申请人请在 build.py 中跳过党员信息栏，并明确说明所报岗位放宽政治要求

### Q5：申请书字数怎么算？

**A**：按中文字符计算（不含标点、空格）。build.py 会自动统计并显示在生成日志中。如招录公告明确要求"800 字以内""不超过 1500 字"等，请在 build.py 中通过 `custom_word_count` 字段微调，或选择最接近的版本（2000/2500/3000）。

### Q6：申请书需要签字盖章吗？

**A**：
- 申请人本人签字：必填（手写签字或电子签字）
- 学院党委审核签字：定向选调和中央选调通常要求，非定向选调部分省份要求
- 学院党委盖章：定向选调和中央选调通常要求
- build.py 会在文档末尾自动生成签字栏，请申请人打印后手写签字

### Q7：可以同时报考多个省份的选调生吗？

**A**：可以。定向选调各省份之间不冲突，可多省投递。但中央选调与定向选调的时间可能冲突，需合理安排。建议主报 1~2 个省份，避免分散精力。

### Q8：申请书提交后还能修改吗？

**A**：通常不能。线上报名系统提交后无法修改，纸质材料邮寄后无法回收。请在提交前严格按 §12 质检清单核对。

## §15 工作流程总结

### 15.1 总流程

1. **信息采集**（30~50 分钟）：按 §3 清单采集 10 项必采信息
2. **分类定位**（10 分钟）：按 §0.4 确定选调类型 + §2 确定字数版本
3. **内容撰写**（90~120 分钟）：按 §4 五段结构 + §5 4 维度框架撰写
