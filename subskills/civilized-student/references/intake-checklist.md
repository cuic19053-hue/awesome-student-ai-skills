# 三、信息采集清单

> 从 `subskills/civilized-student/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：需要逐条向用户提问采集信息时。

按字段优先级 P0/P1/P2 标注。P0 必采，缺失则警告；P1 建议采，缺失则降低文档质量；P2 可选，提供则增强文档。

| 字段 | 说明 |

| opening / ideology / civility / morality / academics_life / ending | 提供则直接使用，跳过模板拼装 |

**追问话术**：
- 缺文明素养事例时追问"课堂纪律方面本学年有无迟到早退？有无手机违规记录？请举 1~2 个正面事例（含时间+证明人）"
- 缺宿舍卫生时追问"宿舍本学年卫生检查得分？有无获评文明宿舍？时间与级别？证明人是辅导员还是宿管？"
- 缺网络文明时追问"网络言行方面有无违规？有无主动举报不实信息或参与网络文明志愿活动？时间与证明人？"
- 缺道德事例时追问"本学年有无拾金不昧、见义勇为、助人为乐等具体事例？请按 时间+地点+事件+影响+证明人 五要素提供"
- 缺证明人时追问"该文明事例的证明人是谁？（辅导员/班主任/宿管/同学姓名均可，必须可联系核实）"
- 缺公共秩序事例时追问"食堂就餐是否参与光盘行动？累计次数？图书馆自习有无主动提醒喧哗同学？上下楼梯有无礼让师生或搀扶老教师？时间与证明人？"
- 缺课堂纪律事例时追问"本学年课程是否零迟到零早退？有无主动维护课堂秩序的具体事例（如转交遗留物品、提醒同学关闭手机）？时间与任课教师姓名？"
- 缺道德事例影响时追问"该道德事例的具体影响是什么？（如失主是否写感谢信、医院诊断结果、被救助同学恢复情况、是否有媒体报道）"
- 缺宿舍荣誉级别时追问"文明宿舍是院级、校级还是省级？获评学期数？证书复印件是否可提供？"

**字段缺失处理策略**：
- P0 字段缺失：必须追问，3 轮追问仍无果则在文档中标注"【待补充】"并提示用户
- P1 字段缺失：建议追问，1 轮追问无果则省略该段或用默认表述
- P2 字段缺失：直接省略，不追问

**证明人字段规范**：
- 必须可联系核实（评审会电话回访）
- 教师优先于同学（教师证明力更强）
- 管理人员优先于学生（辅导员/宿管/保卫处老师优于同学）
- 至少 1 名教师/管理人员作为证明人，避免全部为同学姓名
- 证明人姓名+职务+联系方式（联系方式可仅记录于附件，正文仅写姓名+职务）

**信息采集顺序**：通用必采 → 学业信息 → 思想品德 → 文明素养 4 维度（按课堂→宿舍→网络→公共秩序顺序）→ 道德事例（按时间倒序）→ 生活信息 → 荣誉信息。每个维度采集完后立即向用户复述确认，再进入下一维度。

**复述确认**：信息采集结束后，必须向用户复述"本学年课堂零迟到（证明人：辅导员 XXX），宿舍连续 2 学期文明宿舍（证明人：宿管 XXX），网络零违规；道德事例 2 件：2024.05 拾到钱包 800 元交保卫处（证明人：保卫处 XXX）；2024.11 扶起摔倒老人陪同送医（证明人：校医院孙医生）"，确认无误后再进入撰写阶段。
