# 转专业申请书 Skill

本 skill 处理"转专业申请书""转系申请书""专业调整申请"全流程：信息采集 → 书信体撰写 → docx 生成 → 质检。

**核心定位**：转专业是大学本科生在大一或大二学年申请转入本校其他专业的正式程序，依据教育部《普通高等学校学生管理规定》（教育部令第 41 号）第六十一条与各校转专业管理办法。申请书是转专业考核的重要材料之一，正文约 1000~1500 字，侧重"为什么转 + 转入后做什么"。多数学校转专业申请窗口集中在大一第二学期末（5~6 月）或大二第一学期初（9~10 月），错过则等下一年度。

**输出文件**：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐、目标专业课程表与转后学习计划表自动嵌入）。

## §0 适用场景与定位

### 0.1 适用范围

**适用**：用户提到"转专业""转专业申请书""转系""转院""专业调整""申请转专业""转入XX专业""大一转专业""大二转专业""本科转专业""换专业"等关键词，且本人为大一或大二在校生（少数学校允许大三上学期申请）。

**典型场景**：
1. 大一第二学期末（5~6 月）申请转入其他专业（最常见的窗口期）
2. 大二第一学期初（9~10 月）申请转入其他专业（部分学校第二窗口）
3. 入学后因身体原因、家庭变故等申请调整专业（特殊通道，需医疗证明或户籍证明）
4. 大类培养分流前申请转入其他大类（部分 985 高校大类培养模式）

### 0.2 不适用场景（需走其他 skill）

- **保研推免**：跨专业保研走 `graduate_recommendation` skill（保研是研究生阶段跨专业，转专业是本科阶段校内转）
- **休学复学**：复学申请不属于本 skill，需走教务系统提交复学申请表
- **跨校转学**：跨校转学走教育部跨校转学流程，非本 skill 范围
- **研究生转导师/转方向**：研究生阶段不适用本 skill
- **专科升本科**：专升本属于升学考试，非本 skill 范围
- **大类培养分流**：大类分流走学校分流系统，但若分流前申请转入其他大类则适用本 skill

### 0.3 转专业 vs 保研推免 跨专业 关系

转专业与保研推免跨专业是两种不同的"换专业"路径，必须区分清楚：

| 对比项 | 转专业（本 skill） | 保研推免跨专业（graduate_recommendation） |
|-------|------------------|---------------------------------------|
| 申请阶段 | 本科阶段（大一/大二） | 本科毕业前（大三下/大四上） |
| 申请结果 | 本校其他专业本科生 | 外校或本校研究生 |
| 学历层次 | 本科 | 研究生（硕士/直博） |
| 评审材料 | 转专业申请书 + 成绩单 + 笔试面试 | 推免申请表 + 个人陈述 + 推荐信 |
| 字数 | 1000~1500 字 | 1500~2000 字 |

**触发后第一步**：核对申请阶段。若用户说"我要转专业"且为大一大二在校生 → 本 skill；若用户说"我要跨专业保研"且为大三 → `graduate_recommendation` skill。若用户混淆（如大三学生说"转专业"），必须追问"您是要本科阶段校内转专业（大一/大二窗口），还是要跨专业保研（研究生阶段）？两者申请阶段与材料差异很大"。

### 0.4 申请窗口与时间节点

- **大一第二学期窗口**（最常见）：5 月初启动 → 5 月中旬提交申请书 → 5 月底笔试 → 6 月初面试 → 6 月中公示 → 9 月新学期入学新专业
- **大二第一学期窗口**（部分学校）：9 月初启动 → 9 月中旬提交申请书 → 9 月底考核 → 10 月初公示 → 10 月中转入新专业
- **特殊通道窗口**：身体原因/家庭变故随时申请，需医疗证明或户籍证明 + 学校审批
- **申报窗口期**：约 2~3 周，错过则等下一年度或下个窗口
- **同年度限制**：一般同年度仅可申请 1 个目标专业，部分学校允许 2 个志愿

## §1 转专业 3 类对照表（必加章节 1）

### 1.1 3 类对照表

| 维度 | 兴趣驱动型 | 学业优势型 | 职业规划型 |
|------|----------|----------|----------|
| 核心动机 | 对目标专业有持续兴趣与初步探索 | 在目标专业相关课程/竞赛中表现突出 | 目标专业与长期职业规划高度匹配 |
| 评审侧重 | 兴趣的真实性 + 持续性 + 已有探索 | 学业能力的可迁移性 + 已有成果 | 职业目标的清晰度 + 专业的支撑性 |
| 适用人群 | 高考填报失误 + 入学后自主探索 + 兴趣明显转向 | 现专业某门课与目标专业交叉且高分 + 自学目标专业课程 | 有明确职业方向（如医生/律师/科研）+ 现专业无法支撑 |
| 必备佐证 | 自学笔记/项目/读书清单/相关社团经历 | 高分交叉课程/目标专业相关竞赛/科研经历 | 职业调研报告/实习经历/行业人物访谈 |

| 常见雷区 | 兴趣无据可查（仅一句"我喜欢"）；贬低现专业 | 学业成绩无量化（仅"成绩优异"）；交叉课程名模糊 | 职业规划空泛（仅"想做XX"）；无行业调研 |
| 评审风险 | 中（需充分佐证兴趣真实性） | 低（学业数据客观可信） | 高（需职业规划具体可执行） |
| 推荐档位 | 1000 字标准版 | 800 字短版（数据为主） | 1500 字长版（规划要详） |

### 1.2 兴趣驱动型详细规范

**核心撰写要点**：兴趣必须有据可查，必须体现"持续性 + 主动性 + 已有探索"三要素。

**必备 4 要素**：①兴趣萌芽时间点（如"大一上学期阅读《XXX》后"）②持续探索时长（如"自 2024.09 起持续 8 个月"）③已有探索成果（自学课程/项目/读书清单/社团活动，必须量化）④兴趣与目标专业的契合点（具体课程/方向/方法）。

**正例**：自 2024.09 入学后，我在通识课《人工智能导论》中接触到机器学习基础，由此萌生对计算机科学的浓厚兴趣。8 个月来，利用课余时间自学吴恩达《Machine Learning》课程（累计 120 小时），完成 3 个 Kaggle 入门项目（最好成绩 top 30%），阅读《深度学习》前 6 章。同时加入校 ACM 协会，每周参与 2 次算法训练。这些探索让我确认计算机科学是我真正热爱的方向。

**反例**：我一直对计算机科学很感兴趣，希望转入计算机学院深入学习。（无时间点、无探索成果、无量化）

### 1.3 学业优势型详细规范

**核心撰写要点**：学业优势必须可迁移到目标专业，必须含具体课程/成绩/排名数据。

**必备 4 要素**：①与目标专业交叉的高分课程（含课程名/学分/成绩）②目标专业相关竞赛/科研经历（含级别/角色/产出）③现专业总 GPA 与排名④学业能力可迁移性论证（如"数学基础可迁移至计算机算法"）。

**正例**：大一学年 GPA 3.92/4.0，专业排名第 3/95。其中与计算机科学交叉的高等数学（上）95 分、线性代数 94 分、离散数学 96 分（专业第一），为转入计算机科学后的算法与数据结构学习奠定扎实数学基础。同时参加 2025.04 全国大学生数学建模竞赛获省级二等奖（队长，负责建模与编程）。这些学业成果证明我具备转入计算机科学后的学业竞争力。

**反例**：我成绩优异，擅长数学，希望转入计算机科学发挥我的数学优势。（无具体课程、无成绩、无竞赛、无可迁移论证）

### 1.4 职业规划型详细规范

**核心撰写要点**：职业规划必须具体可执行，必须含行业调研与目标专业支撑性论证。

**必备 4 要素**：①明确职业方向（如"医疗 AI 算法工程师"，非"IT 行业"模糊表述）②行业调研基础（实习/访谈/调研报告，含量化数据）③目标专业对职业的支撑性（具体课程/师资/平台）④现专业对职业的限制（如"现专业无相关课程与实践平台"）。

**正例**：长期职业目标是成为医疗 AI 算法工程师，将深度学习应用于医学影像诊断。2025.01~2025.04 在 XX 医院信息科实习 3 个月，参与肺结节 CT 影像辅助诊断项目，独立完成数据预处理模块（处理 1200 例 CT 数据），深入理解医疗 AI 行业的技术需求与监管要求。访谈 3 位行业从业者后，确认计算机科学（医学影像方向）是通往该职业的必经路径。现就读的化学工程专业无相关课程与实践平台，无法支撑我的职业目标，故申请转入计算机科学与技术专业。

**反例**：我未来想做 IT 行业，化学工程专业不好就业，希望转入计算机科学。（职业方向模糊、无调研、无支撑论证、贬低现专业）

### 1.5 3 类对照判定口诀

**兴趣驱动判定**：核心是"喜欢" → 关键词"喜欢/热爱/兴趣/萌生" → 必须有"持续探索 + 已有成果"
**学业优势判定**：核心是"擅长" → 关键词"擅长/优势/高分/排名" → 必须有"交叉课程 + 可迁移论证"
**职业规划判定**：核心是"想做" → 关键词"职业/规划/未来/想成为" → 必须有"行业调研 + 支撑论证"

**3 类不可混写**：一份申请书只能聚焦 1 类主线，可在结尾段弱关联另 2 类作辅助。混写将导致评审无法抓住主线，降低通过率。

### 1.6 3 类混合场景处置

若用户实际动机含多类元素，按以下规则处理：兴趣 + 学业优势 → 选学业优势为主线；兴趣 + 职业规划 → 选职业规划为主线；学业优势 + 职业规划 → 选学业优势为主线；3 类全有 → 选学业优势为主线，另 2 类各 80 字辅助。

## §2 转专业 5 段结构（必加章节 2）

转专业申请书正文遵循"个人基本情况 15% + 现专业学习 20% + 转专业原因 25% + 目标专业认知 25% + 转后规划 15%"的权重配比。注意：此处的百分比是字数与撰写侧重配比，不等于评审打分权重。

### 2.3 5 段结构详细分解

**第一段：个人基本情况（15%）**

按 4 要素撰写，缺一不可：
1. 身份信息（学院 + 专业 + 年级 + 姓名）
2. 入学背景（高考年份 + 录取方式 + 入学分数概况，简洁）
3. 高考志愿填报说明（为何填报现专业：调剂/家长建议/分数限制，简洁）
4. 申请事项收束句（"现申请转入 XX 学院 XX 专业"）

**第二段：现专业学习情况（20%）**

按 4 要素撰写：
1. 现专业 GPA + 排名（含基数与百分比）
2. 主干课程表（现专业 4~6 门，含课程名/学分/成绩）
3. 与目标专业交叉课程（学业优势型必含，需高亮）
4. 整体学业能力评价（一句话，不展开）

**第三段：转专业原因（25%）**

按 §1 确定的主线类型撰写：
- 兴趣驱动型：兴趣萌芽 + 持续探索 + 已有成果 + 契合点
- 学业优势型：交叉课程高分 + 竞赛/科研 + 可迁移论证
- 职业规划型：明确职业方向 + 行业调研 + 目标专业支撑性 + 现专业限制

**严禁贬低现专业**：不得写"现专业不好""现专业没前途""现专业老师水平低"等贬低表述。可写"现专业与我的兴趣/职业规划方向存在差异"等中性表述。

**第四段：目标专业认知（25%）**

按 §3 的 4 维度撰写（专业课程/师资力量/就业前景/学科竞赛），每维度必须含具体名称。

**第五段：转后规划（15%）**

按短/中/长期 3 阶段撰写：
1. 短期（转入后 1 学期）：补修目标专业基础课（具体课程名 + 学分 + 补修方式）
2. 中期（转入后 1~2 学年）：科研/竞赛/实习计划（具体项目 + 时间 + 目标）
3. 长期（毕业去向）：保研/考研/就业方向（具体方向 + 目标院校/公司）

| **合计** | 100% | **1000 字** | **1500 字** |

### 2.5 5 段结构模板（按 1000 字版速查）

标题：转专业申请书（黑体二号居中） → 称呼：尊敬的学院领导、教务处老师：（顶格，全角冒号） → 开头（50 字）：身份 + 申请事项 + "现就转专业事宜汇报如下：" → 一、个人基本情况（150 字，15%）：[身份 + 入学背景 + 高考志愿说明 + 申请事项收束] → 二、现专业学习情况（200 字，20%）：[GPA + 排名 + 课程表 + 交叉课程] → 三、转专业原因（250 字，25%）：[3 类主线之一 + 量化数据] → 四、目标专业认知（250 字，25%）：[4 维度 + 课程名 + 师资] → 五、转后规划（150 字，15%）：[短/中/长期 + 学习计划表] → 结尾（50 字）："以上是我的转专业申请，恳请审批。此致 敬礼！" → 落款（右对齐）：申请人：XXX / XXXX 年 XX 月 XX 日

### 2.6 段落衔接与此致敬礼规范

- 开头末句固定为"现就转专业事宜汇报如下："（不用"如下所示"）
- 各段标题为"一、个人基本情况""二、现专业学习情况"等中文序号；首句必须含本段核心数据，禁用抒情开头
- 结尾首句固定为"以上是我的转专业申请。"
- "此致"另起一行，首行缩进 2 字符；"敬礼！"另起一行，顶格，后接感叹号
- 落款"申请人：XXX"另起一行，右对齐；日期另起一行，右对齐

## §3 目标专业认知 4 维度（必加章节 3）

目标专业认知段（250~375 字，25%）按"专业课程 + 师资力量 + 就业前景 + 学科竞赛"4 维度撰写。每个维度必须有具体名称，禁用泛泛而谈。这是评审判断"申请人是否真正了解目标专业"的关键段落，4 维度缺一即触犯雷区 3。

### 3.1 4 维度量化框架

| 维度 | 权重（段内） | 字数 | 必含量化要素 |
|------|-----------|------|-----------|
| 专业课程 | 30% | 约 75~115 字 | 至少 5 门目标专业核心课程名 + 学分 + 培养目标 |
| 师资力量 | 25% | 约 60~95 字 | 至少 2 位教师姓名 + 职称 + 研究方向 |
| 就业前景 | 25% | 约 60~95 字 | 至少 3 个就业方向 + 行业数据 + 薪资水平 |
| 学科竞赛 | 20% | 约 50~75 字 | 至少 2 个目标专业相关学科竞赛 + 已规划参与 |

### 3.2 维度 1：专业课程（30%）

**必含 3 要素**：①至少 5 门目标专业核心课程名（必须从目标专业培养方案中查证，不能编造）②课程学分（可选，提供则增强可信度）③培养目标说明（一句话）。

**正例**：通过查阅贵院计算机科学与技术专业 2024 版培养方案，我已了解其核心课程体系。其中《数据结构》（4 学分）培养算法设计能力，《操作系统》（4 学分）培养系统级编程能力，《计算机网络》（3 学分）培养网络协议分析能力，《数据库系统原理》（3 学分）培养数据管理能力，《编译原理》（4 学分）培养语言处理能力。

**反例**：我了解计算机科学专业的课程设置，包括编程、算法、网络等课程。（无具体课程名、无学分、无培养目标）

### 3.3 维度 2：师资力量（25%）

**必含 3 要素**：①至少 2 位目标专业教师姓名（必须从目标学院官网查证）②教师职称（教授/副教授/讲师）③研究方向（具体方向）。

**正例**：贵院师资力量雄厚，我特别关注两位教授的研究方向：李XX 教授（ACM 杰出会员）的研究方向为计算机视觉与医学影像分析，与我的医疗 AI 职业目标高度契合；王XX 副教授的研究方向为机器学习与推荐系统，其团队近 3 年在 KDD、SIGIR 发表论文 12 篇。

**反例**：贵院师资力量雄厚，有许多知名教授和专家。（无姓名、无职称、无方向）

### 3.4 维度 3：就业前景（25%）

**必含 3 要素**：①至少 3 个目标专业就业方向（具体方向）②行业数据（就业率/人才缺口/市场规模，必须可查证）③薪资水平（应届生起薪/3 年经验薪资，可标注来源）。

**正例**：据麦可思《2024 年中国大学生就业报告》数据，计算机科学与技术专业应届生就业率达 96.8%，平均起薪 8500 元/月，3 年经验平均薪资 1.8 万元/月。主要就业方向包括：互联网公司算法工程师、金融机构 IT 岗位、政府/事业单位信息化岗位。我特别关注医疗 AI 方向，目前行业人才缺口约 30 万人。

**反例**：计算机科学专业就业前景广阔，薪资水平高，发展空间大。（无具体方向、无数据、无薪资）

### 3.5 维度 4：学科竞赛（20%）

**必含 3 要素**：①至少 2 个目标专业相关学科竞赛全称②竞赛级别（国家级/省级/校级）③已规划参与时间与角色。

**正例**：我已规划转入后参与以下学科竞赛：2025.09 全国大学生数学建模竞赛（国家级，担任算法负责人，目标省级一等奖）；2026.03 ACM-ICPC 国际大学生程序设计竞赛区域赛（担任队长，目标铜牌）；2026.05 中国大学生计算机设计大赛（担任后端开发，目标省级二等奖）。

**反例**：我会积极参加各类学科竞赛，提升专业能力。（无具体竞赛、无级别、无规划）

### 3.6 4 维度完整示例（约 320 字）

> 通过查阅贵院计算机科学与技术专业 2024 版培养方案，我已了解其核心课程体系。《数据结构》（4 学分）培养算法设计能力，《操作系统》（4 学分）培养系统级编程能力，《计算机网络》《数据库系统原理》《编译原理》共 10 学分。**师资力量方面**，李XX 教授（ACM 杰出会员）研究方向为计算机视觉与医学影像分析，王XX 副教授研究方向为机器学习与推荐系统，团队近 3 年在 KDD 发表论文 12 篇。**就业前景方面**，据麦可思《2024 中国大学生就业报告》数据，应届生就业率 96.8%，平均起薪 8500 元/月，主要方向包括算法工程师、IT 岗位、信息化岗位。**学科竞赛方面**，已规划 2025.09 全国大学生数学建模竞赛（国家级，算法负责人）、2026.03 ACM-ICPC 区域赛（队长）。

### 3.7 4 维度查证渠道

撰写前必须从以下渠道查证目标专业信息，禁止编造：

| 维度 | 查证渠道 | 关键信息 |
|------|---------|---------|
| 专业课程 | 目标学院官网"本科教育"/"培养方案"栏目 | 课程名 + 学分 + 学期 |
| 师资力量 | 目标学院官网"师资队伍"/"教师名录"栏目 | 姓名 + 职称 + 研究方向 |
| 就业前景 | 麦可思就业报告/目标学院就业质量报告/智联招聘 | 就业率 + 起薪 + 方向 |
| 学科竞赛 | 中国高等教育学会竞赛排行榜/目标学院官网"学科竞赛"栏目 | 竞赛全称 + 级别 + 时间 |

**查证缺失处理**：若用户未提供具体查证信息，必须追问"请提供目标专业核心课程名（至少 5 门）/目标学院 2 位教师姓名与研究方向/目标专业就业数据/目标专业 2 个学科竞赛全称。这些信息可从目标学院官网与麦可思就业报告查证"。无法查证则触发雷区 3。

## §4 学校政策差异说明（必加章节 4）

不同学校转专业政策差异极大，生成前必须核对学校政策。本节列出 6 类常见政策差异，每类必须确认后再撰写。

### 4.1 政策差异 6 维度对照表

| 维度 | 严格型学校 | 宽松型学校 | 中等型学校 |
|------|----------|----------|----------|
| GPA 门槛 | 前 10% 且无挂科 | 前 50% 或无要求 | 前 30% 且无挂科 |
| 名额限制 | 各专业接收≤5 人 | 各专业接收≤30 人 | 各专业接收≤15 人 |
| 考核方式 | 笔试 + 面试 + 申请书 | 仅申请书 | 笔试 + 面试 |
| 可转专业 | 仅限同院系或指定专业 | 全校开放（除特殊专业） | 跨院系但限制热门专业 |
| 不可转专业 | 艺术类/体育类/中外合作/定向 | 无限制 | 艺术类/中外合作/定向 |
| 申请次数 | 本科期间仅 1 次 | 每年 1 次（共 2~3 次） | 大一大二各 1 次 |

### 4.2 典型学校政策示例

**清华大学（严格型）**：
- GPA 门槛：前 10%
- 名额：各专业接收≤5 人
- 考核：笔试（数学+英语）+ 面试 + 申请书
- 不可转：艺术类、国防定向、临床医学（八年制）
- 申请次数：本科期间仅 1 次（大一第二学期末）

**北京大学（宽松型）**：
- GPA 门槛：无硬性要求（按学院考核）
- 名额：各专业接收≤30 人
- 考核：仅申请书 + 面试
- 不可转：医学部各专业
- 申请次数：大一第二学期 + 大二第一学期各 1 次

**复旦大学（中等型）**：
- GPA 门槛：前 30% 且无挂科
- 名额：各专业接收≤15 人
- 考核：笔试（专业基础）+ 面试
- 不可转：临床医学、法学（卓越班）、外语类保送生
- 申请次数：大一第二学期 1 次

**普通本科院校（多数）**：
- GPA 门槛：前 30% 或加权平均分≥80
- 名额：各专业接收≤10 人
- 考核：笔试 + 面试
- 不可转：艺术类、体育类、中外合作办学
- 申请次数：大一第二学期 1 次（部分学校大二第一学期可补申请）

### 4.3 特殊专业限制说明

以下专业通常不可转入或转出限制严格：

| 专业类别 | 限制说明 |
|---------|---------|
| 艺术类专业 | 招生考试方式特殊，一般不可转入也不可转出 |
| 体育类专业 | 招生考试方式特殊，一般不可转入也不可转出 |
| 中外合作办学 | 学籍与学费标准不同，一般不可转入 |
| 定向/委培生 | 与原单位签订协议，不可转专业 |
| 临床医学（含八年制） | 学制特殊，一般不可转入（少数学校允许转出） |
| 外语类保送生 | 招生方式特殊，不可转非外语专业 |
| 国防生/军警类 | 招生方式特殊，不可转专业 |
| 强基计划 | 部分学校允许在强基专业内转，不可转非强基专业 |

### 4.4 申请前必核对的 6 项政策

撰写申请书前，必须向学校教务处或目标学院核对以下 6 项政策：

1. **GPA 门槛**：本校转专业 GPA 门槛是多少？是按加权平均分还是 GPA 计算？
2. **名额限制**：目标专业本年度接收名额是多少？往年录取比例是多少？
3. **考核方式**：是否需要笔试？笔试科目是什么？面试形式是个人还是小组？
4. **可转专业范围**：我的现专业是否可以转入目标专业？是否有跨院系限制？
5. **不可转专业清单**：我的现专业是否在不可转清单中？目标专业是否接收外院系学生？
6. **申请次数**：我还有几次申请机会？错过本次窗口下次是什么时候？

**核对缺失处理**：若用户未提供学校政策信息，必须追问"请提供本校转专业管理办法的关键信息：GPA 门槛、名额、考核方式、可转专业范围、不可转专业清单、申请次数。这些信息可从本校教务处官网或学生手册查证"。无法查证则建议用户先查证再撰写。

### 4.5 政策差异对申请书的影响

不同政策下申请书撰写侧重不同：

| 政策类型 | 申请书撰写侧重 | 字数档位 |
|---------|-------------|---------|
| GPA 门槛严格 | 弱化 GPA 表述（因已达标），强化目标专业认知与转后规划 | 1000 字标准版 |
| GPA 门槛宽松 | 强化现专业 GPA 与排名（凸显学业优势），弱化目标专业认知 | 800 字短版 |
| 笔试 + 面试 | 申请书作为面试参考，强化转专业原因与转后规划（面试重点） | 1000 字标准版 |
| 仅申请书 | 申请书是唯一评审材料，4 维度必须详尽 | 1500 字长版 |
| 名额极少（≤5） | 强化差异化优势（独特经历/成果），避免模板化 | 1500 字长版 |
| 名额较多（≥20） | 标准化撰写，突出基础符合度 | 1000 字标准版 |

### 4.6 跨院系转专业特殊说明

跨院系转专业比同院系内转专业难度更大，申请书需特别注意：现专业学习段说明学分认定（如"现专业已修 30 学分中，通识课 18 学分可认定"）；转专业原因段说明跨院系的必要性；转后规划段详细说明补修计划（如"转入后第 1 学期补修《C++》《数据结构》共 8 学分"）；字数档位建议用 1500 字长版。

## §6 转专业原因撰写规范

### 6.1 3 类主线撰写要点速查

**兴趣驱动型撰写 5 步骤**：
1. 兴趣萌芽时间点（具体到月与触发事件）
2. 持续探索时长（量化到月或小时）
3. 已有探索成果（自学课程/项目/读书清单/社团活动，量化）
4. 兴趣与目标专业的契合点（具体课程/方向/方法）
5. 收束句（"这些探索让我确认 XXX 是我真正热爱的方向"）

**学业优势型撰写 5 步骤**：
1. 现专业总 GPA 与排名（量化）
2. 与目标专业交叉课程高分（课程名 + 学分 + 成绩）
3. 目标专业相关竞赛/科研经历（级别 + 角色 + 产出）
4. 学业能力可迁移性论证（如"数学基础可迁移至算法"）
5. 收束句（"这些学业成果证明我具备转入 XX 后的学业竞争力"）

**职业规划型撰写 5 步骤**：
1. 明确职业方向（具体岗位，非模糊行业）
2. 行业调研基础（实习/访谈/调研报告，量化）
3. 目标专业对职业的支撑性（具体课程/师资/平台）
4. 现专业对职业的限制（中性表述，不贬低）
5. 收束句（"故申请转入 XX 专业以支撑我的职业目标"）

### 6.2 转专业原因段开头规范

**3 类开头模板**：

- 兴趣驱动型开头："自 2024.09 入学后，我在 XX 课/XX 活动/XX 书中接触到 XX，由此萌生对 XX 的浓厚兴趣。"
- 学业优势型开头："大一学年 GPA X.XX/4.0，专业排名第 X/N。其中与 XX 交叉的 XX 课 X 分、XX 课 X 分，为转入 XX 后的 XX 学习奠定基础。"
- 职业规划型开头："我的长期职业目标是成为 XX，2025.01~2025.04 我在 XX 实习/调研 N 个月，深入理解 XX 行业的需求与挑战。"

### 6.3 严禁贬低现专业规范

**禁止表述**：
- ❌ "现专业不好就业"
- ❌ "现专业没前途"
- ❌ "现专业老师水平低"
- ❌ "现专业课程枯燥无趣"
- ❌ "现专业学不到东西"
- ❌ "现专业不适合我"（过于主观）

**中性替代表述**：
- ✅ "现专业与我的兴趣方向存在差异"
- ✅ "现专业与我的长期职业规划方向存在差异"
- ✅ "现专业缺乏 XX 方向的课程与实践平台"
- ✅ "现专业的课程体系侧重 XX，与我希望深入探索的 XX 方向有所不同"
- ✅ "经过大一一年的学习与思考，我发现自己的兴趣/优势/职业目标更适合 XX 专业"

### 6.4 转专业原因段完整示例

**兴趣驱动型示例（约 280 字）**：兴趣萌芽时间点 + 持续探索 8 个月（自学 120 小时 + 3 个 Kaggle 项目 + 阅读《深度学习》前 6 章 + ACM 协会每周 2 次训练）+ 收束句"这些探索让我确认计算机科学是我真正热爱的方向" + 中性表述"现专业课程体系侧重存在差异" + 申请转入。

## §7 转后规划撰写规范

### 7.1 短期规划（转入后 1 学期）

**必含 3 要素**：①补修课程清单（具体课程名 + 学分 + 补修方式）②补修时间安排（第 1 学期 / 暑期 / 第 2 学期）③学分认定情况（现专业已修学分可认定多少）。

**正例**：短期规划（2025.09~2026.01 第 1 学期）：补修《C++ 程序设计》（4 学分）、《数据结构》（4 学分）共 8 学分，跟班补修；现专业已修通识课 18 学分可认定，专业课 12 学分需在 1 学年内补修完毕。第 1 学期目标 GPA≥3.8。

### 7.2 中期规划（转入后 1~2 学年）

**必含 3 要素**：①科研计划（课题组 + 教授 + 研究方向 + 时间）②竞赛计划（竞赛名 + 级别 + 角色 + 目标）③实习/项目计划（公司/项目 + 时间 + 目标）。

**正例**：中期规划（2026.02~2027.06 第 2~3 学期）：加入李XX 教授课题组（计算机视觉方向），参与医学影像分析项目，目标以第二作者发表 1 篇 SCI 论文；2026.03 参加 ACM-ICPC 区域赛（队长，目标铜牌）；2026.07~2026.09 赴字节跳动算法岗实习 3 个月。

### 7.3 长期规划（毕业去向）

**必含 2 要素**：①毕业去向（保研/考研/就业/出国，明确选择）②目标院校/公司（具体名称 + 方向）。

**正例**：长期规划（2027.07~2028.06）：本科毕业后保研至清华大学计算机系医疗 AI 方向（目标导师：XX 教授），攻读硕士/博士学位，深入医疗影像 AI 算法研究。

### 7.4 转后学习计划表

转后规划段必须含学习计划表（4 列：阶段/时间/主要内容/目标），至少 3 行（短/中/长期各 1 行）：

| 阶段 | 时间 | 主要内容 | 目标 |
|------|------|---------|------|
| 短期 | 2025.09~2026.01 | 补修《C++》《数据结构》共 8 学分 | GPA≥3.8，学分补修完毕 |
| 中期 | 2026.02~2027.06 | 加入李XX 课题组 + ACM-ICPC 区域赛 | 第二作者 SCI 论文 1 篇 + 铜牌 |
| 长期 | 2027.07~2028.06 | 保研清华计算机系医疗 AI 方向 | 获保研资格 + 入读清华 |

### 7.5 转后规划完整示例（约 200 字）

短/中/长期 3 阶段 + 学习计划表：短期补修 8 学分（含学分认定 18 学分）+ 中期加入李XX 课题组（SCI 论文 1 篇）+ ACM-ICPC 铜牌 + 长期保研清华医疗 AI 方向，结尾收束"通过上述规划能够迅速适应并取得优异成绩"。

### 8.6 3 档字数版本切换方法

- **短版**：仅提供 P0 字段，P1 字段省略（如 interest_books、career_interview 等）
- **标准版**：提供 P0 + 关键 P1 字段
- **长版**：提供 P0 + 全部 P1 + P2 自定义段落

**字数自检**：生成后必须用 §13 质检清单的字数检查项验证。

## §9 雷区 10 条（必加章节 6）

以下 10 条雷区任一触犯，申请书将被评审委员会退回或评分大幅扣减。生成后必须按 §13 质检清单逐项排查。

### 9.1 雷区 1：贬低现专业

❌ 反例：化学工程与工艺专业不好就业，老师水平也一般，课程枯燥无趣。

✅ 正例：经过大一一年的学习与思考，我发现自己的兴趣与化学工程与工艺专业的课程体系侧重存在差异，计算机科学与技术专业更契合我的长期发展方向。

**排查方法**：全文检索"不好就业""没前途""水平低""枯燥""学不到"等贬低词汇，必须替换为中性表述。

### 9.2 雷区 2：转专业原因无量化数据

❌ 反例：我一直对计算机科学很感兴趣，希望转入计算机学院深入学习。

✅ 正例：自 2024.09 起持续 8 个月自学吴恩达《Machine Learning》课程（累计 120 小时），完成 3 个 Kaggle 项目（最好成绩 top 30%），加入校 ACM 协会每周 2 次训练。

**排查方法**：转专业原因段必须含量化数据（时长/小时/项目数/成绩），无量化即触犯。

### 9.3 雷区 3：目标专业认知无具体课程名

❌ 反例：我了解计算机科学专业的课程设置，包括编程、算法、网络等课程。

✅ 正例：通过查阅贵院 2024 版培养方案，已了解《数据结构》（4 学分）、《操作系统》（4 学分）、《计算机网络》（3 学分）、《数据库系统原理》（3 学分）、《编译原理》（4 学分）等核心课程。

**排查方法**：目标专业认知段必须含至少 5 门具体课程名（带书名号），无具体课程名即触犯。

### 9.4 雷区 4：目标专业师资无姓名

❌ 反例：贵院师资力量雄厚，有许多知名教授和专家。

✅ 正例：贵院李XX 教授（ACM 杰出会员）研究方向为计算机视觉与医学影像分析，王XX 副教授研究方向为机器学习与推荐系统，其团队近 3 年在 KDD 发表论文 12 篇。

**排查方法**：目标专业认知段必须含至少 2 位教师姓名 + 职称 + 研究方向，无姓名即触犯。

### 9.5 雷区 5：转后规划无具体学习计划

❌ 反例：转入后我会努力学习，争取取得优异成绩，参加各类竞赛与科研活动。

✅ 正例：转入后第 1 学期补修《C++ 程序设计》（4 学分）、《数据结构》（4 学分）共 8 学分；第 2 学期加入李XX 教授课题组参与医学影像分析项目；2026.03 参加 ACM-ICPC 区域赛（队长，目标铜牌）。

**排查方法**：转后规划段必须含具体课程名 + 学分 + 时间 + 目标，无具体学习计划即触犯。

### 9.6 雷区 6：3 类原因混写

❌ 反例：我一直对计算机科学感兴趣（兴趣），数学成绩优异（学业），未来想做 IT 行业（职业），希望转入计算机学院。

✅ 正例（学业优势为主线）：大一学年 GPA 3.92/4.0，专业排名第 3/95。其中数学类课程均 94+，为转入计算机科学后的算法学习奠定基础。（结尾段弱关联：这些学业成果也印证了我对计算机科学的兴趣与职业方向）

**排查方法**：全文检索"兴趣""擅长""职业"3 类关键词，主线只能聚焦 1 类，另 2 类仅作辅助（每类≤100 字）。

### 9.7 雷区 7：抒情开头与乞求结尾

❌ 反例（开头）：时光荏苒，岁月如梭。转眼间大一一年过去了。回顾这一年的学习生活，我感慨万千。

❌ 反例（结尾）：综上所述，本人完全符合转专业条件，恳请领导批准！

✅ 正例（开头）：我是化学工程学院化学工程与工艺 2024 级学生张明，现申请转入计算机科学与技术学院计算机科学与技术专业。现就转专业事宜汇报如下：

✅ 正例（结尾）：以上是我的转专业申请。无论审批结果如何，我都将继续努力学习，以更高标准要求自己。恳请评审委员会予以考虑。

**排查方法**：开头必须含身份 + 申请事项 + 汇报句；结尾必须含"以上是我的转专业申请"+ 朴素表态，禁用"恳请领导批准""完全符合条件"。

### 9.8 雷区 8：排名不写基数

❌ 反例：专业排名第 3。

✅ 正例：专业排名第 3/95（前 3.2%）。

**排查方法**：排名必须含"X/N"格式与百分比，缺基数即触犯。

### 9.9 雷区 9：未核对学校政策

❌ 反例：直接撰写申请书，未核对学校转专业管理办法。

✅ 正例：撰写前已核对《XX 大学本科生转专业管理办法》：GPA 门槛前 30% 且无挂科，目标专业本年度接收 10 人，考核方式为笔试（数学+英语）+ 面试，化学工程与工艺专业可转入计算机科学与技术专业。

**排查方法**：撰写前必须向学校教务处或目标学院核对 6 项政策（GPA 门槛/名额/考核方式/可转专业范围/不可转专业清单/申请次数），未核对即触犯。

### 9.10 雷区 10：目标专业认知 4 维度缺一

❌ 反例：仅写专业课程与师资力量，未写就业前景与学科竞赛。

✅ 正例：4 维度齐全（专业课程 + 师资力量 + 就业前景 + 学科竞赛），每维度有具体名称与数据。

**排查方法**：目标专业认知段必须含 4 维度齐全（专业课程/师资力量/就业前景/学科竞赛），缺一即触犯。

### 9.11 雷区汇总速查表

| 雷区编号 | 雷区名称 | 关键排查点 |
|---------|---------|-----------|
| 1 | 贬低现专业 | 禁用"不好""没前途""水平低" |
| 2 | 原因无量化 | 必含时长/小时/项目数/成绩 |
| 3 | 目标专业无课程名 | 至少 5 门带书名号课程 |
| 4 | 目标专业师资无姓名 | 至少 2 位教师姓名+职称+方向 |
| 5 | 转后规划无具体计划 | 必含课程名+学分+时间+目标 |
| 6 | 3 类原因混写 | 主线聚焦 1 类，另 2 类辅助 |
| 7 | 抒情开头乞求结尾 | 身份+申请事项开头；朴素表态结尾 |
| 8 | 排名无基数 | "X/N（前 X.X%）" |
| 9 | 未核对学校政策 | 必核 6 项政策 |
| 10 | 4 维度缺一 | 4 维度齐全（课程/师资/就业/竞赛） |

- **三、转专业原因（职业型）**：`我的长期职业目标是成为 {career_target}。{internship_period} 我在 {company} 实习 {duration}，{internship_work}。访谈 {n} 位行业从业者后，我确认 {target_major} 是通往该职业的必经路径。现就读的 {current_major} 专业缺乏相关课程与实践平台，故申请转入 {target_major} 专业。`
- **四、目标专业认知**：`通过查阅贵院 {target_major} 专业 {year} 版培养方案，我已了解其核心课程体系。其中《{course1}》（{credit1} 学分）培养 {goal1} 能力，...。师资力量方面，{teacher1}（{title1}）研究方向为 {research1}，...。就业前景方面，据 {source} 数据，{employment_data}。学科竞赛方面，我已规划 {competition1}、{competition2}。`
- **五、转后规划**：`转入后第 1 学期补修《{course1}》（{credit1} 学分）、《{course2}》（{credit2} 学分）共 {total} 学分；第 2~3 学期 {research_plan}；{competition_plan}。本科毕业后 {graduation_plan}。`
- **结尾**：`以上是我的转专业申请。无论审批结果如何，我都将继续努力学习，以更高标准要求自己。恳请评审委员会予以考虑。`

### 12.1 build.py 接口概览

build.py 位于 `/home/z/my-project/skills/awesome-student-ai-skills/subskills/major_transfer/build.py`，提供 CLI 接口生成转专业申请书 docx。

**主构建方法**：`build(data: Dict[str, Any], output_path: str) -> str`

**编排顺序**：标题 → 称呼 → 开头 → 个人基本情况 → 现专业学习 → 转专业原因 → 目标专业认知 → 转后规划 → 结尾 → 落款

### 12.2 CLI 调用方式

**基础调用（用户提供 data.json）**：
```bash
python build.py --data data.json --out output.docx
```

**演示模式（使用内置示例数据）**：
```bash
python build.py --demo --out demo.docx
```

**参数说明**：
- `--data`：数据 JSON 文件路径（与 `--demo` 二选一）
- `--out`：输出 docx 文件路径（必填）
- `--demo`：使用内置示例数据生成演示文档

### 12.5 字段消费规则

- **整段覆盖字段优先**：若 `opening` / `basic_info` / `current_study` / `transfer_reason` / `target_understanding` / `future_plan` / `ending` 任一提供非空字符串，则直接使用，跳过模板拼装
- **3 类原因切换**：`transfer_reason_type` 为 `interest` / `academic` / `career` 时，分别调用 `_build_interest_reason` / `_build_academic_reason` / `_build_career_reason` 子方法
- **数组字段缺失处理**：`current_core_courses` / `target_courses` / `target_teachers` / `target_competitions` / `study_plan_table` 缺失则省略对应表格
- **必填字段警告**：P0 字段缺失触发 warning，但不阻断生成

### 13.5 警告处理决策树

```
生成后出现 warning
  ↓
是否为 P0 字段缺失？
  ├─ 是 → 必须补全 P0 字段后重新生成
  └─ 否 → 是否为排名基数缺失？
            ├─ 是 → 补充 rank_total 或改为 "X/N" 格式
            └─ 否 → 是否为目标专业课程不足 5 门？
                      ├─ 是 → 从目标学院官网培养方案查证补全至 5 门
                      └─ 否 → 是否为师资不足 2 位？
                                ├─ 是 → 从目标学院官网师资队伍查证补全至 2 位
                                └─ 否 → 是否为 4 维度缺一？
                                          ├─ 是 → 补全缺失维度（就业前景/学科竞赛）
                                          └─ 否 → 警告可忽略，文档可提交
```

### 13.6 端到端流程

1. 信息采集（§5 信息采集清单，按 P0/P1/P2 优先级）
2. 复述确认（向用户复述核心字段，确认无误）
3. 调用 build.py 生成 docx（`python build.py --data data.json --out output.docx`）
4. 检查 warnings（按 §13.5 决策树处理）
5. 按 §13 质检清单 35 项逐项排查
6. 修正后重新生成
7. 输出可提交 docx

### 13.7 常见 FAQ

**Q1：用户未提供学校转专业政策？** → 追问 6 项政策（GPA 门槛/名额/考核方式/可转范围/不可转清单/申请次数），无法查证则按通用模板生成但提示用户必须自行核对。

**Q2：用户混淆转专业与跨专业保研？** → 明确区分（转专业是本科阶段校内转，跨专业保研是研究生阶段跨专业），大三以上建议走 `graduate_recommendation` skill。

**Q3：兴趣驱动型但无探索成果？** → 建议先进行 3~6 个月探索（自学课程/项目/读书/社团）再申请。

**Q4：目标专业课程查证不到？** → 必须从目标学院官网培养方案栏目查证，禁止编造；官网未公开则联系目标学院教务老师或开放日咨询。

**Q5：目标专业是冷门专业（哲学/历史）？** → 4 维度框架同样适用，但就业前景段调整为学术研究/教育/文化机构方向，学科竞赛段可弱化。

## §14 红线规则与免责声明

### 14.1 红线规则

以下规则不可违反，违反即触犯雷区：

1. **严禁编造目标专业课程名**：必须从目标学院官网培养方案查证
2. **严禁编造师资姓名**：必须从目标学院官网师资队伍栏目查证
3. **严禁编造就业数据**：必须从麦可思就业报告/目标学院就业质量报告查证
4. **严禁贬低现专业**：必须使用中性表述
5. **严禁 3 类原因混写**：主线只能聚焦 1 类
6. **严禁抄袭模板**：必须结合本人真实经历
7. **严禁隐瞒学校政策**：必须核对学校转专业管理办法

### 14.2 免责声明

本 skill 生成的申请书为模板化初稿，用户必须：

1. **核对学校政策**：生成前必须核对学校转专业管理办法（GPA 门槛/名额/考核方式/可转专业范围/不可转专业清单/申请次数）
2. **查证目标专业信息**：目标专业课程名/师资姓名/就业数据必须从官网与权威报告查证
3. **结合本人真实经历**：转专业原因必须基于本人真实兴趣/学业/职业经历，禁止编造
4. **遵守学术诚信**：申请书必须本人撰写，禁止他人替代撰写（部分学校将撰写视为学术不端）
5. **遵守学校格式要求**：若学校有指定模板，必须按学校模板调整

### 14.3 与其他 skill 的协同

- **graduate_recommendation**：跨专业保研（研究生阶段）走该 skill，本 skill 仅处理本科阶段转专业
- **outstanding_student**：转专业成功后可申报目标专业评优，走该 skill
- **college_research**：转入后参与科研立项，走该 skill
- **innovation_research**：转入后参与大创项目，走该 skill
