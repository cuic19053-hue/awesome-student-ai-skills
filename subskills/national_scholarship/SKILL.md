# 国家奖学金申请书 Skill

本 skill 处理"国家奖学金申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 质检。国家奖学金面向特别优秀的二年级及以上本科生（8000 元/人），评审侧重学业极其优异 + 综合素质突出（科研/竞赛/荣誉）。仅处理"国家奖学金"，国家励志奖学金（5000 元）与校级奖学金请走其他 skill。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐，含主要获奖与科研成果表）。

---

## 一、适用场景与触发条件

**适用**：用户提到"国家奖学金""国奖""8000 元奖学金""国家奖学金申请书""8000元"等关键词，且本人学业成绩与综合素质表现特别突出。

**硬门槛**：
- 必须为全日制二年级及以上本科生（含专升本二年级）
- 学习成绩排名与综合考评排名均位于前 10%（若位于前 10%~30%，须在道德风尚、学术科研、创新发明、社会实践、体育竞赛等某一方面取得特别突出成绩）
- 本学年无挂科、无违法违纪处分

**不适用（必须分流）**：

| 用户实际情况 | 应分流到的 skill |
|---|---|
| 家庭经济困难、需要 5000 元励志奖学金 | `motivation_scholarship` |
| 只是成绩不错，未达前 10% 且无突出成果 | `university_scholarship`（校级）或 `single_scholarship` |
| 企业冠名、社会团体设立的奖学金 | `enterprise_scholarship` |
| 家庭经济困难但成绩一般 | `grant_application`（国家助学金） |

**关键红线**：国家奖学金**严禁**把家庭经济困难作为申请理由或论证主体。评审看的是"卓越"，不是"困难"。写家庭困难不仅不加分，反而会被认定为"不了解评审标准"，甚至影响学院推荐名额。这一点与励志奖学金完全相反，是最容易串味的错误。

## 二、工作流程总览

| 步骤 | 名称 | AI 行为 | 输出 |
|---|---|---|---|
| S0 | 硬门槛预检 | 先问年级、排名、有无挂科/违纪、是否已获国奖，任一项不达标即提示并建议分流 | 达标/不达标结论 |
| S1 | 信息采集 | 按第三章清单逐项追问，缺项必须追问，禁止自行编造 | 结构化 JSON |
| S2 | 事实核验与亮点排序 | 把成果按"评审权重"排序（国家级 > 省级 > 校级；一作 > 二作；主持 > 参与），并核查时间线是否矛盾 | 亮点排序表 |
| S3 | 六段式撰写 | 按第四章结构逐段撰写，遵守第五章字数与句式规范 | 正文段落数组 |
| S4 | 段落自检 | 逐段做字数检查、数据检查、禁用词检查 | 自检报告 |
| S5 | docx 生成 | 调用 `build.py` 输出 .docx | .docx 文件 |
| S6 | 质检与交付 | 按第十三章清单终检，附交付说明与待补附件清单 | 交付说明 |

**执行原则**：
1. 先达标再动笔 —— 不达标直接告知并建议分流，不硬写；
2. 无数据不成段 —— 每个论断必须有具体数字、名称或时间，缺失就追问；
3. 宁缺毋伪 —— 用户说不清楚的成果，宁可换一条能说清的，不允许编造。

## 三、信息采集清单

> 采集方式：先一次性列出清单让用户批量填，用户说"不知道从哪填起"时改为逐项追问（每轮 2~3 个问题）。
> 字段冲突时以用户提供的原始材料（成绩单、证书）为准。

### 3.1 通用必采（10 字段）

| # | 字段 | 说明 | 缺失后果 |
|---|---|---|---|
| 1 | 姓名 | 与学籍一致 | 无法落款 |
| 2 | 性别 | 用于表格类模板 | 部分模板必填 |
| 3 | 政治面貌 | 中共党员/预备党员/共青团员/群众 | 思想政治段无支撑 |
| 4 | 年级 | 如 2023 级（须为二年级及以上） | 硬门槛判定 |
| 5 | 专业 | 全称，如"计算机科学与技术" | 开篇段必填 |
| 6 | 学院 | 全称 | 称呼与落款 |
| 7 | 学号 | 数字串 | 部分学校模板必填 |
| 8 | 申请学年 | 如 2025—2026 学年 | 全文时间口径 |
| 9 | 专业排名 | 如 1/120 或"前 1%" | 核心论据 |
| 10 | 联系方式 | 手机号 | 学校备案 |

### 3.2 学业硬指标（8 字段）

| # | 字段 | 采集要点 |
|---|---|---|
| 1 | GPA 数值与满分制 | 明确是 4.0 制、5.0 制还是百分制；**必须说明制式**，否则评审无法判断 |
| 2 | 加权平均分 | 写清是否含公共课 |
| 3 | 专业排名（分子/分母） | 优先"1/120"这种精确写法，避免"名列前茅" |
| 4 | 综合考评排名 | 国奖要求成绩与综测**双达标**，两项都要问 |
| 5 | 主干课程及分数 | 3~5 门与专业相关的核心课，取分数最高且有代表性的 |
| 6 | 英语等级 | 四级/六级分数，或雅思/托福 |
| 7 | 本学年是否有挂科 | 硬门槛，必问 |
| 8 | 是否已获得过国家奖学金 | 同一学业阶段一般不重复获得，必问 |

### 3.3 科研与创新成果（每条 6 字段）

| 字段 | 采集要点 |
|---|---|
| 成果类型 | 论文 / 专利 / 软著 / 科研项目 / 技术报告 |
| 成果名称 | 全称（论文写题名，专利写名称+申请号） |
| 层次 | 国家级 / 省部级 / 校级 / 院级 |
| 本人位次 | 第一作者 / 第二作者 / 主持 / 参与（位次直接决定含金量） |
| 时间 | 年月（与学年口径对应） |
| 状态 | 已发表 / 已录用 / 在审 / 已授权 / 已受理 / 已结题 |

### 3.4 竞赛获奖（每条 5 字段）

| 字段 | 采集要点 |
|---|---|
| 竞赛全称 | 必须写全称，如"第十九届'挑战杯'全国大学生课外学术科技作品竞赛" |
| 竞赛级别 | 国家级 / 省部级 / 校级（注意区分"国家级"与"全国性行业赛"） |
| 获奖等级 | 特等奖 / 一等奖 / 二等奖 / 三等奖 |
| 团队位次 | 第 1 完成人 / 第 2 完成人（位次影响评分） |
| 获奖时间 | 年月 |

### 3.5 综合素质与社会工作（每条 4 字段）

| 字段 | 采集要点 |
|---|---|
| 职务 | 如"班级学习委员""院学生会科创部副部长" |
| 层级 | 校级 / 院级 / 班级 |
| 任职时长 | 如"2024 年 9 月至今" |
| 量化产出 | 组织活动的场次、参与人数、覆盖范围（有数据才算有效成果） |

### 3.6 志愿服务与社会实践（每条 3 字段）

| 字段 | 采集要点 |
|---|---|
| 项目名称 | 具体活动名，避免"参加志愿服务"这类空泛表述 |
| 累计时长 | 小时数（多数学校有最低时长要求） |
| 组织单位 | 校团委 / 学院 / 社区 / 公益机构 |

### 3.7 硬门槛预检（一票否决自查）

撰写前必须逐项确认，任一项不达标应提示用户并给出分流建议：

- [ ] 全日制本科二年级及以上
- [ ] 学习成绩排名位于前 10%（或前 10%~30% 且具备某方面特别突出成绩）
- [ ] 综合考评排名同样达标（多数学校要求双达标）
- [ ] 本学年无挂科记录
- [ ] 无违法违纪处分记录
- [ ] 未在同一学业阶段重复获得国家奖学金
- [ ] 材料真实可核验（有证书、成绩单等佐证）

### 3.8 字段优先级与追问话术

| 优先级 | 字段组 | 缺失时的追问话术 |
|---|---|---|
| P0 必填 | 排名、GPA、学年、挂科情况、违纪情况 | "你的专业排名具体是第几？分母是多少人？综合考评排名也一样吗？" |
| P0 必填 | 最高层次成果（通常 1~2 项） | "一学年里最拿得出手的一项成果是什么？它在什么级别的平台？你是第几完成人？" |
| P1 重要 | 主干课程分数、英语等级 | "你成绩最好的 3 门专业核心课是什么、分别多少分？四级/六级分别多少分？" |
| P1 重要 | 学生工作与志愿服务量化数据 | "你担任这个职务期间，组织过几次活动、大概覆盖多少人？志愿服务累计多少小时？" |
| P2 可选 | 其他荣誉、文体活动 | "除了上面这些，还有没有校级以上的荣誉称号或文体获奖？" |

**追问禁忌**：不要一次抛 10 个问题；不要用"最好""尽量"这类模糊要求让用户自己判断；用户答不上来时，改为提供选项引导（"是国家级还是省级？"）。

### 3.9 复述确认模板

信息采集完成后，用下述格式复述给用户确认，确认后再动笔：

```
我整理到的情况如下，请核对（有误请直接指出）：
· 学业：专业排名 1/120（前 0.83%），GPA 3.92/4.0，综测排名 2/120，无挂科
· 科研：主持国家级大创 1 项（已结题）；第一作者会议论文 1 篇（CCF-C，已录用）
· 竞赛：挑战杯国家级一等奖（第 1 完成人，2025 年 5 月）
· 综合素质：班级学习委员（2024.09 至今）；志愿服务 120 小时
· 政治面貌：中共预备党员
确认无误后我就开始撰写正文。
```

## 四、书信体结构详解

### 4.1 六段式正文结构（基础骨架）

1. **标题与称呼**：标题《国家奖学金申请书》，称呼《尊敬的学校领导、评审委员会老师：》。
2. **第一段（开篇志愿）**：明确表达申请意向，注明学年、专业及申请目标。
3. **第二段（思想政治）**：理想信念、政治立场、团干或党建表现。
4. **第三段（学业科研）**：GPA、专业排名、获奖情况、发表论文或专利成果。
5. **第四段（社会实践与综合素质）**：竞赛获奖、学生工作、志愿服务与社会实践。
6. **第五段与落款**：总结决心、此致敬礼、落款姓名与日期。

### 4.2 各段字数与权重配比

| 段落 | 建议字数 | 评审权重 | 说明 |
|---|---|---|---|
| 称呼 | —— | —— | 顶格，全角冒号 |
| 开篇志愿 | 150~200 字 | 低 | 交代身份、学年、申请意向 |
| 思想政治 | 200~300 字 | 中 | 政治面貌 + 实际表现，忌空喊 |
| **学业科研** | **500~800 字** | **最高** | 全文核心，必须占最大篇幅 |
| 综合素质与社会实践 | 300~450 字 | 中高 | 竞赛、学生工作、志愿服务 |
| 结尾 | 150~250 字 | 低 | 表态与承诺，不做空泛抒情 |
| 合计 | **1500~2500 字** | —— | 少于 1500 字显单薄，超过 2500 字易超模板上限 |

### 4.3 标题与称呼规范

- 标题：`国家奖学金申请书`，黑体二号居中，不加书名号、不加"关于……的申请"这类公文式改写（部分学校模板有固定标题，以学校模板为准）。
- 称呼：`尊敬的学校领导、评审委员会老师：`，顶格、冒号用全角、正文首行缩进 2 字符。
- 若学校要求写给"××学院国家奖学金评审工作小组"，以学校要求为准。

### 4.4 开篇段写法

**结构**：身份交代 → 学年 → 申请事项 → 一句核心优势概括。

✅ 正确示例：
> 我是计算机科学与技术专业 2023 级本科生张华。在 2025—2026 学年中，我始终以严谨求实的态度投入学习与科研，本学年学业成绩与综合考评排名均为专业第一（1/120）。现郑重向学校申请国家奖学金。

❌ 错误示例：
> 时光荏苒，转眼间我已经度过了两年大学时光……（抒情开头，浪费字数，评审看不到信息）

### 4.5 思想政治段写法

**必备要素**：政治面貌 → 具体行动（组织生活、主题党日、志愿服务中的思想体现）→ 荣誉（如有）。

- 有党员/预备党员身份：写全称、写具体参与的组织活动名称与频次；
- 仅团员身份：写团组织活动、青年大学习、主题教育中的具体表现，不要硬套党员表述；
- 避免"我始终拥护党的领导"这类无事实支撑的表态堆砌，至少配一个具体事例。

### 4.6 学业科研段写法（核心段）

**顺序**：排名与 GPA → 主干课程 → 英语等级 → 科研项目 → 论文/专利 → 竞赛获奖。
**要求**：每一项都带数字或名称；用"成果清单式"陈述，不用"我非常努力"式描述。详见第六章、第七章。

### 4.7 综合素质与社会实践段写法

**顺序**：学生工作（职务 + 量化产出）→ 志愿服务（项目 + 时长）→ 文体或其他荣誉。详见第八章。

### 4.8 结尾段写法

**结构**：对已获成绩的定性（一句）→ 对评审的认识（一句）→ 无论结果如何的承诺（一句）→ 恳请批准（半句）。

❌ 避免："恳请领导批准，以减轻家庭负担"（国奖大忌，等同于自证不符合评审标准）。

### 4.9 落款规范

- `此致` 另起一行、空两格；`敬礼！` 另起一行、顶格、加粗。
- 落款右对齐：第一行 `申请人：张华`，第二行 `2026 年 10 月 15 日`。
- 日期必须用阿拉伯数字，年份写全。

## 五、各段落撰写规范

### 5.1 字数配比

见 4.2。**核心原则：学业科研段必须是全文最长的一段**，若它短于综合素质段，说明素材挖掘不足或顺序有误。

### 5.2 句式规范

| 要求 | 说明 |
|---|---|
| 主谓宾完整 | 避免"通过……使我……"这类主语残缺句 |
| 数据前置 | "专业排名 1/120，GPA 3.92/4.0"优先于"成绩优异" |
| 一句一事实 | 长句拆开，每句承载一个可核验信息 |
| 不用第一人称抒情 | "我深深感到""我无比激动"一律删除 |
| 时间口径统一 | 全文统一"本学年"，不混用"今年""上学期" |

### 5.3 事实+数据原则

**每个论断必须能回答"凭什么这么说"**：

| ❌ 无支撑表述 | ✅ 数据化表述 |
|---|---|
| 成绩优异 | 专业排名 1/120（前 0.83%），GPA 3.92/4.0 |
| 科研能力强 | 主持国家级大创 1 项（已结题），第一作者发表会议论文 1 篇 |
| 积极参加志愿服务 | 累计志愿服务 120 小时，参与"三下乡"支教 1 次（14 天） |
| 获得了不少荣誉 | 获国家级竞赛一等奖 1 项、校级荣誉 2 项 |

### 5.4 段落衔接

段首不重复上一段结尾内容；用"在……方面"的板块式开头（如"在学业科研方面"），使评审能快速定位。全篇不出现"其次""另外""还有"这类口语化连接词。

### 5.5 时态与时间表达

统一使用"本学年""2025—2026 学年"；成果时间写"2025 年 5 月"这类精确到月的表达；避免"最近""前段时间"。

### 5.6 段落字数自检

撰写完成后逐段统计字数，与 4.2 的建议区间对照。偏差超过 30% 的段落必须调整。

### 5.7 高频词禁用清单

| 禁用词 | 替换方案 |
|---|---|
| 努力、认真、积极、刻苦、勤奋 | 删除，直接写做了什么事、拿到什么结果 |
| 我认为、我觉得、我深深感到 | 删除，直接陈述事实 |
| 名列前茅、成绩优异、表现突出 | 换成具体排名与数据 |
| 各种、多项、若干 | 换成确数（"3 项""5 门"） |
| 极大地、非常、十分 | 删除，用数据体现程度 |
| 不断、继续、始终 | 保留不超过 2 处，其余删除 |

### 5.8 段落首句规范

每段首句必须是**信息句**（含有身份/时间/数据），不能是过渡句或抒情句。

✅ "在学业科研方面，我本学年专业排名 1/120（前 0.83%），GPA 3.92/4.0。"
❌ "在学业科研方面，我付出了很多努力。"

## 六、学业优势撰写方法

### 6.1 排名写法

| 写法 | 效果 |
|---|---|
| 1/120 | ✅ 最精确，评审一眼看懂 |
| 专业前 0.83% | ✅ 排名不好看时可换算成百分比（如 5/120 = 前 4.17%） |
| 名列前茅 | ❌ 无效，视为无数据 |
| 班级第一 | ⚠️ 分母太小，若专业排名一般，写班级第一反而暴露短板 |

**注意**：国奖看的是**专业（或年级）排名**，不是班级排名。若专业排名未进前 10%，先回到 S0 复核硬门槛。

### 6.2 GPA 表达

- 必须先说明制式：`GPA 3.92/4.0`、`加权平均分 92.3/100`；
- 4.0 制换算百分制参考：3.9 以上≈90+，3.7 以上≈85+，低于 3.5 一般不宜强调 GPA，改强调排名与课程分数；
- 不同学校换算规则不同，如用户提供了学校官方换算说明，以学校口径为准。

### 6.3 主干课程展示

挑选 3~5 门**与专业相关且分数最高**的核心课程，写法：

> 专业核心课程成绩突出：数据结构 96 分、计算机组成原理 94 分、操作系统 93 分。

不要罗列公共课（体育、思政）分数，除非该课分数特别突出且与专业有关。

### 6.4 英语等级

写分数而非"通过"：`CET-4 602 分、CET-6 551 分`。若分数一般（如 CET-6 刚过线），可只写 CET-4 成绩或省略该项，不要用"顺利通过六级"这种表述。

### 6.5 与励志奖学金学习段的关键区别

| 维度 | 国家奖学金 | 国家励志奖学金 |
|---|---|---|
| 主体 | 学业卓越 + 科研竞赛成果 | 学业 + **家庭经济困难 + 勤工助学** |
| 排名要求 | 前 10%（双达标） | 前 30% 左右（各校不同） |
| 家庭情况 | **严禁提及** | **必须写，且要有数据** |
| 篇幅重心 | 学业科研段最长 | 家庭经济段与勤工助学段占大头 |

**若用户同时符合两类条件**：按用户实际申请的项目撰写，不得把两套逻辑混在一份材料里。

### 6.6 完整示例（学业段，约 300 字）

> 在学业方面，我本学年专业排名 1/120（前 0.83%），综合考评排名 2/120，GPA 3.92/4.0，加权平均分 93.1 分，全学年无任何补考与挂科记录。专业核心课程成绩突出：数据结构 96 分、计算机组成原理 94 分、操作系统 93 分、数据库系统原理 92 分。英语能力方面，CET-4 602 分、CET-6 551 分，能够熟练阅读本专业英文文献。为夯实科研基础，我还自学了机器学习与深度学习相关课程，完成《统计学习方法》全部习题并复现了 3 个经典模型。

## 七、科研与创新撰写方法

### 7.1 论文

**必写要素**：题名（可简写）→ 发表载体（期刊/会议全称）→ 收录层次（SCI/EI/CSSCI/CCF 推荐等级/核心）→ 作者位次 → 状态（已发表/已录用/在审）→ 时间。

✅ 示例：
> 以第一作者在 CCF 推荐 C 类会议《××××》发表学术论文 1 篇（已录用，2025 年 6 月），该文提出了一种面向小样本场景的图文匹配方法，实验在 3 个公开数据集上相较基线提升 4.2 个百分点。

**红线**：不写"在审"就当"已发表"；不把导师的成果写成本人主导；不写非本人参与的挂名论文。

### 7.2 专利与软著

**必写要素**：名称 → 类型（发明专利/实用新型/外观设计/软件著作权）→ 申请号或登记号 → 状态（已受理/已授权）→ 本人位次。

✅ 示例：
> 作为第一发明人申请国家发明专利 1 项（申请号 2025×××××××××.×，已受理）。

### 7.3 科研项目

**必写要素**：项目级别（国家级大创/省级/校级）→ 项目名 → 主持或参与 → 状态 → 本人承担的具体工作。

✅ 示例：
> 主持国家级大学生创新训练项目 1 项（《基于多模态融合的××××研究》，已结题），独立完成数据采集与模型训练，构建数据集 1 套，形成技术报告 1 份。

### 7.4 竞赛获奖

**必写要素**：竞赛全称 → 级别 → 获奖等级 → 完成人位次 → 时间。

✅ 示例：
> 作为第 1 完成人参加第十九届"挑战杯"全国大学生课外学术科技作品竞赛，获国家级一等奖（2025 年 5 月）。

**注意**：区分"国家级竞赛"与"全国性行业赛事"，后者如果含金量存疑，如实写主办方即可，不要夸大层次。

### 7.5 成果量化原则

成果排布按此顺序：**层次（国家级 > 省部级 > 校级）→ 位次（一作/主持 > 参与）→ 状态（已发表/已授权 > 已录用 > 在审）**。同一层次的成果，位次高的写前面。

### 7.6 完整示例（科研段，约 350 字）

> 在科研与创新方面，我主持国家级大学生创新训练项目 1 项（《基于多模态融合的××××研究》，已结题），独立完成数据采集、模型设计与实验验证，构建数据集 1 套，撰写技术报告 1 份，项目结题评为优秀。在此基础上，我以第一作者在 CCF 推荐 C 类会议《××××》发表学术论文 1 篇（已录用），提出一种面向小样本场景的图文匹配方法，在 3 个公开数据集上相较基线平均提升 4.2 个百分点；作为第一发明人申请国家发明专利 1 项（已受理）。此外，我作为第 1 完成人参加第十九届"挑战杯"全国大学生课外学术科技作品竞赛，获国家级一等奖。

## 八、综合素质与社会实践撰写方法

### 8.1 学生工作写法

**结构**：职务全称 → 任职时间 → **量化产出**（场次/人数/覆盖率）→ 一句成效。

✅ 示例：
> 在综合素质方面，我担任班级学习委员期间（2024 年 9 月至今），牵头建立课程笔记共享机制，组织考前答疑 6 场，班级期末平均分较上学期提升 4.3 分，四级通过率由 76% 提升至 92%。

❌ 示例：
> 我担任学习委员，工作认真负责，得到了老师和同学的一致好评。（无数据、无产出）

### 8.2 志愿服务写法

**要素**：项目名称 + 累计时长 + 组织单位 + 具体角色。

✅ 示例：
> 累计志愿服务时长 120 小时，其中参加校团委组织的"三下乡"暑期社会实践 1 次（14 天，任支教组组长），面向乡村小学开设科学实验课 12 课时。

### 8.3 文体与其他荣誉

只保留校级及以上、且与"综合素质突出"相关的荣誉（如优秀共青团员、社会实践先进个人）。同一类荣誉不重复罗列（三年都是三好学生，写一次即可）。

### 8.4 避免罗列堆砌

一段内**荣誉数量控制在 3~5 项**，且必须按层级排序。堆 15 项校级荣誉反而会让评审认为"没有高层次成果"。

### 8.5 完整示例（综合素质段，约 350 字）

> 在综合素质与社会实践方面，我担任班级学习委员（2024 年 9 月至今），牵头建立课程笔记共享机制，组织考前答疑 6 场，班级期末平均分较上学期提升 4.3 分，CET-4 一次通过率由 76% 提升至 92%，所在班级获评校级"先进班集体"。我累计参与志愿服务 120 小时，参加校团委组织的"三下乡"暑期社会实践 1 次（14 天，任支教组组长），面向乡村小学开设科学实验课 12 课时，相关实践成果被校团委公众号专题报道 1 次。此外，我获校级"优秀共青团员"荣誉称号 1 项，并在校运会 400 米项目中获第 3 名。

## 九、评审标准与打分维度

> 说明：各校评审细则不同，本章为**通用框架 + 典型权重**，用于帮助用户自查材料是否覆盖各维度，不做为某一学校的官方标准。若用户提供本校细则，以学校细则为准。

### 9.1 总分构成（典型权重）

| 维度 | 典型权重 | 材料中对应位置 |
|---|---|---|
| 学业成绩（GPA、排名、课程） | 45%~55% | 学业科研段前半 |
| 科研与创新（论文、专利、项目） | 20%~25% | 学业科研段后半 |
| 竞赛获奖 | 10%~15% | 学业科研段 / 综合素质段 |
| 综合素质（学生工作、志愿服务、文体） | 10%~15% | 综合素质段 |
| 思想政治表现 | 5%~10% | 思想政治段 + 组织评价 |

### 9.2 学业维度自查细则

| 档次 | 表现 | 常见得分区间 |
|---|---|---|
| 顶尖 | 专业排名前 1%，GPA 3.9+/4.0 | 90~100 |
| 优秀 | 专业排名前 3%，GPA 3.7+ | 80~89 |
| 良好 | 专业排名前 10%，GPA 3.5+ | 70~79 |
| 达标边缘 | 专业排名 10%~30%，无特别突出成果 | 通常不满足硬门槛 |

### 9.3 科研与创新维度自查细则

| 成果 | 判定要点 |
|---|---|
| SCI/EI/CCF-B 以上一作论文 | 强加分项，务必放首位 |
| 国家级大创主持（已结题） | 加分项，需写清本人承担工作 |
| 发明专利（已授权） | 加分项，受理状态需如实标注 |
| 会议论文/软著/校级项目 | 一般加分，作为补充 |

### 9.4 竞赛维度自查细则

按 **级别 × 等级 × 位次** 三要素判断：国家级一等奖第 1 完成人 > 国家级二等奖第 1 完成人 > 省级一等奖第 1 完成人 > 校级一等奖。同一赛事不同年份的奖按最高一次写，避免重复。

### 9.5 思想政治维度自查细则

看的是"有事实支撑的表现"：党员/预备党员身份 + 组织活动参与 + 荣誉（优秀团员等）。仅有表态无事实的段落，此维度基本不得分。

### 9.6 评分自检示例（两位候选人对照）

| 项目 | 候选人 A | 候选人 B |
|---|---|---|
| 专业排名 | 1/120（前 0.83%） | 8/120（前 6.7%） |
| GPA | 3.92/4.0 | 3.75/4.0 |
| 科研 | 一作会议论文 1 篇 + 主持国家级大创 | 参与省级大创 1 项 |
| 竞赛 | 挑战杯国家级一等奖（第 1 完成人） | 数学建模省级二等奖 |
| 综测排名 | 2/120 | 10/120 |
| 判断 | 材料全面覆盖五维度，具备竞争力 | 达标但科研维度偏弱，建议强化成果描述或补充其他成果 |

### 9.7 一票否决项清单

- 本学年有挂科记录
- 有违纪处分记录
- 学习成绩排名未进前 10%，且不具备"某方面特别突出"的证明
- 材料存在弄虚作假（后果最严重，可能影响学籍）
- 同一学业阶段重复获得国家奖学金

### 9.8 用户自查表（可直接发给用户）

```
请逐项确认（有任一项不符合，建议改申其他奖学金）：
□ 全日制本科二年级及以上
□ 学习成绩排名位于专业前 10%
□ 综合考评排名同样达标
□ 本学年无挂科
□ 无违纪处分
□ 有至少 1 项可支撑"特别突出"的成果（国家级竞赛 / 论文 / 专利 / 项目）
□ 所有数据均有证书、成绩单等佐证材料
```

## 十、避坑指南与正反例

### 10.1 写家庭经济困难（最致命）

- ❌ "我来自农村，家庭经济困难，恳请领导批准以减轻家庭负担。"
- ✅ 完全删除此类表述。国奖评审看卓越，不看困难；写了等于自证不了解评审标准。
- 想申请困难类资助，应分流到 `motivation_scholarship` 或 `grant_application`。

### 10.2 排名只写"名列前茅"

- ❌ "我的成绩在班级名列前茅。"
- ✅ "本学年专业排名 1/120（前 0.83%），综合考评排名 2/120。"

### 10.3 荣誉罗列无层次

- ❌ 连续列出 12 项校级荣誉。
- ✅ 按层级排序，只保留 3~5 项最高层次成果，国家级放最前。

### 10.4 抒情堆砌占篇幅

- ❌ "时光荏苒，回首这一年的点点滴滴，我感慨万千……"
- ✅ 直接进入信息。抒情句占的字数，评审看不到任何加分点。

### 10.5 成果虚报或时间矛盾

- ❌ 把"在审"写成"已发表"；把团队成果写成本人独立完成。
- ✅ 状态如实标注；时间线自检（成果时间不得晚于申请时间，不得跨学年错标）。

### 10.6 混入励志奖学金的内容

- ❌ 在同一份国奖材料里写家庭收入、勤工助学经历。
- ✅ 两套逻辑严格分离，见 6.5。

### 10.7 GPA 制式不说明

- ❌ "我的 GPA 是 3.9。"
- ✅ "GPA 3.92/4.0（学校采用 4.0 制）"，百分制则写"加权平均分 93.1 分"。

### 10.8 忽略综合考评排名

- ❌ 只写学习成绩排名。
- ✅ 学习成绩与综测排名双写——多数学校要求双达标，缺一项会被直接筛掉。

### 10.9 结尾空喊口号

- ❌ "我一定会继续努力，不辜负领导和老师的期望，为实现中华民族伟大复兴的中国梦贡献青春力量！"
- ✅ "如有幸获得国家奖学金，我将以此为新的起点，继续在××方向深入研究。无论结果如何，我都将保持严谨求实的学风。恳请评审老师考察与批准。"

### 10.10 附件缺失

- ❌ 文中写了"发表论文 1 篇"却没有附件材料。
- ✅ 文末附材料清单：成绩单、排名证明、获奖证书复印件、论文录用通知、专利受理通知书。

### 10.11 与同班同批次材料高度雷同

- ❌ 直接套用网络模板或同学的材料，只改名字数据。
- ✅ 用自己的具体项目、课程、数据填充每个论断，形成独立事实链。

### 10.12 段落顺序颠倒

- ❌ 把学生工作写在学业科研之前，导致核心亮点被埋。
- ✅ 严格按 4.1 的六段式顺序，学业科研段居中且最长。

## 十一、政治用语规范

### 11.1 全称与简称

| 规范写法 | 错误写法 |
|---|---|
| 中国共产党 | 我党、党组织（首次出现须用全称） |
| 中国共产主义青年团 | 共青团（可简称，但首次宜用全称） |
| 中共预备党员 / 中国共产党党员 | 预备党员（写政治面貌时应带全称） |
| 习近平新时代中国特色社会主义思想 | 习思想等任何简称 |

### 11.2 政治面貌写法

规范表述：`中共党员`、`中共预备党员`、`共青团员`、`群众`。不写"入党积极分子"作为政治面貌（这是发展阶段，不是政治面貌），可在正文中作为具体表现描述。

### 11.3 党团活动表述

写具体活动名称与频次，如"参加党支部组织生活 8 次、主题党日活动 3 次"，不使用"积极参加各类党团活动"这类空泛表述。政治面貌与组织关系必须与事实一致，不得虚报。

### 11.4 慎用表述清单

以下表述容易显得空洞或不当，建议删除或替换：
- "在思想上、政治上、行动上同党中央保持高度一致"（无具体事实支撑时空洞）
- 任何涉及未公开会议、内部文件、敏感性社会议题的表述
- 对他人的政治评价（如评价同学的政治表现）
- 涉及宗教、民族等敏感话题的表述

**写作边界**：本 skill 只协助规范政治类公文的**格式与事实表述**，不替用户生成政治观点、不代替组织鉴定或评价。

当前渲染器**只支持段落文本，不支持表格渲染**，因此：

- 主要获奖、科研成果以**段内分号分条**的形式写入对应段落，例如：
  `在科研方面，我……；获国家级竞赛一等奖 1 项（第 1 完成人，2025 年 5 月）；以第一作者发表会议论文 1 篇。`
- 标题（《国家奖学金申请书》）、称呼（尊敬的学校领导、评审委员会老师：）、"此致/敬礼！"、落款均由脚本自动生成，**不要写进 `paragraphs`**，否则会重复。

### 12.4 输出格式

A4 纸张，页边距上下 2.54 cm、左右 2.5 cm；标题黑体二号居中；称呼宋体小四加粗顶格；正文宋体小四、1.5 倍行距、首行缩进 2 字符；落款右对齐。

### 12.5 已知限制（待扩展，需确认后另行开发）

| 限制 | 影响 | 建议处理 |
|---|---|---|
| 不支持表格 | 无法渲染"主要获奖列表""科研成果表" | 暂以段内分条替代；如需表格需扩展 `build.py` |
| 不支持加粗/分段内的强调 | 关键数据无法突出 | 依赖措辞而非格式 |
| 固定称呼 | 学校要求不同称呼时需改脚本 | 以学校模板为准，必要时手动调整 |

## 十四、学校差异处理

### 14.1 三类常见模板差异

| 模板类型 | 特征 | 应对 |
|---|---|---|
| 自由书信体 | 无固定栏目，字数 1500~2500 字 | 本 skill 默认输出形式 |
| 表格式 | 固定栏目（思想/学习/工作/生活）+ 字数上限 | 按栏目分别成段，标题保留"×××方面" |
| 混合式 | 前面表格 + 后面附申请书 | 先按栏目填表内容，再输出书信体正文 |

### 14.2 学院补充要求

部分学院会另发细则（附加分项、格式模板、封面要求）。用户提供学院通知时，**以学院细则优先**，本 skill 只保证内容要素完整。

### 14.3 字数上限冲突

若学校要求不超过 1200 字，按此优先级削减：结尾段 → 思想政治段 → 综合素质段 → 保留学业科研段完整。**核心亮点段永远最后削减**。

## 十五、与其他奖学金的边界

| 用户情况 | 目标 skill | 判断依据 |
|---|---|---|
| 排名前 10% + 突出成果，无困难认定 | **本 skill（国家奖学金）** | 卓越导向 |
| 家庭经济困难 + 排名前 30% | `motivation_scholarship` | 困难 + 励志导向 |
| 仅成绩良好，无突出成果 | `university_scholarship` / `single_scholarship` | 校级 / 单项 |
| 企业冠名奖学金 | `enterprise_scholarship` | 行业兴趣 + 职业规划导向 |
| 家庭经济困难但成绩一般 | `grant_application` | 助学金，非奖学金 |

**同一学年同时申请多个奖项**：材料需分别撰写，不可一份多用（评审标准与权重完全不同）。
