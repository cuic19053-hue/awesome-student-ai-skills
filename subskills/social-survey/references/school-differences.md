# 十三、学校差异处理

> 从 `subskills/social-survey/SKILL.md` 外移而来（渐进式披露）。
> 何时阅读：用户指定了具体学校、需要适配格式时。

不同学校模板有微调，处理规则：

**栏目顺序差异**：个别学校把"经费预算"放在"预期成果"后，或合并"指导教师意见"与"学院团委意见"。按学校下发模板顺序调整 build.py 的 build() 方法调用顺序。

**字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。

**页边距差异**：部分学校要求 3cm 左右边距。修改 build.py setup_page() 中的 left_margin/right_margin。

**栏目增减**：
- 校级通常无"学校审批意见"栏 → 删除 _add_review_section() 中对应行
- 部分学校增加"中期检查计划"栏 → 在 build() 中追加 _add_midterm_check() 方法
- 部分学校要求附"问卷全文"与"访谈提纲"作为附件 → 设置 include_appendix: true

**级别差异**：
- 国家级：12 栏目全要 + 经费 1~1.5 万 + 调研报告 2 万字
- 省级：12 栏目全要 + 经费 0.8~1 万 + 调研报告 1.8 万字
- 校级：可省"学校审批意见"栏 + 经费 0.5~0.8 万 + 调研报告 1.5 万字

### 13.1 常见学校差异速查

| 学校类型 | 栏目顺序 | 字体 | 页边距 | 备注 |
|----------|----------|------|--------|------|
| 国家级模板（默认） | 12 栏目标准顺序 | 宋体小四/黑体三号 | 2.54/2.5cm | 本 skill 默认 |
| 综合类大学 | 同国家级 | 同上 | 2.54/2.5cm | 含团中央专项报送栏 |
| 师范类大学 | 经费预算移至宣传计划后 | 仿宋 GB2312 正文 | 2.54/2.5cm | 含支教联动栏 |
| 农林类大学 | 含产业调研专属栏 | 同上 | 3cm 左右 | 强调农业产业数据 |
| 理工类大学 | 同国家级 | 同上 | 2.54/2.5cm | 强调方法科学性 |

### 13.2 自定义模板适配步骤

1. 询问"学校名称？是否下发模板？"
2. 若有模板，让用户提供 docx/pdf 模板或截图
3. 对照本 skill 标准模板，标记差异点（栏目顺序、字体、页边距、增减栏）
4. 修改 build.py 对应函数（顺序调整 / 常量修改 / 增删方法）
5. 重新生成 docx，告知用户"已按 XX 学校模板调整"

适配修改记录到 worklog.md，便于后续项目复用。

### 13.3 模板适配后自检

适配完成后逐项自检：
- 栏目顺序与学校模板一致
- 字体符合学校要求（宋体/仿宋/楷体）
- 页边距符合学校要求
- 增减栏目已落实到 build.py
- 生成 docx 后人工目测与学校模板对齐

自检不通过 → 重新调整 build.py → 再生成 → 再自检。

### 13.4 团中央专项报送处理

若项目被推荐至团中央专项（如"乡村振兴""红色之旅"等专项），需在申报书末尾追加"专项报送说明"段，注明：
- 对应专项名称（如"乡村振兴青春建功专项行动"）
- 团中央对应通知文号
- 本项目与专项主题的契合点（3~5 句话）
- 预期专项成果（如优秀调研报告、典型案例）

专项报送不影响主申报书结构，仅追加段落。build.py 可通过 `tuancentral_special: "乡村振兴专项"` 字段控制是否生成。

### 13.5 与其他子类 skill 联动

调研类申报书若同时含支教/宣讲/服务子活动，可联动调用对应 skill：
- 调研为主 + 支教为辅：调用 social_survey 为主，支教子活动写入实施方案表
- 调研为主 + 宣讲为辅：宣讲场次列入按天安排（如 7.19 下午 A 村宣讲 1 场）
- 调研为主 + 服务为辅：服务记录列入预期成果

主子类区分以"产出占比"为准：调研产出占比 ≥ 60% 即归调研类。适配流程：先问"学校下发的模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按国家级模板处理。适配完成后告知用户"已按 XX 学校模板调整，请核对栏目顺序与字体"。

### 13.6 修改记录管理

每次适配后，在 worklog.md 中追加：日期、学校名称、修改字段（栏目顺序/字体/页边距/增减栏）、修改前后对比、影响 build.py 哪些函数。便于后续相同学校项目直接复用，减少重复适配工作。

完成全部流程后，最终交付物为可提交的 docx 申报书 + 问卷全文附件 + 访谈提纲附件。

本 skill 执行流程：触发 → 信息采集 → 撰写 12 栏目 → 调 build.py 生成 docx → 15 项质检 → 提交。
