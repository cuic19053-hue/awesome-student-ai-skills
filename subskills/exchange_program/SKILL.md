# 交流项目申请书 SKILL

## §0 适用场景与三渠道分流

### 0.1 本 skill 的适用范围

- 在校本科生（少数项目含研究生）申请学期/学年交换项目
- 校际交换、院际交换、CSC 公派留学三类项目任一
- 目标院校为境外（含港澳台）正规高校，含联合培养/双学位/3+1/2+2/学期交换/暑期学校等模式
- 涵盖纸质邮寄、电子上传、系统填报三类提交方式

### 0.2 交流项目 vs 留学申请

| 维度 | 交流项目（本 skill） | 出国留学 PS/SOP |
|------|----------|------|
| 申请阶段 | 本科在校期间（学籍保留在本校） | 本科毕业申请研究生 |
| 学籍归属 | 学籍保留本校，交流期满回本校 | 学籍转入目标院校 |
| 学位授予 | 不授目标院校学位（少数双学位项目除外） | 授目标院校学位 |
| 语言 | 多为中文申请书 + 英文成绩单 | 全英文 SOP/PS |
| 字数 | 1500~2500 字（中文） | 500~1000 字（英文） |
| 评审重点 | 学业 + 交流动机 + 学习计划 + 文化交流 + 安全 | 学术潜力 + 研究方向匹配 |
| 资金来源 | 校际协议免除学费 / CSC 资助 / 自费 | 自费 / 学校全奖 / CSC |

### 0.3 三渠道分流决策

申请人应根据自身学业水平、外语成绩与目标方向选择合适渠道：

| 渠道 | 时间窗 | 选拔概率 | 申请人定位 |
|------|--------|----------|------------|
| 校际交换 | 每年 3~4 月、9~10 月（学校合作项目集中选拔） | 中（按学业排名择优） | 学业前 20% + 语言达标 + 对方院校有合作 |
| 院际交换 | 每年 3~5 月（学院合作项目分散选拔） | 较高（院系推荐 + 简化程序） | 学业前 30% + 院系认可 |
| CSC 公派 | 每年 1~3 月（国家留学基金委统一选拔） | 较低（全国竞争 + 严格评审） | 学业前 5% + 语言达标 + 有科研潜力 |

**渠道选择建议**：
- 学业硬指标强（GPA 前 5%）+ 语言达标（雅思 6.5+/托福 90+）+ 顶校合作：优先校际交换冲 QS 前 50
- 学业合格（前 20%）+ 语言达标 + 想体验海外学习：选院际交换冲目标院校
- 学业突出（前 5%）+ 有科研论文 + 想读博深造：CSC 公派冲 QS 前 30
- 自费预算充足 + 灵活时间：选暑期学校或短期项目（4~8 周）

### 0.4 触发条件与不触发场景

**触发条件**：用户提到"交流项目""学期交换""学年交换""校际交流""院际交流""出境交流""海外交流""交换生""交换生申请""交流项目申请""CSC 公派""国家公派""短期交流""暑期学校""暑期课程""海外学习""联合培养""双学位项目""3+1 项目""2+2 项目""学期项目""访学""访学申请"等任一关键词时激活。

**不触发**：
- 用户明确说"出国留学申请 PS"——属英文留学文书 skill
- 用户明确说"考研报名表"——属考研 skill
- 用户明确说"保研推免"——属 graduate_recommendation skill
- 用户明确说"研究生复试简历"——属复试 skill
- 用户明确说"实习申请"——属实习 skill

### 0.5 工作流程总览

四阶段流程，禁止跳步：

**阶段 1：信息采集（30~50 分钟）**
按 §5 信息采集清单分批采集，先采学业硬指标，再采交流项目信息，最后采学习计划与文化交流意愿。每采完一类即复述确认。

**阶段 2：栏目内容撰写（60~90 分钟）**
按 §2 五段结构 + §3 4 维度动机 + §4 3 阶段学习计划撰写。重点：交流动机（按 §3 4 维度）、学习计划（按 §4 3 阶段）。

**阶段 3：docx 生成（5 分钟）**
按 §13 build.py 接口生成 docx，按 §14 质检清单逐项排查。

**阶段 4：用户复核与提交（10~20 分钟）**
用户复核后修改提交。

### 1.2 校际交换详细规范

**核心特征**：校际交换是学校与境外高校签署合作协议的官方交换项目，学费互免，是最主流的本科交流方式。

**适用人群**：
- 在校本科生（大二、大三为主，少数项目含大一）
- GPA 排名专业前 20%（顶尖合作院校要求前 10%）
- 语言达标（雅思 6.0+ / 托福 80+ / 英语六级 500+，部分小语种项目可放宽）
- 学业无不及格科目

**申请前必查**：
1. 本校国际处官网"学生海外交流"栏目发布的合作院校清单
2. 合作院校的 QS 排名与学科排名（与本人专业匹配度）
3. 申请截止日期（多数校际项目截止于 3~4 月或 9~10 月）
4. 名额限制（多数项目每校每年 1~5 个名额）
5. 学分转换政策（出发前必须取得本校教务处学分认定承诺）

### 1.3 院际交换详细规范

**核心特征**：院系与境外高校的院级合作项目，通常简化申请程序、降低语言要求，但选择面较窄。

**适用人群**：
- 本院系内本科生（部分项目含研究生）
- GPA 排名专业前 30%（院系合作门槛较低）
- 语言达标（雅思 6.0+ / 托福 80+，部分项目接受六级）
- 院系认可（部分需院系推荐）

**申请前必查**：
1. 本院外事秘书发布的合作院校清单（一般在院官网"国际交流"栏目）
2. 院系合作期限与名额（部分院系合作到期不再续签）
3. 学分认定流程（院系级流程较校级简单，但仍需提前确认）
4. 出发前是否需院系导师同意（部分项目要求）

### 1.4 CSC 公派详细规范

**核心特征**：国家留学基金管理委员会（CSC）资助的公派留学项目，全额资助，但竞争激烈且回国义务严格。

**适用人群**：
- 在校本科生（少数项目，如"优秀本科生国际交流项目"）
- 在校硕士/博士研究生（联合培养博士为主）
- GPA 排名专业前 5%（顶尖要求前 1%）
- 语言达标（雅思 6.5+ / 托福 95+，部分项目要求更高）
- 有科研潜力（论文/竞赛/大创等佐证）

**申请前必查**：
1. CSC 官网（https://www.csc.edu.cn）当年项目指南
2. 本校国际处 CSC 申请通知（每年 1~3 月）
3. 目标院校是否在 CSC 合作清单
4. 回国服务 2 年的强制义务（违反将记入国家征信系统）
5. 联合培养博士需双方导师共同制定学习计划

### 1.5 3 类对照判定口诀

**校际判定**：核心是"学校官方合作" → 关键词"合作院校/学费互免/学期交换" → 必须有"QS 排名 + 学分转换"
**院际判定**：核心是"院系合作" → 关键词"院系推荐/简化程序/院级项目" → 必须有"院系适配度 + 学分认定"
**CSC 判定**：核心是"国家资助" → 关键词"CSC/公派/资助/回国服务" → 必须有"国家需求匹配 + 回国义务承诺"

**3 类不可混写**：一份申请书只能聚焦 1 类主线渠道，混写将导致评审无法判断资金来源与回国义务，降低通过率。

### 1.6 3 类混合场景处置

若用户实际申请含多类元素（如校际交换 + CSC 资助叠加），按以下规则处理：
- 校际 + CSC 资助叠加 → 选 CSC 公派为主线，校际作渠道说明
- 院际 + 校际协议互认 → 选校际为主线，院际作简化程序说明
- CSC + 校际联合培养博士 → 选 CSC 为主线，校际作渠道说明
- 3 类全有 → 选 CSC 为主线（资金来源决定主渠道），另 2 类各 80 字辅助

## §2 交流项目 5 段结构（必加章节 2）

交流项目申请书正文遵循"个人基本情况 15% + 交流动机 25% + 学习计划 30% + 文化交流意愿 15% + 安全保障 15%"的权重配比。注意：此处的百分比是字数与撰写侧重配比，不等于评审打分权重。

              ↓

### 2.3 5 段结构详细分解

**第一段：个人基本情况（15%）**

按 4 要素撰写，缺一不可：
1. 身份信息（学院 + 专业 + 年级 + 姓名 + 学号）
2. 学业信息（GPA + 排名 + 主修课程简述，不展开）
3. 语言水平（雅思/托福成绩 + 取得时间，CSC 公派需注明有效期）
4. 申请事项收束句（"现申请赴 XX 大学参加 XX 交流项目"）

**第二段：交流动机（25%）**

按 §3 的 4 维度撰写（学术深化 / 视野拓展 / 语言提升 / 职业规划），每维度必须有具体事实与量化数据。至少展开 3 维度，禁用"开阔眼界""出国镀金"等空泛表述。

**第三段：学习计划（30%）**

按 §4 的 3 阶段撰写：
1. 行前准备阶段：语言强化 + 文化预习 + 课程预选 + 学分认定沟通
2. 在外学习阶段：具体课程（≥5 门，含课程名/学分/学期）+ 每周时间分配 + 学术活动参与
3. 归国总结阶段：学分转换 + 经验分享 + 后续学业衔接

**第四段：文化交流意愿（15%）**

按"主动融入 + 传播中华 + 学术交流"3 维度撰写：
1. 主动融入当地文化（参与当地节庆/社团/家庭寄宿等）
2. 传播中华文化（组织中国文化展示/参加学联活动等）
3. 学术交流（参加学术讲座/研讨会/与其他交换生交流等）

**第五段：安全保障（15%）**

按"法律 + 保险 + 汇报 + 预案"4 维度撰写：
1. 遵守当地法律与校规（不参与非法活动 + 按时完成学业）
2. 购买海外保险（含医疗 + 意外 + 紧急救援，保额不低于 30 万元人民币）
3. 定期向本校汇报（每月汇报学习情况 + 紧急情况 24 小时内汇报）
4. 紧急情况预案（紧急联系人 + 使馆联系方式 + 当地报警电话）

### 2.4 开头与结尾配比

开头与结尾不计入 5 段配比，独立计算：

| 段落 | 字数占比 | 字数（1500 字版） | 字数（2000 字版） | 字数（2500 字版） |

### 2.5 5 段结构模板（按 2000 字版速查）

标题：交流项目申请书（黑体二号居中） → 称呼：尊敬的评审委员会：（顶格，全角冒号） → 开头（100 字）：身份 + 申请事项 + "现就交流项目申请事宜汇报如下：" → 一、个人基本情况（300 字，15%）：[身份 + 学业 + 语言 + 申请事项收束] → 二、交流动机（500 字，25%）：[4 维度 + 量化数据] → 三、学习计划（600 字，30%）：[3 阶段 + 课程名 + 学分转换] → 四、文化交流意愿（300 字，15%）：[融入 + 传播 + 学术交流] → 五、安全保障（300 字，15%）：[法律 + 保险 + 汇报 + 预案] → 结尾（100 字）："以上是我的交流项目申请。恳请评审委员会予以考虑。" → 落款（右对齐）：申请人：XXX / XXXX 年 XX 月 XX 日

### 2.6 段落衔接与此致敬礼规范

- 开头末句固定为"现就交流项目申请事宜汇报如下："（不用"如下所示"）
- 各段标题为"一、个人基本情况""二、交流动机"等中文序号；首句必须含本段核心数据，禁用抒情开头
- 结尾首句固定为"以上是我的交流项目申请。"
- "此致"另起一行，首行缩进 2 字符；"敬礼！"另起一行，顶格，后接感叹号
- 落款"申请人：XXX"另起一行，右对齐；日期另起一行，右对齐

## §3 交流动机 4 维度（必加章节 3）

交流动机段（375~625 字，25%）按"学术深化 + 视野拓展 + 语言提升 + 职业规划"4 维度撰写。每个维度必须有具体事实与量化数据，禁用泛泛而谈。这是评审判断"申请人为何申请交流项目"的关键段落，4 维度至少展开 3 维度，缺 2 维度即触犯雷区。

### 3.1 4 维度量化框架

| 维度 | 权重（段内） | 字数 | 必含量化要素 |
|------|-----------|------|-----------|
| 学术深化 | 30% | 约 110~190 字 | 目标院校学科排名 + 1~2 门特色课程 + 1~2 位导师 + 学术资源 |
| 视野拓展 | 25% | 约 90~155 字 | 1~2 个跨文化经历预期 + 1~2 个目标院校特色项目 |
| 语言提升 | 20% | 约 75~125 字 | 当前语言成绩 + 目标语言成绩 + 具体提升方式 |
| 职业规划 | 25% | 约 90~155 字 | 1 个明确职业方向 + 交流项目对职业的支撑性 |

### 3.2 维度 1：学术深化（30%）

**必含 4 要素**：①目标院校学科排名（QS / THE / 软科，必须查证）②1~2 门目标院校特色课程（必须从官网查证课程名）③1~2 位目标院校导师（必须从官网查证姓名 + 研究方向）④学术资源（实验室/数据库/学术活动）。

**正例**：伦敦大学学院（UCL）计算机科学专业在 2025 年 QS 学科排名全球第 8，其开设的《Machine Learning》（4 学分）由 Alexei Efros 教授（ACM Fellow，研究方向为计算机视觉）主讲，课程内容覆盖深度学习前沿。同时 UCL 拥有 Gatsby Computational Neuroscience Unit 等顶级实验室，定期举办 ICML、NeurIPS 等顶级会议讲座。我希望通过交流深入学习其计算机视觉与机器学习方向，弥补本校在该方向的课程空白。

**反例**：UCL 计算机科学专业很强，我想去学习先进知识。（无排名、无课程、无导师、无学术资源）

### 3.3 维度 2：视野拓展（25%）

**必含 3 要素**：①1~2 个目标院校特色项目（如国际周/学术节/跨文化交流项目）②预期参与的跨文化活动（具体活动名 + 时间）③跨文化经历的预期收获（具体能力提升）。

**正例**：UCL 每年 3 月举办"International Week"跨文化交流活动，吸引来自 150 多个国家的学生参与。我计划参与该活动，与来自不同文化背景的学生组成 5 人小组，共同完成 1 个跨文化主题项目。此外，我计划加入 UCL Chinese Society，在传播中华文化的同时，深入了解英国本土文化。通过这些跨文化活动，我预期能提升跨文化沟通能力，培养全球视野。

**反例**：我希望通过交流项目开阔视野，体验不同文化。（无具体项目、无具体活动、无预期收获）

### 3.4 维度 3：语言提升（20%）

**必含 3 要素**：①当前语言成绩（雅思/托福分数 + 取得时间 + 有效期）②目标语言成绩（交流结束时的预期分数 + 提升幅度）③具体提升方式（沉浸式学习 + 学术英语课程 + 日常交流）。

**正例**：当前雅思总分 6.5（听力 7.0 / 阅读 7.0 / 写作 6.0 / 口语 5.5，2024.09 取得，有效期至 2026.09）。通过 UCL 交流，我目标将雅思总分提升至 7.0 以上，其中口语提升至 6.5。具体提升方式包括：每周参与 UCL Language Centre 的学术英语课程（2 小时/周），加入 UCL English Speaking Union 每周练习口语（3 小时/周），与当地学生组成语言交换伙伴（每周 2 次）。同时通过沉浸式英语环境，提升日常交流能力。

**反例**：我希望通过交流提高英语水平。（无当前成绩、无目标成绩、无具体方式）

### 3.5 维度 4：职业规划（25%）

**必含 3 要素**：①1 个明确职业方向（具体岗位，非模糊行业）②交流项目对职业的支撑性（具体课程/资源/经历如何支撑）③归国后的发展路径（学业衔接 + 职业路径）。

**正例**：我的长期职业目标是成为跨国科技公司（如 Google、Microsoft）的算法工程师，从事计算机视觉与医学影像 AI 研究。UCL 计算机科学在计算机视觉领域全球领先，其导师 Alexei Efros 教授的团队近 3 年在 CVPR、ICCV 发表论文 25 篇。通过交流学习其计算机视觉课程与参与其团队研究，我将积累前沿学术经历，为未来申请海外博士项目（目标：斯坦福、CMU 计算机视觉方向）奠定基础。归国后，我计划将交流经历转化为科研论文（目标 1 篇 CVPR/ICCV），并申请清华或北大直博项目，最终实现跨国科技公司算法工程师的职业目标。

**反例**：我希望未来从事 IT 行业，交流经历能帮我找到好工作。（职业方向模糊、无支撑论证、无归国路径）

**短版（约 360 字）**：4 维度各精简至 80~95 字，列目标院校 QS 排名 + 1 门课程 + 1 位导师 + 1 个特色项目 + 当前语言成绩 + 目标成绩 + 1 个职业方向。

**标准版（约 500 字）**：4 维度各 110~130 字，列 QS 排名 + 2 门课程 + 2 位导师 + 1 个特色项目 + 当前语言成绩 + 目标成绩 + 具体提升方式 + 1 个职业方向 + 支撑论证。

**长版（约 625 字）**：4 维度详尽展开，含 QS 排名 + 2 门课程（含主讲教师论文数）+ 2 位导师 + 1 个实验室 + 1 个特色项目 + 当前语言成绩 + 目标成绩 + 具体提升方式（含小时数）+ 1 个职业方向 + 归国路径 + 量化目标。

## §10 雷区 10 条（必加章节 6）

以下 10 条雷区任一触犯，申请书将被评审委员会退回或评分大幅扣减。生成后必须按 §14 质检清单逐项排查。

### 10.1 雷区 1：交流动机空泛

❌ 反例：我希望通过交流项目开阔视野，体验不同文化，提高英语水平。

✅ 正例：通过参与 UCL International Week 与 150 多个国家学生组成 5 人小组，提升跨文化沟通能力；通过 UCL 计算机视觉课程与 Alexei Efros 教授课题组研究，目标发表 1 篇 CVPR Workshop 论文。

**排查方法**：全文检索"开阔眼界""出国镀金""体验不同文化""提高英语水平""学习先进知识""感受异国风情"等空泛词汇，必须替换为具体表述。

### 10.2 雷区 2：目标院校信息无查证

❌ 反例：UCL 计算机科学专业很强，我想去学习先进知识。

✅ 正例：UCL 计算机科学专业在 2025 年 QS 学科排名全球第 8，其开设的《Machine Learning》（4 学分）由 Alexei Efros 教授（ACM Fellow）主讲，团队近 3 年在 CVPR、ICCV 发表论文 25 篇。

**排查方法**：交流动机段必须含 QS 排名（含年份）+ 具体课程名 + 导师姓名 + 研究方向，无查证信息即触犯。

### 10.3 雷区 3：4 维度动机缺 2 维度

❌ 反例：仅写学术深化与职业规划，未写视野拓展与语言提升。

✅ 正例：4 维度齐全（学术深化 + 视野拓展 + 语言提升 + 职业规划），每维度有具体内容与量化数据。至少展开 3 维度。

**排查方法**：交流动机段必须含 4 维度至少 3 维度齐全，缺 2 维度即触犯。

### 10.4 雷区 4：学习计划无具体课程

❌ 反例：在外学习期间我会努力学习，修读相关课程。

✅ 正例：第 1 学期修读《Machine Learning》（4 学分，主讲 Alexei Efros 教授）、《Computer Vision》（4 学分，主讲 John S. 教授）、《Academic English》（2 学分）共 10 学分。

**排查方法**：学习计划段必须含至少 5 门具体课程名（含学分与主讲教师），无具体课程即触犯。

### 10.5 雷区 5：学习计划 3 阶段缺一

❌ 反例：仅写在外学习，未写行前准备与归国总结。

✅ 正例：3 阶段齐全（行前准备 + 在外学习 + 归国总结），每阶段有具体内容与量化要素。

**排查方法**：学习计划段必须含 3 阶段齐全，缺一即触犯。

### 10.6 雷区 6：学分转换无方案

❌ 反例：归国后我会办理学分转换。

✅ 正例：5 门 UCL 课程共 16 学分已与本校教务处确认转换为 12 学分（含 8 学分专业核心课 + 4 学分专业选修课），不影响本校毕业学分要求。

**排查方法**：学习计划段必须含具体学分转换方案（含课程对应 + 学分数 + 沟通进展），无方案即触犯。

### 10.7 雷区 7：安全保障 4 维度缺一

❌ 反例：仅写遵守法律与购买保险，未写定期汇报与紧急预案。

✅ 正例：4 维度齐全（法律遵守 + 保险购买 + 定期汇报 + 紧急预案），每维度有具体承诺与量化要素。

**排查方法**：安全保障段必须含 4 维度齐全，缺一即触犯。

### 10.8 雷区 8：抒情开头与乞求结尾

❌ 反例（开头）：怀揣着对知识的渴望与对世界的好奇，我郑重提交本次交流项目申请。

❌ 反例（结尾）：综上所述，本人完全符合交流项目条件，恳请领导批准！

✅ 正例（开头）：我是计算机科学与技术学院计算机科学与技术 2023 级学生张明，现申请赴伦敦大学学院（UCL）参加 1 学年交流项目。现就交流项目申请事宜汇报如下：

✅ 正例（结尾）：以上是我的交流项目申请。无论审批结果如何，我都将继续努力学习，以更高标准要求自己。恳请评审委员会予以考虑。

**排查方法**：开头必须含身份 + 申请事项 + 汇报句；结尾必须含"以上是我的交流项目申请"+ 朴素表态，禁用"恳请领导批准""完全符合条件"。

### 10.9 雷区 9：排名不写基数

❌ 反例：专业排名第 5。

✅ 正例：专业排名第 5/120（前 4.2%）。

**排查方法**：排名必须含"X/N"格式与百分比，缺基数即触犯。

### 10.10 雷区 10：文化交流意愿无具体活动

❌ 反例：我会积极参与文化交流活动，传播中华文化。

✅ 正例：我计划加入 UCL Chinese Society，参与组织 2026 年春节文化展示活动（含书法、茶艺、汉服展示），并向英国同学介绍中国传统文化。同时在学联组织的中秋节、端午节活动中担任志愿者。

**排查方法**：文化交流意愿段必须含具体活动名（含组织 + 形式 + 时间），无具体活动即触犯。

### 10.11 雷区汇总速查表

| 雷区编号 | 雷区名称 | 关键排查点 |
|---------|---------|-----------|
| 1 | 交流动机空泛 | 禁用"开阔眼界""出国镀金"等 |
| 2 | 目标院校无查证 | 必含 QS 排名+课程+导师 |

## §13 build.py 接口说明（必加章节 8）

### 13.1 build.py 接口概览

build.py 位于 `/home/z/my-project/skills/awesome-student-ai-skills/subskills/exchange_program/build.py`，提供 CLI 接口生成交流项目申请书 docx。

**核心类**：`ExchangeProgramDocBuilder`

**主构建方法**：`build(data: Dict[str, Any], output_path: str) -> str`

**编排顺序**：标题 → 称呼 → 开头 → 个人基本情况 → 交流动机 → 学习计划 → 文化交流意愿 → 安全保障 → 结尾 → 落款

### 13.2 CLI 调用方式

**基础调用（用户提供 data.json）**：
```bash
python build.py --data data.json --out output.docx
```

**演示模式（使用内置示例数据）**：
```bash
python build.py --demo --out demo.docx
```

**参数说明**：
- `--data`：数据 JSON 文件路径（与 `--demo` 二选一）
- `--out`：输出 docx 文件路径（必填）
- `--demo`：使用内置示例数据生成演示文档

### 13.3 文档格式规范

| 项 | 规范 |
|----|------|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上下 2.54cm，左右 2.5cm |
| 标题 | 黑体二号（22pt），居中，段前后 12pt |
| 称呼 | 顶格，宋体小四（12pt），全角冒号 |
| 正文 | 宋体小四（12pt），1.5 倍行距，首行缩进 2 字符 |
| 小节标题 | 黑体小四加粗（12pt），首行缩进 2 字符 |
| 表格 | 宋体五号（10.5pt），居中，表头加粗 |
| "此致" | 另起一行，首行缩进 2 字符 |
| "敬礼！" | 另起一行，顶格，后接感叹号 |
| 落款 | 右对齐，含申请人 + 日期 |

### 13.5 字段消费规则

- **整段覆盖字段优先**：若 `opening` / `basic_info` / `motivation` / `learning_plan` / `cultural_exchange` / `safety` / `ending` 任一提供非空字符串，则直接使用，跳过模板拼装
- **4 维度动机切换**：`motivation` 整段优先；否则按 4 维度拼装，缺维度则跳过
- **3 阶段学习计划切换**：`learning_plan` 整段优先；否则按 3 阶段拼装，缺阶段则跳过
- **数组字段缺失处理**：`current_core_courses` / `target_courses` / `target_teachers` / `study_plan_table` 缺失则省略对应表格
- **必填字段警告**：P0 字段缺失触发 warning，但不阻断生成

3. 调用 build.py 生成 docx（`python build.py --data data.json --out output.docx`）
4. 检查 warnings（按 §14.5 决策树处理）
5. 按 §14 质检清单 35 项逐项排查
6. 修正后重新生成
7. 输出可提交 docx

### 14.7 常见 FAQ

**Q1：用户未提供目标院校 QS 排名？** → 追问"请从 QS 官网（topuniversities.com）查证目标院校 2025 年 QS 全球排名与学科排名"，无法查证则按通用模板生成但提示用户必须自行核对。

**Q2：用户混淆交流项目与出国留学？** → 明确区分（交流项目学籍保留本校，出国留学学籍转入目标院校），本科毕业想读研出国走留学 SOP skill。

**Q3：用户语言成绩未达标？** → 建议先考语言再申请，或选无语言要求的院际交换项目。

**Q4：目标院校课程查证不到？** → 必须从目标院校官网查证，禁止编造；官网未公开则联系目标院校 International Office 或本校国际处协助。

**Q5：CSC 公派回国服务 2 年义务？** → 必须在申请书与协议中明确承诺，违反将记入国家征信系统影响未来学术生涯。

## §15 红线规则与免责声明

### 15.1 红线规则

以下规则不可违反，违反即触犯雷区：

1. **严禁编造目标院校信息**：必须从目标院校官网与 QS 官网查证
2. **严禁编造导师姓名**：必须从目标院校官网师资队伍栏目查证
3. **严禁编造 QS 排名**：必须从 QS 官网查证（含年份）
4. **严禁空泛表述**：禁用"开阔眼界""出国镀金"等
5. **严禁 4 维度动机缺 2**：至少展开 3 维度
6. **严禁 3 阶段学习计划缺一**：行前/在外/归国必须齐全
7. **严禁安全保障 4 维度缺一**：法律/保险/汇报/预案必须齐全
8. **严禁抄袭模板**：必须结合本人真实学业经历与交流目标
9. **严禁隐瞒 CSC 回国义务**：CSC 公派必须承诺回国服务 2 年

### 15.2 免责声明

本 skill 生成的申请书为模板化初稿，用户必须：

1. **核对项目政策**：生成前必须核对本校国际处发布的交流项目通知（GPA 门槛/名额/语言要求/学分转换/申请截止日期）
2. **查证目标院校信息**：QS 排名/课程名/导师姓名/特色项目必须从官网与权威报告查证
3. **结合本人真实经历**：交流动机与学习计划必须基于本人真实学业与职业规划，禁止编造
4. **遵守学术诚信**：申请书必须本人撰写，禁止他人替代撰写（部分学校将撰写视为学术不端）
5. **遵守项目格式要求**：若项目有指定模板，必须按项目模板调整
6. **遵守 CSC 协议**：CSC 公派必须遵守回国服务 2 年义务

### 15.3 与其他 skill 的协同

- **graduate_recommendation**：交流项目归国后可申请保研推免，走该 skill
- **national_project_eval**：交流项目经历可作为评国奖的科研经历佐证
- **innovation_research**：交流项目期间可参与大创项目，走该 skill
- **college_research**：交流项目归国后可参与科研立项，走该 skill
- **outstanding_student**：交流项目归国后可申报评优，走该 skill
