# 转正申请书 Skill

本 skill 处理"转正申请书"全流程：信息采集 → 书信体撰写 → docx 生成 → 政治审查质检。转正申请书是**预备党员**在预备期满前，正式向党组织递交的、总结预备期内表现并申请按期转正的正式文书。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐）。

> ⚠️ **重要澄清（请先读）**：共青团**没有"预备团员"制度和"团员转正"程序**。《中国共产主义青年团章程》规定，经支部大会通过、上级团委批准即为团员，无预备期。因此**不存在"团员转正申请书"这一文书**。当用户说"团员转正"时，须先澄清其真实需求（多为以下之一），再决定是否使用本 skill：
> - **推优入党** → 属"推荐优秀团员作为入党积极分子"程序，改走入党/推优类文书；
> - **团籍确认 / 团组织关系转接** → 属组织关系手续，非本 skill；
> - **预备党员转正**（用户虽自称"团员"，实为预备党员）→ 用本 skill。
>
> 本 skill 仅服务**中共预备党员按期转正**。

## 一、适用场景与触发条件

### 1.1 适用

用户为**中共预备党员**、预备期即将/已经届满，需要提出按期转正申请时触发。触发词："转正申请书""转正申请""预备党员转正""党员转正""预备期满转正"。

**核心板块**：
1. **预备期起止与申请**：明确预备期起止时间，正式提出按期转正申请。
2. **思想政治理论提高**：预备期内理论学习、党性修养与理想信念的巩固。
3. **学业/科研/工作实绩**：预备期内专业学习、科研攻关、学生工作的具体成果。
4. **缺点认识与整改**：对入党时支部指出的缺点、自身短板的整改情况。
5. **表态与决心**：服从组织决定，无论批准与否均继续努力。
6. **落款**：申请人姓名与日期。

### 1.2 不适用（应走其他 skill）

| 场景 | 处置 |
|---|---|
| 尚未入党，首次申请入党 | 入党申请书类 skill |
| 申请入团 | `youth_league_application` |
| 预备期内的季度思想汇报 | `summary_report` |
| 团员"转正" | **不存在该文书**，见上方澄清 |
| 入党积极分子→发展对象 | 属发展程序，非本 skill |

### 1.3 触发后第一句话：前置确认（7 项硬门槛）

1. **身份确认**：是否为**中共预备党员**？（非预备党员一律不生成）
2. **预备期起止**：支部大会通过之日 = 预备期起算日；止 = 起算日 + 1 年。请用户给出准确起止日期。
3. **呈交对象**：通常为`尊敬的党组织：`。
4. **递交时机**：是否在预备期满前一周至一个月内？（见 §二 红线 2.2）
5. **入党时支部指出的缺点**：当初被指出的问题是否已整改？（第四段核心）
6. **预备期内成果**：理论学习、学业/科研/工作实绩（**≥3 条实数据**）。
7. **是否需要手写**：多数支部要求本人手写签名。

### 1.4 与其他文书的区别

- **与思想汇报**：思想汇报是"定期汇报表现"，转正申请书是"期满申请审批"，有明确诉求和时间节点。
- **与入党申请书**：入党申请书表达"志愿加入"，转正申请书请求"转为正式党员"。
- **与转正大会发言**：发言是口头/简短书面陈述，本 skill 产出的是随附材料的正式文书。

## 二、红线提示（生成前必读，违反任一项即退回重写）

### 2.1 身份与前提红线

- 申请人**必须是中共预备党员**；对团员、群众不得使用本 skill。
- 不得生成"团员转正申请书"（该文书不存在，见导言澄清）。

### 2.2 递交时机红线

- 一般在**预备期满前一周至一个月内**主动递交，不得提前过早或无故拖后；各支部可能另有要求，**以支部通知为准**。
- 落款日期须落在该时间窗内，且不早于正文所述最晚事件。

### 2.3 预备期计算红线

- 预备期**自支部大会通过其为预备党员之日起算，为期一年**（党章规定）。
- 例：2025年10月10日成为预备党员 → 预备期至 2026年10月10日届满。
- 不得把"成为发展对象/积极分子"的时间误当作预备期起点。

### 2.4 政治表述红线

- 理论、会议、政策名称须用官方原词，不得自造简称（详见 §七）。
- 不得出现**对转正结果的"交易式"表达**（如"若批准我将……若批准我就……"），表态须是无条件的服从组织。
- 不得出现消极、抱怨、功利化动机。

### 2.5 真实性红线

- 成绩、荣誉、实绩须真实可核；缺点段不得编造"假缺点"应付（如"我太追求完美"）。
- 信息缺失时留占位/追问，**不编造**。

### 2.6 抄袭与代写

转正申请书是**入党转正的正式组织材料**，抄袭或原样提交机器全文代写一旦被发现，会被退回并影响转正评价。本 skill 输出为**草稿底稿**，用户须用自己的语言补充真实经历后手写提交。

## 三、工作流程总览

```
① 触发 → 前置确认 7 项（§1.3；非预备党员即终止）
② 核对预备期起止（§2.3，防时间错误）
③ 信息采集（P0 → P1 → P2，§五）
④ 复述确认（按五段结构复述给用户核对）
⑤ 选字数档（compact / standard / full，§4.2）
⑥ 逐段撰写（§六 结构 + §七 必引 + §八 规范）
⑦ 质检（§十 25 项；不过则回 ⑥ 重写）
⑧ 生成 docx：python build.py --data data.json --out 转正申请书.docx
⑨ 字数脚本复跑，交付用户校对
```

## 四、类型与字数分级

### 4.1 三类情形

| 情形 | 说明 | 正文重点 |
|---|---|---|
| 按期转正（常规） | 预备期满、表现合格 | 五段完整，表态服从 |
| 延期后再次申请 | 上次被延长预备期 | 增写整改成效与变化 |
| 说明性转正申请 | 预备期内有缺席/变动 | 主动说明情况并表态 |

### 4.2 字数下限分级表（3 档）

| 档位 | 英文标识 | 中文字符下限 | 适用 |
|---|---|---|---|
| 精简 | `compact` | 1200 | 情况简单、支部简版要求 |
| 标准 | `standard` | 1500 | 按期转正（默认） |
| 完整 | `full` | 2000 | 延期再申请、重点考察 |

### 4.3 字数自检脚本（生成后必跑）

```python
import re
text = open("转正申请书.txt", encoding="utf-8").read()
n = len(re.findall(r"[\u4e00-\u9fff]", text))
print("中文字符数：", n)
assert n >= 1500, f"字数不足（{n}/1500），请补充实绩段与整改段"
```

### 4.4 不达标处理

优先补：① 整改情况（对照入党时指出的缺点逐条回应）→ ② 实绩段量化细节 → ③ 表态段的具体努力方向。**禁止套话灌水**。

### 4.5 字数档与段落配比

| 段落 | standard（1500）占比 | 建议字数 |
|---|---|---|
| ① 开头：预备期起止 + 申请 | ~13% | 180~200 |
| ② 思想政治理论提高 | ~22% | 320~350 |
| ③ 学业/科研/工作实绩 | ~33% | 480~520 |
| ④ 缺点认识与整改 | ~19% | 280~300 |
| ⑤ 表态与决心 | ~13% | 180~200 |

## 六、书信体结构详解（逐段）

### 6.1 结构总览（5 段 + 落款）

```
标题《转正申请书》（黑体二号居中，build.py 固定生成）
称呼（顶格，全角冒号）
① 开头：预备期起止 + 提出按期转正申请
② 预备期内思想政治理论提高与理想信念巩固
③ 预备期内学业/科研/学生工作实绩（重点段）
④ 对缺点的认识、整改情况及不足
⑤ 表态与决心（无条件服从组织决定）
此致（空两格）
敬礼！（顶格）
落款（右对齐：申请人：XXX / 年 月 日）
```

> 注：build.py 将标题**硬编码为"转正申请书"**，`paragraphs` 只需放 5 段正文。

### 6.2 标题

《转正申请书》——固定，不加时段、不加"我的"。

### 6.3 称呼

`尊敬的党组织：`（全角冒号，顶格独立成行）；若由支部转呈，可按支部要求写`敬爱的党支部：`，全文统一即可。

### 6.4 ① 开头段（180~200 字）——最具标识性的一段

必须包含**三个要素**：预备期起止日期、"成为预备党员"的事由、正式提出按期转正申请。模板：

> `[YYYY]` 年 `[M]` 月 `[D]` 日，经党支部大会讨论通过、上级党组织批准，我成为一名中共预备党员。截至 `[YYYY]` 年 `[M]` 月 `[D]` 日，我的预备期已满一年。今天，我向党组织提出按期转正申请。

- 日期务必与 §2.3 推算一致。
- 用"郑重"等词体现态度，但不要过度抒情。
- ⚠️ 不要写"我光荣地成为"——"光荣"是自我评价，支部不认，删掉不影响文意。

### 6.5 ② 思想政治理论提高段（320~350 字）

写**预备期内的理论成长与党性锤炼**，须落到具体：
1. 参加了哪些理论学习（三会一课、主题教育、党纪学习教育）；
2. 一个结合自身的思想转折；
3. 党性修养与宗旨意识的提升。
- 必引见 §七；至少 1 处落到自己的事。

### 6.6 ③ 学业/科研/工作实绩段（480~520 字，重点）

**全文含金量所在**，量化表达：
- 学业：绩点/排名/核心课成绩；
- 科研：课题名 + 阶段产出（论文/专利/数据/系统）；
- 工作：职务 + 履职（组织活动场次、服务人次）；
- 志愿服务：时长与项目。
- 与"思想汇报"不同：本段可稍强调"以党员标准发挥作用"（如带动同学、承担任务）。

### 6.7 ④ 缺点认识与整改段（280~300 字）——转正文书的**关键差异段**

- 先**回顾入党时组织/介绍人指出的不足**；
- 再写**具体整改措施与成效**（要有变化对比："过去……现在……"）；
- 最后写**仍然存在的不足**与下一步打算。
- 缺点须真实、非原则性；不得编造假缺点，也不得写成自我表扬。
- 示例（方括号必填）：
  > 入党时，组织指出我"理论联系实际不够"。一年来，我坚持学以致用，把党的群众观点落到班级学风建设中，牵头组织了 `[N]` 次考前答疑，覆盖 `[N]` 余人次；但面对复杂问题仍偶有急躁，今后我将 `[具体改进动作 + 时间节点]`。

### 6.8 ⑤ 表态与决心段（180~200 字）

- 表态须**无条件**：
  > 如果党组织批准我按期转正，我将以此为新的起点，牢记入党誓词，更加严格要求自己；如果党组织认为我还不够成熟，决定延长我的预备期，我也决不气馁，一定诚恳接受组织的考验，以实际行动克服缺点，争取早日成为正式党员。
- 不得出现"如果能给个机会就……""希望批准后给我加分"等交易式表达。

### 6.9 结尾与落款

- `此致`（另起一行空两格）+ `敬礼！`（另起一行顶格，带叹号）。
- 落款右对齐两行：`申请人：XXX` 换行 `2026年10月08日`。
- 日期口径与 build.py 一致：阿拉伯数字、月份补零（`2026年10月08日`）；支部要求汉字则生成后手工替换。
- 递交时通常需**本人签名**，部分支部要求手写全文。

## 七、必引理论表述清单

### 7.1 入党誓词（建议引 1 处）

"我志愿加入中国共产党，拥护党的纲领，遵守党的章程，履行党员义务，执行党的决定，严守党的纪律，保守党的秘密，对党忠诚，积极工作，为共产主义奋斗终身，随时准备为党和人民牺牲一切，永不叛党。"

### 7.2 党章相关

- **党员的八项义务与八项权利**（可概括引用）；
- 党章关于预备党员的规定（"预备党员的预备期为一年"）；
- 若为延期转正，应对照党员义务自查。

### 7.3 党的创新理论与会议精神

- 习近平新时代中国特色社会主义思想（**全称，不得简称**）；
- 党的二十大精神及当期重要会议精神（按实际更新）。

### 7.4 时政数据

- 党员总数等须引用中共中央组织部**最新年度党内统计公报**；不得使用过时数字。
- 引用领导人讲话须以新华社/人民日报通稿原文为准。

### 7.5 理论表述自检脚本

```python
import re
t = open("转正申请书.txt", encoding="utf-8").read()
required = ["习近平新时代中国特色社会主义思想"]
banned = ["习近平新时代思想", "习思想"]
assert any(k in t for k in required), "缺少必引理论表述"
for b in banned:
    assert b not in t, f"出现自造简称：{b}"
print("理论表述检查通过")
```

## 八、撰写规范

### 8.1 事实 + 数据原则

每个观点后给事实或数据；实绩段尤其忌"表现突出、成绩优异"三连。

### 8.2 人称与时态

- 第一人称"我"，全文统一（落款"申请人："除外）。
- 回顾式时态写预备期，展望式时态写决心段。
- 不用"本人"指代自己（除落款）。

### 8.3 标点与序号

- 正文为纯文本段落，不含 Markdown 符号；
- 分点用"一是……二是……"或"① ②"，不用阿拉伯列表；
- 全角标点、中文引号。

### 8.4 避免空话

| 空话 | 改写 |
|---|---|
| 我的党性修养有了显著提高 | 参加 `[N]` 次支部集中学习后，我开始在完成课程设计时主动考虑其对同学的实际帮助 |
| 我充分发挥了先锋模范作用 | 我带动 `[N]` 名同学组队参加 `[赛事全名]`，最终全队获 `[级别 + 等次]` |

### 8.5 与前文（思想汇报）呼应

若预备期内提交过思想汇报，本申请书可与其中之一呼应（"在 2026 年第三季度思想汇报中我曾反思……"，使材料形成闭环）。

### 8.6 段落衔接

段间至少一句逻辑过渡，避免五段各自独立。

### 8.7 字数配比

按 §4.5 控制，写完用 §4.3 脚本核对。

## 九、避坑指南与正反例（10 条）

1. **写成团员转正** ❌"作为预备团员申请转正" → ✅ 本 skill 仅限预备党员；团员需求先澄清。
2. **预备期日期算错** ❌把成为积极分子的时间当起点 → ✅ 以支部大会通过成为预备党员之日起算一年。
3. **交易式表态** ❌"若批准我将……若批准我则……" → ✅ 无条件服从组织决定。
4. **缺点段造假** ❌"我的缺点是太追求完美" → ✅ 回应组织当初指出的真实不足 + 整改成效。
5. **不写整改** ❌只列缺点不写怎么改 → ✅ "过去……现在……"对比 + 下一步措施。
6. **实绩无数据** ❌"成绩一直优秀" → ✅"绩点 `[X.X]`，专业前 `[N]%`"。
7. **身份错位** ❌群众/团员套用 → ✅ 仅预备党员使用。
8. **称呼冒号错** ❌半角":" → ✅ 全角"："。
9. **标题加时段** ❌《2026年[姓名]转正申请书》→ ✅《转正申请书》。
10. **机器腔** ❌通篇对仗无个人细节 → ✅ 至少 2 处只属于本人的具体经历。

## 写作风格规范（去 AI 味）

> 完整规范见 [`docs/design/WRITING_STYLE.md`](../../docs/design/WRITING_STYLE.md)。
> 撰写时优先使用用户确认的事实；文风检测仅提供人工复核线索，不能单凭分数拒绝交付。

### 一条总原则

**每个句子都必须能落到具体的人、事、时间、数字或对象上；落不到的句子，删掉。**
自检方法：读完一句问「这句能换成别人吗？」——能换，就是套话。

### 句式要求

1. **长短句交替**：每 3~5 句里至少有一句 ≤12 字或 ≥60 字。
2. **一段一个事实**：段首句不要用「在……方面」。
3. **少用第一人称抒情**：「我深深感到」「我深刻认识到」一律删除。
4. **事实优先**：仅用用户确认的数字；次数或数量未知时追问或保留原意。
5. 不用破折号堆叠解释，不连续套用「不仅……而且……」。

### 交付前文风复核

```bash
# 文风提示供复核；分数不是事实真实性或交付资格的判定。
python3 utils/ai_flavor_check.py --file draft.txt

# 按需查重；评审模拟仅用于已有评审标准的赛道。
python3 utils/plagiarism_checker.py --file draft.txt
python3 utils/review_simulator.py --list-skills
# 例：当赛道对应 grant_application 时
python3 utils/review_simulator.py --skill grant_application --text-file draft.txt
```

对低分或高分都应核对事实与语境，不能为凑数字虚构内容。

### 冲突处理

政策条文、领导讲话、文件原名**允许庄重书面语**，不算套话。
检测时加 `--allow-policy-quotes`（该维度扣分减半）。
但引用必须写成 `《文件全名》（发文号）`，且只引与论点直接相关的 1~2 句。

### 反模式

- ❌ 把子 skill 里的「金句模板」当范文直接套用
- ❌ 用排比段凑字数
- ❌ 通篇无一个数字、无一个专有名词
- ❌ 仅凭检测分数决定交付，或为提高分数编造事实
- ❌ 只删套话不补事实（删完变空段落，同样不及格）

## 十、质检清单（25 项）

### 10.1 红线检查（6 项，任一不过即退回重写）

- [ ] 申请人为预备党员（非团员/群众）
- [ ] 预备期起止计算正确（起日 + 1 年）
- [ ] 落款日期在递交时间窗内
- [ ] 无自造/错误理论简称
- [ ] 无交易式、消极、功利化表达
- [ ] 缺点与实绩均真实

### 10.2 字数与结构检查（6 项）

- [ ] 中文字符数 ≥ 所选档位下限
- [ ] 五段齐全（开头/理论/实绩/整改/表态）
- [ ] 实绩段为全文最长段
- [ ] 各段字数比例接近 §4.5
- [ ] 无 Markdown 残留
- [ ] 段间有过渡句

### 10.3 必引与时限检查（4 项）

- [ ] 开头段含预备期起止日期与申请表述
- [ ] 至少 1 处党的创新理论全称
- [ ] 入党誓词/党章内容引用准确（如引）
- [ ] 时政数据为最新口径

### 10.4 内容质量检查（5 项）

- [ ] 实绩段 ≥3 条可核对事实/数据
- [ ] 整改段回应了入党时指出的不足
- [ ] 表态段为无条件服从
- [ ] 无"表现优异/深受好评"类空话
- [ ] 有 ≥2 处个人独有细节

### 10.5 格式与落款检查（4 项）

- [ ] 标题为《转正申请书》
- [ ] 称呼顶格、全角冒号
- [ ] "此致"空两格、"敬礼！"顶格带叹号
- [ ] 落款右对齐、姓名与日期各一行

### 10.6 质检脚本（可选）


## 十二、常见问题 FAQ

**Q1：预备期是从哪天算起？**
自支部大会通过你为预备党员之日起算，为期一年（党章规定）。

**Q2：什么时候递交？**
预备期满前一周至一个月内主动递交；具体以支部通知为准。落款取递交日或支部指定日。

**Q3：上次被延长预备期，还能再申请吗？**
可以。延期后应在延长期满前再次申请，且在缺点段重点写延期原因的整改成效。

**Q4："团员转正"怎么做？**
共青团无预备团员制度，不存在团员转正申请书。你实际需要的可能是**推优入党**或**团组织关系转接**，请先与团支部确认。

**Q5：必须手写吗？**
多数支部要求本人手写并签名。本 skill 产出 docx 草稿，用户誊抄、补充个人经历后提交。

**Q6：写不出"缺点"怎么办？**
回想入党时介绍人或支部提过的意见，或写真实存在且已着手改进的短板（如时间统筹、群众工作方法），不要编造。

**Q7：字数不够？**
按 §4.4 优先补整改成效与实绩细节，不要重复口号。

## 十三、免责声明

1. 本 skill 输出为**草稿底稿**，最终以本人手写、支部审核版本为准。
2. 预备期计算、递交时限、支书材料要求各支部可能有差异，**以本单位党组织规定为准**。
3. 本 skill **不具备**判定转正资格的功能；转正须经支部大会讨论表决、上级党委审批。
4. 政治理论表述与时政数据须以官方最新通稿/统计公报为准，本 skill 不保证时效性。
5. 实绩、荣誉、缺点等由用户提供并对其真实性负责。
