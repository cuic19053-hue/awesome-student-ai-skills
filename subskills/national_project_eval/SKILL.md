# 国家级项目立项逻辑评测 Skill

本 skill 处理"国家级项目立项逻辑评测"全流程：申报书导入/输入 → 5 维逻辑评估 → 缺陷诊断 → 优化建议报告输出。针对国家级科研、创客及大创等项目申报书进行深度评审诊断。

输出文件：可提交的 .docx（A4 纸张，黑体二号标题居中、宋体小四正文、1.5 倍行距、首行缩进 2 字符、"此致/敬礼！"格式、落款右对齐）。

---

## 一、适用场景与触发条件

**适用**：用户提到"国家奖学金""国奖""国奖申请书""8000 元奖学金""本科生国家奖学金"等关键词，且本人 GPA 排名专业前 5%。

**不适用**（需走其他 skill）：
- 国家励志奖学金（5000 元，侧重家庭经济困难）→ 走励志奖学金 skill
- 校级一等奖学金（侧重纯学习）→ 走校级奖学金 skill
- 企业专项奖学金（侧重行业兴趣）→ 走企业奖学金 skill
- 单项奖学金（科研/社工/文体）→ 走单项奖学金 skill

**硬门槛**（任一不达标直接劝退）：
- GPA 加权平均分 ≥85 或 GPA 3.7+/4.0
- 专业排名前 5%（如 1/87、3/120，需明确基数）
- 本学年无挂科、无违纪处分
- 至少 1 项国家级竞赛奖项或 1 篇正式发表论文（含期刊级别、作者排序）

**子类型区分**：
- 国奖 vs 励志：国奖重学业+综合素质，励志重学业+家庭经济困难
- 国奖 vs 校级：国奖需国家级竞赛/论文，校级仅需 GPA
- 国奖 vs 单项：国奖综合考察四维度，单项只看某一领域

**触发后第一步**：核对硬门槛。若用户排名 >5% 或无国家级竞赛/论文，告知"国奖评审侧重学业+综合素质，建议改申励志或校级"，避免无效申请。

## 二、工作流程总览

四阶段串行执行，每阶段完成后再进入下一阶段：

**阶段 1 信息采集（8~12 轮对话）**：
按"通用必采 → 学业信息 → 荣誉经历 → 科研经历 → 社会实践 → 英语计算机等级"顺序采集。每轮不超过 5 个字段。关键缺失字段必须追问，禁止编造 GPA/排名/奖项/论文。

**阶段 2 书信体撰写（一次性产出）**：
按"标题 → 称呼 → 开头 → 思想方面 → 学习方面 → 科研实践方面 → 生活方面 → 结尾 → 落款"顺序撰写。正文 1200~2000 字，每段严格控制在规范区间。事实+数据原则，禁止形容词堆砌。

**阶段 3 docx 生成**：
调用 `python build.py --data data.json --out output.docx` 生成 Word 文档。data.json 字段定义见第十二章。

**阶段 4 质检**：
按第十三章 25 项清单逐项检查。任何一项不达标返回阶段 2 修改。

**禁止行为**：
- 开头抒情堆砌（"时光荏苒""岁月如梭"）
- 形容词代替事实（"成绩优异""积极参加"）
- 获奖不写级别与时间
- 学生干部只写头衔不写履职
- 结尾"恳请领导批准"
- 编造 GPA/排名/竞赛/论文/志愿服务时长
- 把励志类内容（家庭困难）写入国奖申请书

## 三、信息采集清单

### 3.1 通用必采（10 字段）

| 字段 | 说明 | 示例 | 缺失追问策略 |
|------|------|------|--------------|
| name | 申请人姓名 | 张明 | "申请人全名？" |
| student_id | 学号 | 2022123456 | "学号？" |
| gender | 性别 | 男 | "性别？" |
| college | 学院全称 | 计算机科学与技术学院 | "学院全称？" |
| major | 专业全称 | 计算机科学与技术 | "专业全称？" |
| grade | 年级 | 2022 级 大三 | "入学年份与年级？" |
| class_name | 班级 | 计科 2201 班 | "班级？" |
| political_status | 政治面貌 | 中共党员/共青团员 | "政治面貌？" |
| phone | 联系电话 | 138XXXXXXXX | "手机号？" |
| apply_year | 申报学年 | 2024-2025 学年 | "申报学年？" |

### 3.2 学业信息（硬指标，7 字段）

| 字段 | 说明 | 示例 |
|------|------|------|
| gpa | GPA | 3.92/4.0 |
| weighted_avg | 加权平均分 | 92.5 |
| rank | 专业排名 | 1/87（必须前 5%） |
| core_courses | 主干课程成绩 5~8 门 | [{name:"高等数学",credit:5,score:95},...] |
| cet4 | CET-4 成绩 | 568 |
| cet6 | CET-6 成绩 | 542 |
| computer_level | 计算机等级 | 二级 C 语言/三级数据库技术 |

### 3.3 荣誉经历（按时间倒序）

每项荣誉 4 字段：时间（YYYY.MM）、奖项全称、级别（国家/省/校/院）、颁发单位。

示例：
- 2025.05 全国大学生数学建模竞赛 国家二等奖 中国工业与应用数学学会
- 2024.11 校级一等奖学金（专业前 5%） XX 大学
- 2024.10 校级优秀学生干部 XX 大学

### 3.4 科研经历

**大创/科研立项**：项目名称、级别（国家级/省级/校级）、角色（负责人/参与）、起止时间、产出。

**论文**（含期刊级别、作者排序）：题目、期刊名、级别（SCI/EI/中文核心/普刊）、作者排序（第一/第二/通讯）、录用或见刊时间。

**专利**：名称、类型（发明/实用新型）、申请号、状态（受理/授权）。

**学科竞赛**：竞赛全称、奖项（国家一等奖/国家二等奖/省级一等奖）、时间、角色（队长/队员）。

### 3.5 社会实践

- 学生干部职务 + 任期 + 履职数据（活动数、服务人次）
- 志愿服务总时长（小时）+ 服务对象
- 三下乡/社会实践参与情况
- 实习经历（单位/岗位/时长/产出）

### 3.6 字段优先级与追问话术

**P0 必采**（缺则无法撰写）：name、major、grade、gpa、rank、core_courses、honors、competitions
**P1 重要**（缺则影响质量）：political_status、cet6、research、volunteer_hours
**P2 可选**（缺则用占位）：student_id、phone、internship

追问话术示例：
- 用户说"我参加过竞赛"→ "竞赛全称？奖项级别？时间？你是队长还是队员？"
- 用户说"我发表过论文"→ "题目？期刊名？期刊级别（SCI/EI/核心）？你是第几作者？"
- 用户说"我担任过学生干部"→ "职务？任期？主要组织了什么活动？服务多少人？"
- 用户说"我成绩不错"→ "GPA 是多少？加权平均分？专业排名（X/N）？"

**复述确认**：所有信息采完后，按"学业/荣誉/科研/实践"顺序复述给用户确认，再进入撰写阶段。

## 四、书信体结构详解

国奖申请书是书信体（非表格），整体结构：

```
标题：国家奖学金申请书（黑体二号居中）

称呼：尊敬的学院领导、评审委员会：（顶格，全角冒号）

开头（100~150 字）：
  身份 + 申报奖项 + 核心数据 3 项 + 进入正文

一、思想方面（200~300 字）
  政治立场 + 入团/团情况 + 思想觉悟 + 具体活动

二、学习方面（300~400 字，重点）
  GPA + 排名 + 主干课程表 + 英语计算机等级 + 学习方法 1 句

三、科研与实践方面（300~500 字）
  大创/论文/竞赛 + 学生工作 + 志愿服务

四、生活方面（150~250 字）
  生活作风 + 人际关系（国奖不写家庭困难）

结尾（80~150 字）：
  事实总结 + 朴素表态 + "此致/敬礼！"

落款（右对齐）：
  申请人：XXX
  XXXX 年 XX 月 XX 日
```

### 4.1 标题

格式：黑体二号，居中，段前段后 12pt。

文本：固定为"国家奖学金申请书"（7 字），不要写"2025 年度国家奖学金申请书"——标题简洁有力，与学校模板保持一致。

### 4.2 称呼

格式：顶格（首行不缩进），宋体小四，加冒号。

文本：固定为"尊敬的学院领导、评审委员会："。冒号用全角"："（非半角":"）。

部分学校要求"尊敬的评审委员会："或"尊敬的学院领导："——按学校下发模板调整。

### 4.3 开头段落

字数：100~150 字，1 段。

句式 3 句结构：
1. 身份 + 申报奖项："我是 XX 学院 XX 专业 2022 级学生 XXX，特申请 2024-2025 学年国家奖学金。"
2. 核心数据 3 项："本学年 GPA X.XX/4.0，专业排名第 X/N；获 XXX 奖项；担任 XXX 职务。"
3. 进入正文："现将本人情况汇报如下："

禁止：抒情开头（时光荏苒/岁月如梭/感慨万千）、感谢老师培养、回顾大学时光。

### 4.4 思想方面

字数：200~300 字，1~2 段。

要素 4 项（必须真实，党支部会向辅导员核实）：
- 政治立场：拥护党的领导、学习习近平新时代中国特色社会主义思想
- 入团/团情况：入团时间、优秀团员/积极分子培养阶段
- 思想觉悟：党课学习次数、理论学习、时政关注
- 具体活动：主题党日、志愿服务、阶段汇报篇数

句式："作为一名中共党员/共青团员，我始终坚持……，积极参加……"

### 4.5 学习方面

字数：300~400 字，2~3 段。**全篇重点**，评审权重 40%。

要素 5 项：
1. GPA 表达："本学年 GPA 3.92/4.0，加权平均分 92.5，专业排名第 1/87"
2. 主干课程表（5~8 门，表格呈现，含课程名/学分/成绩）
3. 主干课程亮点描述："高等数学 95、数据结构 92、操作系统 94，专业核心课平均 93 分"
4. 英语等级："CET-4 568 分、CET-6 542 分，能熟练阅读英文文献"
5. 计算机等级："计算机二级 C 语言、三级数据库技术"
6. 学习方法（1~2 句，不要长篇）："注重课前预习与课后总结，建立知识体系"

禁止：形容词堆砌、不写具体数据、写"成绩优异"。

### 4.6 科研与实践方面

字数：300~500 字，2~3 段。评审权重 30%+20%。

要素 4 类：

**大创/科研立项**：项目名称、级别、角色、时间、产出（必须含数据）。例："主持国家级大创项目《XXX》（2024.03-2025.03），负责整体方案设计，发表中文核心论文 1 篇"。

**论文**（含期刊级别、作者排序）：题目、期刊、级别、作者排序、时间。例："以第一作者在《计算机应用》（中文核心）发表论文《XXX》，2025.03 见刊"。

**学科竞赛**：竞赛全称、奖项、时间、角色。例："2025.05 全国大学生数学建模竞赛 国家二等奖（队长），建模与论文主笔"。

**学生工作 + 志愿服务**：职务 + 任期 + 履职数据。例："担任学院学生会主席（2024.09-2025.06），组织大型活动 8 场，累计参与 2000+ 人次；志愿服务时长 120 小时"。

### 4.7 生活方面

字数：150~250 字，1 段。

要素 3 项：
- 生活作风（勤俭、规律、自律）
- 人际关系（团结同学、乐于助人，举 1 个具体例子）
- 经济情况（国奖**不写家庭困难**，励志类才写）

句式："生活中我注重勤俭节约，作息规律。担任宿舍长期间，组织宿舍 6 次集体活动，宿舍连续两学期获评'文明宿舍'。与同学相处融洽，曾帮助室友完成 1 次重要实验调试。"

### 4.8 结尾

字数：80~150 字，1 段。

结构 3 部分：
1. 事实总结："以上是我本学年的基本情况。"
2. 朴素表态："无论结果如何，我都将以此为新的起点，继续努力学习、全面发展。"
3. 礼貌收尾："恳请评审委员会予以考虑。"
4. "此致"另起一行，空两格
5. "敬礼！"另起一行，顶格

禁止："完全符合""恳请领导批准""倍感荣幸"等绝对化/乞求/抒情词。

### 4.9 落款

格式：右对齐，宋体小四。

文本：
```
                                              申请人：张明
                                              2025 年 6 月 15 日
```

日期格式与全文统一（全用阿拉伯数字或全用中文大写，二选一）。落款与正文之间空 1~2 行。

## 五、各段落撰写规范

### 5.1 字数配比

| 段落 | 字数区间 | 占比 |
|------|----------|------|
| 开头 | 100~150 | 8% |
| 思想方面 | 200~300 | 14% |
| 学习方面 | 300~400 | 22% |
| 科研与实践 | 300~500 | 27% |
| 生活方面 | 150~250 | 12% |
| 结尾 | 80~150 | 7% |
| 合计 | 1200~2000 | 100% |

学习方面 + 科研实践方面合计应占总字数 50% 以上（评审重点）。

### 5.2 句式规范

**事实句**（核心）："主语 + 动词 + 数据 + 时间/范围"
- ✅ "本学年 GPA 3.92/4.0，专业排名第 1/87"
- ✅ "2025.05 全国大学生数学建模竞赛国家二等奖"

**禁止抒情句**：
- ❌ "时光荏苒，岁月如梭"
- ❌ "怀着激动的心情"
- ❌ "感慨万千"

**禁止评价句**：
- ❌ "我学习成绩优异"
- ❌ "我科研能力突出"
- ❌ "我热心公益"

**慎用副词**：
- 禁用：特别/非常/极其/深感/深切/深刻
- 可用：曾/已/将/在/于（事实描述）

### 5.3 事实+数据原则

每段必须含 3 个以上可验证事实或数据：
- 思想方面：党课 X 次、阶段汇报 X 篇、志愿活动 X 次
- 学习方面：GPA X.XX、排名 X/N、主干课程 X 门 90+、CET-6 X 分
- 科研方面：论文 X 篇（含级别与作者排序）、竞赛 X 项（含级别与角色）、大创 X 项
- 生活方面：宿舍评比 X 次、集体活动 X 次、奖学金覆盖学费 X%

无数据则不写——评审查不到证据等于没写。

### 5.4 段落衔接

段落之间用"在……方面""此外""同时"等过渡词，不要用"如下所示""现汇报如下""具体情况如下"等指代。

✅ "在思想方面，我……"
✅ "学习上，我……"
✅ "在科研与社会实践方面，我……"

❌ "现将学习情况汇报如下："
❌ "具体情况如下："
❌ "如下表所示："

### 5.5 时态与时间表达

- 过去事实用"已完成""已发表""已获得"
- 持续状态用"担任""参与"
- 时间格式统一为"YYYY.MM"或"YYYY 年 MM 月"
- 时间倒序排列（最近的在前）

### 5.6 段落字数自检

撰写完成后用以下脚本核对各段字数：

```python
import re
text = open('output.txt').read()
sections = {
    '开头': extract(text, '申请书', '一、思想'),
    '思想': extract(text, '一、思想', '二、学习'),
    '学习': extract(text, '二、学习', '三、科研'),
    '科研实践': extract(text, '三、科研', '四、生活'),
    '生活': extract(text, '四、生活', '此致'),
    '结尾': extract(text, '此致', '申请人'),
}
limits = {
    '开头': (100, 150), '思想': (200, 300), '学习': (300, 400),
    '科研实践': (300, 500), '生活': (150, 250), '结尾': (80, 150),
}
for name, content in sections.items():
    n = len(re.sub(r'[\s\W]', '', content))
    lo, hi = limits[name]
    status = '✅' if lo <= n <= hi else '❌'
    print(f'{status} {name}: {n} 字（{lo}~{hi}）')
```

### 5.7 高频词禁用清单

撰写完成后全文检索以下词汇，命中即修改：

- 抒情类：时光荏苒/岁月如梭/感慨万千/怀着激动/倍感荣幸
- 评价类：优异/突出/积极/热心/认真/刻苦/努力/深感/深切/深刻
- 程度类：特别/非常/极其/十分/格外
- 乞求类：恳请领导批准/恳请批准/无论如何/完全符合
- 模糊类：若干/一定/相关/多次/部分/有些

### 5.8 段落首句规范

每段第一句必须是事实陈述句，不要用"在……方面，我……"以外的句式开头：

✅ "本学年 GPA 3.92/4.0，专业排名第 1/87。"
✅ "在思想方面，我作为一名中共党员……"
✅ "科研上，我主持国家级大创项目 1 项……"

❌ "首先，我要感谢学校培养……"
❌ "说起大学三年，我有很多话想说……"
❌ "众所周知，国家奖学金是……"

## 六、学习方面撰写方法

学习方面是国奖评审的"硬指标段"（权重 40%），撰写 3 要素：

### 6.1 GPA 表达

**必须 3 项齐全**：GPA 绝对值 + 加权平均分 + 专业排名。

✅ 标准表达：
> 本学年 GPA 3.92/4.0，加权平均分 92.5，专业排名第 1/87（前 1.1%）

❌ 错误表达：
> 学习成绩优异，名列前茅
> GPA 3.9（缺排名）
> 排名专业第一（缺基数 1/N）

**GPA 制度差异处理**：
- 4.0 制：写"3.92/4.0"
- 5.0 制：写"4.85/5.0"
- 百分制：写"加权平均分 92.5"

学校使用何种制度，按成绩单原始数据填写，不要换算。

### 6.2 主干课程展示

**选课原则**：5~8 门，专业核心课优先，分数 90+，含 1~2 门基础课（如高等数学）。

**表格格式**（必须用表格）：

| 课程名称 | 学分 | 成绩 |
|----------|------|------|
| 高等数学（上） | 5 | 95 |
| 数据结构 | 4 | 92 |
| 操作系统 | 4 | 94 |
| 计算机网络 | 3 | 91 |
| 数据库原理 | 3 | 93 |

**描述句式**：表格后用 1~2 句话概括
✅ "高等数学 95、数据结构 92、操作系统 94，专业核心课平均 93 分，全部 90+。"

❌ "主干课程成绩如下表所示："（指代）
❌ "成绩优异，多门课程 90+。"（无数据）

### 6.3 英语计算机等级

**英语**（按等级递进写）：
- CET-4：✅ "CET-4 568 分（2023.06）"
- CET-6：✅ "CET-6 542 分（2024.06）"
- TOEFL/IELTS：✅ "TOEFL 105 分（2024.10）"
- 无证书：不写，或写"具备良好英文文献阅读能力，能独立完成英文论文撰写"

**计算机**：
- 二级：✅ "计算机二级 C 语言（优秀）"
- 三级：✅ "计算机三级数据库技术"
- 四级：✅ "计算机四级网络工程师"

**禁用**：
- ❌ "英语水平良好"（无数据）
- ❌ "计算机能力较强"（无证书）

### 6.4 学习方法（1~2 句）

学习方面末尾用 1~2 句话讲学习方法，**不要长篇大论**（评审看数据不看说教）：

✅ "学习上注重课前预习与课后总结，建立知识体系；遇到问题主动与老师、同学讨论。"

❌ "我学习刻苦努力，每天早起晚睡，泡在图书馆，是我大学生活的真实写照。"

### 6.5 完整示例（学习方面 350 字）

> 二、学习方面
>
> 本学年 GPA 3.92/4.0，加权平均分 92.5，专业排名第 1/87（前 1.1%）。修读 12 门课程，9 门 90 分以上。主干课程成绩如下：
>
> | 课程名称 | 学分 | 成绩 |
> |----------|------|------|
> | 高等数学（上） | 5 | 95 |
> | 数据结构 | 4 | 92 |
> | 操作系统 | 4 | 94 |
> | 计算机网络 | 3 | 91 |
> | 数据库原理 | 3 | 93 |
>
> 高等数学 95、数据结构 92、操作系统 94，专业核心课平均 93 分，全部 90+。CET-4 568 分（2023.06）、CET-6 542 分（2024.06），能熟练阅读英文文献；计算机二级 C 语言（优秀）、三级数据库技术。学习上注重课前预习与课后总结，建立知识体系。

### 6.6 GPA 制度差异处理

不同学校成绩单格式不同，处理规则：
- 4.0 制（多数 985/211）：直接写"3.92/4.0"
- 5.0 制（部分高校）：直接写"4.85/5.0"，不要换算成 4.0 制
- 百分制（部分老牌院校）：写"加权平均分 92.5"，并备注"百分制"
- 排名一定要写基数："1/87"而非"专业第一"

转专业学生：按现专业排名填写，注明"原 XX 专业转入，排名按现专业计算"。

辅修学位：单独写"辅修 XX 专业 GPA X.XX"，不计入主修 GPA。

## 七、科研实践方面撰写方法

科研实践方面权重 30%+20%（科研 30% + 综合素质 20%），撰写 4 类内容：

### 7.1 大创/科研立项

**4 要素**：项目名称 + 级别 + 角色 + 时间 + 产出（含数据）。

✅ 标准表达：
> 主持国家级大创项目《分布式光伏故障智能诊断系统》（2024.03-2025.03），负责整体方案设计与 CNN 模型实现，发表中文核心论文 1 篇，申请发明专利 1 项，项目结题评估优秀。

❌ 错误表达：
> 参与国家级大创项目，担任负责人，取得一定成果。
> （无项目名、无时间、无产出数据）

**角色表述**：
- 主持人/负责人：写"主持""担任负责人"
- 参与：写"作为第二完成人参与""作为核心成员参与"
- 不要写"积极参与"（"积极"是评价，不是事实）

### 7.2 论文

**5 要素**：题目 + 期刊 + 级别 + 作者排序 + 时间。

期刊级别必须写明：
- SCI：写"SCI 二区"或"SCI 三区"
- EI：写"EI 收录"
- 中文核心：写"中文核心（北大核心）"或"CSSCI"
- 普刊：写"省级期刊"或"国家级期刊"
- 会议：写"CCF-A 类会议"或"国际会议"

✅ 标准表达：
> 以第一作者在《计算机应用》（中文核心）发表论文《基于对比学习的法律问答系统》，2025.03 见刊；以第二作者在 EMNLP 2024（CCF-B 类会议）发表论文 1 篇。

❌ 错误表达：
> 发表论文 2 篇。（无题目、无期刊、无作者排序）
> 在核心期刊发表论文。（无具体题目与期刊名）

**作者排序必须真实**：第一作者/第二作者/通讯作者，不能写"主要作者"。

### 7.3 学科竞赛

**4 要素**：竞赛全称 + 奖项级别 + 时间 + 角色。

奖项级别必须写完整：
- 国家级：国家特等奖/一等奖/二等奖
- 省级：省级特等奖/一等奖/二等奖
- 校级：校级一等奖

✅ 标准表达：
> 2025.05 全国大学生数学建模竞赛 国家二等奖（队长），负责整体建模与论文主笔；
> 2024.11 中国大学生计算机设计大赛 省级一等奖（核心成员），负责前端开发。

❌ 错误表达：
> 多次获得国家级、省级竞赛奖项。（无具体竞赛名）
> 数学建模竞赛获奖。（无级别）

**竞赛名称必须用全称**：
- ✅ "全国大学生数学建模竞赛"（CUMCM）
- ✅ "中国大学生计算机设计大赛"（4C）
- ❌ "数模竞赛"（简称）
- ❌ "计设大赛"（简称）

### 7.4 学生工作与志愿服务

**学生干部**（职务 + 任期 + 履职数据）：

✅ 标准表达：
> 担任学院学生会主席（2024.09-2025.06），主要工作：组织学院迎新晚会、运动会等大型活动 8 场，累计参与 2000+ 人次；牵头建立学院学生服务平台，覆盖学习辅导、心理咨询、就业指导 3 大模块；推动学院学生会获评 2024 年度"校级优秀学生组织"。

❌ 错误表达：
> 大二至大三担任学院学生会主席，工作认真负责，深受同学好评。

**志愿服务**（时长 + 服务对象 + 频次）：

✅ 标准表达：
> 累计志愿服务时长 120 小时：参与三下乡 2 次（2024.07、2025.07），累计支教 16 课时；担任图书馆管理员（2024.09-2025.06，每月 8 小时）；组织班级"一对一"帮扶活动，服务同学 30 余人次。

❌ 错误表达：
> 热心公益，乐于助人，多次参与志愿服务。

### 7.5 量化表达总则

科研实践方面每个事实必须有量化指标：
- 项目：级别 + 时间 + 产出（论文 X 篇/专利 X 项/系统 X 套）
- 论文：期刊级别 + 作者排序 + 时间
- 竞赛：奖项级别 + 角色 + 时间
- 学生工作：职务 + 任期 + 活动数 + 服务人次
- 志愿服务：总时长 + 服务对象 + 频次

无量化 = 无效信息。

### 7.6 完整示例（科研实践方面 450 字）

> 三、科研与实践方面
>
> 主持国家级大创项目《分布式光伏故障智能诊断系统》（2024.03-2025.03），负责整体方案设计与 CNN 模型实现，发表中文核心论文 1 篇，申请发明专利 1 项，项目结题评估优秀。以第一作者在《计算机应用》（中文核心）发表论文《基于对比学习的法律问答系统》，2025.03 见刊；以第二作者在 EMNLP 2024（CCF-B 类会议）发表论文 1 篇。
>
> 学科竞赛方面，2025.05 全国大学生数学建模竞赛 国家二等奖（队长），负责整体建模与论文主笔；2024.11 中国大学生计算机设计大赛 省级一等奖（核心成员），负责前端开发；2024.05 全国大学生英语竞赛 三等奖。
>
> 担任学院学生会主席（2024.09-2025.06），主要工作：组织学院迎新晚会、运动会等大型活动 8 场，累计参与 2000+ 人次；牵头建立学院学生服务平台，覆盖学习辅导、心理咨询、就业指导 3 大模块；推动学院学生会获评 2024 年度"校级优秀学生组织"。累计志愿服务时长 120 小时，参与三下乡 2 次，累计支教 16 课时。

### 7.7 边界情况处理

**论文在投/审稿中**：
- 已投未录用：写"已投 XX 期刊（SCI 二区），审稿中"，不写"录用"
- 录用未发表：写"已录用，2025.06 见刊"
- 不要把"投稿"说成"发表"

**大创未结题**：
- 进行中：写"在研，预期结题时间 2025.06"
- 已结题：写"结题评估优秀/良好/合格"

**竞赛参与未获奖**：
- 不写"参与但未获奖"
- 可写"进入决赛（X 支队伍中第 X 名）"，前提是进入决赛本身有含金量

**志愿服务短时频次高**：
- 总时长 ≥50 小时再写，<50 小时不必单独成段
- 写法："志愿服务时长 80 小时，主要服务对象为社区老年人"

### 7.8 学生干部履职数据量化维度

学生干部履职表述必须含至少 2 个量化维度：

| 维度 | 量化指标 | 示例 |
|------|----------|------|
| 活动数 | 组织活动 X 场 | 组织大型活动 8 场 |
| 参与人次 | 累计参与 X 人次 | 累计参与 2000+ 人次 |
| 项目产出 | 建立 X 个平台/制度 | 建立学生服务平台 |
| 荣誉 | 获评 X 称号 | 获评"校级优秀学生组织" |
| 任期 | 任期 X 个月 | 2024.09-2025.06（10 个月） |

仅写"工作认真负责"=无效信息。

## 八、评审标准与打分维度

国奖评审 4 维度（参考教育部《国家奖学金评审办法》与多所高校实施细则）：

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 学业 | 40% | GPA 排名、主干课程、英语计算机等级 |
| 科研 | 30% | 论文（含期刊级别、作者排序）、大创、专利、竞赛 |
| 综合素质 | 20% | 学生工作、志愿服务、社会实践、文体特长 |
| 思想 | 10% | 政治面貌、入团情况、阶段汇报、党团活动 |

### 8.1 学业 40% 评分细则

- 排名 1-2/N：满分
- 排名 3-5/N：扣 5 分
- 排名 6-10/N：扣 15 分（基本无望）
- 排名 >10/N：直接淘汰
- 主干课程 90+ 占比 ≥80%：满分
- CET-6 ≥425：基础分；≥550：加分
- 计算机三级及以上：加分

### 8.2 科研 30% 评分细则

- SCI 一区论文（第一作者）：满分
- SCI 二/三区论文（第一作者）：90 分
- EI/中文核心论文（第一作者）：80 分
- 中文核心论文（第二作者）：60 分
- 国家级竞赛一等奖（队长）：满分
- 国家级竞赛二等奖（队长）：85 分
- 国家级竞赛三等奖/省级一等奖：70 分
- 国家级大创（负责人，结题优秀）：85 分
- 省级大创（负责人，结题优秀）：65 分

### 8.3 综合素质 20% 评分细则

- 校级学生组织主席 + 评优：满分
- 校级学生组织副主席/部长：80 分
- 班长/团支书 + 评优：85 分
- 志愿服务 ≥100 小时：满分
- 志愿服务 50~100 小时：80 分
- 三下乡参与 ≥2 次：加分
- 文体特长（校级以上奖项）：加分

### 8.4 思想 10% 评分细则

- 中共党员：满分
- 优秀团员/积极分子（培养 1 年+）：85 分
- 共青团员 + 优秀团员：75 分
- 共青团员：60 分
- 阶段汇报 ≥4 篇/年：加分

### 8.5 评分计算示例

> 张明：学业 95 分×40% + 科研 90 分×30% + 综合素质 85 分×20% + 思想 95 分×10%
> = 38 + 27 + 17 + 9.5 = 91.5 分

**提分策略**：
- 学业已达上限（排名前 1）→ 重点提科研（论文+竞赛）
- 科研已达上限 → 重点提综合素质（学生工作+志愿服务）
- 思想分普遍不高 → 入团是关键加分项

### 8.6 一票否决项

- 本学年有挂科
- 本学年有违纪处分
- GPA 排名 >5%
- 材料造假（GPA/排名/论文/竞赛）
- 抄袭他人申请书

任一项触发 → 直接淘汰，不再评审。

### 12.1 字数自动检查

撰写完成后用以下脚本核对各段字数：

```python
import re
text = open('output.txt').read()
def extract(text, start, end):
    s = text.find(start); e = text.find(end)
    return text[s:e] if s >= 0 and e > s else ''
sections = {
    '开头': extract(text, '申请书', '一、思想'),
    '思想': extract(text, '一、思想', '二、学习'),
    '学习': extract(text, '二、学习', '三、科研'),
    '科研': extract(text, '三、科研', '四、生活'),
    '生活': extract(text, '四、生活', '此致'),
    '结尾': extract(text, '此致', '申请人'),
}
limits = {
    '开头': (100, 150), '思想': (200, 300), '学习': (300, 400),
    '科研': (300, 500), '生活': (150, 250), '结尾': (80, 150),
}
for name, content in sections.items():
    n = len(re.sub(r'[\s\W]', '', content))
    lo, hi = limits[name]
    status = '✅' if lo <= n <= hi else '❌'
    print(f'{status} {name}: {n} 字（{lo}~{hi}）')
```

## 十三、学校差异处理

不同学校国奖申请书模板有微调：

**字数差异**：多数学校要求 1200~2000 字，少数要求 1500~2500 字。按学校要求调整字数区间。

**称呼差异**：默认"尊敬的学院领导、评审委员会："，部分学校改为"尊敬的评审委员会："或"尊敬的学院领导："。

**栏目顺序**：极少数学校把"生活方面"前移到"思想方面"后。按学校模板调整 build.py 调用顺序。

**主干课程呈现**：表格（推荐，本 skill 默认）或文字（"高等数学 95、数据结构 92……"）。

**字体差异**：少数学校要求"仿宋 GB2312"正文或"楷体"标题。修改 build.py 的 FONT_SONG/FONT_HEI 常量。

**附加栏目**：部分学校要求附"成绩单""获奖证书复印件""论文录用通知"。提醒用户在 docx 后附纸质材料。

适配流程：先问"学校下发的国奖申请书模板有特殊要求吗？"→ 若有则按学校模板调整 → 若无按本 skill 默认处理。

本 skill 执行流程：触发 → 核对硬门槛 → 信息采集 → 书信体撰写 → 调 build.py 生成 docx → 25 项质检 → 提交。
